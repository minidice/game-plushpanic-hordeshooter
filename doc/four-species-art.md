# 거위·오리·호랑이·코뿔소 병렬 개선 (2026-10-26)

상태: 네 종 제작·게임/Studio 연결·자동 플레이/실제 렌더 검수 완료. 사용자가 다른 LLM의 로컬 작업과 분리해 네 종을 병렬 개선하도록 요청했다. de43ab9 기준의 별도 worktree와 `codex/four-species-art` 브랜치에 통합했다. 초기 제작에서는 원래 폴더의 미커밋 사격 변경을 분리했다. 이후 사용자 요청으로 최신 main의 완료된 사격 변경3c4f8e6을 합쳐 main 반영용 검수를 완료했다. 최종 사용자 미술 수락은 별개다.

기존 확정 아트 기준을 적용한다. 거위는 긴 세로 윤곽/상대적으로 좁은 부리, 오리는 짧고 넓은 몸/납작한 부리로 구별한다. 호랑이는 얼굴·몸의 큰 무늬와 주둥이, 코뿔소는 뿔·큰 턱·무거운 몸의 연결을 중심으로 다듬는다. 실제 비례·조형값은 제작 시안이며 최종 사용자 수락과 구분한다.

종별 모델/생성기/검사는 분리하고 공통 런타임·Studio·문서는 통합 담당자가 합쳤다. 기존 커스터마이징·종족/전투 수치·무리 팔레트·네트워크 계약·일반 몬스터 투구/눈 장구류 제외를 유지한다.

## 검증 범위와 증거

종별 격리 제작에서 Blender 동일 카메라 실루엣/단색/최종색/장비 전후 비교와 독립 GLB 재가져오기를 실행했다. 원본과 선택하지 않은 종의 불변 확인은 각 단일 종 제작 시점의 검사이며, 통합 뒤 다른 개선 종도 이전 해시여야 한다는 뜻은 아니다.

실제 창 모드 검사는 Stage 2 자동 입력/물리 시뮬레이션이다. 거위61·오리59 검사로 이동·사격·기본/장비 확대를 확인했다. 호랑이와 코뿔소는 추격·몽둥이/칼 타격·활 발사/중단 및 게임 거리/정면 확대를 확인했다(통합 호랑이42·코뿔소42). 손으로 전구간을 완주하거나 전체 조합을 수동 검수했다는 뜻은 아니다.

네 종의 Studio 기본형/장비형과 실제 Stage 2 화면을 열어 확인했다. 기존 거위의 세로 실루엣과 오리의 넓은 부리 차이는 유지된다. 코뿔소의 Studio 무장+조끼에서도 팔/손이 몸 배색을 따르는 것을 확인했다. 기본형 조류의 키와 넓은 날개 파지는 원래 몸 마스크/변형 계약을 보존한 결과다.

산출물은 무시되는 로컬 경로에 있다:

- `game/output/four-species-art/`: 통합 빌드/검사 로그.
- `game/output/{goose,duck}-clean/`, `game/output/hunter-combat-{tiger,rhino}-stage2-*.png`: 실제 게임 화면.
- `studio/output/{goose-clean,duck-clean,rhino-clean,roster}/`: 실제900px 렌더.
- `prototypes/common-monsters/output/{rhino-clean-forms,tiger-clean-final-review}/`: 통합 폴더에서 생성한 Blender 렌더. 조류 및 호랑이 수정 전 비교는 각 제작 worktree의 output에 보존했다.

원래 다른 LLM의 작업 디렉터리와 Studio4317/4323은 사용하지 않았다. 검사용 Studio4331~4334와 프로젝트별 임시 이름으로 `user://`를 분리했고, 검수 뒤 설정을 복원하고 자체 서버/렌더러를 종료했다.

## 검토에서 수정한 부분

- 거위의 초기 발은 옆에서 겹친 판처럼 보였다. 닫힌 단일 연결 물갈퀴/발목으로 교체하고 연결성·법선·밑면·두 색 채널을 검사했다. 교차 렌더 검토에서 수정 확인.
- 코뿔소 손이 두꺼운 형상 검사 실패는 모델을 얕게 수정했다. Studio 원거리 검사 실패는 허용 최소 zoom0.75보다 작은0.65 요청이 원인이어서 요청만 보정했다.
- 통합 시 공통 그립/생성기/검사에 호랑이와 코뿔소를 모두 보존하고 결정/이슈 문서의 종별 이력을 합쳤다.
- 최종 독립 검토에서 거위 검증기와 공통 렌더 도구가 ignored baseline을 필수로 읽는 문제를 발견했다. 새 체크아웃에서 모델 자체 검증/현재 모델 렌더는 바로 실행하고, 제작 전 해시 비교만 명시적 선택으로 분리했다. 호랑이 검증기의 Blender 시작 큐브도 제거해 감사 대상이 GLB만 되도록 했다.
- 최종 독립 재검토에서 위 재현성 수정과 조류 얼굴 가림 수정에 추가 차단 결함이 없었다. 변경 문서의 상대 링크496개와 충돌 마커/차이 공백을 확인했다. GLB 변경은 요청한 네 종뿐이다.
- 실제 조류 사격 직후 확대에서 눈이 사라지는 문제를 추가 발견했다. 원인은 별도 얼굴 피벗이 최대140mm 이동하면서 연속 몸통 안으로 들어가는 것이다. 부리가 보이는 정면이었으므로 초기 오리 문서의 뒤쪽 카메라 해석도 정정했다. 두 조류만 기존 HeadSpringScale을0.05로 줄였고, 기본 진폭에서 눈 가림 실패 → 수정 뒤1,800개 통과 및 같은 Stage2 사격/확대 재렌더로 확인했다. 몸통/얼굴 마스크와 물리 수치는 변경하지 않았다.
- 최종 검사 로그의 Godot 오류/종료 경고는 없었다. Blender API 폐기 예정 경고는 모델 성공과 구분한다. 이 브랜치에 없는 다른 LLM의 사격 수정이나 기존 전체 통합 사격 실패를 해결했다고 주장하지 않는다.

## 2026-10-26 최신 main 통합 검수

사용자가 원래 main 작업 완료 후 이번 변경의 커밋·병합·원격 main 푸시를 요청했다. fetch한 origin/main과 원래 main은3c4f8e6으로 일치했고, 원래 폴더는 추적 파일 변경 없이 개인 첨부 폴더만 미추적이었다. 첨부는 포함하지 않는다. 기존 네 종 브랜치0c71e31에 최신 main을 합쳐 검수한 결과를 원래 main으로 이동한다.

- 코드/에셋 충돌 없음. feature-checklist의 추가 기록 충돌은 모델/치명타 기록 모두 보존했다. 네 종 GLB 해시는 기존 검수본과 동일하다.
- main에서 추가된 집중 치명타의 C-31이 기존 일반몹 C-31과 중복되어, 새로운 치명타 항목만 미사용 C-32로 정정했다. 해당 규격/기록/코드 주석도 함께 수정하고 두 결정의 내용은 그대로 유지했다.
- Debug/ExportRelease 오류0·경고0, Godot import 성공. Integration149, WeaponAimCheck32, NetSyncCheck32(localhost), BirdFaceVisibility1,800, GroundedArt212, 호랑이 손4,464·코뿔소 손4,200, 일반몹264 통과.
- 병합본 실제 Stage2 창에서 거위61·오리59 이동/사격/기본·장비 렌더 재확인. 기존 다른 종 Blender/Studio 증거는 동일 에셋의 앞선 검수 결과를 유지한다. 최종 Godot 검사 로그 오류/종료 경고 없음.
- 독립 병합 검토에서 최신 main 코드와 네 종 에셋 보존을 확인했다. 위 ID 중복만 수정했다. 다른 LLM의 전투 변경을 되돌리거나 중복 구현하지 않았다.
- 로그는 `game/output/four-species-main-merge/`, 실제 화면은 기존 `game/output/{goose,duck}-clean/`에 저장했다. 검사 전용 user:// 이름은 원복했다. 전체 수동 완주/실제2PC/장시간 성능의 앞선 미검증 범위는 유지한다. 원격 반영 커밋은 Git의 main/origin/main 이력으로 확인한다.

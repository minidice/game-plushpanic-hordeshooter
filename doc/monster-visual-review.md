# 몬스터 외형·사망 연출 점검 — 2026-10-23

상태: **최초 점검 당시 기록**. 후속 사용자 승인으로 표면·접지·체형별 사망 수정이 적용됐으며 현재 상태는 [개선 기록](monster-visual-improvements.md)을 따른다. 사용자 요청에 따라 네임드·보스 사망 모습과 체형·표면 품질을 확인했다. 이번 변경은 재현용 장면·읽기 전용 분석 도구·기록뿐이며 게임 동작, GLB, 전투 데이터는 변경하지 않았다. 앞선 플레이어 아트 통합 작업은 그대로 보존했다. 아래 개선안은 추천이며 새 아트 방향이나 래그돌 도입 확정이 아니다.

## 확인 범위와 조건

- 기존 `MonsterLineupCapture`: 일반/특수 적 줄 세우기, 보스 4종 정측면, 근접 렌더 11장.
- 새 `MonsterReviewCapture`: 네임드 6종(`bull`, `balloon`, `tether`, `leaper`, `spitter`, `armed_veteran`)과 보스 4종을 실제 `Stage.Spawn`/`Enemy.Die` 경로로 촬영. 풍선은 실제 `Pop` 재정의 경로를 탄다. 종당 생존·측면·사망 직후·넘어짐·착지 부근·정지·낮은 시점 7장, 총 70장.
- 게임용 모델 크기 그대로, 평지·고정 조명·동일 직교 카메라(크기 7.5)·HUD 숨김. 일반 게임보다 가까운 점검 시점이다. 장면 간 네임드 기록과 시체를 제거하고 이전 바닥 페인트는 숨긴다. 사망 순간 생성되는 페인트·섬광은 유지.
- 1/11/15/24 physics frame 간격으로 촬영하며 렌더 대기가 추가된다. 파일명 `fall`/`land`는 비교용 구간 이름이고 정확한 초 단위 키프레임이나 실제 접촉 이벤트를 의미하지 않는다. `rest`는 공용 0.67초 연출 종료 이후.
- 생존 상태의 공격·점프를 멈춘 통제 장면이다. 공격 도중 사망, 경사·계단, 실제 멀티·장시간 성능은 이번에 확인하지 않았다.

## 1. 사망 자세 — I-83 / I-69, 미해결

**크게 두 문제가 겹친다: 지면에서 뜨고, 서로 다른 체형이 같은 방식으로 넘어간다.**

`Effects.SpawnCorpse`는 네임드/보스의 강체를 먼저 고정된 누운 위치로 옮기고, `Topple`이 외형만 0.45초 동안 뒤로 90도 회전시킨 뒤 0.22초 반동을 준다. `CharacterRig.ApplyDeathPose`는 공통 머리 기울임, 발 벌림, 팔 회전을 즉시 적용한다. 큰 배/머리, 사족형 황소, 직립형 황소 두목 모두 같은 전환이다. 마지막에도 주먹·발이 위로 향하고 큰 몸통이 단단한 덩어리처럼 남는다.

**접지 계산 원인 확인:** `RestingMeshBottom`은 메시의 실제 표면 대신 로컬 AABB 8개 꼭짓점을 회전한 값으로 최저 높이를 구한다. 몸 밖의 빈 상자 모서리가 바닥에 닿도록 전체 모델을 들어 올려, 실제 표면이 뜬다. 모델이 이미 지면을 뚫지 않으므로 기존 `MinimumMeshY >= -.02` 검사는 통과한다. 바닥에 닿는지에 대한 상한 검사가 없다.

| 종 | 정지 상태 실제 정점 최저 Y(m) | AABB 최저 Y(m) |
|---|---:|---:|
| 황소 | 0.080 | 0.020 |
| 풍선(머리 숨김) | 0.020 | 0.020 |
| 끌개 | 0.370 | 0.020 |
| 덮치는 적 | 0.159 | 0.020 |
| 토사물 적 | 0.243 | 0.020 |
| 황소 두목 | 0.414 | 0.020 |
| 거대 황소 | 0.116 | 0.020 |
| 풍선 대왕 | 0.020 | 0.020 |
| 토사물 어미 | 0.217 | 0.020 |

평지 Y=0, 사망 방향 고정, 현재 모델/크기에 한정한 값이다. 무장 정예는 로그에 0.020이지만 총 파지 셰이더의 GPU 변형을 CPU 정점 측정이 반영하지 않으므로 위 표의 접지 근거에서 제외했다. 낮은 시점 렌더에서도 끌개·보스의 공중 간격을 확인했다.

**권장 순서**

1. 사망 최종 자세에서 실제 메시 또는 사전에 만든 접지용 대표점으로 높이 보정. 전체 정점을 매 프레임 순회하는 방식은 비용 검토 없이 제품에 넣지 않는다. 바닥 관통과 과도한 공중 간격을 함께 검사.
2. 사망 동작을 체형별로 나누기: 황소는 앞다리 꺾임→옆으로 체중 이동, 황소 두목은 주저앉음→어깨/몸통 착지, 둥근 풍선/토사물형은 찌그러짐→옆으로 기울어 정착. 기존 고정된 사망 기록·수명(T-16/T-21)은 유지 가능.
3. 머리·팔·다리의 시간차를 주고 착지 후 힘을 풀기. 일부 모델에 `*_leftLeg`, `*_rightLeg`, `bull_tail` 피벗이 이미 있으나 현재 사망 코드가 움직이지 않는다. 모든 모델에 관절이 아예 없다는 이전 I-83 설명은 현재 자산 전체에 해당하지 않는다. 최종 황소 두목 등은 필요한 피벗을 개별 확인해야 한다.
4. 공격 중 사망 시 `ResetPose`로 기본 자세가 즉시 복원되는 전환은 코드상 위험이다. 이번 정지 상태 촬영으로 그 전환의 시각적 정도까지 확인한 것은 아니다.

전체 물리 래그돌을 먼저 도입할 필요는 없다. 소수의 관절과 체형별 정해진 사망 동작으로 비교 후보를 만드는 것을 추천한다.

## 2. 거친 표면 — I-84 / I-86, 재점검에서 미해결 확인

황소 머리/등, 보스 몸통·주먹 등에서 각진 면과 틈이 보인다. **단순한 삼각형 수 부족으로만 설명할 수 없다.** 원본 GLB와 게임 GLB의 위치가 같은 정점을 합쳐 경계를 측정해 UV·노멀 분리만으로 생기는 경계를 제외했다. 아래 경계 수는 구멍 개수가 아니라 한쪽 면만 연결된 모서리 개수다. 의도적인 열린 부위도 포함될 수 있어 모든 수치를 자동 결함 수로 해석하지 않는다.

| 모델 | 게임 삼각형 | 원본 위치 결합 후 열린 경계 | 게임 위치 결합 후 열린 경계 |
|---|---:|---:|---:|
| 인간형 | 4,223 | 0 | 1,531 |
| 크롤러 | 3,787 | 0 | 1,367 |
| 끌개 | 3,881 | 0 | 1,375 |
| 덮치는 적 | 3,896 | 0 | 1,408 |
| 토사물 적 | 4,005 | 0 | 1,449 |
| 황소 | 2,644 | 0 | 924 |
| 풍선 | 2,264 | 0 | 664 |
| 황소 두목 | 4,466 | 0 | 1,558 |
| 풍선 대왕 | 3,752 | 0 | 522 |
| 토사물 어미 | 3,352 | 64 | 552 |

**원인 분리 실험:** Blender에서 동일한 황소 원본과 현재 감축 비율 0.25를 사용했다. 현재 순서는 2,644삼각형/경계 924, 감축 **전에** 중복 위치 정점을 연결한 경우 2,592삼각형/경계 0. GLB를 저장하거나 원본을 바꾸지 않은 메모리상 실험이다. `optimize_game_roster.py`가 분리된 정점을 연결하지 않고 Decimate를 수행하는 것이 황소 표면 틈의 원인임을 재현했다. 다른 종 전체의 수정본 검증은 아직 하지 않았다. 토사물 어미는 원본에도 경계가 있어 별도 형상 검토가 필요하다.

권장: 원본 연결 정리→부위별 감축→노멀/곡면 확인→예산 검사의 순서. 큰 머리·등·배의 곡면은 보호하고, 화면에서 읽히지 않는 작은 장식부터 줄인다. 재질 경계·UV·의도적 개구부를 무조건 합치거나 막으면 안 된다. 새 모델을 다시 그리기 전에 이 생성 파이프라인부터 수정하는 편이 효율적이다.

## 3. 체형·디자인 판단 — 개선 추천, 사용자 확정 아님

| 대상 | 현재 읽히는 문제 | 추천 |
|---|---|---|
| 황소 / 거대 황소 | 몸통·얼굴의 큰 둥근 덩어리, 짧게 겹치는 다리. 거대 황소는 동일 자산 1.6배여서 크기 외 차이가 적음 | 어깨와 등 높이, 앞다리 지지 자세, 뿔 방향으로 돌진 역할을 강화. 거대형은 어깨/뿔/장비 실루엣 중 한 가지를 추가 구분 |
| 황소 두목 | 큰 주먹은 잘 보이지만 머리·배·어깨의 둥근 덩어리가 겹침. 주먹·뿔 표면 각짐, 왕관이 평평한 배지처럼 읽힘 | 가슴→허리→골반 흐름, 어깨와 손의 연결을 정리. 왕관은 작은 돌기를 늘리기보다 외곽 높이로 구분 |
| 풍선 대왕 | 왕관은 식별되지만 작은 몸·팔보다 머리가 지배적. 풍선 다발이 얼굴 옆 볼 장식처럼 겹침 | 큰 풍선 머리는 유지. 다발을 얼굴에서 떼고 끈/손 연결을 읽히게, 하체 지지와 풍선 특유의 탄성으로 성격 부여 |
| 토사물 어미 | 등·후드·볼·배가 큰 공들의 조합으로 보이고 눈이 작음. 누우면 얼굴이 더 안 보임 | 물방울형 몸통의 흐름을 하나로 정리, 눈/입 대비와 위쪽 가시성 확보. 등 주머니는 실루엣을 해치지 않게 정돈 |
| 끌개 / 덮치는 적 / 토사물 적 | 둥근 머리·돌출된 눈·작은 팔다리의 공통 인상이 강함 | 혀, 웅크린 다리, 부푼 볼 등 역할별 큰 특징을 우선. 새 플레이어 아트와 함께 실제 게임 거리에서 재질·디테일 밀도 비교 |
| 무장 정예 | 기본 랫서판다 무장 외형을 재사용 | 정예 전용 헬멧/어깨/조끼 실루엣 한 곳으로 먼저 구분. 새 종 전체 제작은 필수 아님 |

현재 몬스터 가이드는 봉제 인형·과장 비율을 의도한다. 플레이어의 차분한 장비 스타일로 바꿨다고 몬스터 전체를 사실적인 해부 비율로 바꾸는 결정이 자동으로 따라오지는 않는다. 귀여운 과장은 유지하면서 표면 연결, 무게감, 역할 식별을 개선하는 것을 추천한다. 이번 통제 조명은 게임 전체 재질/후처리 평가를 대신하지 않는다.

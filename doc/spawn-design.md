# 몬스터 등장 · 반응 · 지형 설계

> **상태**: 1~4단계 구현 (2026-10-20, `SpawnCheck` 헤드리스 40개·창 모드 42개 통과). 5단계(스테이지 1 재구성)는 다음 작업입니다. 실제 플레이 체감(대기형 수·경보 웨이브 크기)은 아직 확인 전입니다.
> 결정은 `decisions.md` L-4~L-11에 기록합니다. 시나리오 레벨 규칙은 [`level-design-rules.md`](level-design-rules.md), 시간·전투 배분·아이템 배치 추천은 [`scenario-level-design.md`](scenario-level-design.md)를 봅니다. 해당 추천은 **시나리오 전용**이며 생존·서바이버에 적용하지 않습니다. 공용 몬스터 반응·생성 기능의 사용 가능 범위와 모드별 배치 정책은 구분합니다.

## 1. 원칙: 모든 등장에는 이유가 보여야 한다 (권장)

**권장 규칙이며 절대 규칙은 아닙니다.** 연출상 필요하면 예외를 둘 수 있습니다.

| 상황 | 방식 |
|---|---|
| 화면 밖 | 정해진 등장 지점(지나온 길, 앞 구역, 숨은 자리)에서 생성 |
| 화면 안 | **등장 연출이 있는 지점에서만**: 높은 곳에서 뛰어내리기, 벽 뚫기, 환풍구·맨홀, 창문, 셔터 |
| 피함 | 화면 안 빈 바닥에서 갑자기 생기기 |

- 지금 게임은 손전등 원뿔 밖의 적을 숨깁니다. 그래서 원뿔 밖이라도 **화면 안**에서 생기면, 원뿔을 돌렸을 때 그 자리에 "허공에서" 나타나 보입니다.
- 생성 지점은 다음 순서로 고릅니다.
  1. 화면 밖이면서 시야 원뿔 밖
  2. 화면 밖
  3. 시야 원뿔 밖(예전 방식, 마지막 수단)

## 2. 반응 유형

몬스터 종류가 아니라 **배치마다** 반응 유형을 정합니다. 같은 좀비라도 미리 깔린 무리는 대기형이고, 디렉터가 부른 무리는 웨이브형입니다.

| 유형 | 생기는 곳 | 달려드는 조건 | 용도 |
|---|---|---|---|
| **대기형** | 다음 구역에 미리 배치 | 아주 가까움(`wake_range_m`), 맞음, 소음 반경 안, **근처 동료가 깨면 연쇄로 깸** | 평소 진행. 조용히 지나가거나 하나씩 정리 |
| **경계형** | 안 보이는 자리(골목, 문 뒤, 다른 층) | 위 조건 + **자기 눈에 플레이어가 보이면**(시야 거리 안, 막힘 없음) | "저쪽 확인 안 하면 튀어나온다" |
| **웨이브형** | 디렉터가 화면 밖 등장 지점에 생성 | 생길 때부터 깨어 있음. 멀리서도 흐름장을 따라 몰려옴 | 큰 소리 장치, 크레센도, 시간 습격 |

### 깨우는 조건

- **맞음**: 맞은 몬스터는 깹니다. 반경 `alert_radius_m`(기본 6m) 안의 동료도 연쇄로 깹니다. 연쇄는 한 번만 퍼지게 해서 맵 전체가 한 번에 깨지 않게 합니다.
- **소리**: 반경은 데이터입니다.
  - 무기: `weapon_types.csv`의 `noise_m`. 근접 4, 권총 14, SMG 16, 소총 20, 산탄 22, 저격 26, 로켓 30, 박격포 30
  - 폭발 30, 화염병 18, 풍선 20, 큰 소리 장치 60
- **거리**: 몬스터별 `wake_range_m`.
- **시야**: 경계형만. 플레이어가 `sight_range_m`(기본 14m) 안에 있고 사이에 벽이 없으면 깹니다.
- 예전에는 "플레이어 시야에 들어온 12m 안의 적"이 모두 깼습니다. 이제 이 규칙은 경계형만의 규칙입니다. 대기형은 쳐다보기만 해서는 달려들지 않습니다.

## 3. 등장 경로

| 경로 | 설명 |
|---|---|
| **미리 배치** | 플레이어가 구역 N에 들어가면 **구역 N+1**을 채움. 처음엔 시작 구역과 다음 구역만 |
| **지나온 길** | 화면 밖, 플레이어 뒤로 걸어온 길(분대원 따라잡기와 같은 기록) 15m 이상 지점 |
| **앞 구역** | 화면 밖 앞쪽 등장 지점에서 달려옴 |
| **뛰어내리기** | 높은 벽·담장·컨테이너 위에서 거리로 뛰어내림. 플레이어는 못 올라감. 화면 안이어도 됨 |
| **벽 뚫기** | 벽이 부서지며 튀어나오고, 잔해가 바로 길을 막음 (5단계 레벨 작업에서) |
| **환풍구·맨홀·창문·셔터** | 기어 나오거나 깨고 나옴. 사람은 못 들어감 (5단계에서) |

## 4. 큰 소리 장치

L4D의 차 경보기처럼, **실수로 켤 수 있는** 장치입니다.

- **차 경보기**: 쏘거나 폭발에 휘말리면 울립니다. 경보가 울리는 동안(20초) 웨이브형 무리가 등장 지점에서 몰려옵니다.
- 셔터 경보(크레센도)는 지금처럼 일부러 켜는 장치입니다.
- 나중에 더할 것: 경보 문, 확성기, 발전기.

## 5. 지형과 층 이동

### 통로 크기

| 공간 | 폭 | 용도 |
|---|---|---|
| 주 통로(거리·광장) | 10~14m | 호드에 둘러싸이는 장면 |
| 병목(문·골목) | 3~4m | 지키기 좋은 자리 |
| 옆 공간(작은 방·골목) | — | 미리 배치 무리, 탄약, 우회로 |

### 층 이동

| | 계단(꺾인 형태) | 사다리 | 하수도 |
|---|---|---|---|
| 이동 | 걸어서 이어짐 | 타는 동안 무방비 | 내려가면 돌아오기 어려움 |
| 몬스터 | 걸어 올라와도 자연스러움 | 기어오르기 어색 | 아래에서 기다리거나 따라옴 |
| 시야 | 꺾인 곳에서 끊김 | 끊김 | 끊김 |

- **꺾인 계단을 기본**으로 하고, 하수도는 한 방향 진행 구간에 가끔 씁니다.
- 위 표는 위아래로 겹치는 **층** 이야기입니다. 야외 지형의 턱 · 절벽(**높이 단**)에서는 사다리를 플레이어 · 무장 동물이 쓰고 좀비는 벽을 기어오릅니다(L-16, [높이 단 규격](elevation-tiers.md)). 2026-10-23 검토: 이 장의 층 규칙(L-10 · L-11)은 바꿀 필요가 없었습니다.
- **다른 층은 그 층에 있는 사람만 봅니다.** 멀티에서 먼저 간 사람이 정찰하는 역할이 생깁니다.
- **도착 지점 보호**: 계단·하수도 출입구 반경 8m 안에는 미리 배치하지 않고 웨이브도 생기지 않습니다. 내려가자마자 맞는 불쾌한 상황과, 오르내리며 쏘는 꼼수를 막습니다.

### 시야와 전략

뒤쪽 시야가 좁은 것은 의도입니다. 멀티에서는 "누가 뒤를 볼지" 역할이 생기고, 경계형이 아무도 안 보던 쪽에서 나와도 억지스럽지 않습니다.

## 7. 구현 순서

1. 생성 지점 고르기: 화면 밖 우선(권장 규칙)
2. 반응 유형 3종과 깨우는 조건: 연쇄 깨움, 무기별 소음 반경, 경계형 시야
3. 배치·등장 지점 데이터: 구역 단위 미리 배치, 지나온 길·앞 구역·뛰어내리기 등장, 보호 구역
4. 큰 소리 장치: 차 경보기와 웨이브
5. 스테이지 1 다시 짜기: 넓은 거리, 병목, 옆 공간, 꺾인 계단 1곳, 하수도 1곳, 벽 뚫기·환풍구 연출. 시간·흐름 목표는 [시나리오 레벨 디자인](scenario-level-design.md) 6장(15분 흐름표)과 9.2(현재 Stage 1은 목표의 1/4~1/5 규모, 디렉터 시간 습격 재검토)

## 8. 구현 메모 (1~4단계)

| 항목 | 코드 | 동작 |
|---|---|---|
| 등장 지점 고르기 | `HordeDirector.PickEntry` | 후보 = 거리 안의 숨은 자리·벽 위 + 지나온 길(15~40m 뒤, 화면 밖). ① 화면 밖이면서 원뿔 밖, 또는 벽 위 ② 화면 밖 ③ 원뿔 밖 ④ 가장 먼 원뿔 밖 지점. 특수 몬스터는 벽에서 뛰어내리지 않음 |
| 풍선 소환 | `HordeDirector.SummonAround` | 같은 순서. 풍선은 가까이서 터지므로 대개 화면 안이라 ③으로 내려감(권장 규칙의 예외) |
| 반응 유형 | `Enemy.Reaction`, `Enemy.Wake` | 디렉터 생성 = 웨이브형. 미리 배치 = 데이터의 유형. 맞음·가까움·경계형 시야로 깨면 6m 안 동료를 한 번만 깨움. 소리로 깬 몬스터는 연쇄하지 않음 |
| 구역 채우기 | `HordeDirector.UpdateAreas` | 살아 있는 생존자 중 가장 앞선 사람의 구역 + 1까지. 화면 밖 자리를 먼저 고르고, 없으면 아무 빈 자리. 테스트용 `DirectorEnabled = false`이면 시작 때만 채움 |
| 벽 위 등장 | `HordeDirector.SpawnWave`, `Enemy.LeapDown` | 벽 위(높이 + 0.05m)에 세우고 뛰는 방향으로 밀어 떨어뜨림. 벽을 따라 ±1.8m로 퍼짐 |
| 데이터 대조 | `HordeDirector.UseEncounters` | 레벨을 만든 뒤 등장 지점·벽 위 착지 폭·특수 몬스터 자리를 흐름장과 보호 구역으로 확인. 막힌 것은 빼고 `[spawn]` 오류로 알림 |
| 차 경보기 | `AlarmCar` | 대시보드의 빨간 불이 1.4초마다 깜빡임. 사람의 총알이나 폭발(반경 + 2m)에 한 번만 울림: 60m 소음(사이렌 재생 음량은 작게 — I-62), 20초 동안 6초마다 6~9마리 웨이브(디렉터를 끈 검사에서는 소음만). **분대원 총알로는 안 울림**(AI는 보조 — M-12) |

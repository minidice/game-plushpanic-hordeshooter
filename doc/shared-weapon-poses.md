# 플레이어·몬스터 공통 총기 자세

2026-10-26 사용자 확정 방향: 모델 파일/종족이 달라도 최대한 같은 자세를 사용한다. 공통 자세 + 체형 기준점 + 무기 접촉점으로 분리하고 실제 형태 간섭만 예외 처리한다. 이전 포유류 팔꿈치 작업의 배 높이 파지와 플레이어 한손 소총 정책을 대체한다.

## 계약

- `Shouldered`: 소총·개머리판 있는 SMG/산탄총/저격총/LMG. 오른쪽 어깨와 실제 `StockContact`를 먼저 일치시킨 뒤 양손을 `GripRight`/`GripLeft`에 맞춘다.
- `Pistol`: 단일 권총. 몸 앞에 양손이 모이는 공통 자세. 어깨 견착점 없음.
- 쌍권총은 두 손의 독립 무기, 중화기·활·근접은 기존 전용 처리. 감염체 비무장 정책은 그대로다.
- 캐릭터: 기존 Arm/Shoulder 기준점을 정지 기준 변환으로 읽는다. 체형 커스터마이징의 부모 변환을 반영하되 팔 크기로 어깨 위치를 밀지 않는다. 앞으로 다른 모델을 넣을 때도 같은 기준점을 제공하며 종별 사격 애니메이션 복제는 하지 않는다.
- 무기: Blender 모델에 개머리판 후면 `StockContact`를 추가한다. 메시/총구/방아쇠 손 좌표는 유지한다. 소총·SMG의 왼손은 총열 덮개 뒤쪽(`0.42 × length`, 이전0.52)을 받쳐 팔의 과도한 신장을 줄인다. 도형 대체 무기는 실제 도형 후면에 기준점을 둔다.
- 자세 계산은 종족 이름을 기준으로 분기하지 않는다. 기존 날개/고정 손 표면을 목표점에 연결하는 방식만 형태에 따라 유지한다. 기존 전신 리그를 새로 만들지 않는다.
- 사격 시 총구 방향/출발점을 실제 모델과 일치시킨다. 이동 대기와 재장전은 같은 자세에서 전환하며 전투·속도·충돌 수치를 바꾸지 않는다.

## 검수 기준

어깨–개머리판 접촉과 실제 양손 접촉을 별도로 검사한다. 정면/측면/플레이 거리에서 배 견착·얼굴/조끼 관통·팔 길이와 무기별 차이를 본다. 네 플레이어와 여섯 일반 동물의 공통 자세, 크기 변형, 사격 직전/반동/이동/재장전/무기 교환을 확인한다. 대표 호랑이만 통과한 것을 전체 완료로 기록하지 않는다.

## 참고

- [미 육군 소총 교범](https://www.moore.army.mil/infantry/DoctrineSupplement/ATP3-21.8/PDFs/fm3_22x9.pdf): 검색 인덱스에서 개머리판–사격 어깨 접촉 확인. PDF 본문 도구 접근은 실패했으므로 전체 교범을 검토했다고 주장하지 않는다.
- [NRA 권총 자세 비교](https://www.americanrifleman.org/articles/choosing-a-handgun-shooting-stance/): 양손 자세의 시각적 차이 참고. 현재 데포르메 체형과 게임 카메라에 맞게 조정하며 실사 자세를 그대로 복제하지 않는다.

이전 팔꿈치 구현 이력은 [포유류 팔](mammal-weapon-arms.md)에 보존한다. 그 문서의 한손 정책과 고정 총 위치는 이번 A-4로 대체한다.

## 사용자 피드백과 다음 제안 — 93802c8 당시 미구현 이력

사용자는 맨손보다 무장 상태에서 팔이 길게 늘어져 어색하다고 지적했다. 현재 `CharacterLionPaw`는 별도 위팔/아래팔을 사용하고, 목표가 도달 범위를 벗어나면 길이를 늘려 접촉을 유지한다. 공통 접촉 검사를 통과한 것과 원래 캐릭터의 팔 비율에 대한 미술 수락은 다르다.

다음 제안은 라쿤+M4부터 원래 팔 비율을 유지하는 기본 자세를 만들고, 자동 신장을 제한하면서 상체/어깨 회전·왼손 위치·필요한 무기 비율을 함께 조정하는 것이다. 공통 자세 구조는 유지한다. 이는 아직 제작하지 않은 제안이며 사용자 확정 구현으로 표시하지 않는다. 사용자는 먼저 현재 작업을 커밋·푸시하도록 요청했다.

## 2026-10-26 짧은 팔 비율 유지 후속

사용자가 위 개선안 적용을 승인해 라쿤 M4부터 제작했다. 공통 런타임에서 라쿤·랫서판다·사자·호랑이·순록·코뿔소에 적용한다. 기존 Blender 손/팔 구간 메시를 재사용하며 GLB나 커스터마이징 저장 형식을 변경하지 않는다. 조류의 기존 날개 연결은 이번 길이 제한 대상이 아니다.

### 현재 계약과 제작 수치

- 기존 위팔/아래팔 각각0.36m 및 추가 신장으로, 무장 시 구간 합이 원본 어깨–손목 거리의2.3~4.1배였다. 이제 원본 Shoulder–Wrist 거리의1.10배를 위팔52%/아래팔48%로 분배한다. 손 메시 자체는 원래 비율을 유지한다. 이 거리는 실제 골격 뼈 길이 측정이 아닌 저폴리 원본의 기준점 간 거리다.
- 표준 견착·권총 자세는 더 늘리지 않는다. 접촉 거리 상한은 팔+손 길이의96%, 어깨는 원래 XZ반경/Y높이를 유지하며 몸 앞쪽으로 최소 회전한다(최대55도 추가, 절대82도). 검사는 기존 고정 어깨 대신 실제 이동한 어깨와 메시 연결, 원래 반경/높이 보존을 함께 확인한다.
- 소총은 모델 전체를40도 비스듬히 세우고 무기를 반대 방향으로 돌린다. 총구의 조준 방향은 유지한다. 몸/머리가 연속 메시이므로 **가슴만 비트는 스켈레톤 동작은 아니며 머리·발도 함께 돌아간다**.
- 소총 어깨 포켓은 반폭의0.40 안쪽, 위0.08m·앞0.03m. 이동 시 총 기울임0.30rad·낮춤25mm·전진20mm로 몸 가까이 유지한다. 권총은 중앙 앞0.38m 양손 자세다.
- 장착된 총의 길이 배율은 `clamp(0.60/Length,0.75,1)`로 제한하고 폭/높이 및 호출자의 모델 크기 보정은 보존한다. 긴 총의 왼손은 원래 파지점에서 Z최대0.32m인 총몸/앞받침 뒤쪽으로 옮긴다. 원본 GLB·바닥 드롭 모델·무기 수치는 그대로이며, 장착 총구 위치는 실제 변환을 따른다. 최초 모든 총0.60m 상한은 M82가 지나치게 짧아 보여 폐기했다.
- 조준·구르기·무장 적 밀치기의 몸 전체 움직임은 유지하고 총만 추가로 움직이는 양을15%로 줄인다. 원래 양을 유지하면 작은 체형+이동 조합에서 실제 손이 최대79.5mm 떨어지는 것을 재현했다. 변경 후 같은 검사에서 실제 접촉을 확인했다.
- 재장전·수렵·중화기·횡단 전용 자세는 기존 도달 처리(필요시 신장)를 유지한다. **모든 애니메이션의 팔 신장을 제거했다고 주장하지 않는다.** 수치는 이번 아트 제작값이며 사용자 확정 해부학 수치가 아니다.

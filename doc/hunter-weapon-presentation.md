# 수렵단 무기 동작·소리

2026-10-25, C-31 후속. 사용자 승인 범위는 몽둥이·칼·나무활의 공격 표현이다. 피해·사거리·공격 간격·종족별 준비시간·이동속도 데이터는 유지한다. 생성 도구 메시와 절차적 포즈를 사용하며 새 Blender/모션캡처 에셋은 만들지 않았다.

## 동작과 판정

|---|---|---|---|
| club | 위로 들어 올린 뒤 내려찍기. 준비시간76%부터 빠른 궤적 | 기존0.32초 | hunter_club_raise / hunter_club_swing / hunter_club_hit |

`CharacterHunterPose.cs`의 `SetHunterAttackPose(weapon, elapsed, windup, recovery)`를 실제 게임과 Studio가 공유한다. 음수 시간은 즉시 원상복구. `HunterSwingStart`는 포즈와 휘두르는 소리의 공통 기준이다. 기존 감염체 밀기 포즈를 몽둥이/칼 위에 중복 적용하지 않는다. 이 무기를 사용하는 일반 무장단 칼도 같은 무기 포즈를 공유한다.

준비 중 피해 없음, 타격 시 실제 거리·방향·차폐·구르기를 검사하는 기존 판정 유지. 근접 명중음은 실제 체력이 감소한 때만 재생한다. 빗맞으면 휘두르는 소리만 난다. 화살 명중음은 물리 충돌 때만 나며 허공에서 사거리 소진으로 사라질 때는 나지 않는다.

기절/죽음은 준비와 부착된 당김 소리를 정리한다. 활은 별도 시각 시간으로 준비를 보여주지만 로컬 시계만으로 발사하지 않는다. 클라이언트는 실제 `EnemyProjectile` 이벤트를 받으면 발사 자세로 전환한다. 뒤따르는 정상 공격 종료 이벤트가 발사 회복을 지우지 않는다. 근접 명중은 길이 구획이 있는 `HunterMeleeImpact` 이벤트(적ID·위치)로 전달한다. 기존 이벤트 번호/데이터 형식은 유지하고 마지막에 선택적 시각·청각 이벤트를 추가했다. 기존 클라이언트는 모르는 이벤트를 건너뛸 수 있다.

공포·유인·부유·등반의 기존 원거리 AI 일시정지/재개 정책까지 바꾸지는 않았다. 기절 종료 이후 공격을 오래된 보간 스냅샷으로 매 프레임 취소하지 않으며, 신뢰성 있는 공격 시작/종료 이벤트를 따른다. 실제2PC·지연/손실 조건의 최종 체감 검수는 후속이다.

## 소리

9개 모두 `SoundRecipes`의 결정적 합성 음원이다. 녹음 음원이라고 표현하지 않는다. `content/sounds/<id>.ogg|wav|mp3` 교체 계약은 기존과 같다. 준비 소리는 적에 붙는 전용 emitter여서 풀의 다른 소리를 잘못 중단하지 않는다. 활 당김 기본1.2초는 실제 스트림 길이/종족별 준비시간으로 피치를 조정한다. 각 효과는 유한 길이, 근거리 상한과 동시 음성 수 제한을 적용한다. 최종 음색 취향과 기기별 청감 조정은 플레이 피드백으로 판단한다.

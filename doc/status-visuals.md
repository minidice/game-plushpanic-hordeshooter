# 캐릭터·몬스터 상태 시각 시제품

2026-10-24 사용자가 대화의 추천안을 승인했다. 이번 범위는 공통 외형과 Studio 조합 검수, 이미 존재하는 상태의 게임 연결이다. 새 중독/출혈 피해나 빙결 행동 규칙은 추가하지 않는다.

## 승인 방향과 구현 선택

색만 변경하면 색이 다른 캐릭터와 감염체에서 읽기 어렵고, 상태별 효과를 전부 겹치면 얼굴과 무기가 가려진다. 약한 몸 표면 무늬 + 부착 효과 + 모양이 다른 아이콘을 조합한다. 개별 모델에 효과를 굽는 방식 대신 현재 CharacterRig의 크기/자세를 따라가는 공통 생성기를 사용한다.

- 공통 `status_visuals.json`: 12상태(poison, bleed, burn, chill, freeze, blind, stun, shock, fear, weak, restrained, floating), ID/이름/색/형태/우선순위/표면 강도/연결 현황. gameplay 수치와 미리보기 설정은 분리한다.
- 몸 표면은 우선순위가 높은 하나, 장식은 최대2종. 동일 상태의 중첩은 개체 복제가 아닌 제한된 강도로 표시한다. 모든 활성 상태는 Studio 목록/로컬 플레이어 HUD에서 확인하고 머리 위 아이콘은 최대2개+추가 개수로 압축한다.
- 몸의 원본 색·좀비 틴트·장비를 유지한다. 상태 표면은 별도 공유 메시 렌더층으로 조합해 기존 피격/실루엣의 MaterialOverlay 슬롯을 덮어쓰지 않는다. 피격/실루엣 수집에서 상태 메시를 제외한다. 숨김/실루엣 중에는 상태 외형/아이콘을 표시하지 않는다.
- 형태: 독 거품, 아래로 흐르는 핏방울, 작은 불꽃, 서리/얼음, 눈부심의 눈 모양, 기절 별, 번개, 공포의 떨림 표시, 약화 깨진 방패, 구속 고리, 부유 곡선. 지속 바닥 위험 원은 만들지 않는다. 수치·밀도는 시제품 조정값이다.
- 기존 적 화상/기절/공포/약화/부유 및 플레이어 눈부심/기절·멍함/약화/붙잡힘을 해당 상태 값으로 읽는다. 아직 없는 상태는 Studio에서 `미연결`로 명시한다. 쓰러짐 출혈 타이머는 일반 출혈 상태로 오인해 연결하지 않는다. 기존 네트워크로 전달되지 않는 상태를 새로 동기화했다고 표현하지 않는다.
- Studio는 같은 로더와 생성기, 실제 캐릭터/몬스터를 사용한다. 복수 상태·중첩 수·피격 삽입·해제/복원, 전체 프레임 타임라인을 검수한다. 파일/세이브 저장 없음.

## 검증과 제약

잘못된 데이터, 우선순위/중복/개수 제한, 체형/부착 위치, 피격과 해제 복원, 재질 공유 격리, 숨김/실루엣, 사망/부모 제거를 검사한다. 실제 발생원의 상태를 읽는지 검사하고 기존 HitFlash/Vision/EnemyExpansion/Integration과 Studio 회귀를 실행한다. 창 모드와 Studio 렌더에서 단일/복합 상태를 확인한다. 실제2PC와 저사양/장시간 성능은 별도 실행 여부를 명시한다.

### 구현·검증 — 2026-10-24

- `StatusVisualCatalog/Controller/Parts/Icons/Binding`이 공통 데이터·외형·실제 상태 읽기를 분리한다. 같은 상태는 최대 중첩 수로 병합하고 1–5 범위만 허용한다. 남은 시간 0은 외부 상태가 유지되는 동안 표시한다는 뜻이며, 시각 컨트롤러는 전투 타이머를 진행하지 않는다.
- 라이브 연결: 적 burn/stun/weak, 호스트·로컬 fear/floating; 플레이어 blind/stun 또는 daze/weak/restrained. 원격 적 기절은 기존 `NetEnemyFlags.Stunned`, 화상·약화는 기존 이벤트 타이머를 읽는다. 기존 복제 범위를 확장하지 않았으므로 공포·부유의 원격 표시 및 재접속 완전 복원은 이번 완료 범위가 아니다.
- 독 웅덩이는 지속 영역 피해이며 중독 DOT가 아니다. 쓰러짐 `BleedLeft`도 출혈 DOT로 연결하지 않는다. poison/bleed/chill/freeze/shock는 시각 시제품이다. 속도 감소 등 모든 디버프를 chill로 억지 변환하지 않는다.
- 로컬 HUD는 전체 상태명·아이콘·남은 시간/중첩을 표시한다. 월드 효과는 실루엣/숨김/색 복원 중에는 감추고, 피격 순간에는 상태 표면만 양보한다. 사망/제거 시 읽기 어댑터가 빈 상태를 반환하며 독립 표면 메시도 제거한다.
- 1차 실제 렌더에서 충돌 반경 안쪽의 불꽃이 몸에 묻히는 문제가 확인돼 부착 반경을 옷 바깥으로 조정했다(I-122). 낮은 효과 수·무광 스타일·얼굴과 무기의 원본 색은 유지한다. 바닥 영역, 새 광원, 무한 파티클 생성은 추가하지 않는다.
- `StatusVisualCheck`: 헤드리스57/창 모드77(부하 포함80) 검사 통과. 12개 단일 상태, 4종 중첩, 피격/실루엣/숨김/해제, 플레이어4체형, 실제 적/플레이어 타이머, 사망, 독립 재질, 컨트롤러 제거를 검사했다. `game/output/status-*.png`, `status-regression-*.log`.

# 거위 Godot 적용 계획 — 2026-10-19

## 합의된 범위
사용자가 첫 적용 종으로 거위, 엔진으로 Godot 4 C# + Jolt를 선택했다. 기존 게임 프로젝트가 없으므로 `prototypes/goose-playtest`에 별도 로컬 테스트 장면을 만든다. 최종 종 선택, 4인 네트워크, 캠페인 구현은 이번 범위에 포함하지 않는다.

## 설계
- 기존 일체형 거위 외형을 GLB로 추출한다. 정적인 부품을 움직임 기준점별로 합치고 곡면을 줄인다. 본 없이 몸통, 발, 무기를 코드로 움직인다.
- 이동은 CharacterBody3D 캡슐, 사망은 단일 RigidBody3D 캡슐 + 시각적인 squash/stretch다. 소프트바디나 다관절 래그돌은 아니다.
- 55도 직교 카메라, WASD 이동, 마우스 바닥 조준, 좌클릭 사격, H 피격, K 물리 사망, R 재시작. 표적과 장애물을 배치한다.
- 엔진을 실행해 모델 로딩, 이동/벽 충돌, 총알 차폐, 피해/사망 전환, 사망 후 입력 차단, 복구를 검증한다. 실제 엔진 스크린샷으로 외형도 확인한다.

## 실행 순서
- [x] 1. 거위 단독 GLB 생성·최적화, 모델 크기/삼각형/부품 수 보고서.
- [x] 2. Godot C# 프로젝트와 거위 재사용 장면, 조작·사격·피해·물리 사망 구현.
- [x] 3. 테스트 맵·카메라·HUD, 헤드리스 통합 검사와 엔진 화면 확인.
- [x] 4. 시작 스크립트·조작 설명·검증 결과 저장.

## 검증 초점
대각선 속도 증가 방지, 조준 평면과 무기 축 일치, 벽 너머 사격 방지, 사망 시 충돌체 중복 방지, 재시작 때 시체 제거, 초점 상실 시 입력 정리.

## 기록
- .NET SDK 10.0.400 / .NET 8 및 10 런타임 확인.
- Godot 공식 4.7.2 .NET Windows 바이너리를 SHA512 확인 후 사용자 로컬 도구 폴더에 준비.
- 기존 프로젝트는 Git 저장소가 아니므로 커밋/작업트리 생성 없음.
- GLB 1,054,400 bytes / 18,107 triangles / 10 meshes / 49 material slots. LOD 및 재질 병합은 후속 최적화.
- `Start-Playtest.ps1 -Test`: 빌드 경고/오류 0, Godot 가져오기 성공, 엔진 통합 검사 17개 통과. 기존 모델/물리 검사와 추가 에셋 검사 합계 9개 통과.
- 실제 Vulkan Forward+ 렌더의 기본/확대 화면 확인. 초기 Compatibility 렌더의 과노출을 수정.
- 별도 읽기 전용 코드 리뷰: P1/P2 없음. 자동 검사는 실제 OS 키보드/마우스 조작을 대체하지 않으며, Tab UI 입력은 코드 검토/확대 렌더로 확인.
- 사용자 제공 참고 이미지에 기반한 캐릭터 외형은 유지. 월드는 기능 검증용 단순 맵.

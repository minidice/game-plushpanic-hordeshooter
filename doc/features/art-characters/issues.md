# 캐릭터 아트 — 이슈 본문

새 이슈는 여기 ID 아래에 쓰고, [전체 색인](../../issues.md)에는 ID · 한 줄 증상 · 상태 · 날짜 · 링크만 한 줄로 적는다. 새 이슈 ID는 전체 번호(`I-126`부터)를 쓰고, **색인에 한 줄을 먼저 추가해 커밋 · 푸시한 뒤** 본문을 쓴다(먼저 예약). 푸시가 막히면 받아서 다음 번호로 바꾼다.

**옛 기록은 옮기지 않고 그대로 있다**(2026-10-26 결정, [기록 문서 나누기](../../records-split-plan.md) 6.4). 이 기능의 2026-10-26 이전 결정 · 이슈 · 확인 기록은 [decisions.md](../../decisions.md) · [issues.md](../../issues.md) · [feature-checklist.md](../../feature-checklist.md)에 있다.

## I-35 무장 시 과도한 팔 길이 후속

- 증상/확인 원인: 맨손에서는 짧은 팔이 총기 장착 후 길게 보임. `CharacterLionPaw`의 원본과 무관한0.36m×2 및 도달 신장이 원본 Shoulder–Wrist 거리 대비2.3~4.1배의 구간 합을 만들었다.
- 조치: 원본 길이 기준의 제한된 두 구간, 몸 앞쪽으로 이동하는 어깨, 공통40도 자세와 반대 무기 회전, 장착 총 길이 보정 및 뒤쪽 왼손 받침. 최초 긴 총의 과도한 압축은 렌더 확인 후 최소75% 길이로 제한했다. 호출자의 무기 크기 보정과 같은 Built 재연결 시 비율을 보존한다.
- 제작 중 재현: 이동+작은 팔에서 조준/구르기 추가 총 이동이 손을 최대79.5mm 이탈시킴(49개 실패). 공통 총기 자세에 한해 총의 추가 움직임을15%로 줄였고 적 밀치기/예비 동작까지 확장한11,016 검사 통과. 원래 어깨 고정 검사는 이동 어깨 표면 및 원래 반경/높이 보존 계약으로 바꿨다.
- 재발 방지: 손 표식만 검사하지 않고 실제 앞발 접촉, 원본 팔길이 대비 비율, 실제 구간 메시의 어깨/팔꿈치/손목 연결, 체형 변경/반동/조준/구르기/밀치기·숨김 복원을 검사한다. Studio 입력 키 오기(WingSize)는 wing_size로 수정해22장 재렌더 성공. 새 버그 ID를 만들지 않고 기존 파지 이력에 연결한다.
- 실제 검증: 라쿤/랫서판다 창 모드 이동·사격·사다리 포함 각7,620, 호랑이3소총 AI 사격·총구/재장전539, 수렵3무기42, 실제 시간 Integration149 통과. 최종 실행 로그에서 종료 경고 없음.
- 상태/제약: 표준 포유류 총기 길이 개선 구현·검증. 재장전/횡단 신장 예외, 전체 모델 회전(독립 가슴 아님), 확대 관절선 및 최종 미술 수락·장시간/실제2PC/성능은 남음. [실행 결과와 증거](../../shared-weapon-poses.md#2026-10-26-짧은-팔-비율-유지-후속).

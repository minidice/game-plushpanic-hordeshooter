# 장비 효과별 발동 조건 분리

- 사용자 결정: 치명타 확률·피해는 상시/조준 집중/조준 중 옵션을 각각 둔다. 탄퍼짐·반동 감소는 상시/조준 중으로 나누고 조준 조건부 수치를 더 높인다.
- 변경: C-34 본문·색인과 설계/수치 제안 갱신. 무기 조건에서만 장비 확률을 더하는 이전 AI 추천을 사용자 확정으로 취급하지 않았다. 단일 옵션은 효과 하나+발동 조건 하나로 정리했다.
- 수치: 상시/조준 중 비교값은 AI 미검증 제안. 집중 완료100%와 집중 조건부 확률 증가의 중복은 미결로 명시했다. 보장 확률 하향이나 요청 옵션 삭제를 임의 결정하지 않았다.
- 결정·이슈 검토: 기존 C-34 구체화로 새 ID·버그 이슈가 필요하지 않다. C-32의 집중100%는 유지한다. 기능은 미구현이며 완료 체크는 유지한다.
- 검사: 상대 링크 대상과 git diff --check 통과. 문서만 변경하여 게임 빌드·실행·렌더 없음.
- 남은 계약: 집중 조건의 의미, 확률/배율 합산·적용 대상·실제 수치/밸런스. 기존 저장·이월 등 미결도 유지.

# 장비9종 첫 테스트안 수락과 구현 계획

- 사용자 수락: 제안안으로 진행. 치명타 확률2종·피해3종·탄퍼짐2종·반동2종의 표 수치를 첫 테스트 기준으로 채택하고 집중 전용 확률 옵션은 제외한다. 수치는 최종 밸런스 확정이 아니다.
- 변경: C-34 본문·색인과 수치/설계의 미결·제안 표기를 갱신하고 이전 기록을 보존했다. [구현 계획](../equipment-implementation-plan.md)에 데이터·실제 효과·교체/HUD·멀티/이월·플레이 검증의 순서와 파일/인터페이스를 작성했다.
- 구현 판단: 슬롯 배분·합산·판정 단위·빈 슬롯 시작/이월·전용 테스트 배치는 AI 선택으로 구분했다. 무기별 저격30% 예시와 다른 옵션 수치까지 수락한 것으로 해석하지 않는다.
- 조사: 기존 WeaponPickup/Stage.PickUp, WeaponController/WeaponRecoil, HudEquipmentSlot, StageCarry/NetLobby/StageNet 경로를 읽었다. 없는 파일명/PowerShell 와일드카드 검색은 실제 목록과 rg -g로 정정했다. 현재 집중의 IsLocal 제한은 멀티 구현 계획에서 처리하도록 표시했다.
- 검사: 계획 자체 검토(규격 대응·인터페이스·위험 사례 대응), 상대 링크·기존 수정 대상 경로 및 git diff --check 통과. 게임 코드 변경·빌드·렌더·테스트 실행은 없으며 계획의 검사는 실행 예정이다.
- 결정·이슈 검토: 기존 C-34 세부 수락으로 새 ID나 버그 이슈가 필요하지 않다. 장비는 미구현이므로 완료 체크를 추가하지 않았다.
- 남은 범위: 실제 구현/검증, 캠페인 샛길별 배치·난전 보상 빈도·나머지 후보·무기 고유 조건 수치·캐릭터 외형 연결. 기존 저장 규칙을 새로 확정하지 않는다.

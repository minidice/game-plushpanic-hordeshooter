# 이동 시간 임시 기준과 추가 구르기 중 회복 확정

- 변경: [계획](../equipment-movement-plan.md)과 C-1·C-35 본문/색인에서 구르기 한 칸 회복6초·자동 달리기 대기2초를 사용자 수락한 임시 기준으로 갱신. 두 번째 구르기 중에도 진행 중인 회복은 정지·초기화 없이 계속된다. 플레이 후 조정한다.
- 결정·이슈 검토: 기존 결정의 미결 수치와 제안 해석을 확정한 후속으로, 새 ID·가짜 버그 없이 이전 이력을 보존했다. 구현·기능 체크리스트 완료 상태는 바꾸지 않았다.
- 검사 통과: 문서 상대 파일 링크 9개, 사용자 수락한6초/2초 임시 기준 및 초기화·일시정지 없는 회복 규칙 확인, 변경 범위 검토와 `git diff --check`. 문서 검사 실패·종료 경고 없음.
- 렌더·게임 검사: 문서만 수정해 실행하지 않음. 코드 미변경·체감 미검증.
- 남은 제약: 걷기·달리기 속도, 기타 상태 전환, 장비 계약 등은 미결.6초/2초는 최종 밸런스 확정값이 아니다.
- 관련 ID: C-1 · C-35.

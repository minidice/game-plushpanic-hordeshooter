# 추가 장비 옵션 후보와 초기 수치 제안

- 요청: 탄퍼짐·반동·최대/유효/수류탄 사거리·재장전, 받는 피해로 해석한 대미지 감소, 화상/중독/출혈 시간·치명타 피격 확률 감소, 치명타 대미지 증가 후보와 시작 수치 추천.
- 변경: [수치 제안](../equipment-option-tuning.md)을 작성하고 기존 설계에서 연결. 사용자 후보와 AI 미검증 수치를 분리했다. 재장전·대미지 문구의 해석, 확률 %/%p, 치명타 피해 배율, 상태이상과 장판/다운 시간 차이를 명시했다.
- 코드 확인: WeaponDefinition의 사거리·반동·퍼짐·치명타 배율, Player의 집중/피해 올림 처리, FireZone·VomitHazard·PlayerDowned를 읽었다. 없는 경로와 PowerShell 와일드카드 검색 실패는 실제 파일 목록과 rg -g 검색으로 정정했다.
- 결정·이슈 검토: 아직 수치 수락·첫 제작 목록 확정이 아니므로 C-34 확정 내용을 바꾸지 않았다. 피해 정수 처리와 미연결 상태이상은 앞으로 구현할 옵션의 선행 조건이며 기존 버그로 새 이슈를 만들지 않았다.
- 검사: 문서 상대 링크와 git diff --check 통과. 코드 변경·게임 실행·렌더 없음. 수치 효과는 실측하지 않았다.
- 남은 제약: 첫 제작 목록/슬롯 배분·상태/치명타 판정·중첩/교체·정수 처리·모드별 실전 밸런스 미결.
- 관련 ID: C-34 · C-1 · C-35.

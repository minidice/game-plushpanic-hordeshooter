# 구르기 순차 충전과 회복 진행 보존 확정

- 변경: 사용자 선택을 [설계 초안](../equipment-movement-plan.md)과 [C-1 본문](../decisions.md), 전체 색인에 반영. 한 칸씩 순차 회복하며 두 번째 구르기를 써도 진행 중인 회복을 초기화하지 않는다. 현재 칸 완료 후 다음 빈 칸을 회복한다.
- 결정·이슈 검토: 기존 C-1의 미결 항목을 확정한 후속이며 이전 상태는 변경 이력에 보존. 새 결정·버그 ID는 필요하지 않다. 코드와 기능 구현 현황은 그대로다.
- 검사 통과: 설계·작업 기록의 상대 파일 링크 9개 존재, 순차 회복과 두 번째 사용의 영향에 관한 오래된 미결 문구 제거 및 진행 보존 규칙 확인, 문서 변경 범위 확인, `git diff --check`. 실패·종료 경고 없음(게임 종료 경고는 미실행으로 평가하지 않음).
- 렌더·게임 검사: 문서만 변경하여 실행하지 않음. 구현 검증 목록에 순차 회복·추가 사용 시 진행 보존·다음 칸 회복을 명시했다.
- 남은 제약: 첫 회복 시작 시점·기본 회복시간은 미결. 충전 시스템은 구현 전이다.
- 관련 ID: C-1.

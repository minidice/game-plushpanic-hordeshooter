# 구르기 종료부터 회복 · 시간 제안

- 변경: 사용자 결정인 구르기 종료 시 회복 시작을 [계획](../equipment-movement-plan.md)·C-1·색인에 반영. 회복 6초·자동 달리기 대기 2초는 AI의 첫 테스트용 제안으로 분리하고, 사용자 확정이나 구현 수치로 표시하지 않았다.
- 결정·이슈 검토: 기존 C-1의 미결 항목 구체화이므로 새 ID 없음. 과거 이력 보존. 반복 구르기로 장기 도주가 가능할 위험은 설계 검증 항목이며 재현된 제품 버그로 발급하지 않는다.
- 근거 확인: `Player.cs`의 5초 대기·0.42초 동작·10m/s, 일반 플레이 종 4개의 기본 4.4m/s와 기존 추격 검사 문서의 감염체 4.55m/s. 이번 런타임 실측은 아님.
- 검사: 최초 검색에서 추정 경로 2개가 없어 오류가 났고, 실제 콘텐츠 파일 목록과 기존 검사 문서로 범위를 바로잡았다. 최종 문서 상대 파일 링크 9개, 종료 시 회복 시작 확정과 6초/2초 제안 구분, 변경 범위 확인 및 `git diff --check` 통과. 문서 검사 종료 경고 없음.
- 렌더·게임 검사: 문서만 변경해 실행하지 않음. 회복시간·자동 달리기 체감과 반복 도주 가능성은 미검증.
- 남은 제약: 6초/2초 수락 전. 이동 속도·상태별 전환·장비 계약 등 기존 미결 유지.
- 관련 ID: C-1 · C-35.

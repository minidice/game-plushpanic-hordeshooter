- 변경: 사용자 요청에 따라 [계획](../equipment-movement-plan.md)과 C-35 본문·색인에 걷기 3.6m/s·자동 달리기 4.2m/s를 플레이하면서 조정할 임시 기준으로 반영했다. 미결 속도 표현을 갱신하고 검증 기준과 기존 수치와의 차이를 보완했다.
- 결정·이슈 검토: 기존 C-35의 미결 수치 구체화이며 변경 이력을 보존했다. 새 결정·버그 ID는 필요하지 않다. 구현 현황·체크리스트는 그대로다.
- 검사 통과: 상대 파일 링크 9개 존재, 계획·결정 본문·색인의3.6/4.2m/s 일치, 이전 미결 속도 표현 제거, 조건부 평균 속도4.39m/s 산술 확인, `git diff --check`. 문서 검사 실패·종료 경고 없음.

- 남은 제약: 이동 보정 합산·기타 행동 상태 전환·장비 계약 등은 미결. 실제 추격과 사격 중 이동 체감은 향후 플레이에서 확인한다.

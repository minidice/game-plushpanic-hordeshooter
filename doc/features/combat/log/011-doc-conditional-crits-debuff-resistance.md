# 조건부 치명타와 상태이상 저항·정수 피해 계약

- 사용자 결정: 집중 다음 한 발100% 유지와 조건부 확률 치명타로 개선하는 방향. 저격의 거리·조준 조건/30%는 예시로 보존한다. 저항은 디버프 최초 부여 시간 기준. 소수점 처리 때문에 작은 피해의 감소 효과가 없어지는 것은 정상.
- 변경: 기존 C-32 후속 본문·색인 추가, C-34 옵션 처리 갱신, 장비 설계/수치 제안/무기 규격 갱신. 옛 C-32 표와 AI 보정 제안 이력 보존. 기존 정수 올림을 유지하고 보정 도입은 제외했다.
- 확인: 현재 Player 집중/소비와 WeaponController 판정 경로를 읽었다. 확률 치명타·장비 저항은 구현하지 않았다. 기존 기능 현황 체크는 유지.
- 검사: git diff --check와 변경 문서 상대 링크 대상 확인 통과. 문서만 변경하여 빌드·실행·렌더는 미실행.
- 결정·이슈 검토: 기존 C-32·C-34 갱신이며 새 ID가 필요하지 않다. 사용자 수락한 피해 정수 처리 결과는 버그로 등록하지 않는다.
- 남은 계약: 조건 밖 확률·장비 확률 합산·집중 전 판정, 무기별 조건과 수치, 판정 단위·멀티·AI, 상태 갱신/중첩/장비 교체 시 처리. 앞선 AI 수치표는 아직 수락 전.

# 장비 옵션 시작 수치 제안

2026-10-29. 관련 C-34. 사용자 요청은 옵션 후보 추가와 시작 수치 추천이다. 아래 수치는 AI의 미검증 제안이며 사용자 확정값·완성된 장비 목록이 아니다. 모든 행은 각각 별도 장비의 단일 옵션이다. 슬롯별 배분도 미정이다.

## 추가 후보와 첫 테스트 값

| 사용자 후보 | AI 시작값 | 해석·계산 |
|---|---|---|
| 탄퍼짐 비율 감소 | −10% | 최종 탄퍼짐 각도 ×0.90. 이동/연사/조준을 반영한 뒤 적용. 산탄 포함 여부는 첫 구현 계약에서 명시 |
| 반동 감소 | −15% | 조준점 상하·좌우 반동 ×0.85. 캐릭터 밀려남과 반동 복귀 속도는 별개 |
| 최대 사거리 증가 | +10% | 총기의 최대 도달 거리 ×1.10. 유효 사거리 자체는 유지 |
| 유효 사거리 증가 | +10% | 피해 감소가 시작되는 거리 ×1.10, 최대 사거리를 초과하지 않음 |
| 수류탄 사거리 증가 | +15% | 투척 가능 거리 ×1.15, 폭발 반경은 유지. 다른 G 투척물 포함 여부는 미결 |
| 재장전 속도 감소 | 시간 −10% | AI 해석은 이로운 재장전 시간 단축. 2초→1.8초, 한 발씩 넣는 장전도 준비/삽입 시간에 일관 적용 제안 |
| 대미지 감소 | 받는 피해 −5% | AI 해석은 방어 옵션. 공격 대미지 감소가 아님. 기존 피해 올림 유지·효과가 사라지는 작은 피해 허용은 사용자 확정, 적용 피해 범위는 미결 |
| 화상 지속시간 감소 | −25% | 캐릭터에게 부여되는 화상 지속시간 ×0.75 가정. 장판 수명은 줄이지 않음 |
| 중독 지속시간 감소 | −25% | 캐릭터에게 부여되는 중독 지속시간 ×0.75 가정. 장판 수명은 줄이지 않음 |
| 출혈 지속시간 감소 | −25% | 전투 중 출혈 상태의 지속시간 ×0.75 가정. 쓰러진 뒤 사망까지 남은 시간과 구분 |
| 치명타 피격 확률 감소 | 확률의 −20% | 적 치명타 확률10% 가정 시8%. −20%p가 아님. 적 치명타 시스템 확정 후 검증 |
| 치명타 대미지 증가 | +10% | 최종 치명타 피해 ×1.10. 일반 피해100·기존 치명타250 가정 시275 |

일반적으로 적용되는 피해 감소는 작게, 적용 상황이 제한되는 저항은 더 크게 시작해 교체 선택을 비교한다. 탄퍼짐·반동·사거리 옵션의 가치는 무기와 지형마다 달라 수치만으로 동급이라고 보장하지 않는다.

## 앞서 논의한 후보의 시작값 제안

- 밝은 시야 각도: 전체 각도 +10°(좌우 +5°씩), 거리·벽 차폐 유지.
- 치명타 확률: 상시 +3%p는 AI 제안. 사용자 후속으로 무기 조건과 별개인 상시/조준/조준 집중 장비 옵션을 나누는 방향이 확정됐다. 집중은 완료된 다음 한 발만 뜻하며, 집중 전용 확률 옵션은100% 보장으로 실효가 없어 제작 여부를 재검토한다. 합산 규칙은 미결이며, 집중 치명타와 중복 배율 없음은 제안이다.
- 탄창 용량: +10%. 작은 탄창의 반올림과 최소 증가량은 미결.
- 구르기 회복시간: −10%, 현재6초→5.4초. 충전 최대2회 유지.
- 구르기 중 받는 피해: −20%. 기본 무적을 만들지 않음.
- 이동속도: 첫 제작에서는 보류 제안. 현재 일반 이동4.2m/s 상한에서 효과가 사라질 수 있음.

## 현재 코드 확인과 선행 조건

- `Player.CritReady`, `WeaponController`의 집중 대상 판정은 집중 후 치명타다. 기존 기본 확률에 가산하는 구조라고 가정하지 않는다. `Player.TakeDamage`에는 치명타 여부 인자가 없어 피격 확률 감소를 곧바로 연결할 수 없다.
- `FireZone`·`VomitHazard`는 영역 안의 플레이어에게 피해를 준다. 캐릭터의 지속 상태이상 저항을 장판 수명 감소로 구현하면 다른 효과가 된다. `PlayerDowned.BleedLeft`는 쓰러진 뒤 사망까지 시간이며 단축하면 불이익이다. 상태 시각 효과가 존재해도 해당 상태의 게임 판정이 구현되었다고 보지 않는다.
- `Player.TakeDamage`는 피해를 올림해 정수 체력에서 차감한다. 예:10×0.95=9.5→10으로 방어 효과가 사라지는 것은 사용자 후속에서 정상으로 허용했다. 기존 올림 처리를 유지하며 최소1 피해 감소 보장이나 소수 피해 누적 보정을 추가하지 않는다.
- 최대·유효 사거리 증가가 기존 선형 피해 감소 곡선에 미치는 영향도 검사한다. 최대 사거리 증가는 끝점이 멀어져 기존 감소 구간의 피해에도 영향을 줄 수 있다.
- 장비 교체로 진행 중 장전·충전·상태이상 타이머가 초기화되거나 탄약/체력이 생성되지 않도록 검사해야 한다. 중첩·교체 규칙과 실전 밸런스는 아직 미검증이다.

## 사용자 후속 확정 — 치명타·상태이상·정수 피해

- 집중 완료 후 다음 한 발은100% 치명타. 그 외에는 무기별 조건부 확률 치명타를 추가하는 방향이다(C-32). 예를 들어 저격은 무기마다 정한 거리 이상+조준 중이면 집중 첫 발 이후 재집중 전까지30%로 판정한다. 이 거리/30%는 사용자 예시이며 확정 수치가 아니다.
- 장비가 없을 때 조건 밖 기본 확률, 집중 첫 발 이전의 무기 조건부 확률, 산탄/점사/관통·멀티 판정 단위는 미결이다. 장비에는 무기 조건에만 묶이지 않는 상시/조준/조준 집중 옵션을 별도로 둔다(아래 후속). 공격 치명타 방향 확정이 적 치명타 피격 시스템의 확정을 뜻하지 않는다.
- 상태이상 저항은 대상에게 디버프가 처음 부여되는 시점의 지속시간에 적용한다. 예:기본4초·저항25%(제안값)이면 처음부터3초로 부여한다. 이미 진행 중인 디버프에 매 프레임 저항을 곱하는 방식이 아니다. 재피격 갱신/중첩, 교체 후 기존 디버프 소급 변경 여부는 후속 계약이다.
- 작은 피해에서 소수점/올림 때문에 감소 효과가 없어지는 것은 정상으로 허용한다. 수치표의 피해 감소5%·상태이상 저항25% 등은 이번 후속으로 수락된 것이 아니며 계속 AI 제안이다.

### 변경 이력

- 2026-10-29 조건별 장비 후속: 사용자 — 치명타 확률/피해에 상시·조준 집중·조준만 하는 조건을 각각 두고, 탄퍼짐/반동 감소에도 상시·조준 중 조건을 별도로 둔다. 조준 조건부 수치는 상시보다 높인다. 이전의 무기 조건 안에서만 장비 확률을 더하는 AI 추천으로 한정하지 않는다. [기록012](log/012-doc-equipment-activation-conditions.md).

- 2026-10-29 최초: 확률 치명타 도입 여부·저항 적용 시점·소수 피해 처리 미결. AI는 소수 누적 등 보정 검토를 제안했다.
- 같은 날 사용자 후속: 집중100%+조건부 확률 방향, 최초 디버프 지속시간 기준, 소수 처리로 감소 효과가 사라지는 경우 허용을 확정했다. [기록011](log/011-doc-conditional-crits-debuff-resistance.md).

## 장비 옵션의 효과와 발동 조건

- 사용자 확정: 치명타 확률과 치명타 피해 각각 상시·조준 중·조준해서 집중했을 때의 별도 옵션을 둔다. 탄퍼짐·반동 감소 각각 상시·조준 중의 별도 옵션을 둔다. 조준 조건부 옵션은 같은 효과의 상시 옵션보다 높은 수치를 준다.
- 장비당 옵션 하나는 유지한다. 예를 들어 상시 반동 감소 장비와 조준 중 반동 감소 장비는 별개다. 한 장비가 상시/조준 보너스를 동시에 두 개 제공하는 결정이 아니다.
- 무기 자체의 거리/조준 조건과 장비 옵션의 조건은 별도로 평가하는 방향이다. 상시 치명타 확률 장비를 무기의 조건부 확률이 켜질 때만 적용하는 것으로 제한하지 않는다. 피해 종류별 치명타 적용 대상과 여러 확률/배율의 합산 방식은 미결이다.

| 효과 | 상시 시작값(AI 제안) | 조준 중 시작값(AI 제안) |
|---|---|---|
| 치명타 확률 | +3%p | +6%p |
| 치명타 피해 | +10% | +20% |
| 탄퍼짐 감소 | −10% | −15% |
| 반동 감소 | −15% | −25% |

수치는 조건 강도를 비교하기 위한 미검증 제안이며 사용자 수락 전이다. 치명타 피해 수치는 최종 치명타 피해에 곱하는 비율 제안이며, 확률 증가량은 %p다. 조준 상태를 유지하기 쉬운 무기에서는 조건부 옵션이 사실상 상시이므로 실제 플레이에서 비교한다.

집중 조건은 사용자 후속으로 확정: 차오르는 동안은 조준 중으로 보고, 집중은 완료된 다음 한 발만 뜻한다. 조준을 유지하는 동안 집중 준비 상태가 되어도 조준 중이라는 조건 자체가 사라지는 것은 아니다. 장비당 옵션 하나 규칙은 유지한다.

집중 완료 한 발은 이미100%여서 집중 전용 치명타 확률 증가는 효과가 없다. 집중 전용 치명타 피해 증가는 효과가 있다. 따라서 AI는 집중 전용 확률 옵션을 제작 목록에서 제외할 것을 제안하며, 사용자 확정 전이다. 보장100%를 낮추거나100% 초과 확률을 추가 피해로 전환하지 않는다. 집중 전용 치명타 피해 +30%는 첫 비교용 AI 제안(상시 +10%, 조준 중 +20%와 비교)이며 미검증·수락 전이다.

### 집중 조건 명확화 이력

- 2026-10-29 이전: 집중이 차는 동안까지 포함하는지 미결.
- 같은 날 사용자: 차오르는 동안은 조준만 하는 상태, 집중은 완료된 한 발만 의미한다고 명시. 집중 전용 확률 옵션의 실효 없음과 제작 제외 제안은 별도로 구분했다. [기록013](log/013-doc-focus-option-trigger.md).

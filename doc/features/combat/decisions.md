# 전투 — 결정 본문

## C-30 조준 표시의 의미와 강조 보강

- 결정: 기존 C-30 조준·퍼짐·반동 규칙은 유지한다. 일반 조준은 중앙점(조준 위치), 상하좌우 눈금(조준 퍼짐), 대각 눈금(현재 퍼짐이 더 넓을 때) 역할을 구분한다. 기준 눈금14×4px는 유지하고 보조 대각은10×2.5px/알파0.65~0.9로 낮춘다. 열기·명중 번짐은6겹으로 부드럽게, 집중 원은 어두운 바탕+황금 번짐/밝은 중심으로 표시한다.
- 이유: 사용자 요청 「타겟 조준도 개선」과 의미 없는 표시 제거/있는 정보의 인지 개선. 조준 중심/기준 퍼짐에 우선순위를 주고 Esc 조작법에서 의미를 설명한다.
- 상태 · 날짜: `[현재 구현]`, 수치는 제작값·외형 최종 수락 전 · 2026-10-27.
- 표시 의미: 대각 한 줄의 붉은 열기는 연사 상태, 안쪽 눈금 주황/빨강은 유효/최대사거리 경고, 대각 두 줄은 실제 내 공격 명중, 황금 원은 집중 진행과 다음 한 발 치명타 준비(C-32). 한국어/영어 `hud_reticle_legend`로 안내한다. 조준 보조나 명중 보장 규칙을 추가하지 않는다.
- 범위: 무기 데이터·사거리·퍼짐·반동·집중 타이머/소비·치명타 판정은 변경하지 않는다. 장전/충전 고정 네 점 제거는 [M-33](../menu-ui/decisions.md#m-33-장전충전-포인터와-반투명-진행-ui).
- 근거: 사용자 요청, [Hud.cs](../../../game/scripts/UI/Hud.cs), [무기 규격 8장](../../weapon-spec.md), [검사·렌더 기록](../menu-ui/log/003-code-reticle-clarity.md). 기존 C-30 원문은 [전체 결정 기록](../../decisions.md)의 표에 그대로 보존한다.

### 바뀐 결정 — 외형 강조

이전에는 주/보조 눈금이 모두14×4px였고 대각 열기/명중의 번짐은 넓은 두 선이었다. 이후 기준 눈금 크기를 유지하고 보조 눈금만 낮추며 상태 번짐과 집중 원의 재질감을 통일한다. 근거는 표시의 우선순위를 읽기 쉽게 하라는 이번 사용자 요청이다. 기존 동작의 의미는 바뀌지 않는다.

새 결정은 여기 ID 아래에 쓰고, [전체 색인](../../decisions.md)에는 ID · 한 줄 요약 · 상태 · 날짜 · 링크만 한 줄로 적는다. 결정 ID는 지금처럼 영역 접두사(D · M · C · T · L · A · Q)를 쓴다.

**옛 기록은 옮기지 않고 그대로 있다**(2026-10-26 결정, [기록 문서 나누기](../../records-split-plan.md) 6.4). 이 기능의 2026-10-26 이전 결정 · 이슈 · 확인 기록은 [decisions.md](../../decisions.md) · [issues.md](../../issues.md) · [feature-checklist.md](../../feature-checklist.md)에 있다.

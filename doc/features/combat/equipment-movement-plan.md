# 장비 두 슬롯 · 자동 달리기 · 구르기 설계 초안

작성: 2026-10-29. 상태: **걷기·자동 달리기·구르기 구현·검사 완료, 플레이 수치 조정 예정. 장비 슬롯은 후속.** 관련 결정: [C-1 · C-34 · C-35](decisions.md), 기존 C-2 · C-31 · C-32 · L-23 · Q-28은 [전체 결정 기록](../../decisions.md). [구현 계획](movement-implementation-plan.md).

## 1. 목적과 경계

- 사용자 목표: 캠페인 샛길에 들를 만한 장비 보상을 주되, 내구도와 달리기 조작처럼 신경 쓸 것을 늘리지 않는다.
- 캠페인은 레벨이 없고 저장은 최소화한다. 일반 전투의 개별 패턴은 단순하게, 보스는 패턴 대응을 요구한다. 저장 지점·내용·주기는 이번에 정하지 않았다(L-23 재시도와 Q-28 이어하기는 구분).
- 자동 달리기는 전투 사이 이동과 잠깐 공격을 멈췄을 때의 재배치를 돕는다. 이미 시작된 추격을 속도로 따돌리는 수단으로 만들지 않는다.
- [게임 방향](../direction/game-direction.md)의 성장 없는 캠페인과 [캠페인 경험](../direction/details/campaign-experience.md)을 바탕으로 한다. 장비를 반복 파밍하는 영구 수치 성장이나 강화·등급 체계를 승인한 것은 아니다.
- 최초 범위는 설계 정리였다. 후속 사용자 요청으로 걷기·자동 달리기·구르기만 먼저 구현한다. 장비 슬롯·저장 시스템·유료 상품·새 아이템·카드는 후속 범위다.

## 2. 비교한 접근과 선택

| 접근 | 장점 | 부담 | 대화에서 정한 상태 |
|---|---|---|---|
| 수동 달리기 + 구르기 공용 기력 | 달리기와 회피 사이 자원 선택 | 기력과 달리기 조작을 계속 관리 | 최초 사용자 후보 → 자동 달리기로 변경 |
| 기존 구르기 5초 재사용 대기시간 | 사용할 수 있는 시점이 단순 | 급한 순간 연속 회피 불가, 기존 무적은 새 의도와 다름 | 기존 구현 이력, 이번 설계에서는 변경 |
| 자동 달리기 + 기본 구르기 2회 충전 | 이동 조작 부담 감소, 필요하면 연속 회피 | 속도 전환·충전 및 무적 제거 후 체감 조정 필요 | 사용자 선택. 한 칸씩 순차 회복하며 추가 사용 도중에도 진행 유지. 회복 6초·달리기 대기 2초·걷기 3.6m/s·달리기 4.2m/s는 사용자 수락한 임시값 |

구르기 직후 일시적으로 달리기 보너스를 주는 안도 논의했으나, 사용자와 걷기로 복귀하는 방향을 정했다. 빨라짐 → 느려짐 → 자동 달리기의 별도 순환은 넣지 않는다.

## 3. 장비 슬롯과 샛길 보상

### 사용자 확정

- 모자와 갑옷 **2개 슬롯**. 모드 1 캠페인과 모드 3 난전에 적용하며 모드 2는 보류한다.
- 기능 옵션을 붙이고, 당장은 내구도를 두지 않는다.
- 장비당 기능 옵션은 우선 하나로 한다(사용자 수락). 여분 장비는 들고 다니지 않는다. 현장에서 같은 슬롯의 장비로 교체하면 기존 장비는 바닥에 내려놓는다.
- 협동에서는 바닥 장비 하나를 팀이 공유하며 먼저 획득한 사람이 착용한다. 같은 장비를 각자 한 번씩 받는 개인 보상이 아니다. 교체하며 바닥에 내려놓은 장비는 다른 팀원도 획득할 수 있다(사용자 확정). 한 보상 지점에 배치할 장비 개수·빈도와 AI 동료의 획득 행동은 별도 미결이다.
- 캠페인 샛길에는 모자·갑옷·가끔 특수 무기 중 하나를 배치해 우회할 이유를 준다. 모든 샛길의 보상 보장 여부·빈도·인원별 수량은 미정이다.
- 일반 장비로 구르기 최대 충전을 늘리는 아이템은 현재 제작 범위에 없다.

### 옵션 후보 — 실제 아이템 제작 확정 아님

| 후보 | 출처와 상태 | 남은 설계 |
|---|---|---|
| 고글의 밝은 시야 각도 확대 | 사용자 예시 | 각도·시야 공유와의 관계. 벽 투시는 승인하지 않음 |
| 고글의 치명타 확률 증가 | 사용자 예시 1% | 기존 집중 치명타 C-32와 별개 확률 판정인지, 적용 대상·중첩 규칙. AI 제안은 증가량을 %p로 명시 |
| 갑옷의 이동속도 증가 | 사용자 예시 1% | 걷기/달리기 중 적용 대상과 상한. 자동 달리기가 좀비보다 느려야 한다는 목표와 함께 조정 |
| 갑옷의 탄창 최대용량 증가 | 사용자 예시 10% | 소용량 탄창의 정수 처리, 무기별 적용 범위 |
| 구르는 동안 받는 피해 감소 | 사용자 후보 | 적용 피해·감소량. 기본 무적이나 기본 피해 감소 확정이 아님 |
| 구르기 충전 회복시간 단축 | 사용자 후보 | 단축 수치·중첩·충전 진행 중 장비 교체 처리 |

AI 제안 중 장비당 대표 옵션 하나와 여분 보관 없는 현장 교체는 사용자 수락으로 위 확정 항목에 반영했다. 샛길 장비 없이도 진행 가능하게 설계하는 것과 고글을 모자 슬롯에 포함하는 분류는 여전히 제안이며 외형 커스터마이징과 기능 장비의 연결 방식은 미정이다. 예시 1%·10%는 밸런스 확정값이 아니다.

## 4. 자동 달리기

### 사용자 확정

- 별도 달리기 입력이나 공용 기력을 관리하게 하지 않는다.
- 조준하거나 총을 쏘거나 피해를 받으면 걷기. 그런 상태가 끝나고 일정 시간 지나면 자동으로 달린다.
- 자동 달리기 대기는 **2초를 임시 기준**으로 잡고 플레이하면서 조정한다. 조준 중에는 전환하지 않고, 조준 해제·마지막 발사·피격·구르기 종료 중 가장 늦은 시점부터 센다.
- 기본 이동 속도는 **걷기 3.6m/s·자동 달리기 4.2m/s를 임시 기준**으로 잡고 플레이하면서 조정한다. 장비·무기·상태 보정의 적용 방식은 아래 미결 항목과 구분한다.
- 자동 달리기는 전투 사이 이동과 잠깐 공격을 멈췄을 때의 재배치를 돕는 편의 기능이다.
- **자동 달리기 상태에서도 좀비보다 느려야 한다.** 발각 전에 이동해 교전을 피할 여지는 두되, 추격이 시작되면 싸워 정리하는 쪽이 유리해야 한다. 절대적인 탈출 불가능 규칙을 추가하는 뜻은 아니다.
- 구르기 종료 후 걷기로 복귀한다. 별도의 구르기 후 추가 감속 벌칙이나 일시 달리기 보너스는 이번 안에 넣지 않는다.

### AI 제안과 미결

- 제안: 걷기 상태에서도 일반 전투가 성립하도록 조정한다.
- 미결: 무기별 이동 보정과 장비 옵션의 합산 순서, 속도 전환의 완만함. 기본 걷기 3.6m/s·자동 달리기 4.2m/s·대기 2초는 사용자 수락한 임시값이다.
- 미결: 근접 공격·장전·투척·치료·상호작용·쓰러짐·부활·이동 장치에서의 전환 조건. 기존 상태 잠금을 자동 달리기가 무시하지 않도록 설계해야 한다.
- 구르기 충전이 비었다고 기본 이동을 제한하는 규칙은 제안하지 않는다.

## 5. 구르기

### 사용자 확정

- 기본 최대 충전은 **2회**. 급하면 첫 구르기를 끝낸 뒤 두 번째 구르기를 연속 사용할 수 있다.
- 소비한 충전은 **한 칸씩 순서대로 회복**한다. 두 번째 구르기를 써도 이미 진행 중인 회복은 초기화하지 않는다. 현재 회복 중인 한 칸이 완료되면, 비어 있는 다음 칸의 회복을 이어서 진행한다.
- 새 충전 회복은 **구르기 종료 시점부터** 시작한다. 두 번째 구르기를 사용해도 이미 시작된 회복은 위의 진행 보존 규칙을 따른다.
- 한 칸 회복은 **6초를 임시 기준**으로 잡고 플레이하면서 조정한다. **두 번째 구르기 동작 중에도 이미 진행 중인 회복은 계속 흐른다.** 추가 사용은 회복을 초기화하거나 일시정지하지 않는다.
- **기본 무적은 없다.** 피해 감소는 갑옷 옵션 후보로만 남긴다.
- 구르는 도중 일반 공격을 맞으면 **피해를 받고, 자동 달리기 대기시간을 갱신하되, 구르기 동작 자체는 끝까지 이어진다.**
- 동작 종료 후 걷기로 복귀한다. 피격 순간 구르기를 걷기 동작으로 강제 교체하지 않는다.
- 최대 충전 증가는 일반 획득 장비로 만들지 않는다. 치트·테스트용 아이템 수준의 확장 가능성만 열어 둔다. 그 아이템을 지금 만드는 요청은 아니다.
- 모드 3 난전의 특수옵션으로 최대 충전을 늘리는 경우는 **검토 후보**다. 실제 카드·옵션 제작 확정이 아니다.
- 초기 대화의 유료 아이템 가능성은 후속 설명으로 범위에서 제외한다. 유료 상품·판매·가격을 계획하지 않는다.

### AI 제안과 미결

- 미결: 시작·부활·스테이지 전환 시 충전량. 구르기 종료 시 회복 시작·순차 회복·추가 구르기 중에도 회복 지속은 사용자 확정이고, 기본 회복 6초는 사용자 수락한 임시값이다.
- 미결: 일반 피격 외의 경직·잡기·강제 이동 처리. 일반 피격에도 동작이 계속된다는 결정으로 모든 상태이상 면역을 부여하지 않는다.
- 치명적인 피해로 쓰러지거나 사망한 경우까지 구르기를 유지한다는 뜻은 아니다. 기존 사망·쓰러짐 우선 처리를 유지하는 것은 AI 구현 제안이다.
- 기존 적 옆 밀어내기·통과와 낮은 전방 도약 모션(C-2)은 이번 대화에서 변경하지 않았다. 무적 제거 후 실제 근접 공격이 명중할 수 있는지 함께 검증해야 한다.

## 6. 구현 착수 전 코드 확인 이력

2026-10-29 구현 착수 전 소스 확인이며 당시 런타임 검증은 아니다. 아래는 당시 상태를 보존한 이력이고 최신 변경은 10장과 작업 기록을 따른다.

- [Player.cs](../../../game/scripts/Player/Player.cs): `RollCooldown = 5f`, `RollTime = .42f`, `RollSpeed = 10f`. `TryStartRoll`은 재사용 대기시간을 검사하며 2회 충전 시스템이 아니다.
- 같은 파일 `TakeDamage`는 `IsRolling`이면 피해를 무시한다. 새 결정 C-1에 따라 제거할 동작이며, 아직 고치지 않았다. `Launch` 등의 별도 구르기 면역 분기도 함께 확인해야 한다.
- 같은 파일의 이동은 `Definition.MoveSpeed`와 무기·장전·치료·카드 보정을 쓴다. 이번 계획의 자동 달리기 상태는 구현 전이다.
- [CharacterAppearance.cs](../../../game/scripts/Characters/CharacterAppearance.cs)의 모자·고글 표시와 새 기능 장비 슬롯은 별도 계약이다. 외형 부품이 있다는 이유로 기능 장비가 구현됐다고 보지 않는다.
- [무기 규격](../../weapon-spec.md)의 C-32는 집중 후 다음 한 발 치명타다. 치명타 고글을 기존 확률 수치에 단순 가산할 수 있다고 가정하지 않는다.

## 7. 구현 계획 전에 정할 것과 검증 기준

이번 합의로 위의 모든 미결 사항을 승인한 것으로 보지 않는다. 이동과 장비는 나눠 구현할 수 있으며, 먼저 작업할 범위를 고른 뒤 그 범위의 계약을 닫는다.

1. 이동·구르기: 상태별 전환과 이동 보정의 합산 규칙을 정한다. 걷기 3.6m/s·자동 달리기 4.2m/s·한 칸 회복 6초·자동 달리기 대기 2초는 임시 조정값이다. 충전은 구르기 종료부터 순차 회복하며 추가 구르기 중에도 초기화·정지 없이 계속된다.
2. 장비: 여분 보관 없음·현장 교체 시 기존 장비 바닥 배출·옵션 하나·팀 공유 장비 선착순 획득·내려놓은 장비의 팀원 재획득은 확정. 획득 조작·별도 벗기, 보상 지점별 배치 수량, AI 동료 적용, 시작·재시도·복귀·스테이지 이월, 외형과의 관계를 정한다. 저장 최소화라는 목표만으로 저장 내용을 임의 결정하지 않는다.
3. 검증: 조준·연사 중 달리기 금지, 사격 중단 후2초 자동 전환, 피격 시 대기시간 갱신, 구르기 중 피해와 동작 지속, 연속 2회와 충전 소진, 구르기 종료 시 회복 시작·한 칸씩6초 순차 회복·두 번째 구르기 중에도 회복 지속·현재 칸 완료 후 다음 칸 회복, 기본 무적 없음, 일반 장비에 최대 충전 증가 없음.
4. 검증: 기본 걷기 3.6m/s·자동 달리기 4.2m/s 전환과 좀비보다 느린 속도 관계를 확인한다. 감염체 추격·좁은 길·군중 상황에서 도망만 반복하는 것이 유리하지 않은지, 피격 후 계속 얻어맞는 상태에 갇히지 않는지 실제 플레이로 본다. 장비·무기 보정이 있는 상태도 포함한다.
5. 검증: 멀티 권한·상태 동기화, 전용 검사 장면과 `Integration.tscn`, 실제 렌더의 이동·피격·충전 표시. 지금 실행한 검사가 아니라 향후 구현의 확인 기준이다.

참고작: 이번 규칙의 출처는 사용자 대화와 현재 프로젝트다. 다른 게임의 상세 수치를 가져오거나 외부 리서치를 수행하지 않았다.

## 9. 첫 플레이 테스트용 시간과 속도 — 사용자 수락한 임시 기준

| 항목 | 사용자 수락한 임시 시작값 | 의도 |
|---|---|---|
| 구르기 한 칸 회복 | 구르기 종료부터 6초 | 기본 2회로 급한 상황을 넘기되 회복마다 구르기를 반복하는 비중은 제한 |
| 자동 달리기 대기 | 마지막 관련 행동 종료/발생 후 2초 | 잠깐 공격을 멈춘 재배치와 전투 사이 이동의 편의 |
| 기본 걷기 | 3.6m/s | 전투 중 위치 조정과 기본 회피 |
| 기본 자동 달리기 | 4.2m/s | 걷기보다 약 17% 빠르면서 일반 감염체 기준 4.55m/s보다 느린 이동 편의 |

- 대기 기준: 조준 중에는 달리기로 전환하지 않고, 조준 해제·마지막 실제 발사·피격·구르기 종료 중 가장 늦은 시점을 기준으로 2초를 센다. 충전 회복은 이 대기시간과 별개다. 조준 해제 외 기타 상태 계약은 4장의 미결 사항을 따른다.
- 충전 예시: 첫 구르기 종료를 t=0으로 두고 회복 시작. 1초쯤 뒤 두 번째 구르기를 써도 t=6에 한 칸, 추가 사용 없이 t=12에 두 칸이 된다. 이미 진행 중인 회복은 추가 구르기 도중에도 계속된다. 6초는 사용자 수락한 임시값이며 최종 밸런스 확정값은 아니다.
- 비교: 회복 4초부터 시작하면 비축 2회와 반복 회피의 여유가 커질 수 있고, 8초면 두 번 소모한 뒤 회피 없는 시간이 길 수 있다. 자동 달리기 1초는 짧은 사격 간격에도 전환이 잦고, 3초 이상은 짧은 재배치에 늦을 수 있다. 모두 AI 예상이며 체감 검증 전이다.
- 근거: 현재 `Player.cs`는 구르기 시작부터 5초 대기, 동작 0.42초·속도 10m/s다. 일반 플레이 종 4개의 기본 속도는 4.4m/s이며 [기존 추격 검사](../../common-monster-play-review.md)는 일반 감염체 4.55m/s를 기록했다. 이는 기존 코드·과거 검사값이며 새 자동 달리기 수치나 이번 실측이 아니다.
- 속도 판단 근거(AI 계산): 기존 구르기 0.42초·10m/s를 유지하고, 종료 후 걷기 2초·달리기 4초 뒤 충전되는 구르기를 즉시 반복하는 정상 주기를 가정하면 평균은 `(10×0.42 + 3.6×2 + 4.2×4) / 6.42 ≈ 4.39m/s`다. 초기 비축 2회의 순간 이득, 장애물·공격 준비·피격·이동 보정은 제외한 계산이며 실제 추격 검증을 대신하지 않는다. 기존 기본 이동 4.4m/s 대비 걷기는 약 18% 느려지므로 사격 중 답답함도 확인한다.
- 주의할 균형: 달리기 속도가 좀비보다 느려도 구르기로 번 거리를 회복 주기마다 다시 벌리면 장기 도주가 가능할 수 있다. 두 번 비축한 순간 탈출과 장기 반복 도주를 구분하고, 걷기·달리기 속도, 구르기 거리, 6초 회복을 함께 실제 추격에서 조정한다. 숫자만으로 사용자 목표 충족을 보장하지 않는다.
- 시작 수치의 조정 기준: 첫 시도는 6초/2초. 회피 부재가 답답하면 회복 5초와 비교하고, 반복 도주가 유리하면 구르기 거리·기본 이동 속도까지 함께 검토한다. 시간만 계속 늘리거나 피격 대기를 길게 해서 해결하지 않는다.

## 10. 이동 구현 범위와 초기 처리

- `PlayerMovement.cs`가 자동 달리기 대기·충전 수/회복을 관리한다. 캐릭터 리소스의 `MoveSpeed`는 걷기 속도이며 달리기는4.2/3.6배. 기존 무기·치료·장전·카드 보정 후 일반 이동은4.2m/s 상한을 적용한다. 구르기·밀려남·강제 이동은 상한 대상이 아니다.
- 상한은 AI 구현 판단: 기관단총110%만 적용해도4.62m/s로 감염체4.55m/s를 넘으므로 사용자 요구를 지키기 위한 처리다. 카드의 양수 이동 보너스도 상한 아래에서만 유효하다. 카드별 구르기 거리 효과는 유지하며 난전의 상세 밸런스는 후속이다.
- 새 플레이어는 충전2회·걷기 상태로 시작한다. 쓰러짐/사망 중 회복은 정지하며 부활 시 소비 상태를 유지하고 자동 달리기 대기를 다시 센다. 새 스테이지의 새 Player는 충전2회로 시작한다. 장비/충전 영구 저장 계약을 추가하지 않는다.
- 사다리·짚라인·곤돌라의 기존 이동/공격 잠금을 유지하고 돌아오면 대기를 거친다. 강제 구르기 취소는 충돌 마스크를 복원하고 충전 회복 시작을 누락하지 않는다.
- 일반 피해는 Player와 적 근접 판정 양쪽에서 구르기 무적을 제거한다. 특수 Launch/잡기 면역은 기존대로 남으며 이번 일반 피해 결정으로 상태이상 규칙까지 변경하지 않는다.
- 실제 무기 발사(예약 점사 포함)·받은 피해에 대기를 갱신한다. 치료·장전·조준·투척 조준·충전/거치 공격·상호작용 입력 중 달리기를 막고 기존 감속을 유지한다.
- HUD는0/2·1/2·2/2와 다음 충전 진행·초를 표시한다. 멀티 프로토콜20은 충전 수·다음 회복시간·시작 여부·처리한 구르기 입력 카운터를 보내며, 아직 처리하지 않은 로컬 입력보다 옛 스냅샷으로 충전을 돌려주지 않는다. 피해 수신은 방향이 없어도 걷기로 복귀한다.
- [검사·렌더·남은 제약](log/006-code-automatic-movement-roll.md). 수치의 최종 사용자 체감 수락은 실제 플레이 후다.

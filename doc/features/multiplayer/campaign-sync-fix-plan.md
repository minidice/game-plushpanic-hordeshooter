# 캠페인 멀티 진행 복구·재발 방지 실행 계획

2026-10-29. 사용자 승인 범위: 점검에서 확인한 문제를 권장 순서대로 모두 수정하고 검증·재발 방지까지 수행한다. 기준 `7a6da8f`, I-135 → I-136 → I-137 → I-90, 별도 실패 I-72 확인. 기존 작업 트리에서 직접 구현하고 마지막에 독립 리뷰한다.

## 설계와 선택

- 좌표: cm 정밀도를 유지하는 signed24를 사용한다. 기존16비트 범위를 단순 확대해 맵을 줄이거나 정밀도를 낮추지 않는다. 32비트보다 스냅샷 증가가 작고 약±83km를 표현한다. 범위 밖/비정상 값은 전송 전에 실패시켜 조용히 잘리지 않게 한다. Pos 크기를 상수화하고 패킷 길이 검사와 프로토콜을 함께 변경한다.
- 사다리/집라인: 호스트가 실제 이동을 실행하고 소유자와 관전자는 전체3D 위치·이동 종류를 따른다. 완료 때 이동 revision을 올려 이전 위치 입력이 착지를 덮어쓰지 못하게 하고 소유자가 새 revision을 수신한 뒤 정상 이동을 재개한다. 시작/종료/다운·취소와 높은 단의 일반 위치 추종을 검사한다.
- 곤돌라: 호스트의 출발/진행/완료와 탑승자 상태를 월드 상태에 포함한다. 클라이언트는 연출만 적용하고 자율 출발·완료 판정을 하지 않는다. 도착 위치는 위 이동 revision으로 보장한다. 늦은 합류는 완료된 곤돌라 뒤의 유효한 시작 위치를 사용한다.
- 다음 스테이지: 살아 있는 파티의 클리어 후 출구 요청을 호스트가 승인한다. 지속되는 NetLobby가 다음 맵/씨앗과 플레이어별 이월 상태를 보관하고 새 장면 준비/시작을 조정한다. 로딩 동안 기존 timeout 보호를 적용한다. 새 참가자는 현재 맵을 받는다. 기존 오프라인 전환 연출·장비 이월을 유지한다.
- 재발 방지: 좌표 경계·모든 실제 맵 장치·늦은 합류·착지 뒤 이동·두 프로세스 연속 전환을 한 실행 스크립트로 묶는다. 실패 시 즉시 종료하고 결과 manifest를 남긴다. 배포 검증은 같은 소스/데이터에서 통과한 결과만 인정하며, 실패를 통과할 때까지 반복하거나 기본값으로 바꾸지 않는다.

## 작업·검증 순서

1. I-135: `NetCodecCheck`에 기존 범위 경계와 큰 맵 좌표/비정상 값 검사를 추가해 실패 확인. `NetCodec`, `NetMessages`, `NetSurfaceHit`, `NetLobby.Protocol` 수정. 코덱·대역폭·표면 사건 회귀 및 캠페인 후반 장치 요청 확인.
2. I-136: 기존 `CampaignInteractionAudit` 실패를 기준으로 `PlayerNet`, `PlayerLadder`, `Player`, `StageNet`, 스냅샷 계약 수정. 모든 사다리 양방향/집라인·3D 추종·이전 입력 거부·착지 후 이동 확인. 검사 준비용 호스트 위치 보정을 제거해 소유자 위치 전송을 직접 검증한다.
3. I-137: `Gondola`, World 상태 및 late-join 배치 수정. 출발 전 전원 탑승·진행/완료·도중/완료 뒤 합류·이탈을 확인한다. 두 프로세스로 pause 독립성도 확인한다.
4. I-90: `NetLobby`, `Stage`, `StageCarry`, `StageTransition`의 온라인 장면 전환 연결. 실제 두 프로세스에서1→2→3 및 장비/체력·재시작·늦은 합류 검증. 마지막 맵은 종료 화면이다.
5. I-72: 적 위치 오차의 원인을 추적해 검사 시간 기준/실제 위치 처리 중 확인된 원인만 수정한다. 기존 임계값을 완화하지 않는다.
6. `Run-CampaignMultiplayerChecks.ps1` 검증 묶음, 문서·이슈·체크리스트 갱신, 전체 관련 회귀와 Integration 실행, 창 모드 렌더 확인, 독립 리뷰. 코드와 해당 작업 기록을 같은 커밋에 포함한다.

## 검토 초점

- 큰 음수 좌표·범위 밖 값·패킷 길이/버전 불일치.
- 착지 직전/직후 늦게 도착한 입력과 스냅샷, 다른 플레이어에게 보이는 높이.
- 곤돌라 중간/완료 후 참가자와 호스트/클라이언트의 독립 pause.
- 장면 로딩 순서 차이·느린 참가자·이탈·늦은 합류의 현재 맵/장비 일치.
- 기존 로비 복귀·오프라인 전환·짧은 시나리오·문/경보·파괴 사건 회귀.

- 작업1~4 완료: 큰 좌표·호스트 연출 이동/revision·곤돌라 World·캠페인 연속 전환/개인 Carry/epoch를 구현하고 최종 전용 검사와 두 프로세스 검사 통과.

## I-72 후속: 로컬 위치 동기화 검사 간헐 실패 (2026-10-29)

- 증상: `a5b1a49` main 병합 후 NetSyncCheck 1차에서 원격 플레이어 위치 오차0.88m(기준0.3m), 2차에서 적 추적 평균0.39m/최대1.91m(기준0.3m/1m)로 실패했다. 같은 코드·인수의 3차는32개 모두 통과했다.
- 원인: 미확정. 타이밍/실행 부하 가능성은 추정이며 이번 UI/보급 변경의 회귀 또는 기존 네트워크 결함이라고 단정하지 않는다.
- 해결: 미해결. 검사 임계값이나 네트워크 코드를 바꾸지 않았다. 재실행 통과를 해결 증거로 취급하지 않는다.
- 재발 방지·검사: 같은 장면의 원격 위치/호스트 이력 비교와 로그를 보존한다. 실제 두 PC의 지연·손실 조건에서 추가 확인해야 한다.
- 배포 EXE 두 프로세스의 로컬 접속·초기 상태 동기화는 성공했다. 이것이 이동 품질·완주를 보장하지 않는다. [실패/통과 로그와 배포 범위](../level/log/019-check-campaign-main-integration.md).

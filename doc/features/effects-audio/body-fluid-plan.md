# 사망 체액 흔적 — 설계·실행 계획

사용자 요청: 밝은 무작위 원형 페인트를 짙고 점성 있는 체액처럼 바꾼다. 초록·파랑·노랑도 탁하고 깊은 색을 사용한다. 코드·셰이더로 먼저 만들고 실제 바닥에서 확인하는 추천안을 승인했다.

## 선택과 범위

- 코드·셰이더 평면: 불규칙한 고임/가장자리/가까운 방울을 한 메시로 표현, 시간에 따라 젖은 반사가 줄어든다. 이번 선택.
- 손그림 텍스처: 세밀한 고유 튐을 제어하기 좋지만 추가 이미지 제작/관리 필요. 후속 선택지.
- 입체 모델: 높은 두께/옆면이 필요할 때 유효하나 현재 탑다운의 얇은 바닥 흔적에는 불필요.

`BodyFluidSplat`은 점성이 높은 넓은 덩어리와 짧은 늘어짐, 주변 작은 방울을 그린다. 생성 초기에만 조금 퍼지고 약25초에 광택이 줄며 어두워진다. 올리브/남청/황토3종은 몬스터 계열별로 고정한다. 구체 색·시간·종류 연결은 제작값이며 사용자 최종 수락 전이다. 무해한 시각 효과이고 색에 전투 상태 의미를 추가하지 않는다.

일반/풍선 사망에 연결한다. 기존 솜 파편·사망 섬광·시체는 보존하며 새 순간 방울은 소량만 추가한다. 기존 `PaintSplat`을 쓰던 폭발/보스 내려찍기는 무채색 건조 흔적으로 분리해 죽지 않았는데 체액이 생기는 일을 피한다. 승인된 폭발/화염/독 영역 효과는 수정하지 않는다. 최대160개의 기존 흔적 큐와 오래된 순 제거를 유지한다. 높이는 Stage.Tiers의 실제 지면을 사용하되 경사/단차 전체 투영은 범위 밖이다. 별도 이미지·GLB·전투/네트워크 계약 변경 없음.

## 실행·검증

1. 실제 사망의 밝은 페인트 검사 실패 확인 → 공통 체액 셰이더/수명·재질 구현 → 일반/풍선/비사망 호출 구분.
2. 전용 검사: 실제 죽음/색 계열, 무해한 노드, 젖음→건조, 높이,160개 제한·삭제, 비사망 흔적 색. 실제 장면과 색3종·밝은/어두운 바닥 렌더.
3. 순차 빌드·가져오기·전용·Integration·DestructionNetCheck 회귀. 새로운 효과는 기존 combat effects 프로필을 수정하지 않으므로 해당 외형 재제작은 하지 않는다.
4. A-19 후속 결정/색인, 상세 규격·체크리스트, 새017 작업 기록을 코드와 같은 커밋에 포함한다. 워크트리에서 검토 가능하게 마무리한다.

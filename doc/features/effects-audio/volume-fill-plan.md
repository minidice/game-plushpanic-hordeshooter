# 바닥 그림 없는 공간 채움

2026-10-27 사용자가 추천안 실행 승인. 큰 반투명 덩어리를 겹쳐 중앙과 외곽의 빈 공간을 연결하고 작은 고정 불꽃으로 질감을 남긴다. 기존 Godot C# 생성기와 연기 아틀라스를 사용한다.

선택: 입자를 대량 추가하거나 바닥 면을 복구하는 대신 기존 연기층의 카드 크기·분포·시간을 조정한다. 화면 가림과 비용 증가를 줄이기 위해 화염 연결층만 소폭 증량하고 연무 수는 유지한다. 폭발의 외곽 범위는 유지하며 내부 덩어리만 보강한다. 피해·음향·독은 변경하지 않는다.

- [x] `AreaSurfaceVisual.cs` / `area_smoke_particles.gdshader`: 화염 연기층을 넓은 낮은 따뜻한 연결층으로 조정. 초기 빠른 중앙 확산 후 제자리 흐름, 잔연기는 기존 회색으로 돌아가며 개별 소멸. 연무는 같은 수의 더 넓은 카드로 연결.
- [x] `BurstReachVisual.cs`: 외곽16개는 유지, 내부8→12개와 크기 보정으로 중앙~중간 빈 공간 연결. 기존 수명·전방 편향·알파 상한 유지.
- [x] 변경 전후 Studio 전체 수명 렌더 비교, 기존 AreaEffectsCheck/CombatEffectsCheck/BurstRadiusCheck, 실제 HUD·보스 예고 중첩과 성능 검증. 시각 수치 조정이므로 구현을 복제하는 새 단위 검사는 만들지 않는다.
- [x] A-27/A-28/A-29·상세 규격·체크리스트와 새014 작업 로그 기록, 독립 읽기 리뷰와 커밋.

검수 초점: 첫 확산이 다시 갑자기 켜지지 않는지, 불꽃이 자리를 옮기지 않는지, 잔흔이 피해로 남지 않는지, 짧은 수명·일시정지·부모 제거, 12개 중첩의 캐릭터/HUD 가독성. 부드러운 경계는 픽셀 판정선이 아니며 첫 프레임의 전체 위험 범위를 정확히 표시하지 않는다.

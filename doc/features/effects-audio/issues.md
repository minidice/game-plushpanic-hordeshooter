# 이펙트 · 소리 — 이슈 본문

새 이슈는 여기 ID 아래에 쓰고, [전체 색인](../../issues.md)에는 ID · 한 줄 증상 · 상태 · 날짜 · 링크만 한 줄로 적는다. 새 이슈 ID는 전체 번호(`I-126`부터)를 쓰고, **색인에 한 줄을 먼저 추가해 커밋 · 푸시한 뒤** 본문을 쓴다(먼저 예약). 푸시가 막히면 받아서 다음 번호로 바꾼다.

## I-64 기존 근거리 음량·혼합 출력 — 2026-10-27 추가 측정

- 기존 본문과 상태는 [전체 이슈의 I-64](../../issues.md)에 보존했다. 새 ID 발급이나 해결 처리 없음.
- `AudioPilotCapture`에서 Master float 출력의 0 dBFS 초과를 실제 오디오 장치로 확인했다. 가까운 신음과 군중 중첩 조건을 나누었으며, 정확한 조건·수치·재현은 [작업 기록](log/001-art-sound-quality-pilot.md).
- 확인된 사실: 일부 3D 소리는 근거리 상한이 없어 +3 dB 재생기 상한으로 커지고, 여러 재생기 합산은 별도다. 테스트에서 Master limiter는 없고, 캡처 뒤 모니터 감쇠는 측정에 영향을 주지 않는다. 사용자 기기의 모든 찢어짐 원인을 이것 하나로 확정하지 않는다.
- 후속 해결/재발 방지: 후보 선택 후 근거리 상한·군중 동시수·총합 여유를 조정하고 같은 거리/중첩 조건을 다시 측정한다. 최종 출력 제한과 소리 신호의 식별성도 확인한다.

### I-64 후속 적용 — 부분 해결, 2026-10-27

- 위 내용은 변경 전 측정 이력이다. 현재는 요청된 피격/쓰러짐/신음/사망/풍선/황소 충돌 및 좀비 피격에 근거리 상한을 적용한다. 신음/사망은 최대3개이며 초과 요청을 건너뛴다.
- 최종 Master sample-peak limiter(-1 dB)를 추가하여 여러 목소리 합산을 제한한다. `AudioSetup.Ensure` 반복 호출에 중복 설치하지 않는다. 원본의 거친 음색이나 실제 장치의 모든 왜곡을 복구하는 처리는 아니다.
- 검사: `AudioQualityCheck.tscn`(상한/변형/동시수/볼륨), 창 모드 `AudioQualityCapture.tscn`(20조건, 신호·완전성·피크), `AudioMixCheck.tscn`(플레이어 행동별 상대 음량). [결과 기록](log/002-art-sound-quality-rollout.md).
- 남은 제약: 분대원 사격·폭발 등 나머지 3D 소리의 근거리 상대 밸런스는 아직 기존 동작이다. 최종 합산 초과 방지와 개별 3D 감쇠 재설계는 구분하며 I-64 전체는 열린 상태를 유지한다.

- 검증 경로 정정: 상태효과 캡처는 버스 직접 토글 대신 실제 플레이어 상태를 사용하고 캡처 시작/끝의 활성 상태를 검사한다. 이전 효과 지속 미확인과 후속 전투/통합 검증은 [003 기록](log/003-check-combat-soak-main-integration.md)에 남긴다.

## I-74 피격 식별 음량 — 변형 후속 검사, 2026-10-27

- 기존 피격음 과다 음량 해결 이력은 전체 색인에 보존한다. 새 파일 적용 후 작은 B 변형이 pitch0.96에서 소총보다14.4 dB 낮아 기존 식별 하한(14 dB 아래보다 커야 함)을 벗어났다.
- honk 재생 게인을 -2→-1 dB로 조정했다. 출력 상한/원본/피치 범위는 유지한다. AudioMixCheck는 두 변형 각각을 pitch0.96/1.04로 실제 피격 호출에서 재생하며 양쪽 상·하한을 검사한다.
- [실패 재현·조정·검증 기록](log/003-check-combat-soak-main-integration.md). 최종 주관적 음량 선호는 아직 확정하지 않는다.

### I-64 전투 반복음 후속 — 부분 해결 유지, 2026-10-27

- 소총·장전 시작/완료·빈 탄창에 NearCap 추가. 새 파일이 -6dBFS 이하 헤드룸을 가지므로 소총 +7dB는 원본 대비 보정이며, 실제 총구3D 피크 약 -0.9~-0.8dBFS(SFX, limiter 이전)로 확인한다. 다른 총·폭발의 상대 밸런스는 미해결이다.
- 좀비 피격은 3변형·최대3개·초과 생략으로 군중 재시작을 줄인다. 기존 피격/사망 호출과 피해 판정은 그대로다.
- [004 기록](log/004-art-combat-sound-update.md): 세 소총 변형×피치 양끝, 기존 피격 두 변형×피치 양끝, 30발 연사·군중 중첩 포함27캡처. 전체 3D 감쇠 재설계나 인간 피로도 검증을 완료로 보지 않는다.


### I-64 재질 접촉음 후속 — 부분 해결 유지, 2026-10-27

- 새 발소리/환경 명중/파손은 NearCap·priority0·계열별 최대2~3개·초과 생략을 사용한다. 적 피격과 환경 충돌을 구분하고 총/행동 신호를 덮는 반복 재시작을 줄인다. 최종 Master limiter는 기존 -1dB를 유지한다.
- `SurfaceAudioCheck`는 실제 발밑/사격막/사격/파손 호출을, `AudioSurfaceCapture`는 변형34개·발소리7계열·중첩1의 실제 출력을 검증한다. [005 기록](log/005-code-surface-audio.md).
- I-64 전체 해결 아님: 다른 무기의 상대 밸런스, 장시간/실제2PC, 사람의 자연스러움·피로도 청음은 남는다. 새 이슈를 발급하지 않고 기존 음량 후속으로 관리한다.

### I-64 전체 근거리 상한 후속 — 기술 적용, 청음 제약 유지, 2026-10-27

- 위 단락은 단계별 이력이다. 현재는 `SoundDef.NearCap` 기본 true로 등록된 모든 효과음에 레시피+호출 게인 상한을 적용한다. 폭발 +1/황소 경고 -3으로 큰 폭발+2/보스+6 호출도 보정했다. 경고 priority2, 화염/환경 반복 및 좀비 발소리의 초과 재시작 생략을 적용한다.
- 재발 방지: `AudioBalanceCheck`는 모든 ID의 실제 감쇠 호출·부착 소리·풀 우선순위를 검사한다. `AudioBalanceCapture`는 거리/분대/군중/경고/바닥과 Cues의 실제 장치 출력을 기록한다. 최종 합산 limiter와 개별 상한을 구별하며 합산 전 신호가0dBFS를 넘을 수 있다.
- [구현008](log/008-code-audio-balance-followup.md) · [최종 통합·실제 출력009](log/009-check-surface-followup-integration.md). 캡처의 파일/소스 지문과 실제 음원 SHA를 검사해 이전 결과를 재사용하지 않는다.
- 상태는 부분 해결 유지: 상한 누락 구현은 닫았지만 최종 음색·피로도 수락, 모든 보스/무기 조합의 청취, 물리적으로 다른 두 PC의 실전 지연/손실은 자동 검사로 확정하지 않는다. 새로운 ID는 만들지 않는다.

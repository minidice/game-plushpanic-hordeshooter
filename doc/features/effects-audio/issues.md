# 이펙트 · 소리 — 이슈 본문

새 이슈는 여기 ID 아래에 쓰고, [전체 색인](../../issues.md)에는 ID · 한 줄 증상 · 상태 · 날짜 · 링크만 한 줄로 적는다. 새 이슈 ID는 전체 번호(`I-126`부터)를 쓰고, **색인에 한 줄을 먼저 추가해 커밋 · 푸시한 뒤** 본문을 쓴다(먼저 예약). 푸시가 막히면 받아서 다음 번호로 바꾼다.

**옛 기록은 옮기지 않고 그대로 있다**(2026-10-26 결정, [기록 문서 나누기](../../records-split-plan.md) 6.4). 이 기능의 2026-10-26 이전 결정 · 이슈 · 확인 기록은 [decisions.md](../../decisions.md) · [issues.md](../../issues.md) · [feature-checklist.md](../../feature-checklist.md)에 있다.

## I-64 기존 근거리 음량·혼합 출력 — 2026-10-27 추가 측정

- 기존 본문과 상태는 [전체 이슈의 I-64](../../issues.md)에 보존했다. 새 ID 발급이나 해결 처리 없음.
- `AudioPilotCapture`에서 Master float 출력의 0 dBFS 초과를 실제 오디오 장치로 확인했다. 가까운 신음과 군중 중첩 조건을 나누었으며, 정확한 조건·수치·재현은 [작업 기록](log/001-art-sound-quality-pilot.md).
- 확인된 사실: 일부 3D 소리는 근거리 상한이 없어 +3 dB 재생기 상한으로 커지고, 여러 재생기 합산은 별도다. 테스트에서 Master limiter는 없고, 캡처 뒤 모니터 감쇠는 측정에 영향을 주지 않는다. 사용자 기기의 모든 찢어짐 원인을 이것 하나로 확정하지 않는다.
- 후속 해결/재발 방지: 후보 선택 후 근거리 상한·군중 동시수·총합 여유를 조정하고 같은 거리/중첩 조건을 다시 측정한다. 최종 출력 제한과 소리 신호의 식별성도 확인한다.

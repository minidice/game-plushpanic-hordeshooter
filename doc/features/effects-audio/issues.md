## I-64 기존 근거리 음량·혼합 출력 — 2026-10-27 추가 측정

- 기존 본문과 상태는 [전체 이슈의 I-64](../../issues.md)에 보존했다. 새 ID 발급이나 해결 처리 없음.
- `AudioPilotCapture`에서 Master float 출력의 0 dBFS 초과를 실제 오디오 장치로 확인했다. 가까운 신음과 군중 중첩 조건을 나누었으며, 정확한 조건·수치·재현은 [작업 기록](log/001-art-sound-quality-pilot.md).
- 확인된 사실: 일부 3D 소리는 근거리 상한이 없어 +3 dB 재생기 상한으로 커지고, 여러 재생기 합산은 별도다. 테스트에서 Master limiter는 없고, 캡처 뒤 모니터 감쇠는 측정에 영향을 주지 않는다. 사용자 기기의 모든 찢어짐 원인을 이것 하나로 확정하지 않는다.
- 후속 해결/재발 방지: 후보 선택 후 근거리 상한·군중 동시수·총합 여유를 조정하고 같은 거리/중첩 조건을 다시 측정한다. 최종 출력 제한과 소리 신호의 식별성도 확인한다.

### I-64 후속 적용 — 부분 해결, 2026-10-27

- 위 내용은 변경 전 측정 이력이다. 현재는 요청된 피격/쓰러짐/신음/사망/풍선/황소 충돌 및 좀비 피격에 근거리 상한을 적용한다. 신음/사망은 최대3개이며 초과 요청을 건너뛴다.
- 최종 Master sample-peak limiter(-1 dB)를 추가하여 여러 목소리 합산을 제한한다. `AudioSetup.Ensure` 반복 호출에 중복 설치하지 않는다. 원본의 거친 음색이나 실제 장치의 모든 왜곡을 복구하는 처리는 아니다.
- 검사: `AudioQualityCheck.tscn`(상한/변형/동시수/볼륨), 창 모드 `AudioQualityCapture.tscn`(20조건, 신호·완전성·피크), `AudioMixCheck.tscn`(플레이어 행동별 상대 음량). [결과 기록](log/002-art-sound-quality-rollout.md).
- 남은 제약: 분대원 사격·폭발 등 나머지 3D 소리의 근거리 상대 밸런스는 아직 기존 동작이다. 최종 합산 초과 방지와 개별 3D 감쇠 재설계는 구분하며 I-64 전체는 열린 상태를 유지한다.

- 검증 경로 정정: 상태효과 캡처는 버스 직접 토글 대신 실제 플레이어 상태를 사용하고 캡처 시작/끝의 활성 상태를 검사한다. 이전 효과 지속 미확인과 후속 전투/통합 검증은 [003 기록](log/003-check-combat-soak-main-integration.md)에 남긴다.

## I-74 피격 식별 음량 — 변형 후속 검사, 2026-10-27

- 기존 피격음 과다 음량 해결 이력은 전체 색인에 보존한다. 새 파일 적용 후 작은 B 변형이 pitch0.96에서 소총보다14.4 dB 낮아 기존 식별 하한(14 dB 아래보다 커야 함)을 벗어났다.
- honk 재생 게인을 -2→-1 dB로 조정했다. 출력 상한/원본/피치 범위는 유지한다. AudioMixCheck는 두 변형 각각을 pitch0.96/1.04로 실제 피격 호출에서 재생하며 양쪽 상·하한을 검사한다.
- [실패 재현·조정·검증 기록](log/003-check-combat-soak-main-integration.md). 최종 주관적 음량 선호는 아직 확정하지 않는다.

# 연료통 폭발 개선 계획

사용자 승인: 2026-10-27, 추천한 연료통 폭발부터 진행. 기존 화염·연무 질감을 공유하며 순간 폭발과 지속 범위 효과의 리듬을 구분한다. 구현 수치는 제작자 조정값이다.

## 설계와 범위

기존 구형 메시의 크기/색 조정만으로는 텍스처의 부드러운 가장자리를 얻기 어렵다. 새 아틀라스 제작 대신 기존 연무/불꽃 텍스처를 재사용하는 카메라 대면 카드를 선택한다. `barrel`만 빠른 섬광/팽창, 뒤따르는 연기, 개별 소멸 잔불로 변경한다. 바닥 링은 생략한다. 피해/충돌/사운드와 다른 폭발 프로필은 유지한다.

## 실행 계획

- [x] `BarrelBurstVisual.cs`를 추가하고 `CombatBurstEffect`에서 barrel에만 연결한다. 명시적 `Advance(age)`로 Studio/일시정지 동일 재생, 기존24폭발/4광원 제한 유지.
- [x] `combat_effects.json`의 barrel 시각 수명을2.4초로 조정한다. 섬광 약0.14초, 주 화염 약0.6초, 잔불 약1.3초, 연기2.4초 이내 개별 소멸. 기존 lobes/particles/spread/rise/color 수치를 사용한다.
- [x] `CombatEffectsCheck`에서 새로운 재질과 무충돌/종료 계약을 검사하고 수명 대기를 데이터 기반으로 수정한다. 전체 전용검사와 파괴 회귀 실행.
- [x] 실제 Studio의 변경 전후 프레임과 게임 렌더 확인. 늦은 연기 급소멸/카드 가장자리/가독성 확인.
- [x] 결정/규격/기능 현황/새 작업 기록을 갱신하고 독립 리뷰 후 자기 변경만 커밋한다.

## 검토 초점

짧은 duration에서도 각 단계는 전체 수명 안에 끝나야 한다. 입자0·덩어리0의 허용 데이터와 폭발/광원 상한을 보존한다. 부모 제거 시 모든 장식이 함께 사라져야 한다. 연기는 벽을 피하는 물리 시뮬레이션이 아니며 잔불은 새 피해 지대가 아니다. 실제2PC/저사양 성능은 별도 검증이다.

# 사운드 품질 게임 적용 계획

2026-10-27. 사용자의 “현재기준으로 나머지 작업”에 따라 시제품 방향으로 9종을 적용한다. 개별 청음 승인을 기다리지 않고 제작자가 선택하며, 최종 취향 확정과 구분한다.

## 설계와 완료 조건

- 기존 3종 A/B를 발성 변형으로 사용한다. `honk`는 피격 전용, 카드·무기 경적은 `honk_ability`로 분리한다. 이름은 소리 ID만 바꾸며 카드/무기 식별자는 유지한다.
- 나머지 6종: 긴 거위 반응, 공기 팽창/파열, 둔탁한 충돌, 부드러운 오리지널 하강/상승 악구. CC0 소스와 제작 레시피를 보존한다. 결과 악구는 직접 합성한 악기이며 녹음이라고 표현하지 않는다.
- PCM16 mono 48 kHz, 원음 피크 ≤ -6 dBFS. 기존 3종 후보는 보존하고 게임 배포본을 따로 생성한다.
- 요청한 3D 효과와 좀비 피격에 근거리 상한, 신음/사망 동시수 제한. 그 밖의 3D 소리 밸런스는 별도 검토이므로 I-64는 부분 해결로 기록한다.
- 결과음/UI/귀울림은 상태효과 없는 `Cues` 버스로 보내며 효과음 볼륨을 따른다. Master에 -1 dB ceiling limiter 하나를 설치한다.
- 파일 변형은 `<id>_2.wav`부터 레시피의 명시 개수만 로드하며, 직전 변형을 연속 선택하지 않는다. 기존 Stream(id)는 대표 음원을 반환해 Studio 계약을 유지한다.

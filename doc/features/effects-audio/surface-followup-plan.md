# 재질 사운드 후속 병렬 작업 계획

2026-10-27. 사용자가 남은 계획 작업의 멀티에이전트 실행을 요청했다. 기준 `4bacc0d`. 이전 표면 적용 계획은 완료했으며, 명시적으로 남겨 둔 구현/검증을 아래 세 작업으로 이어간다. 무료 소재 정책·기존 물리/내구도·피해 판정은 유지한다.

## 구현 계약과 소유권

1. **원격 환경 명중음** — `surface_net_followup` 독립 worktree. 호스트가 실제로 판정한 접촉의 프리셋/위치를 Shot에 최대3개 전송한다. misses/적 피격은 제외한다. 클라이언트의 환경음 예측은 억제하고 서버 확인음을 한 번 재생하되 자기 총성/섬광의 즉시 예측은 유지한다. 네트워크 버전/표면 데이터 해시를 갱신하고 기존 피해·파손 이벤트와 분리한다. Net/WeaponController/SurfaceAudio 및 전용 테스트, 기록006 소유.
2. **Studio 표면 편집·저장** — `surface_studio_editor` 독립 worktree. 환경 오브젝트의 기존 프리셋 선택과 공용 프리셋의 발/명중/파손 추가 게인만 편집한다. 공용값의 영향 범위를 표시한다. null 장식/소환수는 조회용이며 임의 물리값은 추가하지 않는다. 고정 경로·기존 ID·유한 범위 검증·원본 버전 충돌 확인·원자적 저장을 적용하고 Studio 데이터 재조회, 실행 중 게임 재시작/멀티 PC 데이터 일치 필요를 표시한다. Studio 서버/UI/bridge/SurfaceProfiles 및 테스트, 기록007 소유.
3. **남은 근거리 상한·혼합 출력** — `audio_balance_followup` 독립 worktree. 아직 상한이 없는 총/폭발/경고/행동음에도 일관된 NearCap을 적용한다. 실제 호출의 추가 게인과 분대 감쇠를 고려하고 경고 우선순위/군중 제한을 확인한다. 기존55 WAV/원본41개는 유지한다. SoundRecipes 및 전용 출력 검사 장면, 기록008 소유. 실제 오디오 장치 캡처는 통합 담당만 실행한다.

공유 파일을 동시에 편집하지 않고 각 담당은 자신의 커밋을 반환한다. 통합 담당이 중앙 규격/결정/이슈/체크리스트/기록009를 갱신하고, 반환 커밋을 현재 오디오 worktree에 순서대로 적용한다. 이전 사용자의 커밋·병합·푸시 요청을 이어 최종 검증 후 원격 main에 fast-forward 통합한다. 기존 원격 이력/다른 작업의 미추적 파일과 실행 중인 기본 Studio는 보존한다. 최종 준비 중 기본 main 폴더에서 다른 기획의 미커밋 문서 변경이 확인되어, 그 체크아웃은 자동 stash/수정하지 않고 검증된 worktree의 HEAD를 원격 main으로 푸시한다.

## 검증으로 대체할 수 없는 범위

최종 음색/피로도 수락은 사용자 청음이 필요하다. 현재 연결된 실행 호스트는 로컬 PC이므로 실제 두 PC/네트워크 조건은 주장하지 않고 로컬 ENet 방장·클라이언트 검증으로 구분한다. 종별 발성 새 소재, 무기마다 다른 장전 녹음, 적 투사체/근접/동적 물체의 추가 재질 이벤트는 이전 계획의 구현 항목이 아닌 확장 아이디어이므로 이번 완료 조건에 새로 끼워 넣지 않는다.

# 피해 반경과 보이는 효과 범위 맞추기

2026-10-27 사용자 피드백: 효과 밖의 대상이 피격되어 보이면 이상하므로 실제 피해 범위와 위협으로 읽히는 범위를 비슷하게 맞춘다. 바닥 원/그림 제거 방향은 유지한다.

원인: 실제 R은 전달되지만 기존5종 밝은 덩어리의 중심은 대개0.5R 안쪽이고 텍스처 투명 여백 때문에 가시 범위는 더 작다. 로켓은 전체 중심이0.65R 전방으로 이동해 후방 피해와 어긋난다. 드럼통은 더 넓지만 투명 여백과 개별 분포 때문에 같은 검수가 필요하다.

- [x] 폭발 중심 연출은 유지하고 실제 R 기준 전 방향의 짧은 공간 입자층을 추가한다. 지면 면/연속 원 선은 만들지 않는다. 중심에서 빠르게 퍼지고 개별 소멸한다. 로켓 방향 강조는0.25R로 줄인다.
- [x] 화염 착탄도 같은 범위층을 쓰고 지속 불꽃 뿌리 반경은0.77R→0.94R로 맞춘다. 중앙 순차 점화/고정 위치/개별 소멸은 유지한다. 독은 기존 약0.98R 지면 표시, 연무는 피해 없는 시각 표본이므로 피해 경계를 새로 만들지 않는다.
- [x] 실제 Blast의0.95R 안/1.05R 밖 표적 피해와 사방 반경 표본을 렌더한다. 게임에는 검사 표식이 없다. 폭발/영역 전용 검사와 파괴 회귀·중첩 성능 확인.
- [x] A-27/A-28/A-29 수치·범위 계약과 새 작업 로그를 함께 기록한다. 피해/반경/음향 코드는 변경하지 않는다.

주의: 폭발은3D 거리이며 적은R 경계에도+15피해, 플레이어는R 미만. 드럼통 연쇄/소품1.4R는 별도 상호작용이고 일반 공격 반경으로 그리지 않는다. 화염은 수평 반경이며 초기 확산 중에도 전체 반경 피해가 유효하다. 자연스러운 부드러운 가장자리와 화면 투영 때문에 픽셀 단위 판정선을 보장하지 않는다.

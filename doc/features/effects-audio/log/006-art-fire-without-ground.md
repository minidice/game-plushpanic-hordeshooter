# 바닥 그림 없는 화염

2026-10-27. A-27 후속. 사용자가 원 테두리 제거 후에도 “바닥 그림 없이 자연스럽게” 표현해 달라고 요청했다.

- 지속 화염에서 지면 면을 생성하지 않는다. 열기 무늬/바닥 색/그을음은 표시하지 않고, 종료 뒤에는 기존2초 수명의 옅은 연기만 남긴다. 그을음 원본 PNG와 생성 도구는 보존하지만 화염에서 로드하지 않는다.
- 실제 착탄에서 다시 바닥 링이 나타나지 않도록 fire 계열 순간 효과의 바닥 충격파 면도 생성하지 않는다. 다른 폭발·독의 바닥 표현은 유지한다. 연무 표본은 이번 화염 수정 범위에서 제외한다.
- 바닥 표시가 없어도 활성 시작이 읽히도록 불꽃은 시작부터 최대 농도의35%로 보이고0.32초 동안 자연스럽게 차오른다. 피해 반경·DPS·수명·광원·음향에는 변경이 없다.
- 일시정지 검사는 제거된 지면 셰이더에 의존하지 않도록 실제 화염 수명과 정지 화면 픽셀/재개 뒤 잔연기 전환을 확인한다.
- 기존 A-27의 현재 본문/색인/바뀐 결정, 상세 VFX 규격과 기능 체크리스트를 갱신했다. 사용자 외형 조정이며 새 결정/버그 ID는 불필요하다.

## 검증

- Debug 빌드 오류0·경고0.
- `AreaEffectsCheck` 창1600×900 **36통과**: 밝고 어두운 바닥·벽/단차·원거리 실제 렌더, 수명/정리/잔흔 제한, 일시정지 화면 동일 및 재개 뒤 수명 진행.
- `CombatEffectsCheck` 창1600×900 **92통과**: 실제 화염 착탄/지속/종료, 독/폭발 기존 경로와 전투 중첩. 두 검사 로그에 오류/종료 경고 없음.
- Studio 지속 화염을7.167초/87프레임 재렌더해 바닥 무늬 없이 불꽃이 유지되고 종료 뒤 바닥에 그을음이 남지 않는 것을 확인했다. 전체 음향/네트워크/성능 검사는 이번에 재실행하지 않았다.
- 첫 Studio 요청은 서버가 빌드 중일 때 보내 연결 거부로 실패했다. 준비 완료를 확인한 뒤 다시 요청해 성공했으며 제품 코드 수정으로 우회하지 않았다.
- 로컬 산출물: `game/output/area-effects/no-ground/`, `fire-no-ground.gif`, `no-ground-AreaEffectsCheck.log`, `no-ground-CombatEffectsCheck.log`. `git diff --check` 통과.

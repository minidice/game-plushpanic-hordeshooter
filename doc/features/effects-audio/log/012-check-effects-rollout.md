# 효과 확장 병렬 작업 통합과 검증

관련 ID: A-27, A-28, A-29. 사용자 요청: 현재까지 외형 수락, 현재 방향의 남은 작업을 멀티에이전트로 진행.

## 완료 범위

- 별도 worktree 두 개에서 가독성 검사와 기존5종 폭발 외형을 병렬 구현하고, 역할별 독립 리뷰 뒤 부모 `codex/area-effects`에 합쳤다. 중간 통합은 가독성 `14b61ca`, 폭발 `cead4da`였고 최종적으로 같은 작업의 코드/공유 문서를 한 커밋에 묶었다. 담당 원본은 각각 `a34cf8a`, `5a06144`이며 기록010/011을 코드와 함께 포함했다.
- 화염·연무·연료통의 기존 코드/셰이더/JSON이 기준8d2a16a와 동일함을 diff로 확인했다. 그 외형에 대한 사용자 수락을 A-27/A-28에 반영하고, 이전 지면 마스크/데칼/그을음 계획은 폐기된 이력임을 표시했다.
- blast/grenade/rocket/mortar/lure만 기존 정의로 텍스처 질감을 확장했다. 게임 피해·음향·서버 권한·새 연막 판정·VFX 품질 메뉴는 변경하지 않았다. 기존 공격 예고는 유지한다.
- 결정 A-29·상세 규격·기능 체크리스트·후속 실행 계획을 갱신한다. 별도 버그를 발견하지 않았으므로 새 이슈 ID는 발급하지 않았다.

**실패와 제약을 구분:** 첫 Integration은 headless `--fixed-fps 60`의 가속 실행에서104개 진행 뒤 `awake zombies nearby groan` 검사에 실패했다. 사운드는 실제 오디오 재생기의 Playing/동시 재생 상한을 사용하므로 가속 시뮬레이션과 오디오 벽시계 차이가 영향을 줄 가능성이 있다(추정, 단일 원인 확정 아님). 코드를 바꾸지 않고 저장소 표준 방식의 headless 실행으로 재검사해149개 통과했다. 이 실패를 폭발 결함으로 확정하거나 삭제하지 않는다. `rollout-integration.log`와 `rollout-integration-realtime.log`에 각각 보존했다. 사운드 세션의 코드를 수정하지 않았다.

최종 전용·가독성·부하·표준 Integration 실행에는 ERROR/WARNING/FAIL이 없다. 가속 Integration의 실패와 명확히 구분한다. 다른 기기·장시간 안전성을 주장하지 않는다.

## 성능과 실제 화면

RTX5070Ti, Forward+,1600×900, VSync/프레임 제한 해제. 동일 숲과 고정 적20개, 각6초에서 처음1.5초 제외. 시간은 프레임 간격이고 GPU 단독 측정이 아니다.

## 산출물과 재현

- `game/output/area-readability/`: 담당자가 생성한 일반/축소 조건 PNG·coverage.json·실행 로그를 부모에 복사. 담당 worktree 정리 뒤에도 확인 가능.
- `game/output/area-effects/impact-bursts/`: 담당자의5종 전체 수명 프레임·로그 복사본.
- `game/output/area-effects/rollout-*.log`: 부모 영역/통합/전투/성능/Studio 실행.
- `game/output/vfx-performance.json` 및 조건별 PNG: 최종 통합 부하 측정.
- `game/output/area-effects/rollout-before/`: 확장 전5종 Studio 프레임 보존. 새 Studio 프레임과 비교 GIF 생성에 사용.
- `game/output/area-effects/burst-family-comparison.gif`·`burst-family-sheet.jpg`: 수류탄/로켓/박격포 위쪽 기존/아래쪽 개선 비교. `studio/output/combat-*`는 통합 후 최종 생성기의 전체 프레임.

기본 실행은 각 전용 `game/tests/*.tscn` 장면을 선택한다. `Start-Game.ps1 -Test`는 Integration만 실행하므로 전용 검사 실행을 대신하지 않는다. GPU 작업은 담당별로 직렬 실행했고, 사용 완료한 임시 worktree는 커밋/생성 산출물을 보존한 뒤 앱 archive 도구로 정리했다.

## 남은 제약

로컬에서 실행 가능한 구현/검수 범위를 마무리한다. 실제 저사양 GPU, 다른 두 PC/6인·장시간 플레이, 모든 카메라/지형·효과 조합은 미검증이다. 지형 투영/벽 우회 유체/새 연막 시야 판정은 원래 별도 범위다. 새 폭발5종의 최종 사용자 외형 수락은 별도이며, 현재까지 수락된 화염·연무·연료통 외형과 구분한다. main 병합/푸시는 하지 않는다.

# 화염·연무 계층과 무해한 잔흔

2026-10-27. A-27·A-19·T-25. 사용자가 참고 영상 기반 계획의 추천 작업 진행을 승인했다. 별도 사운드 작업과 음원/믹스 변경을 섞지 않는다.

## 변경

- 원본 절차 생성 도구와 PNG7개: 연무4변형 아틀라스, 연속 불꽃16프레임 아틀라스, 주기적 흐름 노이즈2개, 그을음3개. 알파 경계와 시간 반복 이음새를 생성기에서 검사하고 SHA256 manifest를 남긴다. `.import`·밉맵·`.uid` 포함.
- `AreaSurfaceVisual`: 깊이 기반 접점 감쇠를 쓰는 반투명 GPU 카드, 저층 연무, 불꽃/불티/얇은 연기와 지면 마스크. 고정 시드와 명시적인 시간 진행을 써서 게임과 Studio가 같은 생성기를 사용한다. 첫 렌더의 사선 노이즈를 제거해 덩어리가 다른 방향으로 풀리게 조정했다.
- `FireZone`: 반경·DPS·유효 수명·피해 반복·소리·광원 연결은 유지. 자연 종료 때 시각 노드만 Stage.Effects로 옮기고 피해 노드는 제거한다. 무해한 잔연기/그을음은 기본2초, 동시24개, 오래된 장식부터 정리한다. 부모 중도 제거는 잔흔을 만들지 않는다.
- 기존 독 웅덩이/폭발 생성기는 유지. `smoke_cloud`는 Studio 시각 표본이며 연막탄/시야 차단을 추가하지 않는다. 공통 JSON에 계열·농도·잔흔 수명을 엄격히 검증하고 Studio가 사용처·수치·잔흔까지 재생한다.
- A-27 결정 본문/색인, VFX 상세 규격, 기능 체크리스트, 승인 계획 현황을 기록한다. A-26과 log001~003은 동시 사운드 작업이 사용 중임을 확인해 피했다. 새로 발견한 제품 버그는 없어 새 이슈 ID를 발급하지 않았다. I-7/I-121의 불투명 원판/연기 재발 조건은 실제 렌더로 확인했다.

## 남은 제약

- 벽/단차 표본에서 일반 깊이 가림과 부드러운 교차선을 확인했다. 연무 입자 발생 위치는 벽 반대편에도 있을 수 있다. 벽을 우회하거나 차단하는 연기 시뮬레이션은 아니다.
- 그을음/지면층은 기존 바닥 높이를 쓰는 평면이다. 단차 위/경사로에 밀착되지 않는다. 바닥 전용 데칼 레이어와 다층 피해 판정은 후속이며, 외형만 바꾸고 해결됐다고 표기하지 않는다.
- 낮은 품질 전용 입자 LOD, 저사양 GPU·실제2PC/6인·장시간 검수는 미실행. 위험 지면은 입자 수 제한으로 제거하지 않는다.
- 외형/농도는 제작 시안이며 최종 사용자 취향 검수 전이다. 연무는 전투 기능에 연결하지 않았다.

# 화염 바닥의 원 테두리 제거

2026-10-27. A-27 후속. 사용자가 “바닥의 원이 범위는 명확하지만 너무 어울리지 않는다”고 지적했다.

- `area_ground.gdshader`의 연속 테두리 항을 제거하고 큰 흐름 노이즈에 따라 경계가 흐트러지는 열기 마스크로 바꿨다. 실제 반경 바깥은 계속 잘라내고 안쪽에서 넓게 감쇠한다. 불꽃 군집과 반투명 바닥 열기로 대략적인 범위를 전달한다.
- 정확한 피해 경계를 선으로 표시하던 A-27 초안의 선택을 변경했다. 결정 본문/색인·VFX 상세 규격을 갱신하고 이전 선택을 「바뀐 결정」에 보존했다. 새 기능/버그가 아닌 사용자 외형 피드백이므로 새 결정/이슈 ID를 만들지 않았다.
- 변경 범위는 지속 화염의 지면 셰이더다. 기존 피해 반경/DPS/유효 수명·사운드·잔흔 수명·연무 계산은 그대로다. 착탄 순간의 별도 충격파 연출은 이번 지속 화염 테두리와 다른 효과다.

## 검증

- Studio 실제 게임 생성기로7.167초/87프레임을 다시 렌더했다. 같은2.5초 시점의 이전/이후 렌더를 비교해 연속 원이 사라지고 불규칙한 열기가 바닥으로 부드럽게 풀리는 것을 확인했다. 시작부터 종료/그을음까지 재생 프레임 보존.
- `AreaEffectsCheck` 창1600×900: **36통과**. 밝은/어두운 바닥, 원거리, 벽/단차, 소멸/정리, 일시정지 중 픽셀 동일/재개 확인. 로그에 오류·종료 경고 없음.
- `git diff --check` 통과. 셰이더 외형만 바뀌어 새 단위 검사를 추가하지 않았고 전체 전투/음향 회귀는 재실행하지 않았다.
- 로컬 산출물: `game/output/area-effects/no-ring/` 프레임과 timing.json, `fire-no-ring.gif`, `no-ring-check.log`. Studio 로그에 셰이더 오류 없음. output은 생성 산출물이며 커밋하지 않는다.

남은 제약: 선을 제거했으므로 정확한 판정 경계의 가독성은 이전 원 표시보다 낮다. 불꽃/열기와 실제 위험 반경은 함께 유지하지만 화면의 흐린 가장자리를 픽셀 단위 판정 표시로 보장하지 않는다. 기존 평면/벽/단차 제약과 최종 사용자 외형 수락은 남는다.

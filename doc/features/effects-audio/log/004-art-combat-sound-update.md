# 전투 반복음 5종 녹음 편집·적용

- 관련: A-26, I-64 부분 해결 유지, I-74 피격 식별 회귀. 사용자 추천안 실행 승인. [설계·계획](../combat-sound-plan.md).
- 선정: 이전300초 통제 전투 소총1558회·좀비 피격1209회·장전 시작/완료 각31회. 반복 피로도·행동 식별·전투 청취·미술 방향·타이밍을 기준으로5종을 우선했다.

## 변경

- `shot_rifle`3변형(.30초): CC0 Free Firearm Sound Library의 AR-15 D_24P/D_32P에서3발을 편집. 고역·잔향을 줄이고 부드러운 압축으로 변형간 편차를 줄임.
- `zombie_hit`3변형(.20초): 기존 CC0 soft/wood impact 녹음 레이어. 사망 발성과 분리되는 짧은 접촉. 최대3개·초과 생략.
- `reload_start`(.28초) / `reload_end`(.23초) / `dry_fire`(.15초): CC0 에어소프트 장전 녹음의 서로 다른 구간과 짧은 기계 클릭. 실제 빈 총 녹음을 주장하지 않음. 무기 공용 유지.
- 새5종 모두 NearCap. 소총 재생+7dB, 피격-2dB, 장전 시작0/완료+1/빈 탄창+1. 파일 피크≤-6dBFS. 소총 최대50ms RMS 실제 약-19.0~-19.3dBFS. 양수 게인이 누락 파일의 합성 fallback까지 키우지 않도록 구형 합성 샘플에 반대 보정.
- 총14종/21 WAV와 import. 최초12파일 해시 불변. 소스12개 출처/CC0/해시와 오프라인 레시피 보존. API/MCP 신규 설치·과금 없음.
- 비교 페이지14종 단발(동일50ms RMS), 소총/좀비 피격 전후30회 반복, 최신 게임 통제 출력27조건. 캡처의 credits 및 오디오 구현3파일/캡처 시나리오 SHA-256이 현재 파일과 다르면 페이지 생성을 거부함.

## 검증 / 실패와 수정

- RED `AudioQualityCheck`: 적용 전45검사 중14실패(파일/변형/상한/동시수). fallback 피크 예산 검사 추가 후50검사 중5실패. 구현 후50/50 통과.
- 첫 실제 믹스: 소총+5dB에서 총구3D 피크-2.8dBFS, 휘두르기-4.6과 차이 부족. +7dB로 보정. 후속 검사에서 2D 샷과 총구3D 샷을 혼용하여 잘못된 피격 하한 실패 발생 → 실제 WeaponController와 같은 총구 PlayAt으로 시험 경로 정정. 기준 완화 없음.
- 최종 `dotnet build`: 오류0·경고0. Godot import 완료.
- `AudioQualityCheck.tscn`: 50 통과(14종 파일, 3변형, 군중, fallback 포함).
- `AudioLevelCheck.tscn`:4 통과. 소총 최대50ms 근사+게인 -10.5dB, 좀비 피격-18.6, 기존 경보/발소리 관계 유지.
- `AudioMixCheck.tscn` 창 모드: 15 통과. 소총3변형×피치0.975/1.025 총구3D 약-0.9~-0.8dBFS, 휘두르기-4.5, 걷기-19.6, 플레이어 피격2변형×피치0.96/1.04 약-13.3~-11.7, 경보-24.3. SFX limiter 이전값.
- `AudioQualityCapture.tscn` 창 모드: 27조건 통과. 5종 단독·30발 연사·6개 피격 요청 반복 중첩 추가. 전체 sample peak≤약-1.0dBFS, 0dBFS 초과0, 실신호/프레임수/상태효과 활성 검사. 직접 Sfx 호출의 통제 녹음으로 실제 판정 플레이와 구분.
- `Integration.tscn` headless, 고정fps 없음:149 통과.
- `release.py --page`:21파일 설치/원본 해시·PCM/피크/DC/끝점/import·크레딧, 비교RMS 차이<.05dB, 페이지 파일 링크 통과. `check.py`: 기존 시제품6개/소스12개/옛비교/링크 회귀 통과. 옛11캡처는 이전 시제품의 회귀 자료다.
- 브라우저에서14종 페이지 렌더·소총30회 재생 버튼이 일시중지로 전환되고 시간 스크러버가 활성화됨을 확인. 사람의 음색 청음 판정이 아님.

- 실행 로그: `game/output/combat-*.log`, 캡처 `game/output/audio-quality/capture.json`, 비교 `prototypes/audio-lab/output/index.html`. output은 로컬 재생성 산출물이며 커밋 제외.

## 결정·이슈 검토 / 남은 제약

A-26에 승인 범위 확대, I-64에 소총/기계음 상한·피격 군중 제한을 기록했다. 새 버그를 발급할 근거 없이 기존 믹스·식별 이슈 후속으로 관리한다. 피해·소음 반경·장전 시간은 변경하지 않았다.

최종 사용자 청음, 장시간 실제 플레이/다인 환경, 종별 발성, 무기별 장전 재질, 나머지 총·폭발의 3D 밸런스는 남는다. 이번 최종본으로5분 soak를 재실행하지 않았으며 이전5분 결과나 I-41 시체 누적 렌더 오류를 해결했다고 주장하지 않는다.

## 통합

- 충돌은 `doc/feature-checklist.md`와 이 기능 `decisions.md`의 같은 위치에 추가한 항목이었다. 양쪽 내용을 모두 보존했다. 런타임 코드의 겹친 수정은 없고 UI/사운드는 main, 영역 효과/FireZone 시각 잔흔은 이 작업의 구현을 유지한다.
- 병렬 작업의 로그 번호가 일부 겹쳤지만 `log/README.md`가 종류/주제가 다르면 원래 번호를 유지하도록 명시한다. 번호를 정리하려던 임시 변경을 되돌려004~015의 기존 파일명/링크를 보존했다. 링크 검사에서 발견한 이 폴더 log/README의 기존 상위 문서 상대 경로4개만 수정했다. 기능 문서39개에서 깨진 로컬 링크0개 확인.
- 독립 읽기 리뷰에 중요한 결함 없음. 두 부모의 구현, 화염 잔흔의 피해/음향 소유권, A-19/A-26/A-27/A-28/A-29 보존 확인. 임시 파일명 변경 중 남았던 번호 캡션도 기존 파일명 복구로 일치시켰다.

## 보존과 배포

main 작업 폴더의 미커밋 방향성 문서와 첨부물은 이번 커밋에 넣지 않는다. 최종 main 반영 직전 해당 diff와 파일 상태를 로컬 산출물에 보관하고, Git autostash를 이용해 미커밋 변경을 복원한 뒤 보존을 확인한다. 검증한 통합 이력만 fast-forward로 main에 반영하고 일반 push로 원격에 보낸다. 원격이 바뀌면 다시 fetch/통합하며 강제 푸시하지 않는다. 실제 푸시 결과와 최종 SHA는 완료 응답에서 보고한다.

새 기능·결정·문제 ID는 추가하지 않았다. 기존 외형 조정 내용과 한계는004~015 기록에 보존한다. 이 기록은 최신 main과의 호환성 및 통합 검사 근거다.

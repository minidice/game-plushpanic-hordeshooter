# 수락된 효과 보존과 나머지5종 범위 보정

관련 ID: A-27/A-28/A-29. 사용자: 화염탄·안개·화염통 폭발은 괜찮고 나머지만 범위를 적절하게 수정. [계획](../remaining-burst-radius-plan.md).

## 변경과 판단

- 화염 착탄/지속 화염/연무/연료통의014 결과를 외형 수락으로 기록했다. 기존 독의 범위 표시는 유지한다. 새로운 결정 ID나 피해 판정 이슈를 만들지 않고 기존 A-27/A-28/A-29의 현재 내용과 바뀐 결정을 갱신했다.
- 기본/수류탄/로켓/박격포/유인(`blast/grenade/rocket/mortar/lure`)5종만 `BurstReachVisual`에서 선택한다. 외곽16개 중심0.72~0.79R→0.84~0.90R, 너비0.66~0.74R→0.52~0.60R, 전체 범위층 높이0.12R→0.09R, ProximityFadeDistance0.15→0.3m. 외곽을 작은 덩어리로 더 멀리 분산하고 높이/지면 교차를 조정해 가까운 쪽의 빈 공간과 먼 쪽 시각 편향을 완화한다.
- 첫 높이0.035R 시안은 실제 렌더에서 바닥 교차 단면이 도드라져0.09R로 되돌리고 깊이 교차 감쇠를 넓혔다. 다시 렌더해 형태와 경계 표식을 확인했다. 바닥 면/링은 생성하지 않는다.
- 28카드 수, 내부12개의 수평 분포/크기, 시계/알파/수명/점진적 개별 소멸, 중심 폭발/파편과 실제 피해 반경/수치/소리/권한은 유지한다. 수락 대상은 기존 분기 값과 RNG 호출 순서도 그대로다. 새 에셋·음향 변경 없음.

## 검증

- 최종 코드 Debug 빌드 오류0/경고0. `BurstRadiusCheck` GPU1600×900 fixed-fps60 **62통과**, 종료코드0. 실제0.95R 안 앞뒤 적 피격/1.05R 밖 비피격, 사방 입자,6폭발0.07/0.15초와 화염 렌더 확인.
- `CombatEffectsCheck` 최초 가속 실행은 **171통과**를 출력했으나 종료 후 프로세스가 남았다. 해당 실행의 PID만 확인해 종료했다. 원인은 미확인이며 통과와 정상 종료를 구분한다. 최종 코드의 일반 GPU1600×900 재실행은 **171통과/종료코드0**, ERROR/WARNING/FAIL 없음. 종료 대기 문제를 해결한 코드 변경이나 메모리 안전 입증으로 주장하지 않는다.
- Studio는 최종 코드로 새로 빌드/가져오기, 전체12종 **74통과**. 원본 JSON 불변/전체 수명 렌더 확인.
- 변경 전014 Studio 이미지와 비교: fire_pool87, fire_impact25, smoke_cloud79, barrel50 = 수락 대상 **241프레임** 모든 픽셀 채널 동일. poison_pool79프레임도 동일하여 총320프레임 보존 확인. 다른5종만 변경된 경로임을 코드와 실제 렌더 양쪽에서 확인했다.
- 독립 읽기 리뷰: 구체적 코드 결함 없음. 수락 대상의 값/RNG 호출 순서, 판정/음향 불변, 카드 수/수명 유지 확인. 리뷰에서 직접 판정하지 않은 픽셀 경계·벽/단차·첫 프레임 전체R 표시는 기존 한계로 유지한다. 실제 렌더에서 일반 시점의 가까운 쪽/먼 쪽 분포와 바닥 교차를 별도로 검수했다.
- 구현 수치를 복제하는 새 단위 검사는 추가하지 않았다. 카드 수와 실행 경로 비용은 같고 크기/높이만 조정한 작업이므로 이전 부하5조건을 반복 실행하지 않았으며014 수치를 이번 측정으로 표시하지 않는다. 전체 Integration/음향/실제 다인·저사양은 이번에 재검증하지 않았다.

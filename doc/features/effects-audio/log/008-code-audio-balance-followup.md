# 나머지 3D 근거리 상한·우선순위 후속

- 관련: A-26, I-64, I-74. 기준 `4bacc0d`, 독립 `audio-balance-followup` worktree.
- 요청: 남은 사운드 작업의 객관적 밸런스 구현과 실제 출력 검증 경로. 수치는 제작자 선택이며 최종 사용자 청음 승인이 아니다.

## 변경

- `SoundDef.NearCap` 기본값을 true로 바꿨다. 남은 권총/SMG/LMG/산탄/저격/로켓/박격포·투척·접촉·행동·환경·경고음에도 레시피+호출부 게인이 근거리 상한으로 적용된다. 기존 `Sfx`의 단발/부착 재생 구현을 그대로 사용한다. 2D 재생 음량·버스는 바뀌지 않는다.
- 무기별 기존 게인(-2/-2/-1/+2/+3/+1/0)은 유지한다. `Companion`의 -8 dB 사격 감쇠가 가까이서도 작동한다. 이미 녹음으로 교체된31종/55WAV 및 소총/장전/빈탄창/좀비피격의 합성 fallback 반대 보정은 수정하지 않았다.
- 폭발 +4→+1 dB: `Blast`/기지의 최대 +2 dB 보정을 더해도 기존 근거리 +3 dB 상한을 넘지 않는다. 황소 콧김 0→-3 dB: 보스 최대 +6 dB 호출의 상한도 +3 dB로 유지한다. 기본/강한 호출의 차이는 이제 근거리에서도 보존된다.
- 소나·황소 예고·박격포 낙하를 priority2로 올려 총성이 찬 풀에서도 시작할 수 있게 한다. 이는 무조건 영구 보존이나 믹스에서 항상 식별된다는 보장은 아니다. 같은 priority2의 더 오래된 소리는 기존 정책대로 교체될 수 있다.
- 불/밤바람은 priority0·초과 생략, 기존 priority0 좀비 발소리도 초과 생략으로 맞춘다. 불은 실제 게임에서 전용 부착 emitter이며 기존 부착 개수 제한을 따른다. 배경음의 `Bed`는 풀 밖의 기존 경로다. 40개3D/10개2D 풀, ID별 최대수, 사격의 가장 오래된 음 재시작은 유지한다.

- 기존 `AudioLevelCheck.tscn`: 4/4 통과.
- 기존 `Integration.tscn`: 149/149 통과. 위 정상 실행 로그에 오류·종료 경고 없음.

## 실제 출력 캡처 인계

`Godot_v4.7.2-stable_mono_win64_console.exe --path game res://tests/AudioBalanceCapture.tscn`을 실제 장치에서 실행한다(`--headless` 금지). 이 분기에서는 오디오 장치 병행 사용을 피하려고 실행하지 않았다. 상위 작업에서 다른 캡처/300초 soak와 직렬 실행 후 통합 기록에 결과를 남긴다.

- 총69조건: 소총3변형 기준, 나머지7무기 × .5/8/20m·분대원(-8dB,pitch1.15)·4인8회 발사/군중 중첩35조건, 경고4, 보스+6/폭발0·+2, 근접9종, 불/박격포 부착2, Cues3종 단독/폭발5개 동시6, 실제 바닥 접촉 경로의7계열 발소리10회.
- 고정 피치 단독으로 거리/게인 차이를 분리하고 연사 군중에는 게임 jitter를 유지한다. 실제 `Stage` 리스너/`Sfx`/`SurfaceAudio.Step`을 사용하지만 사격/폭발은 통제된 호출이며 실제 피해·적 생성·네트워크를 재현하는 시험은 아니다.
- SFX·Cues(최종 limiter 전)와 Master(limiter 후) 각각 프레임/피크/RMS/0dBFS 초과를 기록한다. 실제 드라이버·실신호·프레임 완전성80% 이상·버퍼 유실0·유한값·Master≤-0.8dBFS·초과0을 요구한다. 거리 감쇠, 분대원 추가 감쇠6~10dB, 무거운 총과 가벼운 총의 구분, 소총 최대 변형 대비 경고/발소리 범위, 폭발 중 Cues 신호 유지도 검사한다. 음색/마스킹에 대한 사람 판단을 대체하지 않는다.
- 결과: `game/output/audio-balance/capture.json`, 정규화 없는 stereo WAV, 무손실 float `.f32le`. `passed`와 실패 이유, 장치 이름, credits/관련 코드/표면 데이터 SHA-256을 포함한다. 캡처 뒤 -80dB 모니터 감쇠는 측정에 영향을 주지 않는다. 모든 output은 재생성 산출물로 커밋하지 않는다.

## 범위·기록 판단

- I-64의 미구현 근거리 상한 누락은 이번 코드에서 닫는다. 상대 음량의 실제 장치 통과·최종 청음·피로도·실제2PC는 이 분기에서 완료라고 쓰지 않는다. 기존 I-74의 피격/소총 상대 계약은 변경하지 않았다.
- 종별 플레이어 발성, 무기별 장전 전용음, 투사체/근접 환경 재질 충돌, 동적 물체 충돌과 복합 재질은 기존 규격/계획의 후속 또는 범위 밖 항목이다. 이번 요청에서 디자인을 임의 발명하거나 이미 승인된 필수 구현으로 바꾸지 않는다.
- 새 결정/버그 ID를 발급할 사유는 없다. 기존 A-26/I-64 후속이며 중앙 색인·기능 결정/이슈·사운드 규격·체크리스트는 상위 통합 작업이 실제 캡처 결과와 함께 갱신한다. 시각적 게임 변경이 없으므로 별도 화면 렌더는 해당하지 않는다.

# 사운드 품질 1차 — 무료 소재 3종 A/B와 현재 믹스 측정

2026-10-27. 관련: A-26, 기존 I-64·I-74, T-25·T-26. 사용자: 전체 분위기 Escape from Duckov, 좀비 Left 4 Dead. 추천한 첫 단계 승인 후 무료 소재부터 진행하도록 선택.

## 변경

- [설계](../sound-quality-pilot.md)와 [실행 계획](../sound-quality-pilot-plan.md) 기록.
- `prototypes/audio-lab/`에 피격·신음·사망 각 A/B 후보 6개. 원본 7개, 출처·CC0·SHA-256, 편집 레시피 보존.
- 새 게임 적용 파일은 없음. 현재 공유 ID `honk`의 무기·카드 사용처를 바꾸지 않는다. 나머지 6종과 근거리/군중 믹스 개선은 선택 후 후속.
- Python+고정 버전 FFmpeg로 편집·측정·같은 음량 비교·HTML 생성. 후보 파일은 버전 관리, 비교 WAV/HTML/환경/보고서는 output 산출물.
- 테스트 전용 `AudioPilotCapture`에서 현재 게임의 3종 원음, 실제 Stage 리스너/Sfx의 거리 3종×3거리, 군중 사망, 사격 겹침 11조건 측정.
- `.f32le`에 잘리지 않은 믹스 보존. 청취본은 전체 배치에 공통 감쇠를 적용해 새로운 클리핑을 만들지 않는다. 캡처 뒤 모니터 감쇠는 스피커 출력만 줄이고 측정값에는 영향을 주지 않는다.

## 측정 근거

마지막 캡처: `game/output/audio-pilot/capture.json`.

| 현재 믹스 조건 | Master 피크 | 0 dBFS 이상 샘플 |
|---|---:|---:|
| 피격 0.5m | 약 -5.3 dBFS | 0 |
| 좀비 신음 0.5m | 약 +0.2 dBFS | 1 |
| 좀비 사망 0.5m | 약 -1.2 dBFS | 0 |
| 사망 6개 동시 | 약 +10.3 dBFS | 2,578 |
| 신음4·사망6·소총·피격 겹침 | 약 +9.5 dBFS | 7,089 |

이는 자동 통제 장면이며 일반 플레이의 빈도·전체 최악 조건을 측정한 것은 아니다. 재생 피치 흔들림 때문에 실행마다 수치가 달라진다. 기존 레시피 원본에 클리핑이 없어도 혼합 출력은 초과할 수 있음을 확인. 근거리 상한(I-64)과 전체 믹스의 여유·중첩 제한을 후속에서 함께 다룬다. **이번에 I-64를 해결한 것은 아니다.**

후보 6개: mono PCM16 48 kHz, 0.29/0.34/1.22/0.98/0.53/0.40초. sample peak -9.3~-6.0 dBFS 범위. 종류별 기존/A/B 청취 비교는 모두 50 ms RMS -20 dBFS(실제 PCM 재측정 차이 0.05 dB 미만). 이것은 시제품 제작값이지 확정 밸런스가 아니다.

- **통과**: `AudioPilotCapture.tscn` 창 모드, `AUDIO_PILOT_CAPTURE_PASS 11`. 실제 오디오 신호·유한 샘플·수집 길이 검사. 믹스 초과를 숨기지 않고 별도 보고.
- **통과**: `build.py`, 후보6·음량 일치본9 생성. `check.py` 소스 해시7·후보6 형식/길이/피크/DC/끝점·일치본9·캡처 청취본11·미리듣기 링크 검사.

- **통과**: `Integration.tscn` headless 별도 실행, `INTEGRATION_PASS 149`, 종료0.
- **실패 후 수정**: 최초 청취본을 고정 -12 dB로 감쇠했을 때, 재실행한 겹침 피크가 여유를 초과해 캡처 검사가 거부했다. 엔진 출력과 버그를 감추지 않고 raw float 전체를 저장하고 배치 공통 감쇠를 최고 피크에 맞춰 계산하도록 제작 도구를 수정했다. 최신 캡처/청취본 검사는 통과. 중간 `build.py`도 실패한 캡처를 인식해 거부했음.
- **브라우저 확인**: Codex 브라우저에서 비교 HTML 렌더와 피격 A 재생 버튼→일시중지/시간 슬라이더 활성 확인. 인간 청음 품질 승인으로 표현하지 않는다.

## 산출물과 한계

- 비교: `prototypes/audio-lab/output/index.html`, 측정: `output/report.json`, 실제 믹스: `game/output/audio-pilot/`.
- 후보/원본/레시피는 재현 가능하게 보존. `output/`은 커밋하지 않는다.
- 거위는 CC0 공개 저품질 MP3 미리듣기 녹음으로 배경음·압축 한계가 있다. 좀비 팩은 원본24-bit WAV지만 녹음·가공 사슬은 배포 페이지에 명시되지 않음. 48 kHz 변환을 품질 복원으로 주장하지 않는다.
- 후보의 음색·좀비 위협감·반복 피로는 사용자 비교 청취 전. 다른 플레이어 종, 발성 변형, 실제 교체, 9종 전체 개선은 미완료.
- 기존 I-64에 최신 측정 근거를 덧붙이고 상태는 열림 유지. I-74는 옛 피격 음량 수정 이력으로 유지. 새로운 버그 ID를 발급할 변경은 없으며, 방향 결정 A-26만 추가.

## 독립 리뷰·검수 보충

- 독립 리뷰: 중요/치명 결함 없음. 원문 페이지의 CC0, 실제 override 미적용, 모든 float 캡처 수치와 공통 감쇠 청취본의 샘플 대응을 읽기 전용으로 재확인.
- 후속의 경미한 보강 후보: check.py에 청취본 frame/rate/보고서 해시 교차검증 확대, 과거 baseline 혼용 방지를 위한 코드 식별자. 현재 파일은 독립 검사로 일치하며 이번 시제품의 필수 작업으로 확대하지 않았다.
- 청음 품질·일반 플레이 전체·나머지 6종은 리뷰에서도 판단하지 않았다. 제작에 사용한 archive는 출력 폴더에 내려받고 필요한 이름의 멤버만 고정 source 경로로 추출했으며, 재현 빌드는 보존 원본을 써서 다운로드/ZIP 추출을 실행하지 않는다.
- 렌더: `prototypes/audio-lab/output/preview.png`. 좁은 Codex 패널에서 세로 배치·오디오 컨트롤 확인, 피격 A 재생 경로 확인.
- `git diff --check` 통과. Git의 CRLF→LF 정규화 안내는 빌드/게임 종료 경고와 구분한다. 최종 Godot 검사 로그에 오류·종료 경고 없음.

- 최초 staged diff 검사에서 Kenney 라이선스 배포본의 CRLF/말미 공백을 지적했다. 라이선스 문구는 보존하고 줄바꿈·말미 공백만 정규화한 뒤 재검사했다. 원본 오디오7개의 해시는 그대로다.

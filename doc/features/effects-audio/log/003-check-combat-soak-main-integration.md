## 범위와 통합 기준

- 시작 사운드 커밋 7a74593, 로컬 main 0543049(대형 스테이지 작업 포함). 원격을 fetch했고 origin/main은 fd0373e로 로컬 main보다 이전이다. 원격 이력을 되돌리지 않고 로컬 main을 사운드 worktree에 먼저 병합했다. 충돌 없음.
- 기본 작업 폴더의 기존 미추적 `.codex-remote-attachments/`, tech-tools log005/006은 이 작업에 포함하지 않는다. 실행 중인 StudioPreview도 종료하지 않는다. 검사·가져오기·빌드는 별도 사운드 worktree에서 직렬 실행한다.

- 확인된 원인: `Stage._PhysicsProcess`가 매 프레임 `Player.HeliumTime/BlindTime`으로 버스를 설정한다. 이전 `AudioPilotCapture`의 직접 `SetHelium/SetMuffled` 호출은 다음 프레임에 해제될 수 있었다.
- RED: 효과 활성 유지 검사를 먼저 추가했고 `Stage did not retain requested audio state: helium` 실패를 확인했다(`state-capture-red.log`). 이전 log002의 헬륨/먹먹함 피크는 출력 수치 자체만 유효하며 해당 효과가 지속된 증거로 사용할 수 없다.
- 수정: 실제 `Player.ApplyHelium(4)`/`Blind(4)`를 적용하고 물리 프레임 이후와 캡처 끝에서 상태를 확인한다. 다음 조건 전에 만료를 기다리며 보고서에 실제 버스 활성 상태를 저장한다. 지속 전투도 플레이어 상태를 통해 효과를 적용한다.
- 제품 음원·게인·limiter 코드는 이번에 변경하지 않았다. 기존 I-64 검증 경로를 보완하는 작업이므로 새로운 제품 버그 ID를 발급하지 않는다.

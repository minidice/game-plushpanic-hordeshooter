# 바닥 그림 없이 반투명 부피로 범위 채우기

관련 ID: A-27/A-28/A-29. 사용자 요청: 바닥 없이 퍼지는 범위를 채우는 추천안 진행. [계획](../volume-fill-plan.md).

## 변경

- 화염의 기존 회색 얇은 연기12개를 연결층16개로 보강. 카드 너비0.65R→1.05R, 높이0.43R→0.65R, 재질알파opacity×0.22→×0.46. 기존 smoke atlas를 재사용하며 새로운 이미지/지면 면/데칼은 없다. 최초 높이0.5R 렌더는 바닥 그림처럼 납작해 보일 가능성이 있어0.65R로 높인 뒤 다시 검증했다.
- 연결층은 color와accent를0.38 비율로 섞은 따뜻한 색으로 중앙부터0.38초 동안 팽창한다. 반경별 시차0.12초/각 출현0.24초로 외곽 고정 불꽃이 다 켜지기 전에 빈 곳을 연결한다. 유지 중 작은 흐름만 남고, 만료 전후0.35초에 smoke_color로 식어 기존 입자별 소멸을 따른다. 고정 불꽃의 위치/점화/소멸 곡선 자체는 바꾸지 않았다.
- 연무는20개 유지. 카드 너비0.85R→1.05R, 재질알파opacity×0.9, 확산0.95초/반경 시차0.45초/각 출현0.55초로 연결한다. 새 셰이더 uniform은 명시적 시계와 기존 짧은 수명 비례축소를 사용한다.
- 폭발 범위층은 외곽16개를 유지하고 내부8→12개, 너비0.75~0.95R→0.9~1.1R로 보강. 내부는0.58R 안쪽 면적 균등 반경/황금각으로 분포한다. 폭발 수명·농도 상한·로켓 방향 강조와 전용 중심 연출은 그대로다.
- 피해/반경/판정/권한/사운드/독은 변경하지 않았다. 연무는 여전히 시각 표본이며 시야 차단이나 연막탄을 추가한 것이 아니다. A-27/A-28/A-29의 현재 내용·변경 이력, 전체 색인, 상세 규격, 체크리스트를 갱신했다. 이는 승인된 외형 튜닝이므로 새 결정/이슈 ID를 만들지 않았다.

## 검증

- Debug 빌드 오류0/경고0. Studio는 마지막 높이 조정 이후 다시 빌드·가져오기하고 전체12종을 재렌더했다. `studio/tests/combat-effects.mjs` **74통과**, 전체 수명/원본 JSON 불변 확인.
- GPU1600×900/fixed-fps60: `AreaEffectsCheck` **36**, `CombatEffectsCheck` **171**, `BurstRadiusCheck` **62** 통과. 실제 피해 경계 안/밖 표적, 고정 시계, 일시정지 픽셀 동일, 부모 제거, 유한 잔흔/동시 제한을 유지한다.
- `AreaEffectsReadabilityCheck` 일반 **16**, scale0.67/MSAA없음 **16** 통과. 두 조건의 기준 화면 드리프트0, 효과를 숨긴 뒤 기준 장면/HUD와 픽셀 동일. 효과1/6/12개의 RGB변화 화면 면적은 일반1.594/7.225/15.964%, 낮은 렌더 비용1.640/7.340/16.130%. 가독성 점수나 GPU overdraw 수치가 아니다. 실제12중첩 렌더에서 플레이어·분대·보스 윤곽, 조준점/HUD, 빨간 내려찍기 예고를 확인했다. 빨간 바닥 원은 기존 보스 예고이며 새 화염/연무 지면 그림이 아니다.
- `CombatEffectsPerformance` **5조건 통과**. RTX5070Ti/Forward+/1600×900/VSync·프레임 제한 해제, 적20고정, 각6초 중 최초1.5초 제외. 기본 평균1.777/p95 2.163ms. 화염·독6+초당폭발10은3.371/4.378ms. 화염·연무1/6/12+초당폭발10은 각각 평균3.195/3.198/3.505ms, p95 3.828/3.853/4.256ms. 12조건 draw calls약1349. 다른 실행과 비교한 정밀 개선/회귀율은 주장하지 않는다.
- 최종 검사 로그에 ERROR/WARNING/FAIL/누수 경고 없음. 구현 실패 없음. 검토용 파일 읽기에서 존재하지 않는110번째 프레임 경로를 한 번 조회했으나 실제 타이밍은12fps/87프레임임을 확인하고 존재하는0.08/0.25/0.5/1/5/5.5초 프레임으로 시간 변화를 검수했다.
- 독립 읽기 리뷰: 중요한 결함 없음. 직접 판정하지 않은 초기 확산/12중첩 외형/GPU비용은 위 실제 렌더·측정으로 별도 확인했다. 기존 일시정지/짧은 수명/부모 제거/범위0카드 계약과 가시성 AABB 유지 확인. 새 수치를 복제하는 단위 테스트는 추가하지 않고 기존 회귀와 실제 렌더로 검증했다.

## 산출물과 제약

`game/output/area-effects/volume-fill-comparison.gif`는 왼쪽 화염/오른쪽 연무, 위 변경 전/아래 변경 후의 전체 수명 비교다. `volume-fill-sheet.jpg`, `fill-timeline.jpg`, `fill-*.log`, `fill-before/`, `studio/output/combat-*/`, `game/output/area-readability/{normal,reduced}/`, `game/output/vfx-performance.json`은 로컬 재생성 산출물로 커밋하지 않는다.

부드러운 텍스처 가장자리/카메라 투영 때문에 정확한 픽셀 판정선이나 첫 프레임의 전체R 표시는 보장하지 않는다. 초기 연결층은 이전의 빈 시간을 보완하지만 피해는 기존처럼 즉시 전체 수평 반경에 유효하다. 벽 우회/지형 투영/새 다층 피해는 추가하지 않았다. 실제 저사양·다인 네트워크·장시간 실행은 미검증이고, 이번 외형 수치 조정에서 전체 Integration/음향 회귀는 다시 실행하지 않았다. 현재 결과는 새 외형의 사용자 수락 전이다. main 병합/푸시는 수행하지 않는다.

# 중앙 확산과 개별 소멸

2026-10-27. A-27 후속. 사용자가 갑자기 나타나고 사라지는 느낌을 지적하고 중앙부터 퍼진 뒤 전체 영역에서 개별적으로 사그라드는 연출을 제안했다.

## 변경

- 고정된 불꽃 자리는 유지하되 중앙 가까운 순서대로 점화한다. 입자별0.48초 출현 곡선과 반경별 시차로 약1.1초에 전체 분포가 갖춰진다. 기존 전역35% 시작 농도를 제거했다.
- 연무도 `area_smoke_particles.gdshader`의 고정 슬롯과 명시적 clock을 사용한다. 중앙 근처에서 시작해1.25초 동안 외곽으로 팽창하며 각 덩어리가 반경 순서대로0.65초간 부풀어 오른다. 유지 중에는 작은 흐름/회전/농도 변화만 남고 수명마다 위치를 다시 뽑지 않는다.
- 소멸은 반경의 역순이나 전체 동시 숨김이 아니다. 고정 입자 번호로 서로 다른 감쇠 시작/종료 시간을 배정한다. 불꽃은 높이와 농도가 함께 줄고, 연무는 각1.15~1.8초 동안 흐려진다. 짧은 표본 수명은 곡선 길이를 제한한다.
- 화염은 실제 위험 종료 전부터 작아지기 시작해 종료 뒤 최대0.8초 안에 무해한 잔불이 사라진다. 옅은 연기는 기존2초 잔여 수명 안에 소멸한다. 독립 연무 표본은 원래 표본 수명 내에 모두 사라진다. 전역 알파를0으로 바꿔 개별 곡선을 잘라내던 처리를 제거했다.
- 실제 피해 반경·DPS·유효 수명·광원·음향은 유지한다. 시각 확산은 피해 반경 확산을 뜻하지 않으며, 종료 후 잔불은 판정이 없는 시각 노드다. 자연 종료 시 시각 시계를 뒤로 되감지 않도록 보정했다.
- A-27 현재 결정/이력/색인, VFX 상세 규격, 기능 체크리스트를 갱신했다. 사용자 외형 요청에 따른 조정이며 새 제품 버그나 결정 ID는 불필요하다.

## 검증

- Debug 빌드 오류0·경고0.
- `AreaEffectsCheck` 창1600×900 **36통과**, `CombatEffectsCheck` 창1600×900 **92통과**. 실제 위험 종료와 무해한 시각 노드 분리, 소멸/정리, 일시정지 중 화면 동일, 재개, 기존 독/폭발/전투 중첩 확인. 오류/셰이더 오류/종료 경고 없음.
- Studio 실제 생성기로 화염7.167초/87프레임, 연무5.2초/79프레임 재생성.0.25/0.75/1.5/4.8초 비교 렌더와 전체 재생으로 중앙 출현→확산→개별 감쇠를 확인했다.
- 원본 첫 프레임과 픽셀 차이를 비교했을 때 출현 영역은 화염 약3,802→32,588→42,811px, 연무 약5,816→33,043→88,879px로 증가했다(약0.25/0.75/1.5초, 평균 RGB 차이3초과). 순간 이동이나 전체 동시 표시의 증거 대신 실제 확산을 확인하는 보조 수치다.
- 인접 프레임의 최대 신호 감소는 최고 신호 대비 화염11.34%/연무6.78%, 마지막 프레임 신호는 둘 다0이었다. 이는12/15fps로 저장한 렌더의 픽셀 차이 기준이며 모든 기기에서의 지각 품질 보장은 아니다. 실제 프레임도 함께 확인했다.
- `git diff --check` 통과. 음향·전체 통합·네트워크·성능 측정은 다시 실행하지 않았다.

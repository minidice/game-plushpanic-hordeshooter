# 재질 사운드 후속 통합·최종 출력 검사

관련 A-26·I-64·I-74. 사용자가 남은 계획을 멀티에이전트로 진행하도록 요청했다. 기준4bacc0d, 독립 worktree3개에서 구현한 변경을 `codex/sound-quality-pilot`에 통합했다.

## 변경

- 네트워크: 호스트 판정 환경 hitscan 접촉 최대3개, 자기 사격 포함 서버 확인음1회, protocol17/표면 데이터 지문. [006](006-code-surface-network-audio.md).
- Studio: 오브젝트 프리셋/공용 게인 저장, 공유 영향 범위 표시, 입력 검증/버전409/원자적 교체/캐시 재조회. [007](007-code-studio-surface-editor.md).
- 믹스: NearCap 기본 적용, 폭발·황소 호출 게인 보정, 경고 우선순위와 반복음 초과 생략. [008](008-code-audio-balance-followup.md).
- 리뷰 후 보스 산탄 호출 +3→+1로 기존 상한+3 유지. 실제 `StartSkill`→`FanShot` RED 상한5→GREEN3, 공유 플레이어 산탄 +2 유지. [010](010-code-boss-shotgun-gain.md).
- 통합 담당: 300초 전투 캡처에 시간·음원 manifest·오디오/실제 전투 호출 소스 SHA를 기록한다. `followup.py`는 현재 소스와 실제55 WAV 해시를 확인하고 69조건+실제 보스 산탄1조건과 전투20초 발췌4개를 정규화 없이 게시한다. 기존14종 페이지에 후속 청음 링크를 추가한다. 기존 소스41개/배포55 WAV는 변경하지 않는다.
- 중앙 규격·A-26 현재 결정과 바뀐 결정·I-64 후속·체크리스트를 갱신한다. 기존 단계별 이력을 지우지 않는다. 새 결정/이슈 ID를 만들 사유가 없으며 I-64를 전면 해결로 표시하지 않는다.

## 리뷰

독립 리뷰 에이전트가 세 구현의 커밋과 통합 검사/게시 도구를 정적으로 검토했다. Critical0/Important0. Minor1: 게시 도구의 manifest만 비교하면 WAV 단독 수정 시 옛 캡처를 허용할 수 있어 실제 파일별 SHA 검사로 보강했다. 별도로 기존 `release.py`의55음원 재생성/설치 해시 검사를 수행한다. 후속 리뷰에서 보스 산탄 추가 게인(+3)이 NearCap 기본 적용 후 기존 상한+3에서+5로 커짐을 확인했다. 공유 산탄 레시피는 유지하고 보스 호출만 보정하는 전용 후속을 분리했다. 69조건이 모든 보스 호출 조합을 망라하는 것은 아니다.

## 장시간 검사의 거짓 통과 발견·보정

첫 통합300초 실행은 기존 수치 판정에서 passed=true/출력 초과0이었지만 **최종 전투 검증으로 기각**했다. 60초 렌더는 전투, 240초 렌더는 월드 없이 HUD만 보였다. 거리440,720.79m, 처치101회가90초 이후 증가하지 않아 실제 전투 이탈이 드러났다. 이 실행은 `game/output/surface-followup/rejected-soak/`에 별도로 보존한다.

담당 에이전트와 코드로 확인한 원인: `Player.SetControls`는 월드XZ 이동을 받는데 기존 fixture가 카메라 기준으로 재변환했다. 무적 fixture는 Y<-10의 낙사 피해도 무시하므로 추락 후 계속 사격하며 수직 낙하까지 이동거리로 셌다. 황소 launch가 낮은 울타리를 넘긴 것이 최초 이탈 계기일 가능성이 있지만 당시 위치를 기록하지 않았으므로 이는 추정이다. 제품 물리·카메라·무적 규칙은 바꾸지 않았다.

검사만 보강했다: 올바른 월드XZ 입력, 12초 적 교체 시 플레이어 재배치, 안전 구역 이탈의 명시적 복귀/횟수 기록, 유한 위치·높이 검사, 재배치를 제외한 평면 거리, **각60초 구간마다 새 사격>50·명중>5·처치>0** 요구. 보고서에 위치·복귀·매분 증가량을 남기고 실패 시 기존 성공 보고서를 false로 덮어쓴다. 게시 도구도5구간 모두를 검사한다. 이 변경은 일반 게임 플레이 개선이 아닌 통제 음향 검사의 유효성 수정이다.

추가 리뷰: 보강한 검사에 차단 결함 없음. 게시 도구의 마지막20초 발췌가 불완전 녹음에서 짧아질 수 있는 Minor 지적은 최소280초와 실제20초 프레임 길이 검사로 보강했다.

## 렌더·한계

게임 외형·물리·HP·피해 계산은 바꾸지 않는다. Studio 화면은 실제 렌더로 확인한다. 통제 전투는 무적/회복·탄약 보충·주기적 적 교체가 있는 자동 검사이며 일반 캠페인 플레이 또는 사람의 피로도 판단을 대신하지 않는다. 로컬 ENet의 독립 월드 검증은 물리적으로 다른 두 PC의 인터넷 지연/손실 검증과 구분한다.

무료 소재의 원래 녹음 품질, 종별 발성·무기별 장전 신규 제작, 적 투사체/근접/동적 물체 재질 이벤트는 별도 확장이다. 최종 음색·피로도 수락은 사용자 청음으로 남긴다. Studio 외부 편집기는 최종 버전 검사/rename 사이를 강제로 잠그지 않으므로 외부 파일 편집과 저장을 동시에 하지 않는다.

## 통합·보존

기본 main 폴더에서 다른 기획 문서의 미커밋 변경을 확인했다. 자동 stash나 문서 덮어쓰기 없이, 검증된 이 worktree의 커밋을 원격 main에 fast-forward 푸시한다. 기본 체크아웃의 로컬 main 동기화는 그 작업 보존을 위해 수행하지 않는다. 에이전트 작업 폴더는 로그/렌더를 이 worktree에 보존한 후 앱의 복구 가능한 archive로 정리한다. 이 사운드 worktree와 청음 페이지는 유지한다.

최종 정리 확인: 에이전트3개가 archived_worktree로 전환된 것을 목록에서 확인했다. 중앙 문서의 로컬 링크545개 존재 확인, git diff --check 통과. 코드/기록만 커밋하며 output·캐시·다른 작업 문서는 포함하지 않는다.

# 실제 피해 반경과 보이는 위협 범위 보정

관련 ID: A-27/A-28/A-29. 사용자 피드백: 드럼통처럼 다른 범위 효과도 실제 피격 범위에 가까워야 하고, 효과 밖으로 보이는 대상이 맞는 인상을 줄여야 한다.

## 확인과 변경

- 실제 `Blast`는 전달된 중심과R의3D 거리로 판정하지만 새5종의 주 덩어리 중심은 대개0.5R 안쪽에 그쳤다. 카드 전체 너비의 반쪽과 텍스처 투명 여백을 고려하면 보이는 범위는 더 작다. 로켓은 모든 중심에0.65R를 더해 전방만 강조됐다. 반경 전달 오류나 피해 수치 오류가 아니라 외형의 공간 분포 조정이다.
- `BurstReachVisual`을 추가해 모든 blast와 fire_impact에 실제R 기준의 전 방향 공간 입자를 붙였다. 외곽16개+내부8개, 최고 재질알파0.48, 최대0.07초 확산/0.48초 개별 소멸. 첫 렌더의 중앙이 빈 고리 인상을 내부 입자로 보완했다. 바닥 면/링을 만들지 않는다. 기존 중심 연출·잔연기·잔불은 유지한다.
- 로켓의 중심 방향 강조0.65R→0.25R. 범위층은 방향에 영향받지 않아 후방 피해도 읽히게 한다. 지속 불꽃 뿌리는 기본0.77R→0.94R로 넓혔다. 위치 고정/중앙 점화/소멸 시간은 그대로다. 독의 기존 약0.98R 바닥 표시와 피해 없는 연무 표본은 보존한다.
- `Blast`/`FireZone`/`VomitHazard`의 실제 피해/반경·음향·권한 코드는 바꾸지 않았다. 드럼통 연쇄와 물리 소품의 기존1.4R는 일반 생물 피해 반경과 구분한다. 기존 `Blast.PaintSplat`의 장식 자국은 이번 변경 대상이 아니며 새 범위층으로 바닥 그림을 추가한 것은 아니다.
- A-27/A-28/A-29 현재 본문/바뀐 결정·색인, 상세규격의 spread 계약·범위층, 기능 체크리스트와 [계획](../damage-reach-plan.md)을 갱신한다. 시각 수치 보정이므로 새 이슈 ID를 발급하지 않았다.

## 검증

- Debug 빌드 오류0/경고0.
- 새 `BurstRadiusCheck` GPU1600×900 fixed-fps60 **62통과**. 실제 Blast를6종으로 호출해0.95R 앞/뒤 적은 피해를 받고1.05R 밖 적은 피해가 없음을 확인. 초기 공간 입자의 반경 근처 중심·알파·사분면 분포, 실제 렌더13장과 지속 불꽃 뿌리R을 확인했다. 흰 점은 검사에서만 생성한 실제R 표식이고 게임 효과에는 없다.
- 검사 초안은 `SpawnEnemy`의 pending 등록 전에 폭발을 호출해 첫 피해 검사에 실패했다. Stage의 대기 목록을 확인하고 두 PhysicsFrame 뒤에 호출하도록 검사만 수정했다. 이후62개 통과.
- 기존 GPU `CombatEffectsCheck` **171**, `AreaEffectsCheck` **36** 통과. 시간 분할/정지·짧은 수명/0개·부모 제거·폭발/광원/잔흔 상한·실제 전투 연결을 유지한다. headless `DestructionCheck` **42** 통과. 해당 최종 로그에 ERROR/WARNING/FAIL 없음.
- 독립 읽기 리뷰: 중요한 구현 결함 없음. 반경 근처 중심/알파 검사는 텍스처의 실제 픽셀 범위를 증명하지 않으며 실제 렌더 관찰을 보조한다는 한계를 기록한다.
- Studio 공통 효과 **74통과(12레코드)**. 새 DLL/리소스로 전체 수명을 다시 렌더했고 원본 JSON 불변을 확인했다. 최종 렌더를 이용한 변경 전후 GIF도 확인했다.

## 성능과 렌더

RTX5070Ti, Forward+,1600×900, 제한/VSync 해제, 고정 적20. 동일 부하5조건에서 `CombatEffectsPerformance` 통과. 기본 평균1.74/p95 2.08ms. 화염/독6+초당폭발10은3.27/4.39ms. 화염/연무1·6·12+초당폭발10의 p95는3.59/3.67/4.43ms이며12조건 평균3.34ms/draw calls약1330. 별도 이전 실행과 비교한 정밀 성능 회귀율을 주장하지 않는다. 새 범위층의 화면 점유율과 draw call 비용이 추가되며 실제 저사양은 미검증이다.

실제 일반 게임 카메라의 수류탄/로켓/드럼통 초기 모습과 넓어진 지속 불꽃, 숲12개 중첩 화면을 확인했다. 영향 범위 가까이 빠르게 넓어지고 원의 선 대신 공간적인 덩어리로 표현된다.

산출물: `game/output/burst-radius/`의6종0.07/0.15초와 fire1.5초 PNG, `game/output/area-effects/radius-{check,combat,area,destruction,performance,studio-combat}.log`, `game/output/vfx-performance.json`과 부하 PNG. `radius-before/`에는 변경 직전 Studio 프레임을 보존한다. `damage-reach-comparison.gif`·`damage-reach-sheet.jpg`는 위쪽 변경 전/아래쪽 보정 후 비교다. 자동 생성 산출물은 커밋하지 않는다.

## 남은 제약

부드러운 알파와 카메라 투영 때문에 정확한 판정선을 보장하지 않는다. 폭발은3D 구형·단차 제한, 지속 화염은 수평 반경, 독은 높이/벽 차단 등 기존 규칙이 다르며 지형 우회 표시를 새로 만들지 않았다. 불꽃 초기 점화는 기존 시간 그대로여서 착탄 범위 입자가 사라진 뒤 외곽 불꽃이 모두 켜지기 전의 가시성 차이는 남는다(외곽 점화 약0.74~1.22초). 첫 프레임부터 전체 반경을 연속 표시한다고 주장하지 않는다. 이번 시각 수치 보정에서 전체 Integration/음향/네트워크 회귀를 다시 돌리지는 않았다. 새 범위 외형의 사용자 수락·실제 저사양/멀티·장시간은 별도다.

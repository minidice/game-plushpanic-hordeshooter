# 기존 무기 폭발 다섯 종류의 텍스처 표현 확장

관련 ID: A-19, A-28, A-29. 사용자 요청: 수락한 화염·연무·연료통 방향을 기존 계획의 나머지 효과와 전투 가독성으로 이어서 적용.

## 변경

- `ImpactBurstVisual` 하나로 기본 폭발·수류탄·로켓·박격포·유인탄을 표현한다. 기존 `vfx.area_smoke` 2×2 아틀라스를 카메라 대면 카드에 사용하며 새 텍스처/바닥 링/잔불 지대를 만들지 않는다.
- 수류탄은 작은 짧은 충격과 긴 파편, 로켓은 전달받은 진행 방향으로 쏠리는 분포, 박격포는 더 높이 올라가는 먼지, 기본 폭발은 짧은 충격, 유인탄은 분홍색을 유지한다. 연기는 최대 알파0.32이며 뒤 배경이 비친다.
- JSON의 모든 값과 `BarrelBurstVisual`은 그대로 둔다. `fire_impact`/독/지속 화염·연무, 실제 피해·반경·음향·흔들림·기존 박격포 착탄 전 경고는 변경하지 않는다.
- `CombatBurstEffect`의 부모 시계로만 진행하고 고정 독립 RNG7417을 사용한다. 기존24폭발/4광원 제한을 유지한다. 방향은 정규화하고, 파편은 `floorY-at.Y+.06`까지 떨어져 공중 폭발 원점을 바닥으로 오인하지 않는다. 바닥 높이는 하나의 평면 기준이며 지형을 따라 흐르는 물리 시뮬레이션이 아니다.

## 시간과 데이터 계약

전체 수명 D는 기존 값(기본0.95/수류탄0.85/로켓1.0/박격포1.2/유인탄0.85초)을 유지한다. 섬광0.12D, 충격 출현 시차 i×0.006D, 충격 카드 수명은 기본0.25~0.33D/수류탄0.20~0.28D/로켓0.30~0.38D/박격포0.24~0.32D/유인탄0.22~0.30D다. 연기는0.07~0.12D 뒤 나타나며 카드별0.64~0.82D 동안 진행해 최대0.94D 안에 끝난다. 파편은0.55~0.88D에 개별 종료한다. 수치는 조정 가능한 제작값이다.

`lobes`는 충격/연기 각각의 수, `particles`는 파편 수, `spread/rise`는 분포/상승, 색3종은 충격/강조/연기에 적용한다. 수명0.1초·lobes0/24·particles0에서도 종료한다. 새 스키마나 별도 Studio 정의를 추가하지 않는다.

## 검증

- **통과:** 새 작업 폴더의 변경 전 빌드 오류0/경고0, 헤드리스 `CombatEffectsCheck`91개.
- **예상 실패:** 텍스처 카드 연결 검사를 먼저 추가한 뒤 기존 기본 폭발에서 실패(`red.log`). 새 생성기 연결 후 통과.
- **검사 수정:** 유인탄의 짧은 충격이 이미 끝난0.30D에서 색 카드를 찾던 검사 실패. 호출 스택과 카드 수명을 확인하고0.20D로 관찰 시점만 옮겼다. 제품 수명은 바꾸지 않았다.
- **통과:** 최종 빌드 오류0/경고0. 헤드리스 `CombatEffectsCheck`158개, GPU1600×900 fixed-fps60 전용 검사171개. 새 5종의 텍스처/알파·무바닥면·시간 분할 독립·부모 정지·공중 파편 바닥·개별 종료·부모 제거·최소 수명/0개 경계, 로켓 방향 반전/속력 무관/0방향, 실제 유인탄/기본 폭발 선택을 확인했다. 기존 배럴·수류탄·로켓·박격포·화염·독·전투 중첩 검사도 포함한다.
- **통과:** 헤드리스 `DestructionCheck`42개. 기존 폭발 피해·파괴·클라이언트 권한 회귀.
- **종료 경고:** 최종 전용 헤드리스/창/파괴 로그와 Studio 렌더 로그에 ERROR/WARNING/FAIL 없음. 과거 I-17 전체 해결을 뜻하지 않는다.
- **실제 렌더:** 게임 시점5종과 중첩 화면, Studio 전체 수명 기본34/수류탄32/로켓36/박격포42/유인탄32프레임(30fps)을 생성했다. 로켓의 한쪽 팽창·박격포 상승 먼지·분홍 유인탄·종료 후 빈 화면을 확인했다. 브라우저 UI와 전체 Studio 자동 회귀는 이 분리 작업에서는 재실행하지 않았다.

산출물은 이 작업 폴더의 `game/output/impact-bursts/` 아래 baseline/red/contracts/window/destruction 로그와 종류별 PNG/timing.json, `game/output/vfx-*.png`, `studio/output/renderer.log`다. Studio 첫 실행의4329포트가 사용 중이라 서버 시작이 실패했으며4349로 바꿔 렌더를 완료했다. 실패한 서버가 다른 서버를 변경하지 않았다. 산출물은 커밋하지 않는다.

## 남은 검증과 기록 검토

통합 브랜치에서 전체 Studio/성능/Integration 검증을 이어서 실행한다. 실제2PC·저사양·장시간 플레이는 미실행이다. 외형은 기존 승인 방향에 따른 제작값으로 새5종의 최종 사용자 수락과 구분한다. 상위 작업이 결정 A-29·규격·색인·체크리스트를 통합하며, 이 작업은 코드와 이 로그만 담당한다. 실제 새 제품 버그를 발견하지 않아 이슈 ID를 발급하지 않았다. 기존 A-28의 수락된 배럴 표현은 수정하지 않았다.

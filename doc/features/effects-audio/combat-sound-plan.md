# 전투 반복음 5종 개선 계획

2026-10-27. 추천안 실행을 사용자가 승인했다. 기존 A-26 무료 소재·Duckov 장비감·L4D 감염체 방향을 이어간다. 아래 수치는 제작자 선택이며 최종 청음 승인이 아니다.

## 설계 / 선택 기준

- 300초 통제 전투에서 소총1558회·좀비 피격1209회·장전 시작/완료 각31회. 반복 빈도, 행동 식별성, 전투 중 청취, 현재 미술 방향, 타이밍 순으로 우선한다.
- 합성만 수정하면 소재 추가가 없지만 녹음 질감은 제한된다. 유료 AI는 현재 무료 우선 조건 밖이다. 승인된 무료 녹음 편집 방식으로 5종을 바꾼다.
- 소총: 날카로운 상단과 긴 잔향을 억제한 짧은 3변형. 좀비 피격: 사망 발성과 구별되는 짧은 둔탁한 접촉 3변형. 장전 시작은 분리/빼기, 완료는 잠금, 빈 탄창은 단일 짧은 클릭.
- 기존 Sfx 파일 교체/변형 계약을 사용하고 게임 판정·호출 시점은 유지한다. 새 5종에 NearCap, 피격 과밀 재생은 최대3·초과 생략. 장전음은 여러 무기 공용이라는 제약을 보존한다.
- PCM16 mono 48 kHz, 파일 피크≤-6 dBFS. 소총 기준 음량의 급변으로 다른 경고음을 가리지 않도록 실제 AudioMixCheck 상대 상/하한을 유지한다. 개별 게인은 실측으로 정한다.
- 출처·CC0·해시 보존, 동일 50ms RMS 비교와 반복 재생 자료 제공. 자동 측정은 취향/피로도 인간 청음 판정이 아니다.

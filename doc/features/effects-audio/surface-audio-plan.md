# 표면 프리셋·오브젝트 데이터·환경 사운드 적용 계획

2026-10-27. 사용자 승인: 추천7계열 분류, 오브젝트별 추가 데이터와 값 지정, 발소리·총알 명중·소품 파손 연결. 기존 탄성·마찰·질량·체력·차단·관통 규칙 유지. 제작값은 최종 청음/밸런스 승인이 아니다.

## 설계

- 단단한 지면/석재·금속·목재·천/충전재·흙/모래·자갈/잔해·풀/낙엽 7계열. 별도 `surface_profiles.json`에 명명된 프리셋(아스팔트/콘크리트/철판/금속통/모래주머니 등), 이벤트별 소리/게인, 전체 prop ID와 코드 생성 오브젝트 ID 매핑, 기존 맵 지면 구간/큰 맵 region 매핑을 둔다.
- 재질 하나로 물리·파괴를 추론하는 접근은 배제. 기존 `object_interactions.json`의 파괴/엄폐 계약을 유지하고 오디오 데이터만 함께 조회한다. 충격 강도는 이번에 임의 HP와 연결하지 않고 이벤트별 제작 게인으로 시작한다.
- 실제 충돌체에 프리셋을 붙이고 엄폐 사격막은 소유 본체의 재질로 해석한다. 발소리는 발밑 짧은 레이, 바닥/경사면은 맵의 실제 위치·높이 분류를 사용한다. 장식/합성 콜라이더 미연결은 Studio에 범위를 표시하며 보이지 않는 장식물에 새 충돌을 만들지 않는다.
- 일반 지면 기본 발소리 `step`/`zombie_step` 유지. 나머지 계열은 CC0 Kenney foley 편집. 총알 충돌은 살아 있는 적의 기존 피격과 분리하여 환경에만 재생. 샷건/군중은 낮은 동시수·초과 생략. 파괴음은 ObjectBody의 한 번뿐인 파괴 경로에서 재생, 폭발 배럴 폭발음 유지.
- 프리셋 이름과 이벤트/게인/출처를 Studio properties로 조회. 본문 데이터 원본 하나, 저장 UI/물리 설정 UI 추가 없음.
- 소스 라이선스·해시, 배포 mono PCM16/48kHz·피크≤-6dBFS, 2변형을 보존. 새17종34파일을 더해 총55파일. 기존21파일은 변경하지 않는다.

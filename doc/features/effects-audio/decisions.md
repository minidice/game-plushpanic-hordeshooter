# 이펙트 · 소리 — 결정 본문

## A-27 화염·연무의 시각 계층과 무해한 잔흔

- **결정:** 기존 A-19 공통 데이터/생성기 구조 안에서 화염·연무에 지면 마스크와 GPU 입자 카드를 사용한다. 불꽃·불티·얇은 연기와 무해한 그을음으로 수명을 구분한다. 실제 위험 반경·피해·유효 시간·광원·음향은 기존 전투 코드가 소유한다. 연무는 Studio 시각 표본이며 새 연막탄이나 시야 차단 판정은 추가하지 않는다.
- **이유:** 사용자 제공 영상의 불규칙한 가장자리와 농도 차이, 바닥이 보이는 낮은 연무를 반영한다. 사용자가 작성된 추천 계획의 진행을 승인했다. 화염 표현은 연무 영상을 응용한 제작 방향이다.
- **상태 · 날짜:** 2026-10-27 `[현재 구현]`. 방향은 사용자 승인, 농도·입자 수·그을음2초·동시 잔흔24개와 외형은 조정 가능한 제작값이며 최종 외형 수락과 구분한다.
- **구현 계약:** `CombatSurfaceEffect`가 명시적 시간으로 `AreaSurfaceVisual`을 진행한다. `FireZone`은 자연 종료 때만 시각 노드를 Effects 아래로 옮기고 자신과 음향/광원을 즉시 제거한다. 중도 부모/장면 제거는 잔흔을 만들지 않는다. 잔흔에는 충돌·피해·Hazard 그룹이 없다. Studio도 같은 JSON/생성기와 전체 수명을 사용한다.
- **범위:** 첫 적용은 평면 바닥 마스크다. 바닥만 받는 투영 레이어 계약이 없는 상태에서 Decal로 캐릭터·벽까지 칠하지 않도록 기존 높이를 쓰는 평면을 선택했다. 경사/단차 밀착, 벽을 우회하는 연기, 새 다층 피해 판정, 실제 연막탄은 후속이다.
- **근거:** [승인 계획](area-effects-plan.md), [현재 규격](../../vfx-quality.md), [작업 기록](log/004-code-area-effects.md), `game/scripts/Effects/AreaSurfaceVisual.cs`, `game/scripts/Effects/CombatSurfaceEffect.cs`, `game/scripts/Weapons/FireZone.cs`.

# 이펙트 · 소리 — 결정 본문

## A-29 기존 폭발 계열의 반투명 질감 확장

- **결정:** 사용자 수락을 받은 화염·연무·연료통 외형은 보존하고, 기존 blast/grenade/rocket/mortar/lure에 연무 아틀라스 카드의 질감을 확장한다. 바닥 링을 없애고 짧은 중심 섬광/화염 또는 분홍 충격 덩어리, 바깥으로 나가는 파편, 뒤따르는 반투명 연기로 표현한다.
- **이유:** 사용자가 현재까지의 결과를 수락하고 멀티에이전트로 현재 방향의 남은 작업 진행을 요청했다. 연료통처럼 잔불을 모든 폭발에 붙이지 않고 기존 공격별 성격을 유지하는 구현을 선택했다.
- **상태 · 날짜:** 2026-10-27 `[현재 구현]`. 기존 화염·연무·연료통은 사용자 외형 수락. 이번5종의 세부 크기/속도는 제작값이며 별도 최종 외형 수락 전이다.
- **구현 계약:** `CombatBurstEffect`의 기존24폭발/4광원·명시적 시계·부모 제거를 유지하고 barrel은 `BarrelBurstVisual`, 나머지 blast계열은 `ImpactBurstVisual`로 연결한다. JSON의5종 duration/피해/소리/색/반경을 바꾸지 않는다. fire_impact/독은 기존 생성기다. 로켓의3D 방향은 정규화하고0벡터에서는 방사형, 파편 바닥은 폭발 원점 기준 floorOffset을 사용한다. 새 이미지/음향/게임 판정은 없다.
- **검수:** 가독성 계획5단계의 로컬 검수를 함께 마쳤다. 낮은 렌더 비용 조건은 같은 GPU에서3D scale0.67/MSAA해제이며 제품 저품질 설정이나 실제 저사양 장비가 아니다.
- **피해 범위 후속(2026-10-27):** 사용자 피드백에 따라 중심 연출과 별도로 `BurstReachVisual`의 짧은 공간 입자를 실제 피해 반경R 기준으로 추가한다. 최초24개에서 후속 공간 채움은28개(외곽16/내부12)로 보강했다. 내부 카드를0.9~1.1R로 넓혀 빈 곳을 연결한다. 로켓 전방 강조는0.65R→0.25R. 단순 파편 몇 개의 도달 거리로 피해 범위를 대신하지 않는다. 지면 면/선은 없으며 게임 판정은 그대로다. [범위 보정 기록](log/013-art-damage-reach.md), [공간 채움](log/014-art-volume-fill.md).
- **근거:** [실행 계획](effects-rollout-plan.md), [가독성 기록](log/010-check-area-readability.md), [폭발 기록](log/011-art-impact-burst-family.md), [통합 기록](log/012-check-effects-rollout.md), [현재 규격](../../vfx-quality.md).

## A-28 연료통 폭발의 순간 팽창과 잔여 연기

- **결정:** 연료통(`barrel`)은 기존 화염·연무 텍스처를 공유하는 카메라 대면 카드로 표현한다. 짧은 섬광과 빠른 화염 팽창 뒤에 반투명 연기·개별 잔불을 남기고 바닥 링은 표시하지 않는다. 지속 화염과 달리 폭발의 입자는 중앙에서 밖으로 이동한다.
- **이유:** 사용자가 지속 범위 효과와 폭발의 차이를 물었고, 연료통부터 기존 질감을 적용해 비교하자는 추천안의 진행을 승인했다.
- **상태 · 날짜:** 2026-10-27 `[현재 구현 · 외형 수락]`. 사용자가 현재까지의 결과에 만족한다고 확인했다. 시각 수명2.4초, 주 화염 약0.6초, 잔불 약1.3초, 연기2.4초 이내는 계속 조정 가능한 제작값이다. 외형 수락이 실제 저사양/멀티 검증 완료를 뜻하지 않는다.
- **계약:** `CombatBurstEffect`가 명시적 시간을 `BarrelBurstVisual`에 전달한다. 같은 생성기/JSON을 게임과 Studio에서 사용한다. 기존 동시24폭발·4광원, 독립 고정 시각 RNG, 부모 제거/일시정지 규칙을 유지한다. 피해/충돌/사운드는 기존 발생원이 담당하며 잔불에 추가 피해·연소 지대를 만들지 않는다. 최초 연료통 작업에서 다른 폭발은 보존했고, 이후5종 확장은 A-29를 따른다.
- **근거:** [작업 계획](barrel-burst-plan.md), [규격](../../vfx-quality.md), [검사·렌더](log/009-art-barrel-burst.md), `game/scripts/Effects/BarrelBurstVisual.cs`.
- **범위 보정 후속:** 기존 연료통의 중심 화염·잔연기·잔불 곡선은 유지하며, 다른 폭발과 같은 실제 반경 기준 짧은 공간 입자층만 추가했다. 이전 외형 수락과 새 범위층의 최종 수락은 구분한다. [013 기록](log/013-art-damage-reach.md).
- **공간 채움 후속:** 공통 범위층의 내부 카드 보강도 연료통에 적용한다. 연료통 전용 곡선/피해는 유지하며 새 수치는 외형 수락 전이다. [014 기록](log/014-art-volume-fill.md).

## A-27 화염·연무의 시각 계층과 무해한 잔흔

- **결정:** 기존 A-19 공통 데이터/생성기 구조 안에서 화염·연무는 바닥 그림 없이 GPU 입자로 표현한다. 중앙부터 퍼지고 각 입자가 서로 다른 시점/속도로 사그라든다. 지속 불꽃은 불붙은 자리를 유지하며 높이·형태·밝기가 변한다. 피해 종료 뒤에는 작아지는 무해한 잔불과 잔연기를 짧게 남긴다. 실제 위험 반경·피해·유효 시간·광원·음향은 기존 전투 코드가 소유한다. 연무는 Studio 시각 표본이며 새 연막탄이나 시야 차단 판정은 추가하지 않는다.
- **이유:** 사용자 제공 영상의 불규칙한 가장자리와 농도 차이, 바닥이 보이는 낮은 연무를 반영한다. 사용자가 작성된 추천 계획의 진행을 승인했다. 화염 표현은 연무 영상을 응용한 제작 방향이다.
- **상태 · 날짜:** 2026-10-27 `[현재 구현 · 외형 수락]`. 사용자가 현재까지의 결과에 만족한다고 확인했다. 농도·입자 수·잔연기2초·동시 잔흔24개는 계속 조정 가능한 제작값이며 실제 저사양/멀티 검증은 별도로 구분한다.
- **구현 계약:** `CombatSurfaceEffect`가 명시적 시간으로 `AreaSurfaceVisual`을 진행한다. `FireZone`은 자연 종료 때만 시각 노드를 Effects 아래로 옮기고 자신과 음향/광원을 즉시 제거한다. 중도 부모/장면 제거는 잔흔을 만들지 않는다. 잔흔에는 충돌·피해·Hazard 그룹이 없다. Studio도 같은 JSON/생성기와 전체 수명을 사용한다.
- **후속 외형:** 갑자기 나타나고 사라진다는 피드백으로 중앙→외곽 점화/팽창과 입자별 출현·소멸 곡선을 적용했다. 무작위 재생성 대신 고정 입자 번호를 사용한다. 불꽃은 고정된 자리에 순서대로 붙고 연무는 중앙에서 부풀어 퍼진다. [후속 렌더/검사](log/008-art-center-spread-and-staggered-fade.md).
- **피해 범위 후속:** 불꽃 뿌리의 분포 반경을 기본0.77R에서0.94R로 넓히고, 화염 착탄에 실제R 기준 짧은 범위 입자를 더했다. 고정 위치·중앙 점화·소멸 시간은 유지한다. 초기 전체R 피해와 순차 점화의 차이는 여전히 존재하며, 첫 프레임부터 연속적인 전체R 표시를 보장하는 변경은 아니다. [013 기록](log/013-art-damage-reach.md).
- **공간 채움 후속:** 사용자 추천안 실행 승인에 따라 기존 얇은 연기12개를 넓은 연결층16개(1.05R×0.65R)로 보강한다. 따뜻한 반투명 부피가0.38초 동안 먼저 퍼지고 고정 불꽃은 기존 순차 점화를 유지한다. 종료 전후 연결층이 회색으로 식고 기존 개별 소멸을 따른다. 독립 연무는20개를 유지하며 카드 너비/출현 곡선으로 빈 곳을 연결한다. 농도/색/시간은 제작값이며 새 외형 수락 전이다. [014 기록](log/014-art-volume-fill.md).
- **범위:** 화염·연무에는 지면 마스크/데칼을 사용하지 않는다. 벽을 우회하는 연기, 새 다층 피해 판정, 실제 연막탄은 후속이다.
- **근거:** [승인 계획](area-effects-plan.md), [현재 규격](../../vfx-quality.md), [작업 기록](log/004-code-area-effects.md), `game/scripts/Effects/AreaSurfaceVisual.cs`, `game/scripts/Effects/CombatSurfaceEffect.cs`, `game/scripts/Weapons/FireZone.cs`.

## A-26 사운드 품질 방향과 무료 소재 시제품

- 결정: 동물·장비·공간감은 Escape from Duckov, 좀비는 Left 4 Dead를 분위기 기준으로 한다. 추천한 단계적 제작을 진행하되 무료 녹음 소재부터 피격·신음·사망 각 A/B 비교를 만든다.
- 이유: 사용자가 기존 honk·honk_long·groan·zombie_die·balloon_inflate·balloon_pop·bull_bonk의 과한 음량·장난감 음색, game_over·stage_clear의 거친 소리를 지적했다.
- 상태·날짜: 2026-10-27 `[확정]` 참고 방향·무료 소재 우선. 사용자의 “현재기준으로 나머지 작업”에 따라 제작자가 A를 기본/B를 변형으로 선택하고 9종을 게임에 적용한다. 수치와 개별 음색의 최종 사용자 청음 승인을 뜻하지 않는다.
- 접근: 합성만 개선 / 녹음 편집 / 녹음+AI 생성 혼합을 비교했고, 전체 추천안은 혼합이지만 사용자가 첫 단계는 무료 소재로 선택했다. 유료 API·MCP 설치를 승인한 것으로 해석하지 않는다.

### 바뀐 결정 — 2026-10-27 후속 적용

- 이전: 피격·신음·사망 A/B 시제품까지만 진행, 게임 적용과 나머지 6종은 대기.
- 이후: 사용자 후속 지시에 따라 9종 적용. 피격·신음·사망은 2변형, 카드·무기 경적은 `honk_ability`로 분리. 나머지는 긴 거위 반응·공기/충돌 편집과 직접 만든 부드러운 결과 악구.
- 믹스: 대상 3D 효과와 좀비 피격에 NearCap, 신음/사망은 최대3개·초과 생략. 상태효과를 우회하는 `Cues`는 효과음 볼륨을 따르고 Master에는 sample ceiling -1 dB limiter를 하나 둔다. 다른 3D 음량 전면 재설계는 하지 않는다(I-64 부분 해결).
- 이유: 무료 소재 방향 유지 및 사용자의 계속 진행 지시. 반복감, 근거리 증폭, 군중 합산 초과, 결과음의 효과음 볼륨 우회를 함께 해결한다.

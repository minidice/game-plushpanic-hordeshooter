## A-26 사운드 품질 방향과 무료 소재 시제품

- 결정: 동물·장비·공간감은 Escape from Duckov, 좀비는 Left 4 Dead를 분위기 기준으로 한다. 추천한 단계적 제작을 진행하되 무료 녹음 소재부터 피격·신음·사망 각 A/B 비교를 만든다.
- 이유: 사용자가 기존 honk·honk_long·groan·zombie_die·balloon_inflate·balloon_pop·bull_bonk의 과한 음량·장난감 음색, game_over·stage_clear의 거친 소리를 지적했다.
- 상태·날짜: 2026-10-27 `[확정]` 참고 방향·무료 소재 우선. 제작자 선택으로 최초9종·전투 반복음5종·재질17종(55 WAV)을 적용했다. 후속 멀티에이전트 지시에 따라 재질음 네트워크·Studio 편집·전체 근거리 상한을 추가한다. 수치와 개별 음색의 최종 사용자 청음 승인을 뜻하지 않는다.
- 접근: 합성만 개선 / 녹음 편집 / 녹음+AI 생성 혼합을 비교했고, 전체 추천안은 혼합이지만 사용자가 첫 단계는 무료 소재로 선택했다. 유료 API·MCP 설치를 승인한 것으로 해석하지 않는다.
- 근거: [설계](sound-quality-pilot.md), [작업 계획](sound-quality-pilot-plan.md), [제작 도구](../../../prototypes/audio-lab/README.md).

### 바뀐 결정 — 2026-10-27 후속 적용

- 이전: 피격·신음·사망 A/B 시제품까지만 진행, 게임 적용과 나머지 6종은 대기.
- 이후: 사용자 후속 지시에 따라 9종 적용. 피격·신음·사망은 2변형, 카드·무기 경적은 `honk_ability`로 분리. 나머지는 긴 거위 반응·공기/충돌 편집과 직접 만든 부드러운 결과 악구.
- 믹스: 대상 3D 효과와 좀비 피격에 NearCap, 신음/사망은 최대3개·초과 생략. 상태효과를 우회하는 `Cues`는 효과음 볼륨을 따르고 Master에는 sample ceiling -1 dB limiter를 하나 둔다. 다른 3D 음량 전면 재설계는 하지 않는다(I-64 부분 해결).
- 이유: 무료 소재 방향 유지 및 사용자의 계속 진행 지시. 반복감, 근거리 증폭, 군중 합산 초과, 결과음의 효과음 볼륨 우회를 함께 해결한다.
- 근거: [후속 계획](sound-quality-rollout-plan.md), [변경·검증](log/002-art-sound-quality-rollout.md).

### 바뀐 결정 — 전투 반복음5종, 2026-10-27

- 이전: 최초 요청9종 적용, 소총·좀비 피격·장전·빈 탄창은 합성.
- 이후: 사용자 “추천안으로 작업해줘”에 따라 shot_rifle·zombie_hit·reload_start·reload_end·dry_fire 추가. 소총/좀비 피격 각3변형, 나머지 단일 기계음. 기존12파일은 그대로 보존한다.
- 선정 이유: 300초 통제 전투 소총1558회·좀비 피격1209회·장전 각31회. 반복 피로도·행동 구별·전투 청취·아트 방향·시점 일치를 우선한다. 빈 탄창은 실패 행동을 알리는 짧은 신호라 함께 다듬는다.
- 구현: 총성 CC0 녹음·에어소프트 기계음 편집, 충돌 녹음 레이어. 소총/장전/빈 탄창에도 NearCap, 좀비 피격 최대3·초과 생략. 수치는 제작/자동 검증 기준이며 인간 청음 승인은 별도.
- 근거: [설계·계획](combat-sound-plan.md), [변경·검증](log/004-art-combat-sound-update.md).


### 바뀐 결정 — 재질 접촉음·오브젝트 값, 2026-10-27

- 이전: 전투 반복음14종 적용, 환경 접촉은 재질 분류/전용 음원 없음.
- 이후: 사용자 추천안 실행 승인에 따라 단단한 지면·금속·목재·천/충전재·흙/모래·자갈/잔해·풀/낙엽 7계열과 명명 프리셋15개, 오브젝트 매핑93개를 오디오 전용 JSON으로 추가한다. 발소리6/환경 명중7/파손4종에 각2변형 CC0 편집음을 적용한다.
- 이유: 재질의 청각적 정체성과 체력·차단·탄성·마찰 등 게임 규칙을 분리하고, 같은 계열 녹음을 재사용해 과도한 조합/제작량을 줄인다. 모래주머니는 천/충전재이며 HP50/엄폐는 기존 상호작용 계약에 남긴다.
- 적용: 발밑 실제 충돌 위치·높이, 엄폐 사격막 소유 본체, 명시적인 모델/합성 충돌 매핑. 무충돌 장식은 그대로. Studio는 프리셋/계열/음원/게인 조회를 제공한다.
- 제작 수치/개별 음색/재질별 자연스러움은 최종 청음 승인 전. 물리/파괴값 자동 추론·Studio 저장 폼·원격 사격 재질 이벤트까지 확장하지 않는다.
- 근거: [설계·계획](surface-audio-plan.md), [오브젝트 규격](../../object-data-spec.md), [변경·검증](log/005-code-surface-audio.md).

### 바뀐 결정 — 재질 후속 완성, 2026-10-27

- 이전: Studio 조회만 제공, 원격 환경 명중음과 다른 3D 소리의 상한 후속 보류.
- 이후: 사용자의 남은 계획 멀티에이전트 실행 지시에 따라 Studio 기존 프리셋/공용 게인 편집·저장, 호스트 판정 환경 hitscan 명중 최대3개 동기화, 모든 레시피 NearCap 기본 적용·경고 우선순위 보강. 기존55 WAV와 물리/파괴/피해 규칙은 유지한다.
- 이유: 데이터에 맞는 편집 경로와 멀티의 동일한 재질음, 새 소리를 포함한 일관된 근거리 음량 계약이 필요하다. 종별 신규 녹음·무기별 장전·적 투사체 재질음은 별도 확장이다.
- 근거: [후속 계획](surface-followup-plan.md), [네트워크006](log/006-code-surface-network-audio.md), [Studio007](log/007-code-studio-surface-editor.md), [음량008](log/008-code-audio-balance-followup.md), [통합009](log/009-check-surface-followup-integration.md).

# 승인된 효과 스타일 확장과 남은 검수

2026-10-27. 사용자가 현재까지의 외형에 만족한다고 밝히고 현재 계획들을 멀티에이전트로 진행하도록 요청했다. 화염·연무·연료통의 현재 외형 수락을 기록한다. 앞서 제안한 기존 폭발 계열로의 확장과 범위 효과 계획5단계의 검수 마무리를 이번 실행 범위로 잡는다. 새로운 연막탄/유체/게임 규칙이나 별도 효과 아이디어는 포함하지 않는다.

## 구현과 검증

- [x] **가독성 검수:** 별도 작업 폴더에서 테스트 전용 장면으로 실제 플레이어/조준점/공격 예고와 화염·연무 중첩을 캡처한다. 효과 없는 기준 화면 대비 픽셀 변화 면적을 보조 지표로 기록하고 실제 렌더를 확인한다. 동일 GPU의 낮은 렌더 비용 조건을 비교하되 실제 저사양 장비 검증으로 표현하지 않는다. 새 게임 품질 설정은 추가하지 않는다.
- [x] **폭발 계열 확장:** 별도 작업 폴더에서 `ImpactBurstVisual`을 추가해 blast/grenade/rocket/mortar/lure의 기존 JSON 시간과 파라미터로 반투명 질감을 공유한다. 수류탄은 짧은 화염·빠른 파편, 로켓은 진행 방향, 박격포는 상승 먼지, 유인은 분홍색을 보존한다. 바닥 링 없이 표현한다. 연료통·지속 화염·연무 외형은 유지한다.
- [x] **합치기와 검증:** 부모 작업 브랜치로 각 담당 커밋을 가져와 전용검사/Studio 공통 원본/실제 렌더/중첩 성능을 확인한다. 런타임 피해·소리·멀티 규칙을 바꾸지 않는다. 각각의 작업은 역할별 검토 후 전체 리뷰한다.
- [x] **기록:** A-27/A-28 외형 수락과 후속 폭발 결정, 폐기된 바닥 그림 방향, 현재 완료 범위·외부 장비 제약을 문서/체크리스트/새 로그에 기록한다. 코드와 함께 커밋하고 main 병합/푸시는 별도 요청 전 하지 않는다.

## 담당과 경계

| 담당 | 소유 파일 | 공유 계약 |
|---|---|---|
| 가독성 에이전트 | 새 AreaEffectsReadabilityCheck 장면/코드·uid, log010 | 기존 CombatSurfaceEffect/실제 예고 API 사용, 런타임·공통 데이터 무수정 |
| 폭발 에이전트 | ImpactBurstVisual·uid, CombatBurstEffect, CombatEffectsCheck, 필요 시 해당5 JSON 레코드, log011 | Play(parent,def,at,radius,direction,floorY), 부모가 시간/수명/상한 관리 |
| 부모 | 이 계획·결정/규격/색인/체크리스트, 통합 log012 | 충돌 검토·통합 실행·시각 비교·최종 커밋 |

작업 폴더별 빌드/import는 분리한다. GPU 캡처/성능 검사는 한 담당씩 실행해 측정 간섭을 막는다. 새 PNG/소리 제작과 다른 세션 파일 편집은 없다. 변경에 필요한 `.uid`는 담당자가 포함한다.

## 남겨 두는 제약

실제 다른 PC/저사양 GPU·다인 장시간 플레이, 벽 우회 유체·지형 투영·새 연막 시야 판정은 이 계획의 완료 조건이 아니다. 이를 로컬 재현으로 통과했다고 쓰지 않는다. 문서의 옛 검사/방향은 삭제하지 않고 최신 상태와 연결한다.

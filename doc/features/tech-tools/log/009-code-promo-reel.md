## 검사

- 빌드: 오류 0.
- `PromoReel --promo-scout`(창 모드): 종료 0, `PROMO_REEL_PASS`, 정지 화면 65장(Stage 1 26 · 2 20 · 3 19).
- 녹화 1회차(1600 × 900, 43.9초 · 2632프레임, 실시간의 37%로 1분 55초): 통과. 볼 것 — "+100 AMMO / FULL" 글자, 자막이 화면 밖, 크기 1600 × 900.
- 녹화 2회차(1920 × 1080, 1분 27초): 위 셋을 고쳐 확인. 다만 **오류 로그 1건**이 났다. 컷 사이에 적을 `QueueFree`만 하고 `stage.Enemies`에서 빼지 않아, 분대 AI의 `PickTarget`이 지워진 적을 읽었다(`ObjectDisposedException`). 촬영 장면 쪽 문제라서 `Clear`가 목록에서도 빼고 2프레임 기다리게 고쳤다. 게임 코드는 그대로다.
- 녹화 3회차(최종, `tools/Make-PromoReel.ps1`로 실행): 종료 0, `PROMO_REEL_PASS`, 오류 · 예외 로그 0, `override.cfg`가 지워진 것 확인. 1920 × 1080 · 60fps, 42.9초(2574프레임), AVI 약 507 MB, 녹화 1분 27초(실시간의 48%). 컷 사이 검은 화면은 페이드 0.25초 · 대기 8프레임으로 줄였다(약 1초 → 0.6초).
- 프레임 확인: OpenCV로 1초마다 뽑은 접촉 인화(contact sheet)와 원본 크기 프레임을 봤다(scratchpad, 커밋 안 함).

## 남은 제약

- **mp4 변환**: 이 PC에는 ffmpeg가 없다. AVI(MJPEG + PCM, 1분에 약 700 MB)만 나온다. SNS용 mp4는 ffmpeg 설치 뒤 `-Mp4`로 만들거나, Clipchamp에서 연다.
- **재현성**: 적 배치는 시드를 고정했다. 다만 분대 AI · 적 행동은 난수라 찍을 때마다 조금씩 다르다.
- **음악**: 넣지 않았다. 게임 효과음만 있다. 음악은 편집 단계에서 얹는다.
- **제목**: 지금 제목이 "HORDE SHOOTER (가칭)"이다. 정식 이름 · 로고가 생기면 `ui_menu_title`이나 제목 카드를 바꾼다(로고 그림은 Codex).
- **분대 외형**: 분대원 모두 같은 파란 헬멧 차림이라 화면에서 잘 구별되지 않는다.

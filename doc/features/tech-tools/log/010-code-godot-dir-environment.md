# 010 · code · PC별 Godot 설치 경로 환경변수

- 작성일: 2026-10-29. 사용자 요청: `GODOT_DIR`을 읽도록 실행 스크립트 수정, 현재 PC의 사용자 환경변수 등록, 관련 문서 기록.
- 관련: I-46(다른 PC의 Godot 로컬 NuGet 경로 제약). 새 결정 ID는 추가하지 않음: 게임·도구의 별도 정책 변경이 아니라 사용자가 요청한 실행 경로 설정이며 선택 순서를 아래와 README에 기록했다. 새 이슈 ID도 추가하지 않음: 설치 위치 차이에 대한 실행기 대응과 기존 I-46의 남은 제약을 구분해 기록한다.

## 원인과 변경

- 기존 `game/Start-Game.ps1`은 `-GodotDir`을 생략하면 D 드라이브 경로를 사용했다. 해당 드라이브가 없는 PC에서는 `Join-Path`부터 실패했다. 환경변수를 지정해도 읽는 코드가 없어 무시되는 것을 수정 전에 확인했다.
- [Start-Game.ps1](../../../../game/Start-Game.ps1)은 명시한 `-GodotDir` → 프로세스 환경변수 `GODOT_DIR` → 기존 D 경로 순서로 선택한다. 환경변수가 없거나 빈 값이면 기존 경로를 유지한다. `.cmd`의 인수 전달은 그대로 사용한다.
- 현재 PC의 실제 Windows 사용자 설정에 `GODOT_DIR`을 사용자 요청의 C 드라이브 설치 폴더로 저장하고 같은 사용자 계정에서 다시 읽어 확인했다. 개인 설정값은 Git 파일에 저장하지 않았다. 별도 로컬 설정 파일과 `.gitignore` 수정 없음.
- [게임 README](../../../../game/README.md#pc별-godot-경로)에 등록 명령, 적용 우선순위, 새 프로세스 재시작과 현재 PowerShell 적용 방법을 추가했다. [루트 README](../../../../README.md#실행)에서 안내한다.

## 검증

- 수정 전: 실제 스크립트의 매개변수 블록을 PowerShell AST로 읽어 바인딩 검사. C 경로의 `GODOT_DIR`을 설정해도 D 경로가 선택되어 예상대로 실패했다.
- 수정 후: `.cmd`가 사용하는 Windows PowerShell 5.1.19041.7802에서 실제 스크립트의 구문 분석과 매개변수 블록 바인딩 검사 통과. 게임 실행 본문은 호출하지 않았다.
  - 실제 사용자 환경변수를 읽으면 C 경로 선택, 콘솔·창 모드 실행 파일 모두 존재: 통과.
  - `GODOT_DIR`이 있어도 명시한 `-GodotDir` 우선: 통과.
  - 환경변수 없음·빈 값 모두 기존 D 경로 유지: 통과.
  - 환경변수 없이도 명시한 `-GodotDir` 사용: 통과.
- 검증 환경 구분: 샌드박스는 별도 Windows 계정이라 실제 사용자의 저장값을 읽지 못해 첫 사용자 설정 검사가 실패했다. 실제 사용자 계정으로 동일 검사를 다시 실행하여 통과했다. 스크립트 수정이 추가로 필요했던 실패는 아니다.
- `git diff --check`: 통과.
- 게임 빌드·통합 검사·게임 창 실행·렌더: 미실행. 변경 범위는 실행기의 경로 선택이며 해당 동작과 설치 파일 존재를 검증했다.

## 남은 제약

- 이미 실행 중인 터미널·Codex는 환경변수 등록 전의 값을 상속할 수 있으므로 완전히 종료한 뒤 다시 연다. 현재 PowerShell만 즉시 적용하려면 README의 `$env:GODOT_DIR` 설정 명령을 사용한다.
- `Export-Game.ps1` 등 별도 스크립트는 이번 수정 범위에 포함하지 않는다.
- `game/nuget.config`의 D 드라이브 로컬 패키지 소스(I-46)는 그대로다. `GODOT_DIR`은 Godot 실행 위치만 선택하며 NuGet 소스를 자동 변경하지 않는다. 이 PC의 전체 빌드 성공은 아직 확인하지 않았다.

### 후속

- 같은 날 [기록 011](011-code-nuget-godot-dir.md)에서 NuGet 소스도 `GODOT_DIR`로 전환하고 C 설치 PC의 복원·빌드를 확인했다. 위 미검증·NuGet 제약은 이 작업 시점의 이력이며, 현재 상태는 후속 기록과 [I-46](../issues.md#i-46-pc별-godot-로컬-nuget-경로)을 따른다.

# 007 · code · 수관에 맞춘 낮은 품질 나무 그림자

- 관련: [M-37](../decisions.md#m-37-개인-그래픽-품질과-명시적-환경-분류), [최초 그래픽 옵션](006-code-graphics-options.md). 사용자 피드백: 낮음에서 나무 그림자가 없는 것처럼 보이며 가장 넓은 수관보다 넓어야 한다.
- 확인된 원인: 원본 manifest 폭×0.38을 반지름으로 쓰면서 최대1.5m로 제한했다. 실제 배치 스케일·회전과 수관 중심도 반영하지 않았다. 예시 나무의 실제 수관4.30×4.50m 대비 그림자는2.66×2.20m였고, 투명도0.20/빠른 가장자리 감쇠로 수관 아래에 가려졌다.
- 수정: 나무의 실제 월드 메시 경계 상자를 합쳐 수관 중심과 최대 폭을 구한다. 원형 그림자 지름을 폭의1.6배로 두고, 중심 농도0.46을 반지름의0.65까지 유지한 뒤 부드럽게 없앤다. 예시 나무는7.20m, 다른 배치 나무는6.33m로 서로 다르게 적용된다. 이 수치는 최종 사용자 수락 전 미술 조정값이다.
- 비용/범위: 시작 시 나무 크기를 한 번만 계산한다. 기존 MultiMesh 한 묶음과 전체256개 상한을 유지한다. 캐릭터/바위의 크기·농도·감쇠, 높은 그림자, 충돌/이동/시간대는 변경하지 않았다. 기존 개별 배치 KitProps 대상이며 외곽 MultiMesh 숲 전체를 새로 등록하는 작업은 포함하지 않는다.

## 검증

- 회귀 검사는 실제 배치 메시와 가장 가까운 그림자를 비교해 수관 밖까지의 크기 및 중심 정합을 검사한다. 초기 headless에서는 MultiMesh 변환 읽기가1×1로 나와 크기 근거로 쓰지 않았다. 실제 GPU에서 이전 크기를 복원해 **2.66×2.20m/검사 실패**를 확인하고 수정 코드로 되돌려 통과했다(`graphics-trees-red-gpu.log`).
- 최종 빌드 경고0/오류0. 실제 GPU `GraphicsOptionsCheck` **37 통과**(`graphics-trees-check.log`): 나무 크기/중심, 옵션 UI/입력, 저장 복원, 캐릭터 경사 접지, 도시 전환 포함. 오류/셰이더 오류 없음.
- [변경 전](../../../../game/output/graphics-trees-before.png), [변경 후](../../../../game/output/graphics-low.png), [수관을 잠시 숨긴 지면 검사](../../../../game/output/graphics-tree-shadow-ground.png). 실제 게임 렌더이며 마지막 이미지만 검사에서 나무2개의 가시성을 잠시 끈 진단 캡처다.
- 성능: RTX5070Ti에서 동일7지점/적30마리 비교를 재실행해 `FOREST_PERFORMANCE_PASS graphics-low`. 기존 낮음→수정 낮음의 평균 프레임은 숲 중앙1.710→1.725ms, 전투1.997→1.990ms. 중앙 렌더 호출317회 유지. 이 측정에서는 유의미한 비용 증가가 관찰되지 않았지만 저사양 하드웨어는 미검증이다. 로그 `game/output/graphics-trees-performance.log`, 이전 원자료 `forest-performance-graphics-low-before-trees.json`, 수정 원자료 `forest-performance-graphics-low.json`.

## 기록 검토와 제약

- M-37의 낮은 품질 단순 음영을 사용자 피드백에 맞춰 보정했다. 새 결정 ID는 필요하지 않다. 아직 커밋되지 않은 그래픽 구현의 수정 이력으로 이 로그에 원인과 재현을 보존하며 별도 원격 이슈 예약/푸시는 수행하지 않았다.
- 낮음은 나뭇잎 투영이나 풀 위의 실시간 그림자가 아닌 지면 원형 음영이다. 높은 품질과 같은 방향성/세부 모양을 재현하지 않는다. 가까운 개별 배치 나무 중심의 기존 대상·거리·상한은 유지한다.

# 006 · code · 개인 그래픽 옵션

- 작성일: 2026-10-28. 관련: M-37, [환경 분류](../../art-environment/environment-categories.md), [계획](../../../../docs/superpowers/plans/2026-10-28-graphics-options.md).
- 범위: 기존 `codex/forest-surface-quality` 작업 트리의 바위/풀 개선을 유지하면서 그래픽 옵션과 환경 분류만 추가한다. 랜덤 시간대, 시계, 조명/날씨 효과 자동 적용은 없음.

## 화면과 저장

- ESC → 그래픽, 메인 메뉴 설정 → 그래픽에 공통 `GraphicsOptions`를 사용한다. 그림자·표면·소환수 모델의 높음/낮음은 상호 배타 선택이며 체크·색·테두리로 상태를 보여 준다.
- 각 변경은 바로 적용하고 `user://settings.cfg`의 graphics.shadow_quality / surface_quality / 기존 pet_quality에 저장한다. 기본값/유효하지 않은 숫자는 높음. 검사에서는 별도 임시 설정 파일을 써 사용자 설정을 보호한다.
- `Start-Game.ps1`처럼 메인 메뉴 없이 스테이지를 직접 실행할 때도 시작 시 저장 설정을 불러온다. 검사 장면의 자식 Stage는 사용자 설정을 읽지 않는다.
- 그래픽에서 뒤로/ESC는 일시정지 메뉴로 돌아가고 다음 ESC는 재개한다. 돌아간 뒤에는 버튼 초점을 해제해 기존 Enter 재시작/방으로 돌아가기 단축키를 가로채지 않는다. 탭으로 버튼을 선택한 경우 Enter는 정상 버튼 조작이다.
- 온라인에서는 세계는 계속 움직이고 내 메뉴만 열린다. 메뉴 중에는 이동·사격·장비/상호작용 입력을 차단하며 메뉴 닫기 클릭과 누르고 있던 E가 바로 발사/상호작용으로 이어지지 않는다.

## 렌더 동작

- 그림자 높음: 각 광원이 원래 갖고 있던 ShadowEnabled와 환경 SSAO 값을 복원한다. 조명 색/방향/세기에는 손대지 않는다.
- 그림자 낮음: 실제 그림자 맵과 SSAO를 끈다. 새로 생기는 광원에도 적용한다. 살아 있는 플레이어·가까운 적, 선택한 자연 소품에는 단순 타원형 음영을 MultiMesh 한 묶음으로 표시한다. 전체256/캐릭터192 한도이며 플레이어 우선, 적은 가까운 순서. 지면/경사로 접점은 월드 물리 레이로 구하고 경사에 맞춰 눕힌다. 그림자에는 충돌이 없다.
- 적 후보 선택은0.1초마다 갱신한다. 물리 레이는 물리 프레임당 최대32회이며 바닥 없는 결과도 캐시한다. 풀 개수·적 개수·AI·판정은 줄이지 않는다.
- 표면 낮음: 숲의 흙 미세 입자/자갈, 바위 틈 세부 계산, 도시의 잔 균열/얼룩/자갈, 풀 바람 등을 생략한다. 큰 색/흙길·도로·보도·표시선·위험 표시 유지. 실제 이미지 텍스처 용량이나 해상도를 낮추는 기능은 아니다.
- 높은 품질의 기존 계산은 유지한다. 설정은 해당 PC의 렌더에만 적용되며 네트워크로 공유하지 않는다.

## 검증

실제 실행 결과를 아래에 기록한다. 단순 그림자/메뉴 캡처는 `game/output/graphics-*.png`, 성능 원자료는 `forest-performance-graphics-{high,low}.json`이다.

- 최초 새 검사/인터페이스를 추가한 상태에서 빌드가 미구현 품질 API로 실패한 로그를 확보한 뒤 구현했다(`graphics-red-build.log`). UI의 모든 실패를 런타임에서 먼저 재현한 완전한 red-green 절차는 아니다.
- 검토 중 일시정지 복귀 버튼의 Enter 가로채기, 온라인 메뉴에서 Stage의 E 입력이 남는 경로를 확인해 함께 수정했다. 낮음에서 전체 적 정렬을 매 프레임 수행하던 구현도 범위 필터·0.1초 후보 갱신·레이 예산으로 바꿨다.
- 최종 빌드 경고0/오류0. 실제 GPU `GraphicsOptionsCheck` **33 통과**, 메인 메뉴 **44 통과**, 소환수 회귀 **39 통과**, 환경 분류 **265 통과**. 실제 클릭/Esc 입력, 저장 재시작, 직접 Stage 실행, 높음 복원, 신규 광원/적, 높은 바닥·경사로, 숲→도시 전환을 검사했다. 오류/셰이더 오류 없음. 수동 장시간 플레이 대신 자동 입력과 실제 게임 렌더 검증이다.
- 렌더: [옵션 낮음](../../../../game/output/graphics-menu-low.png), [숲 높음](../../../../game/output/graphics-high.png), [숲 낮음](../../../../game/output/graphics-low.png), [경사로](../../../../game/output/graphics-ramp-low.png), [도시 높음](../../../../game/output/graphics-urban-high.png), [도시 낮음](../../../../game/output/graphics-urban-low.png). 높은 품질의 방향 그림자와 낮은 품질의 접지 음영, 낮은 표면에서도 도로·보도·중앙선 유지 확인.

### 성능 측정

RTX 5070 Ti, 같은 맵/카메라 위치, 출력1280×720(논리1600×900), VSync/FPS 제한 없이 각 지점 준비2초·측정4초. 높음/낮음은 그림자와 표면을 함께 변경했다. 전투 구역은 적30마리. 두 실행 모두 `FOREST_PERFORMANCE_PASS`. 수치는 이 PC에서의 결과이며 저사양 성능 보장은 아니다.

## 제약

- 투명한 단순 음영은 정밀한 투영 그림자가 아니며 가림·높은 물체의 실루엣은 생략된다. 기존 낮은 그림자에서 실제 광원 방향은 표현하지 않는다.
- 실제 저사양 GPU, 대규모 호드/6인 네트워크 장시간 비교는 미검증이다. 로컬의 세계 진행 상태에서 메뉴 입력 차단은 검증한다.
- 환경 분류는 데이터/검증만 있고 현재 맵이나 Studio의 환경 편집 UI에 연결하지 않았다.
- 최초 구현 시에는 작업 트리에 보존했으며 이후 사용자 요청으로 메인에 병합했다. [통합 검증](008-check-graphics-main-integration.md).

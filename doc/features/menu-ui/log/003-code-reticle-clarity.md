# 조준 표시의 의미 정리와 장전 네 점 제거

관련: **M-33 · C-30 · C-32**, [계획](../reticle-clarity-plan.md), [M-33 현재 결정·변경 이력](../decisions.md#m-33-장전충전-포인터와-반투명-진행-ui), [C-30 외형 보강](../../combat/decisions.md#c-30-조준-표시의-의미와-강조-보강), [무기 규격](../../../weapon-spec.md).

## 요청과 확인

사용자가 타겟 조준 개선과 장전 원 주변 네 점의 의미를 물으며, 의미 없는 장식은 제거하고 의미 있는 정보는 인지할 수 있어야 한다고 요청했다. 우리 네 점은 일반 조준 눈금을 회전·축소한 고정 장식이며 퍼짐·탄수·진행률을 나타내지 않았다. 참고 게임의 원래 의도는 확인되지 않았다. 원형 진행 표시가 이미 커서 위치/진행을 나타내므로 네 점에 임의의 새 의미를 붙이지 않고 제거했다.

## 변경

- `Hud.cs`: 장전/충전/재충전 진입 중 일반 눈금·중앙점은 제자리에서 사라진다. 고정 네 점 없음. 진행 링과 실제 명중 표시는 유지한다.
- 일반 조준은 주 눈금14×4px/중앙점 유지, 바깥 대각10×2.5px·알파0.65(차가움)~0.9(연사)로 시각 우선순위를 낮춘다. 열기/명중 번짐6겹, 어두운 선 알파0.4→0.28. 집중 원은 공유 `DrawLightArc`의 황금 번짐/밝은 중심과 어두운 트랙으로 그린다.
- `hud-polish.csv` 한/영 `hud_reticle_legend`: 조준 위치/기준·현재 퍼짐/거리 경고/연사 열기/집중 치명타/명중/장전 표시의 의미를 Esc 조작법에 추가했다. 거리 경고는 안쪽 눈금, 연사 열기는 바깥 대각이라고 구분했다. 일시정지 본문880px와 자동 줄바꿈으로 작은 창에서도 읽히게 했다. 상시 설명 라벨은 추가하지 않았다.
- 무기 데이터, 퍼짐·사거리·반동·조준 보조·집중 타이머/소비·피해 판정은 변경하지 않았다. 집중은 기존대로 다음 한 발 치명타 준비이며 명중 보장이 아니다.

최종 실행 로그에 오류·경고·종료 누수 없음. 변경 기능 문서의 로컬 링크31개와 `git diff --check` 통과. 한/영 안내 키가 각각1개 존재하며 실제 렌더에서도 번역된 안내를 확인했다.

### 검사 중 발견한 캡처 제약

영어 조작법을 마지막 장으로 저장한 뒤 즉시 종료하는 실행에서 일부 글자/HUD가 빠지거나 마지막 장이 빈 화면으로 저장됐다. 같은 실행의 직전 `aim-controls-open.png`는 정상이라 텍스트/레이아웃 부재가 아닌 마지막 캡처와 종료 경로의 문제로 좁혔다. 메뉴를 연 뒤3프레임 기다리는 것만으로는 해결되지 않았고, 최종 저장 후 장면을15프레임 유지하고 종료하도록 검사 도구를 바꾸자 정상 이미지가 저장됐다. 렌더 작업과 종료 중 자원 정리가 겹치는 타이밍으로 추정하며 엔진 내부 원인을 확정한 것은 아니다. 제품 코드에는 지연을 넣지 않았다. 단순 검사 통과 숫자만으로 렌더 정상 여부를 판단하지 않았다.

재현: Godot에 `--path game --max-fps 60 res://tests/ReloadUiCheck.tscn` 또는 `res://tests/WeaponAimCheck.tscn`을 전달. headless는 `--headless`, 렌더는 `--resolution 1600x900`/`1280x720`. 장전의 영어/창고 위치는 `-- --still-only --outdoor --english`; 조준 영어는 `-- --english`. `Start-Game.ps1 -Test`는 Integration만 실행한다.

## 렌더와 검토

- 장전: `reload-ui-half.png`, `reload-ui-outdoor-half.png`. 진행 링만 남고 주변 네 점 없음. 명중 표시는 `reload-ui-recharge-hit.png`로 별도 확인.
- 일반 조준/연사/집중/명중: `reticle-kor/aim-hip.png`, `aim-aimed.png`, `aim-hip-burst.png`, `aim-focus-ready.png`, `aim-hit.png`(같은 폴더). 주/보조 눈금과 상태별 빛 표현 확인.
- 조작법: `reticle-kor/aim-controls.png`(1600×900 한국어), `reticle-eng/aim-controls.png`(1280×720 영어). 설명 전체와 버튼이 화면 안에 보인다.
- 독립 읽기 전용 검토에서 조치할 문제 없음. 조준/거리/집중 판정 유지, 장전 UI의 의미, 두 언어 화면 및 픽셀 검사 조건 검토.

## 기록 검토와 제약

M-33 현재 내용/바뀐 결정, C-30 외형 보강 본문과 색인, 규격/참고 분석/체크리스트를 갱신했다. 기존 C-30 표와 최초 장전 기록은 당시 이력으로 보존했다. 새 게임 규칙이나 확정 제품 결함을 추가한 작업이 아니므로 새 결정·이슈 ID를 발급하지 않았고 기존 이슈 상태도 바꾸지 않았다.

모양·치수는 외형 최종 수락 전 제작값. 모든 배경/거리/해상도 조합, 실제2PC, 내보내기, 장시간 성능은 미검증. 참고 게임의 네 점 의미를 밝혀낸 작업은 아니다.

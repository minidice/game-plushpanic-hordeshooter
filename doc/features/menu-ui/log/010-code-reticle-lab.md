# 전체 무기 조준점 실험실

관련: C-30 · M-33 · M-27 개발 실험실. 사용자 요청: “쉽게 다 바꿔보며 확인해볼 방법”. 기존 카드 실험실은 F11/F12로 난전 무기 풀을 순환하지만 권총·M82가 빠져 있어 전체 조준점 검수에는 부족했다.

## 설계·변경

- 별도 전투 시스템을 만드는 대신 기존 카드 실험실의 평온한 필드·무적·무한 예비탄을 재사용하는 **선택 실행 모드**로 구현했다. 기존 `-CardLab` 동작은 유지한다.
- 실행: 저장소에서 `./game/Start-Game.ps1 -ReticleLab`. 내부적으로 `CardLab.tscn -- --reticle-lab`을 실행한다.
- CSV에서 읽은 전체 무기와 `DualVariant`를 목록에 포함한다. 현재21종(권총2종·쌍권총2종·M82·특수무기·근접 포함). 목록 직접 선택/이전·다음 버튼/F11·F12를 지원하고 양 끝에서 순환한다.
- 선택하면 진행 중 충전/투척 조준을 취소하고 입력·반동을 지운 뒤2번 칸에 새 무기를 장착한다. 탄창은 가득 찬 상태다. 목록 클릭이 발사로 이어지지 않도록 패널/팝업 위에서는 기존 HUD 입력 억제 경로를 사용한다. 포인터 진입과 클릭이 같은 프레임에 들어와도 물리 입력 처리보다 먼저 억제되도록 `_Input`과 팝업 열기 신호에서 즉시 반영한다.
- 좌클릭 사격·우클릭 조준·R 장전은 실제 게임 조작이다. Home은 선택 무기를 다시 지급해 즉시 탄창을 채운다. T 과녁, F7 적 무리, Backspace 적·과녁 제거, F10 느리게/원래 속도. 카드 조작은 이 모드에서 제외하고 목적 문구도 조준점 실험실로 바꾼다.
- 일반 총은 무한 예비탄이지만 탄창 소비·장전은 유지한다. 특수무기는 기존 난전 실험실의 재충전 규칙을 사용한다. 캠페인의 유한 예비탄/특수무기 장전을 비교하는 전용 모드는 아니다.

## 구현·검사 계획과 결과

1. 기존 실험실에서 직접 선택기가 없음을 ReticleLabCheck 실제 장면으로 실패 확인(`reticle-lab-red.log`).
2. CardLab의 명시적 실행 분기와 별도 `CardLabReticle.cs`, 한/영 설명, Start-Game 실행 스위치를 추가.
3. 전 카탈로그·쌍권총 선택/장착/탄창, 이전·다음 순환, 장전 중 교체, Home 재지급, 무적·무한 예비탄, 자동 적 없음, 팝업 입력 억제를 실제 장면으로 검사.
4.1280×720 실제 패널/전체 목록 렌더 확인. 기존 CardLabCheck 회귀를 순차 실행하고 결과를 아래에 남긴다.

- Debug 빌드: 오류·경고0. Godot 가져오기: 종료0 (`game/output/reticle-lab-import.log`).
- ReticleLabCheck 실제 렌더: **53 통과**, 오류·종료 경고 없음 (`game/output/reticle-lab-final.log`). 수동 조작 우회 없이 실제 마우스 입력으로 목록 열림·첫 프레임 억제·탄창 미소비도 검사했다. 동기 억제를 제거한 상태에서 새 검사가 실패함을 확인한 뒤 복구해 통과했다 (`reticle-lab-input-red.log`, 의도한 실패).
- 기존 카드 실험실 회귀: **172 통과**, 오류·종료 경고 없음 (`game/output/reticle-lab-regression.log`).
- 코드 리뷰: 최초 클릭의 프레임 순서 문제를 수정한 뒤 재검토에서 추가 지적 없음.
- 렌더: `game/output/reticle-lab.png`, `reticle-lab-list.png`.720p에서도21종 목록 전체와 선택 패널이 화면 안에 보인다.

## 기록 검토·제약

개발용 검수 경로 추가이며 전투 규칙/조준점 계약을 새로 결정하지 않았다. 기존 C-30/M-33/M-27의 확정 내용·이슈 상태를 바꿀 필요가 없어 신규 결정/버그 ID를 만들지 않았다. 기능 체크리스트에 실행 경로를 추가한다. 문서와 검사 코드를 같은 커밋에 포함한다.

실제 캠페인 예비탄 소진과 멀티 동기화는 이 실험실 검수 범위 밖이다. 일반 플레이·전체 패키지 내보내기·저사양 장시간 부하는 이번 개발 도구 추가에서 다시 검사하지 않는다.

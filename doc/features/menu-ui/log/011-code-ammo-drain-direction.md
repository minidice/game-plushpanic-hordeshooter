# 탄창 잔량 원호의 소모 방향 반전

관련: M-33. 사용자 요청: 기존 아래→위로 올라가는 소모 방향을 반대로 변경.

- `HudReticle.DrawMagazineAction`의 잔량 채움을 원호 시작점 기준에서 끝점 기준으로 바꿨다. 기본 오른쪽 아래 배치에서 위쪽부터 지워지고 남은 탄약은 아래쪽에 남는다.
- 탄창 비율·원호 전체 위치·발사 모드 도형·장전/충전 진행 방향과 전환 시간은 유지한다. 기존 M-33 현재 내용/변경 이력, 결정 색인, 상세 무기 규격, 설계 문서를 함께 갱신했다.
- UI 방향에 대한 사용자 수정이며 새 고장이나 독립 결정이 아니므로 새 이슈/결정 ID는 만들지 않았다. 기능 완료 범위는 같아 체크리스트의 완료 상태는 유지한다.

## 검사·렌더

- Debug 빌드: 오류0·경고0.
- `ReticleCheck.tscn` 1600×900 실제 렌더: 52 통과, 종료0. 반 탄창에서 위쪽 트랙이 비고 아래쪽 채움이 남는 화면을 직접 확인했다. 장전 진입/취소/복귀와 화면 가장자리도 기존 검사 통과. 로그 `game/output/reticle-direction-check.log`, 렌더 `game/output/reticle-m4-half.png`.
- `ReloadUiCheck.tscn` 헤드리스: 38 통과, 종료0. 1600×900 실제 렌더: 42 통과, 종료0 (`game/output/reticle-direction-reload-render.log`). 세 실행 모두 오류·종료 경고 없음.
- 남은 제약: 화면 가장자리에서는 기존 사분면 보정에 따라 원호 위치도 반전된다. 이번 수정은 소모 각도 방향만 바꾼다. 전체 통합·내보내기는 재실행하지 않았다.

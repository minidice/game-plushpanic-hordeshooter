# 조준 표시의 의미와 강조 정리

> 실행: 기존 워크트리에서 `superpowers:executing-plans` 방식으로 직접 진행한다.

사용자 요청: 타겟 조준도 개선하고 장전 원 주변 네 점의 용도를 설명한다. 의미 없는 장식은 제거하고 의미 있는 정보는 인지할 수 있게 한다.

확인: 현재 장전 네 점은 일반 조준 눈금을 회전/축소한 고정 장식이다. 퍼짐·탄수·진행률을 표시하지 않는다. 원작의 의도는 확인되지 않았다. 일반 안쪽 눈금은 조준 퍼짐, 대각 눈금은 현재 퍼짐, 가운데 점은 조준 위치, 황금 원은 집중 치명타 진행, 두 줄 명중 표시는 실제 내 공격 명중이다(C-30/C-32).

제작안: 장전/충전 진입 시 일반 조준은 제자리에서 사라지고 진행 링만 남긴다. 사격 가능 상태에서는 중앙점/안쪽 눈금을 선명하게, 바깥 퍼짐 눈금을 더 짧고 가늘게 표시한다. 열기/명중의 번짐을 부드럽게 하고 집중 호는 공유 발광 호를 사용한다. 사거리 색과 퍼짐/반동/집중 판정은 유지한다. Esc 조작법에 한국어/영어 의미 안내를 추가한다. 상시 설명 라벨은 추가하지 않는다.

접근 비교: 네 점에 새 탄수/단계 의미를 부여하면 현재 규칙과 불필요한 대응을 만들어야 한다. 단순 숨김만으로는 일반 조준 개선 요청이 남는다. 따라서 무의미한 장전 장식 제거+기존 조준 정보의 시각 계층 조정을 선택했다. 이미지 에셋이나 새 게임 규칙은 필요 없다.

## 실행

- [x] `ReloadUiCheck.cs`: 실제 렌더의 링 주변 네 점 영역을 비교해 장전 시 장식 부재와 진행 링 존재를 확인한다. 변경 전 네 점 존재로 실패 확인.
- [x] `Hud.cs`: 장전 시 일반 조준 페이드, 주/보조 눈금 위계, 상태별 번짐, 집중 호, 일시정지 조작법 설명. `hud-polish.csv` 한/영 안내.
- [x] `WeaponAimCheck.cs`: 기존 실제 조준/연사/명중·집중 검사와 렌더에 집중 준비/조작법 화면 추가. 빌드→장전 전용→조준 전용→통합을 순차 실행하고 두 해상도·두 언어 실제 렌더 확인.
- [x] M-33 현재 내용/바뀐 결정, C-30의 외형 보강 추가 기록, 규격·체크리스트·새 작업 기록 갱신. 기존 본문은 보존. 같은 커밋에 기록.

성공 기준: 장전 50%에서 원 주변 네 점이 보이지 않는다. 타이머·명중표시·완료/취소/교체 계약이 유지된다. 조준 상태에서 중심/기준 퍼짐/현재 퍼짐의 우선순위가 구분되고 Esc 설명은 한/영 1280×720에서도 읽힌다. 색·치수는 제작값이며 외형 최종 수락 전이다.

실행 결과: [작업·검사·제약](log/003-code-reticle-clarity.md). 한글은1600×900, 영문은1280×720에서 조작법을 확인했다. 최종 캡처 직후 종료 시 이미지 누락이 있어 검사 도구에서 저장 후15프레임 장면을 유지한다. 제품 코드의 대기나 타이머 변경은 없다.

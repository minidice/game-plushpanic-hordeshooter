## 설계

목표: 어두운 반투명 면·밝은 중립 글자·청백색 선택/행동 빛을 메뉴부터 HUD·상호작용까지 공유한다. 기존 위험 빨강·치료 초록·집중/희귀도 황금 등 의미색은 보존한다.

선택지: (A) 화면 하단 안내만 꾸미면 물체 연결이 약하다. (B, 사용자 승인 추천 방향) 작은 월드 표식 → 선택 대상 하나의 행동/키 → 실제 진행/중단 피드백. (C) 모든 물체에 큰 문구를 띄우면 호드/협동 가독성을 해친다. B를 기존 HUD 재질로 구현한다.

- UiTheme에서 기본/보조 글자, 반투명 면, 선택, 진행 빛, 전환 시간, 둥근 패널/게이지 자원을 공유. 무기별 조준 실루엣·잔탄 감소 방향·사거리/명중/집중/공격 불가 의미와 입력은 유지.
- 물체에 작은 표식, 조작 가능한 대상 하나에 짧은 행동+E 키 캡슐. 가까운 화면 내 가시 대상만 표시, 다른 층/벽 너머 발견 표식은 제한. 화면 가장자리 보정, 물체에 연결되는 짧은 선, 조준점을 가능한 한 피하는 배치.
- 선택은 실제 Stage.FocusedInteractable/RevivePromptTarget와 일치. 표시만 부드럽게 전환(진입0.16초, 퇴장0.12초, 제작값), 사용 불가 즉시 키 강조 해제. 빈 경계에서 짧은 잔상은 가능하되 활성으로 보이지 않음. 삭제/메뉴/사망에서는 즉시 정리.
- L-35의 머리 위 진행 바+하단 퍼센트를 유지하면서 공통 청백색 진행 스타일 적용. 문 옆에도 작은 진행 바. 피격 중단은 명시하고 취소를100%로 만들지 않는다. 구조는 실제 동료 진행값을 읽음.
- 메뉴·설정 버튼·장비 선택·인벤토리 면을 공통 스타일로 정돈. 카드 등급/팀 투표 의미색은 유지. 메뉴 구조와 게임 규칙 변경 없음.
- 완료는 실제 비활성화/구조 상태 변화에만 반응. 사용 요청만으로 성공을 표시하지 않는다. 원격 동료 진행/사용 불가 사유 등 현재 데이터에 없는 상태를 추정해 표시하지 않는다.

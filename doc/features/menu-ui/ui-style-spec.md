# 공통 UI 스타일과 상호작용 표시

관련: M-38, [계획](interaction-ui-plan.md), [작업 기록](log/013-code-ui-consistency.md), [조준·장전 계약](../../weapon-spec.md#64-장전충전-진행-ui-m-33), [기지 문 규칙](../level/stage1-tutorial-scenario.md#4-기지-문-길게-누르기-l-35).

## 방향과 소유자

사용자 승인: 참고 영상 기반 추천안으로 진행하고 최근 총 조준점까지 전체 UI 품질·느낌의 일관성을 유지(2026-10-28). Godot 벡터 UI와 `UiTheme`의 공유 자원으로 구현한다. 아래 치수·알파·시간은 제작값이며 최종 외형 수락과 구분한다.

| 역할 | 공통 값·사용 |
|---|---|
| 기본 글자 / 보조 글자 | `Paper` #f3f4f1 / `Muted` #a8b6c9 |
| 기본 면 / 선택 면 | `Surface` 짙은 남색 alpha .83 / `SelectedSurface` alpha .94 |
| 선택·사용 가능 | `Selection` #b8e5ff. 버튼, 장비 칸, 키 표시, 메뉴 제목 |
| 진행 | `ActionLight` 청백색 중심 + `ActionGlow` 청색 번짐, `ProgressTrack`/`ProgressFill` |
| 조준 | `Glass` 어두운 트랙, `SightTint` 청회색. 기존 무기별 형태·탄창 소모 방향 유지 |
| 의미색 예외 | 피해/실패 빨강, 치료 초록, 집중·보상 황금, 카드 등급·투척물 종류색. 모든 UI를 파랑으로 덮지 않는다 |
| 면과 글자 | `Plate` 기본12px 모서리·얇은 테두리·안티앨리어싱. 버튼10px, 작은 칸6~8px. 글자 윤곽2px |
| 동작 | 진입 .16초, 일반 퇴장 .12초. 무기 조준 복귀 .20초는 M-33 유지 |

적용: HUD 면/장비 선택/도약/동료 체력 바/인벤토리, 일반 메뉴·ESC·그래픽 설정·공통 버튼/입력칸, 상호작용, 조준·탄창 원호·장전 진행. 카드·투표는 기존 HudPlate 공통 면과 의미색을 유지한다. 메뉴 구조·카드 규칙·게임 밸런스 변경 없음.

공통 색·패널을 새 화면에서 다시 숫자로 복제하지 않는다. 기본 면은 `UiTheme.Plate`(기존 HUD 호출은 `HudPlate`), 진행은 `UiTheme.DrawProgress`, 선택은 `Selection`을 쓴다. 별도 색은 역할이 있는 경우만 지정한다.

## 메뉴·게임 진입 전 화면

사용자 후속 요청(2026-10-28): 메뉴와 게임 진입 전 화면에도 같은 품질을 적용하고, 어울리지 않는 주황·노랑 메뉴 강조를 없앤다. [작업 기록014](log/014-code-menu-entry-style.md).

- 홈/커스터마이징/싱글 출격 준비/멀티 방 목록/로비/설정/그래픽 화면은 기존 이동 구조를 유지한다. 왼쪽 캐릭터 미리보기와 오른쪽 조작 영역을 같은 둥근 패널로 묶고, 내부 여백18/24px와 모서리18px를 사용한다(제작값).
- 일반 메뉴 강조에는 `Selection` 청백색을 사용한다. 주황·노랑을 메뉴 장식/선택/포커스에 사용하지 않는다. 캐릭터 자체의 털·부리·장비 색과 색상 편집기의 실제 견본은 데이터 그대로 표시한다.
- 기본/호버/누름/키보드 포커스/비활성, 드롭다운과 팝업, 커스터마이징 탭, 슬라이더·스크롤 바, 체크 스위치를 공통 테마로 지정한다. 드롭다운 팝업은 alpha .98로 뒤쪽 글자와 겹치지 않게 한다. 화살표/손잡이/스위치는 코드 내 작은 SVG로 생성하며 외부 에셋 의존을 추가하지 않는다.
- 출격/방 시작/준비 같은 주 행동은 청회색 면과 청백색 글자를 사용한다. 종 선택은 실제 눌림 상태로 표시해 키보드 포커스가 옮겨져도 선택이 남는다.
- 캐릭터 미리보기 조명은 중립 흰색·옅은 청색, 받침대는 청회색으로 맞춘다. 게임 월드 조명과 캐릭터 재질 데이터는 변경하지 않는다.

## 상호작용

- 발견: 7m 이내, 수직 차이1.5m 이내, 카메라 앞, 시야와 장애물 검사를 통과한 물체에 작은 표식. 최대 가까운12개, 후보 갱신 .12초. 삭제/비활성/숨김은 그리기에서도 즉시 제외한다. 이미 있는 바닥 줍기 링과 피해 예고 규칙은 유지한다.
- 선택: `Stage.RevivePromptTarget` 우선, 이후 실제 `FocusedInteractable`. UI가 임의로 다른 E 대상을 고르지 않는다. 물체 옆 한 개의 행동 이름+키. 짧은 연결선으로 대상 표시. 키 E는 현재 고정 입력과 동일하다.
- 전환: .16초 진입/.12초 퇴장, 부드러운 알파와5px 이내 이동. 재접근하면 기존 알파에서 역전한다. 대상 교체는 문구를 즉시 갱신하며, 범위 이탈 즉시 E 강조를 끈다. 사망/쓰러짐/구속/메뉴/인벤토리/카드/전체 정지에서는 즉시 숨긴다.
- 배치: UI 논리 좌표에서 문구 길이에 맞춘190~330px 폭, 제목17px·보조13px. 긴 제목은 말줄임. 위150px/하단270px 영역과 화면 좌우16px를 비우고, 조준 중심 주변과 겹치면 반대쪽에 배치한다. 조준 레이어를 월드 안내보다 위에 둔다. 모든 장면의 픽셀 단위 무충돌을 보장하는 자동 레이아웃은 아니다.
- 홀드: 실제 `HoldProgress`와 구조 대상 `ReviveProgress`를 읽는다. 머리 위80×12px 바(기존70×8px를 외형만 보강), 하단 퍼센트는 L-35에 따라 유지하고 대상 안내에도 작은 바를 붙인다. 마우스 조준점을 상호작용 게이지로 바꾸지 않는다.
- 중단: 자기 문 열기/자기 구조가 피격으로 중단되면 .75초 이유를 표시한다. 실제 취소 상태일 때 키를 떼고 다시 누르도록 안내. 취소를100%로 표시하지 않는다. 다른 사람이 구조 중이면 그 진행과 ‘동료가 구조 중’을 표시하고 E 강조를 낮춘다.
- 완료: 실제 물체 비활성화/동료 구조 상태 변화에 .30초 완료 표시. 로컬 홀드 제출 이벤트는 대상을 기억하는 용도이며 성공 아님. 클라이언트도 호스트 상태 확인 후 표시하고, 대상 변경/화면 숨김 때 대기를 버린다. 해제된 대상 노드는 즉시 정리한다.

## 기존 계약과 제한

M-33의 권총/기관단총/소총/산탄총/기관총/저격 실루엣, 탄창 잔량(위→아래 소모), 발사 방식, 장전 취소/완료는 유지한다. M-36 공격 불가는 보조 청회색으로 맞추되 원+사선 의미 그대로. 거리 경고·집중·명중 색과 판정은 유지한다.

물체 사용 조건/벽·층을 통과한 실제 E 판정은 이번에 변경하지 않는다. 발견 표식만 가시성 검사를 추가하고 실제 선택 안내는 게임 판정과 일치시킨다. 임의 사용 불가 사유, 새 협동 진행 동기화, 새 대기 시간/키 재설정은 추가하지 않는다. 네트워크 입력·권한은 그대로이며 `HoldSubmitted`는 표시용 알림이다.

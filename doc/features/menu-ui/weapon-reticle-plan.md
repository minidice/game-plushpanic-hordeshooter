# 무기별 조준점과 탄창 전환

2026-10-28. 사용자 수락: 무기 계열별 형태 + 언어 독립 발사 방식 글리프 + 오른쪽 아래 탄창 잔량 원호가 장전 링으로 전환하는 추천 방향. 전체 조준점은 기존 충전 UI와 동급의 반투명 바탕·색 조합·부드러운 경계를 사용한다. 외형 세부 수치는 제작값이며 렌더 수락 전이다.

## 설계와 대안

- 공통 십자 유지: 익숙하지만 무기 계열을 읽기 어렵다. 총마다 완전히 별개 UI: 식별 부담과 제작량이 크다. **선택: 계열 형태 + 실제 무기 상태에 따른 움직임**, 상태 표시 문법은 공유한다.
- 권총 꺾인 좌우 눈금, SMG 좌우 호, 소총 십자, LMG 모서리 괄호, 산탄 분절 원호, 저격 가는 눈금. DMR은 저격보다 짧다. 중앙점은 유지한다.
- 현재 퍼짐을 주 눈금, 완전 조준 시 기준을 옅은 보조 눈금으로 표현한다. 실제 산탄 폭은 PelletSpread와 AimProgress로 구한다. 화면 도형은 수평 퍼짐의 안내이며 2D 탄착 영역/명중 보장이 아니다.
- 글리프는 텍스트 없이 단발 한 획, n점사 n획, 자동 두 꺾쇠. BurstCount를 Automatic보다 먼저 판별한다. 탄창 잔량은 Mag/MagSize, 예비탄 무한과 무관하다. 2026-10-28 후속 피드백으로 원호 끝점을 고정하고 시작점부터 소모하여 기본 배치에서 위→아래로 줄어든다.
- 오른쪽 아래 원호는 집중/명중 눈금보다 바깥에 둔다. 장전·충전·재충전 때 원호의 반경/시작각/길이를 중앙 진행 링으로 전환하고 글리프/일반 조준은 페이드한다. 진행 자체는 기존 실제 타이머를 즉시 읽는다. 완료/취소/한 발씩 장전/무기 교체 계약은 유지한다.
- 근접·꽥·투척에는 총기 글리프/탄창 원호를 붙이지 않는다. 로켓·레일건·박격포는 기존 공격/충전 경로를 유지한다. 공격 불가·투척 조준·메뉴·사망의 우선순위 유지.
- 집중은 안쪽 황금 호, 탄창은 바깥 흰색/청회색, 장전은 청백색. 얇은 밝은 중심 + 색 가장자리 + 투명한 어두운 받침 + 낮은 번짐을 공유한다. 별도 텍스처·셰이더·총 성능 변경 없음.

## 구현 계획

> 실행: superpowers:executing-plans로 이 세션에서 직접 구현한다. 사용자의 진행 지시가 실행 승인이다.

**Goal:** 무기 식별, 발사 방식, 탄창 잔량과 장전 전환을 커서 근처에서 읽게 한다.

**Spec:** 이 문서의 설계 + 기존 weapon-spec.md 6.4/8장, C-30/C-32/M-33/M-36.

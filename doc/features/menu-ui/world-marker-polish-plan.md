# 월드 링·범위·공격 예고 외형 정리

> 실행: 기존 `codex/hud-light-polish` 워크트리에서 직접 진행한다.

사용자 요청: 무기 주변 링, 곡사/수류탄 범위, 몬스터 공격 범위도 현재 HUD처럼 고급스럽게 개선한다.

제작안: 공통 바닥 표시 `GroundMarker`(원/직선 영역)와 거리 기반 셰이더로 밝은 경계·부드러운 번짐·낮은 내부 채움을 만든다. 기존 입체 도넛/원판/박스를 대체한다. 둥근 도형의 PNG는 크기별 관리가 필요하고, 여러 겹 메시 방식은 중첩/그리기 비용이 늘어 셰이더 평면을 선택한다. 줍기 링은 기존 분류색/약한 강조, 내 착탄 범위는 기존 투척 종류색, 적 공격 예고는 붉은 경계로 구분한다. 새 게임 규칙이나 전체3D bloom 설정은 추가하지 않는다.

범위: WeaponPickup/LootPickup, ThrowPreview(착탄/최대거리/곡선 점), MortarShell(비행 중 착탄 예고), BullEnemy 돌진, BossEnemy 내려찍기·산개 사격, RangedEnemy 총격·독, CaptureEnemy 바닥 준비선. 붙잡힌 뒤의 실제 연결선과 폭발/불/독 지속효과는 기존 표현을 유지한다.

계약: 피해·반경·시간·네트워크·취소·층 높이 판정은 그대로. 투척 착탄 원 반경은 기존 표시 반경(`max(.6, AimRadius/ExplosionRadius)`)에 고정하고 크기 맥박은 제거한다. 밝은 경계가 기준 반경, 바깥 번짐은 약한 장식이다. 보스/비행 포탄의 진행 채움은 기존 타이머를 읽으며 최대 범위 경계는 고정한다. 돌진 경로의 기존 길이계수0.7과 폭은 유지(정확한 전체 충돌 영역 표시는 아님). 평면이 기존 바닥 높이에 놓이고 벽은 깊이 검사로 가린다. 경사/단차 전체에 투영하는 데칼은 별도 범위.

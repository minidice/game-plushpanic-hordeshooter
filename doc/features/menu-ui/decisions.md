# 메뉴 · UI — 결정 본문

## M-33 장전/충전 포인터와 반투명 진행 UI

- 결정: 평상시 조준 눈금이 장전/발사 준비/재충전 중 작은 네 점과 진행 링으로 자연스럽게 바뀌며, 하단에 동일 진행률의 퍼센트와 둥근 게이지를 보여 준다. 어두운 반투명 트랙과 청백색 채움을 사용한다.
- 이유: 사용자 제공 `장전.mp4` 5–7초의 전환과 깨끗한 반투명 외형을 참고하여 지금 총을 쓸 수 없는 이유와 남은 진행을 알기 쉽게 한다.
- 상태 · 날짜: 사용자 요청 방향으로 구현, 외형 최종 수락 전 · 2026-10-27. 0.16초 진입/0.20초 복귀, 반경19px, 248×16px 막대와 알파값은 제작자 선택이며 사용자 확정 수치가 아니다.
- 구조: Godot `Paint`, 안티앨리어싱 도형, 공유 `StyleBoxFlat` 리소스. 별도 이미지/셰이더 없이 해상도에 맞춰 그린다. 무기 타이머를 읽고 UI는 전환 가중치만 보간한다. `WeaponState.ReloadCompleted`로 실제 완료와 취소를 구분한다.
- 근거 코드 · 규격: [HudWeaponAction.cs](../../../game/scripts/UI/HudWeaponAction.cs), [Hud.cs](../../../game/scripts/UI/Hud.cs), [WeaponState.cs](../../../game/scripts/Weapons/WeaponState.cs), [상세 규격](../../weapon-spec.md#64-장전충전-진행-ui-m-33), [관찰·설계](reload-ui-design.md), [검사 기록](log/001-code-reload-progress-ui.md).
- 기존 결정과 관계: C-30의 평상시 조준 퍼짐/거리 색, C-32의 집중 치명타 규칙은 유지한다. 기존 장전 중 이동 막대와 발사 준비 사각 막대만 대체한다. 액티브 리로드나 새 취소 조작은 추가하지 않는다.

### 바뀐 표시

기존에는 장전 중 눈금이 회색으로 남고 커서 아래 검은 막대 위에서 선 하나가 이동했다. 이제 눈금을 네 점으로 전환하며, 원형/하단 게이지가 실제 진행률로 함께 찬다. 난전 특수무기 재충전에도 같은 UI가 적용되며 명중 표시는 계속 보인다.

새 결정은 여기 ID 아래에 쓰고, [전체 색인](../../decisions.md)에는 ID · 한 줄 요약 · 상태 · 날짜 · 링크만 한 줄로 적는다. 결정 ID는 지금처럼 영역 접두사(D · M · C · T · L · A · Q)를 쓴다.

**옛 기록은 옮기지 않고 그대로 있다**(2026-10-26 결정, [기록 문서 나누기](../../records-split-plan.md) 6.4). 이 기능의 2026-10-26 이전 결정 · 이슈 · 확인 기록은 [decisions.md](../../decisions.md) · [issues.md](../../issues.md) · [feature-checklist.md](../../feature-checklist.md)에 있다.

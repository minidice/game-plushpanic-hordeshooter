# 게임 시작 화면 · 설정 정리 설계안 (모드 → 종류 → 난이도)

작성일: 2026-10-28 · 기능: 메뉴 · UI · 상태: **사용자 확정 · 구현 2026-10-28**(M-39 · M-40, 7장 · [log/016-code-play-setup.md](log/016-code-play-setup.md)).

관련: L-39(캠페인 네 스테이지), M-31(인원 보정), M-12 ~ M-18(AI 분대원 · 부활), C-31(감염무리 · 수렵단 · 무장단), [난이도 방향](../direction/details/difficulty.md), [UI 스타일](ui-style-spec.md).

## 1. 사용자 요청 (2026-10-28)

> 시작 메뉴와 설정을 좀 정리할까? … 설정에서 사격 반동 밀림(난이도와 관련돼 보이는데 설정에 있으면 안 될 것 같은데), 부활 쓰러진 동료 일으키기도 난이도와 관련된 것 같은데 … 넉백은 그냥 100% 기본, 부활도 기본 난이도에 따름. 싱글이든 멀티든 공용, 시나리오 거점 난전 전부. AI 분대원은 일단 유지, 테스트 옵션은 이제 없애고, 캠페인 내의 실제 맵 배치에 따라 감염체 좀비나 무장병 그런 게 따라서 선택돼야 하는 거고, 캠페인의 종류로만 선택. 시나리오 / 거점 / 난전 가장 큰 메뉴 선택하면 바로 아래 시나리오 중 선택 or 거점 타입별 선택 or 난전 테마 선택. 레포데는 참고만 … 우리 UI에 어울리게, 컨셉 이미지를 활용하는 건 좋은 듯. 그 하단에 난이도 선택, 난이도에 따라 부활 가능 횟수(인게임 UI에도 관련 정보). 거점 · 난전은 맵이 하나라 좀비 · 무장 · 수렵단 세 타입. 시나리오는 두 개: 첫 번째는 계획 중인 시나리오, 두 번째는 나중에 바꿀 짧은 것(지금 들어가면 나오는 지하 짧고 야외 짧은 것). 그림은 항상 Codex.

## 2. 지금

| 곳 | 지금 있는 것 | 문제 |
|---|---|---|
| 싱글 플레이 | 모드 3칸 → AI 분대원 → **테스트 옵션**(스테이지 테마 감염 · 수렵단 · 무장단, F8 끌림 탈출) → 출격 | 테마를 사람이 고름(맵과 상관없이), 테스트 옵션이 노출 |
| 방(멀티) | 모드 3칸만 | 싱글과 고르는 것이 다름 |
| 설정 › 게임플레이 | **사격 반동 밀림**(0 ~ 100%, 지금 40%), **부활** 켜기/끄기 | 둘 다 난이도에 속하는 규칙 |
| 시나리오 맵 | 기본은 옛 소형 맵(창고 지구 → 숲속 벙커길), 큰 캠페인은 `--large-stages` 실행 옵션으로만 | 캠페인을 메뉴에서 못 고름 |
| 난이도 | 없음(코드에 없음) | 부활 횟수 · 이후 적 행동 차이를 담을 곳이 없음 |

## 3. 화면 구조 (싱글 · 방 공용)

카드 이름: "게임 설정"(싱글 플레이 페이지와 방 페이지의 오른쪽 칸이 같은 위젯을 씀). 왼쪽 캐릭터 미리보기 · 위 제목 · 아래 조작 안내는 그대로.

```
┌ 게임 설정 ────────────────────────────────────────────┐
│ 모드    [ 시나리오 ] [ 거점 ] [ 난전 ]                   │  ← 큰 탭 3개(지금 모양)
│                                                       │
│ ┌──────────────┐  ┌────┐ ┌────┐ ┌────┐                 │
│ │  선택한 카드  │  │카드1│ │카드2│ │카드3│                 │  ← 모드에 따라 바뀌는 카드 줄
│ │  큰 그림      │  └────┘ └────┘ └────┘                 │     (그림 + 이름, 고른 것 테두리 강조)
│ └──────────────┘                                       │
│ 이름 · 한 줄 설명 · 스테이지 수 / 길이 / 적 계열          │
│                                                       │
│ 난이도  [ 쉬움 ] [ 보통 ] [ 어려움 ]                     │
│         쓰러짐 2번까지 · 스테이지마다 다시 합류 2번        │  ← 고른 난이도의 규칙 한 줄
│ AI 분대원 [ 1명 (기본) ▾ ]          (싱글만)            │
│                                                       │
│ [            출격 [Enter]            ]                 │
│ [ ← 뒤로 [Esc] ]                                       │
└───────────────────────────────────────────────────────┘
```

- **레포데에서 가져오는 것**: 고른 것의 큰 그림 + 옆 줄에 후보 그림들, 캠페인 이름과 한 줄 설명, 난이도 단계. **가져오지 않는 것**: 기울어진 폴라로이드 · 거친 붓 글씨 · 어두운 사진 배경 — 우리 UI(M-38 공통 스타일: 둥근 패널, 남색 바탕, 하늘색 강조)에 맞춘 둥근 카드 + 얇은 강조 테두리로.
- 키보드 · 패드: 모드 탭 ← → , 카드 줄 ← →, 난이도 ← →, Enter 출격(지금처럼).

### 3.1 모드별 카드

| 모드 | 카드 | 적 계열 | 맵 |
|---|---|---|---|
| **시나리오** | ① **계획 캠페인**(가칭 "도시에서 강까지") — L-39의 네 스테이지. 지금 있는 큰 Stage 1(도시) → 2 → 3으로 진행(지하 · 물과 다리 맵이 생기면 바뀜) | **맵 데이터가 정함**(스테이지마다 `theme`, Stage 1은 감염무리) | 지금 `--large-stages`로 켜던 것 |
| | ② **짧은 캠페인**(가칭 "창고 지구", 임시) — 지금 기본으로 들어가는 옛 Stage 1(창고 홀 실내) → 옛 Stage 2(숲속 벙커길) | 맵 데이터 | 옛 소형 맵 |
| **거점** | 감염무리 · 수렵단 · 무장단 | 카드가 정함 | 거점 맵 하나 |
| **난전** | 감염무리 · 수렵단 · 무장단 | 카드가 정함 | 난전 들판 하나 |

- 시나리오에서는 적 계열을 고르지 않는다. 테마 고르기(`SelectedTheme`)는 거점 · 난전 카드로만 남고, 시나리오는 스테이지 데이터의 `theme`을 쓴다.

### 3.2 난이도와 부활 (제안 수치, `[임시]`)

| 난이도 | 한 생명에 쓰러짐 | 스테이지마다 다시 합류 | 적 |
|---|---:|---:|---|
| 쉬움 | 3번 | 3번 | 지금 값(행동 차이는 나중, [난이도 방향](../direction/details/difficulty.md) B안) |
| **보통(기본)** | 2번(지금 값) | 2번(지금 값) | 지금 값 |
| 어려움 | 1번 | 1번 | 지금 값 |

- 부활은 항상 켜짐(설정의 켜기/끄기 없앰), 횟수만 난이도가 정한다. 값은 `squad_rules.json`의 난이도별 표로.
- 레포데의 "전문가"는 두지 않는다 — 방향 문서가 이지 · 노멀 · 하드 세 단계. 적 행동 차이가 생기면 그때 넷째를 검토.

### 3.3 인게임 표시 (제안)

| 곳 | 보이는 것 |
|---|---|
| 내 체력 막대 옆 | **남은 쓰러짐 점**(● ● ○) — 쓰러질 때마다 하나 빠짐, 마지막이면 빨강(지금 "마지막 쓰러짐" 글자와 함께) |
| 분대 칸(동료마다) | 동료의 남은 쓰러짐 점, 죽어 있으면 "다시 합류까지 N초 · 남은 합류 N번" |
| 오른쪽 위 시간 칸 | 난이도 이름 작게(예: `보통 · 00:42 · 처치 12`) |
| 일시정지 화면 | 모드 · 캠페인/테마 · 난이도 · 규칙 한 줄(쓰러짐 · 합류 횟수) |

### 3.4 설정 정리

- **게임플레이 칸을 없앤다**: 사격 반동 밀림 → 100% 고정(설정 값 · 저장 키 제거, `RecoilScale` = 1), 부활 → 난이도로.
- 언어 · 그래픽 · 소리만 남는다.
- **테스트 옵션 칸을 없앤다**: 스테이지 테마는 3.1로, F8 끌림 탈출은 메뉴에서 빼고 실행 옵션(`Start-Game.ps1 -DebugEscape`)으로만(기본 꺼짐).

## 4. 그림 (Codex)

- 카드 그림 8장: 시나리오 2 · 거점 3 · 난전 3(같은 적 계열이라도 모드별로 배경이 다르게). 크기 640 × 400(큰 그림)에서 줄여 카드 줄에 씀.
- 만드는 법(추천): **실제 게임 렌더 + Codex 스크립트 가공** — Claude가 각 맵의 대표 장면을 창 모드로 찍고(우리 캐릭터 · 적 계열이 보이게), Codex가 Pillow 스크립트로 포스터처럼 가공(색 보정 · 비네트 · 테두리 · 질감, 글자 없음). 우리 게임 외형 그대로라 어울림이 확실하고, 맵이 바뀌면 다시 찍어 돌리면 된다.
- 다른 안: Codex가 Pillow로 처음부터 그린 납작한 일러스트(카드 아이콘처럼) — 통일감은 좋지만 장면 정보가 적다.

## 5. 바뀌는 코드 · 데이터 (구현할 때)

- `GameSession`: `Scenario`(캠페인 id) · `Difficulty` 추가, `LargeCampaign`은 캠페인 ①이면 참(실행 옵션 `-LargeStages`는 그대로 남김), `DebugEscapeEnabled` 기본 꺼짐.
- 새 데이터 `content/data/campaigns.json`(캠페인 id · 이름 키 · 그림 · 첫 스테이지), `squad_rules.json`에 난이도별 `downs_per_life` · `respawns_per_stage`.
- `MainMenu`: 싱글 · 방 페이지가 "게임 설정" 위젯 하나를 함께 씀, 설정 › 게임플레이 · 테스트 옵션 제거.
- 멀티: 방장이 고른 모드 · 카드 · 난이도를 방 상태로 보냄(`NetLobby.SetMode`를 넓힘), 참가자는 보기만.
- `Hud`: 쓰러짐 점 · 난이도 표시, 분대 칸 · 일시정지 화면.
- 검사: `MenuCheck`(새 위젯 · 설정 칸), 난이도별 쓰러짐 횟수(`SquadCheck`), 방 동기화(`NetLobbyCheck` 등), 캠페인 ① · ②로 시작.
- 결정 기록: 새 M-39(시작 화면 구조) · M-40(난이도와 부활), 바뀐 결정 — 설정의 반동 밀림 · 부활 켜기(기존 결정 ID는 반영할 때 찾아 갱신).

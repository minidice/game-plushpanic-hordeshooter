# Pretendard 공통 글꼴 적용 계획

## 요청과 설계

2026-10-30 사용자 요청: 한글·영문에 Pretendard를 우선 적용하고, 나중에 언어별로 교체하며 미지원 문자는 시스템 글꼴로 보완한다. 타이틀·메뉴 외 UI도 굵지 않게 통일한다.

- 언어별 `body/menu/title` 경로를 `content/data/ui_fonts.json`에 둔다. kor/eng는 같은 정적 OTF 세 파일을 참조한다. 선택한 언어의 설정/역할이 없으면 시스템 글꼴을 사용한다.
- 제작 초기값: 본문/HUD/월드 글자 Regular 400, 버튼·탭·메뉴 Bold 700, 게임 제목 ExtraBold 800. 글자 크기·레이아웃은 유지한다. 최종 외형 수락과 구분한다.
- 시스템 글꼴만 굵게 하는 안은 PC별 차이를 유지하고, 화면마다 파일을 지정하는 안은 언어별 교체를 어렵게 하므로 공통 공급자 `UiFonts`와 역할별 공유 글꼴을 사용한다.
- `Loc.Language` 변경 시 공유 글꼴의 원본을 바꿔 기존 UI·월드 이름표에도 반영한다. 번역 문구의 기존 재생성 규칙은 유지한다.
- Pretendard v1.3.9 원본과 OFL 저작권/라이선스 동봉. 설치된 시스템 글꼴의 문자 범위에 따라 미지원 언어의 표시 가능 범위는 달라진다.

## 실행 계획

이 세션에서 직접 구현한다. 코드·에셋·기록을 같은 작업 커밋으로 보존한다.

- [x] `FontCheck`에서 현행 시스템 글꼴이 번들 Pretendard 계약을 만족하지 않는지 확인.
- [x] 공식 폰트/라이선스, JSON 설정, `UiFonts`, 언어 변경 알림, 테마 역할 및 월드 글자 연결 구현.
- [x] 한·영 전환, 미등록 언어, 누락 문자 대체, 기본/메뉴/타이틀 굵기 검사. MenuCheck·AssetPathsCheck·Integration 실행(에셋 검사 기존 실패는 기록021).
- [x] 실제 한·영 메뉴와 인게임 UI 렌더 확인. 작은 해상도도 확인.
- [x] 상세 규격·결정·체크리스트·작업 기록 갱신, diff 검토.
- [x] 자기 변경만 코드/에셋/기록과 함께 커밋.

검토 초점: 초기 설정 로딩 순서, 이미 만들어진 UI의 언어 변경, 설정 없는 언어, 손상/누락된 폰트 경로, 라이선스가 배포물에 포함되는지.

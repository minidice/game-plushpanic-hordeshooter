# 장전 포인터 · 반투명 진행 UI

> 아래는 최초 구현의 관찰·설계 이력이다. 2026-10-27 외형 보강 후 현재 치수·빛 표현은 [M-33](decisions.md#m-33-장전충전-포인터와-반투명-진행-ui)와 [무기 규격](../../weapon-spec.md#64-장전충전-진행-ui-m-33), [보강 기록](log/002-code-hud-light-polish.md)을 따른다.

사용자 요청(2026-10-27): `D:/Recored/커스텀/집라인/장전.mp4` 5–7초의 자연스러운 포인터 전환, 장전 중 사용 불가 인지, 하단 퍼센트 게이지, 반투명하고 깔끔한 외형을 적용한다. 구현 방법은 위임받았다.

## 관찰과 구현 선택

- 영상 5.0–5.5초: 십자 눈금. 약 5.7초 이후: 작게 모인 네 점과 어두운 원형 트랙, 청백색 진행 호. 하단은 어두운 둥근 트랙에 밝은 채움. 세부 전환 시간과 알파는 영상에서 수치 측정하지 않았으며 아래는 우리 구현값이다.
- 이미지 스프라이트는 확대 시 품질과 진행률 마스킹이 불리하다. 셰이더는 이 단순한 형태에 불필요하다. 기존 `Paint`/Godot 벡터 그리기와 `StyleBoxFlat` 리소스를 사용한다. 별도 비트맵은 만들지 않는다.
- 평상시 조준 눈금이 0.16초에 안쪽으로 모이고 대각 방향의 작은 점으로 바뀐다. 장전 링은 고정 반경 19px, 반투명 트랙과 청백색 호로 표시한다. 사격 가능한 조준 눈금은 흐려진다. 완료/취소 시 0.20초에 복귀한다. 명중 표시는 재충전 중에도 유지한다. 수치는 900높이 UI 기준이며 제작자 선택이다.
- 하단 장비 도크 위에 248px 둥근 진행 트랙과 `장전 중 · N%`를 표시한다. 같은 진행값으로 링·막대·숫자를 그린다. 진행률은 보간하지 않아 실제 완료보다 늦게 남지 않게 한다. 완료만 100%로 퇴장하고 취소는 마지막 값으로 사라진다.
- 기존 레일건/박격포 준비와 특수무기 재충전도 같은 스타일을 사용한다. 충전은 장전과 다른 문구를 쓴다. 발사·장전 판정, 밸런스, 조준/집중 치명타 규칙은 유지한다.
- 산탄총은 한 발 삽입 주기의 진행률이다. 무기 교체 시 이전 상태 초기화. 사망/쓰러짐/일시정지/인벤토리/카드창/투척 조준에서는 숨긴다.

## 검토 초점

취소가 100%로 잘못 표시되는지, 쉘 진행이 다음 탄에 초기화되는지, 교체 시 이전 진행값이 새 무기로 넘어가는지, 일시정지 중 UI만 진행하는지, 하단 안내와 게이지가 겹치는지를 확인한다. 2PC/모든 해상도/장시간 성능은 이번 검증 범위 밖이다.

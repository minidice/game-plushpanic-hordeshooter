## 정한 것 (L-39)

1. 도시(바깥, 튜토리얼) — 지금 대형 Stage 1.
2. 건물 지하(실내) — 옛 Stage 1 창고 홀(어두운 실내 · 선반 줄)의 느낌을 대형 규모로 새로 짓는다. Stage 1 세이프하우스 해치(L-14)로 내려감. 실내 키트는 Codex.
3. 풀밭 바깥 지형 — 지금 Stage 3(칠한 땅 · 풀을 처음 깐 맵, 커밋 `5c0f4ff` 당시 이름 Stage 2).
4. 가운데 물과 다리 — 옛 Stage 2 숲속 벙커길(개울 다리)을 대형 규모로. 지금 Stage 3의 협곡 다리는 물이 없어 다른 것.
- 지금 대형 Stage 2(숲 비탈)는 빼고 좋은 부분(단 경사로 · 뛰어내리기 지름길 · 짚라인 · 오두막 바위턱 사다리 · 벌목장 언덕 단)을 3 · 4에 녹인다.

## 검사

- `python tools/level-guide/guide.py check` — Stage 1 현재 상태: 구역 9(큰 3) · 새 18 · 다시 18 · 섞기 0 · 정점 1, **오류 1(G2: F 화물 야적장에 새 경험 없음) · 경고 8**(W1 B 7개 · D 5개, W5 B 길 안내 없음, W6 섞기 없음, W2 경보 함정 · 좁은 통로 · 크레센도 · 스위치). 종료 1(오류가 있으므로 — 의도한 진단 결과).
- 가이드 보드 · 가이드 평면도를 헤드리스 Chrome으로 PNG로 찍어 눈으로 확인: 보드는 행 겹침을 한 번 고친 뒤 깔끔, 평면도는 작은 구역 몇 곳(A · 약국 · H)에서 이름 · 배지가 겹치지만 읽을 수 있음.
- `render_floorplan.py`를 `--guide` 없이 기존 방식으로도 실행 가능(인자 처리 추가만). Stage 1 실행 출력: 주 경로 623 m · L-1 100% · 큰 3 · 작은 6.
- 게임 코드 변경 없음(게임은 가이드 파일을 읽지 않음, 게임이 읽는 stages 파일 경로는 모두 파일 단위라 새 하위 폴더 영향 없음 — 코드 검색으로 확인). Godot 빌드 · 게임 검사는 실행하지 않음.

## 남은 제약

- 경고 기준 수치(새 경험 3개, 정점 뒤 2구역)는 `[임시]`.
- Stage 2 · 3 가이드와 설계안(plan) 가이드는 아직 없음. W2(다시 쓰지 않음)는 다음 스테이지 가이드가 있어야 정확해진다.
- 검사기는 게임 검사(Integration)에 연결하지 않았다. 리서치 규칙 중 화면 기준(다음 목표가 1~2화면 안에 보이는지)은 데이터로 재지 않는다.
- 평면도 표시에서 작은 구역 이름 겹침.

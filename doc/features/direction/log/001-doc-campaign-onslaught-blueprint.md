- D-14 본문과 전체 색인, 방향 README, 기능 체크리스트의 문서화/미구현 항목을 연결했다. 옛 기록은 유지한다.
- 이슈 검토: 밀도 부족·일렬 접근은 사용자 관찰이며 원인 재현을 하지 않았다. 새 버그 ID를 만들거나 기존 이슈를 해결 처리하지 않았다. I-41의 기존 렌더 한계는 후속 검증 조건으로 연결했고 이슈 본문·색인 변경은 불필요하다.

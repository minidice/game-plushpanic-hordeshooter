# 방향 지침 (지우지 않는 문서)

작성일: 2026-10-27 · 관련 결정: [D-14](decisions.md#d-14-캠페인과-난전-blueprint) · 세부 방향성: [details/](details/README.md) · 진행도: [Blueprint](campaign-onslaught-blueprint.md)

이 게임이 **무엇을 향하는지**, 핵심만 적은 문서다. 이상향이면서, 우리 게임을 설명할 때와 잘못된 방향으로 가지 않기 위한 **지침**이다.

## 이 문서의 규칙

- **핵심 목표만 둔다.** 구체적인 방법 · 수치 · 비교 · AI 제안은 [세부 방향성](details/README.md)에 쓴다.
- **완료돼도 지우지 않는다.** 목표가 구현되어도 그 목표는 계속 방향을 설명한다. 체크 표시 · 진행률 · "완료"는 이 문서에 쓰지 않는다. 진행도는 [Blueprint](campaign-onslaught-blueprint.md)와 각 기능 폴더에.
- **바꿀 때는 사용자 결정으로만 바꾸고 이력을 남긴다.** 지우지 말고 「바뀐 방향」에 이전 · 이후 · 이유 · 날짜를 남긴다.
- **목표마다 이유를 쓴다.** 사용자가 직접 밝힌 이유가 없으면 "AI 정리, 확인 전"으로 표시한다.
- 작업을 시작할 때 이 문서와 어긋나는지 먼저 본다. 어긋나면 작업을 바꾸거나, 방향을 바꿀지 사용자에게 묻는다.

## 한 줄로

**쿼터뷰 협동 PvE 호드 슈터**(Isometric Co-op PvE Horde Shooter, D-13). 여러 명과 호드가 한 화면에 보이는 위에서 내려다보는 시점(D-1), 최대 6인 협동 · 밸런스 기준 4인(D-2). 핵심은 **캠페인**과 **모드 3인 난전**이다.

## 핵심 목표

### 1. 캠페인과 3인 난전이 핵심 모드

- 목표: 캠페인과 모드 3인 난전을 핵심 포인트로 삼는다. 다른 모드를 폐기하는 결정은 아니다.
- 출처: 사용자 — "캠페인과 모드 3인 난전을 핵심 포인트로 삼는다. 다른 모드 폐기 결정은 아니다."
- 이유(AI 정리, 확인 전): 제작 자원을 두 모드에 모으고, 두 모드가 서로 다른 재미(함께 배우며 돌파 / 매 판 다른 조합)를 맡게 하기 위해. → [모드 역할 나누기](details/campaign-experience.md#두-핵심-모드의-역할-나누기)

### 2. 여럿이 함께 — 최대 6인, 기준 4인

- 목표: 최대 6인 협동, 밸런스 기준은 4인. 인원 차이는 데이터 보정으로 흡수한다.
- 출처: 기존 확정 결정 D-2 · M-5.
- 이유: "더 많은 친구와 함께"(D-2). 기준을 4인 하나로 두어야 밸런스를 맞출 수 있고, 다른 인원은 보정 표(M-31)로 맞춘다.

### 3. 캠페인은 수치 성장 없이, 배우며 진행

- 목표: 캠페인에는 별도 성장이 없다. 벨트스크롤처럼 진행하면서 상호작용 · 상황 대응을 배우는 것이 늘어난다.
- 출처: 사용자 — "캠페인에 별도 성장이 없으므로 벨트스크롤처럼 진행하면서 상호작용·상황 대응 학습이 증가해야 한다."
- 이유: 성장이 없으니 진행감은 "할 줄 아는 것이 늘어나는 느낌"에서 와야 한다(사용자 문장 안의 이유). → [배우는 순서](details/campaign-experience.md#배우는-순서-소개--압박-속-사용--조합)

### 4. 스테이지마다 새 경험, 다른 분위기

- 목표: 스테이지마다 새로운 경험과 다른 분위기.
- 출처: 사용자 — "스테이지마다 새로운 경험과 다른 분위기가 필요하다."
- 이유(AI 정리, 확인 전): 성장이 없는 캠페인에서 반복감을 막는 가장 큰 장치가 스테이지의 변화다. → [스테이지마다 바꿀 것](details/campaign-experience.md#스테이지마다-바꿀-것), [분위기](details/mood.md)

### 5. 압박은 두 종류 — 몰려오는 호드, 지키는 무장 병력

- 목표: 감염체는 가만히 있거나 배회하다가 보이거나 소리가 나면 몰려온다(수와 포위). 무장 병력(타종족)은 올 법한 방향을 경계하거나 순찰한다(사선 · 사격 타이밍).
- 출처: 사용자 — "가만히 있거나 배회하다가 플레이어가 보이거나 소리가 나면 접근하는 정도면 충분하다", "플레이어가 올 법한 방향을 경계하거나, 정해진 순찰 구역을 돌면 좋겠다." 두 목표를 한 줄로 묶은 것은 AI 정리.
- 이유(AI 정리, 확인 전): 서로 다른 대응(포위를 끊기 / 먼저 발견하고 엄폐하기)을 요구해 전투가 단조롭지 않게 한다. → [적 AI](details/ai.md), [밀도와 호드](details/density-horde.md), [난이도](details/difficulty.md)

### 6. 캠페인 분량 — 8시간, 최대 30시간

- 목표: 캠페인 초기 · 출시 목표 8시간, 최대 목표 30시간. 달성 일정 · 제작량은 정하지 않았다.
- 출처: 사용자 — "캠페인 초기·출시 목표는 8시간, 최대 목표는 30시간이다."
- 이유: 사용자가 이유를 적지 않음 — 확인 필요. → [분량 해석](details/scope.md)

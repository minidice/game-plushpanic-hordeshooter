## 방향 문서 3층

1. **[방향 지침](game-direction.md)** — 핵심 목표 6개만(목표마다 이유 · 출처). 우리 게임을 설명할 때와 방향을 잃지 않기 위한 기준. **완료돼도 지우지 않고 진행도를 쓰지 않는다.** 바꿀 때는 사용자 결정 + 「바뀐 방향」 이력.
2. **[세부 방향성](details/README.md)** — 핵심이 아닌 방향을 주제별로(AI · 밀도 · 난이도 · 캠페인 경험 · 난전 · 분위기 · 분량). 항목마다 이유 · 출처 · 선택지 장단점 · 참고작 특성 · 상태 · 히스토리. 지우지 않고 상태를 바꾼다.
3. **[Blueprint](campaign-onslaught-blueprint.md)** — 진행도(현재 구현 대비 · 측정 · 우선순위).

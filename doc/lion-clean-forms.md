# 사자 — 매끈한 데포르메 후속

2026-10-25. 사용자의 다음 추천 작업 진행 요청을 [공통 아트 기준](character-art-direction.md)의 사자 후속으로 구체화했다. [앵무새](parrot-clean-forms.md)·[독수리](eagle-clean-forms.md)에 이어 포유류 기준을 적용한다. [사자 첫 조형](lion-quality.md)과 [손·발 연결](lion-limbs.md)의 이력은 보존하며 개별 모델의 최종 사용자 아트 수락과 구분한다.

## 범위와 유지 계약

갈기는 둥근 고리 대신 큰 형태의 방향과 끝이 읽히게 하고, 얼굴은 작은 검은 눈과 연결된 주둥이로 정리한다. 손바닥 패치·과한 발 폭·둥근 파우치 등 이전 봉제 해석을 재검토한다. 짧고 귀여운 비율과 사자의 갈기·코/주둥이·귀·발끝을 유지하며 사실적인 털 표현으로 확대하지 않는다.

최근 도입한 고정 비율 손과 별도 전완, `common_lion_{left,right}Paw`/`Wrist`/`Grip`, 평평한 발바닥과 허벅지–발목 연결은 유지한다. 피벗/팔레트·충돌·전투 수치·투구/눈 장구류 제외 정책은 바꾸지 않는다. 앵무새·독수리와 다른4종 GLB는 이번 기준에서 불변이어야 한다.

## 재현과 로컬 증거

- Blender `--background --python-exit-code 1 --python prototypes/common-monsters/tools/build_common_monsters.py -- --species lion --no-render`.
- 독립 재가져오기: 같은 Blender 옵션으로 `validate_common_monsters.py -- --species lion`.
- 같은 카메라 비교: `review_parrot.py -- --species lion --review-name lion-clean-forms --capture-baseline`, 이후 `--label after`. 기존 기준을 덮어쓰지 않는다. 비교판은 `parrot_contact_sheet.py --species lion --review-name lion-clean-forms`.
- Godot import/Debug 빌드 후 `LionLimbCheck.tscn`, `HunterPoseCheck.tscn`, `CommonRosterCheck.tscn`, `ParrotMotionCheck.tscn`, `CommonRosterNetCheck.tscn`.
- 실제 게임 창 `HunterCombatCheck.tscn -- --lion-stage2`: 접근 이동/정지와 수렵3무기 전투·취소 및8렌더. 자동 입력과 검수 지점 배치를 사용하며 전구간 수동 플레이와 구분한다.
- Studio `STUDIO_URL=http://127.0.0.1:4323`, `STUDIO_SPECIES=lion`의 `studio/tests/hunter-attacks.mjs`,6무기 정지 렌더와 브라우저 확인.

Blender는 `prototypes/common-monsters/output/lion-clean-forms`, Studio는 `studio/output/lion-clean-forms`, 게임은 `game/output/lion-clean-forms`와 `game/output/lion-clean-*.log`에 저장한다. 자동 산출물은 버전 관리하지 않는다. 이번 작업에서는 앞선 두 조류의 미커밋 변경도 보존한다. 커밋·푸시는 요청되지 않았다.

## 현재 구현

- 둥근 갈기 고리를 뒤로 흐르며 끝이 좁아지는 큰 갈기 면으로 바꿨다. 머리/몸의 큰 표면과 작은 검은 눈, 하나로 이어진 주둥이·코·짧은 입선으로 얼굴을 단순화했다. 반짝임 구슬·별도 양볼·기본 미소·수염 점 장식은 제거했다.
- 손바닥 패치를 제거하고 작은 손/엄지와 별도 전완의 기존 기준점을 유지했다. 발 폭과 두께를 줄이고 허벅지–발목 연결과 평면 밑면을 보존했다. 양쪽 발바닥 면적 각각 약0.051396m², 바닥 아래 정점 없음. 조끼는 사각 파우치·덮개/여밈·몸을 감싸는 끈으로 정리했다.
- 옆면에서 꼬리가 각진 팔꿈치처럼 보이는 것을 발견해8단면 곡선으로 보완했다. 실제 Studio 배색에서는 주둥이 보조색이 어두운 갈색/녹색/붉은색이 되어 코·입의 대비를 낮췄다. 최종 주둥이는 고정 크림색으로, 기존 꼬리 술은 `common_secondary`로 지정했다. 팔레트 ID/색 값과 다른 종은 변경하지 않았다.
- 기본7,414→6,464삼각형, 조끼 포함8,134→7,648, 비활성 안경 포함전체8,498→8,012. GLB221,920→229,648바이트. 기본8천 미만이며 삼각형 감소를 실제 FPS 향상으로 표현하지 않는다.
- 최종 SHA256 `b2a2e9957c1e98448779586be3eeea19f884dabc6cdb345e46cd6d25e86d7758`. 앵무새/독수리 포함 다른6종 GLB는 이번 기준 해시와 같다. 사자 리소스/런타임 코드 변경 없음, 머리 표시 배율1 유지.

## 검증 결과

- 수정 전 Studio3무기와 실제Stage2 자동 이동/전투38검사·8화면을 보존했다. 최종 Blender 재가져오기74검사, 같은 조명/카메라 전후22뷰 확인. 폐기한 손바닥 패치의2재질 검사 대신 단일 손 표면/밝은 주둥이·보조색 꼬리의 실제 재질 배치를 검사한다.
- 머리 최대140mm 이동/0.224rad 기울기의 앞뒤·좌우8뷰에서 열린 목 틈/절단면 노출을 발견하지 않았다. quaternion import 뒤 회전 모드를 명시해 실제 기울기를 적용했다. 스트레스 렌더는 마지막 재질 변경 직전 해시 `63796de5f661f588aeb5fe2db3c8d72c3c01ce95058a992277818e70784e915f`의 증거다. 최종 재질 변경 전후 GLB를 각각 가져와 정점 위치(1e-5m 반올림), 삼각형 구성·피벗/기준점 변환의 동일성을 확인했으므로 같은 형상 검사로 유지했다. 최종 색 비교22뷰는 최종 해시로 다시 생성했다.

## 남은 한계

확대하면 갈기의 큰 면 경계와 별도 머리/몸 피벗의 접합선이 보인다. 기존 손은 고정 비율로 파지하고 전완만 연결하지만 개별 손가락/팔꿈치 관절은 없다. 발바닥 평면이 경사면 발 IK를 의미하지 않는다. 최종 사용자 아트 수락·나머지 종 확대·실제2PC·전구간 수동 플레이·장시간 호드 성능은 후속이다.

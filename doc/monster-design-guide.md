# 몬스터 — 외형 그룹과 공격 역할

기준일: 2026-10-20. 플레이어와 몬스터는 문서 그룹을 분리한다. 같은 동물 모델을 쓰더라도 **종의 외형**, **적의 공격 역할**, **등급**은 별개다. 종 고유 특징은 [플레이어 동물 가이드](player-species-guide.md)를 참조하고 적 전용 차이는 여기에 기록한다.

## 1. 공통 외형 방향

- 플레이어와 어울리는 귀엽고 우스꽝스러운 비율: 큰 얼굴, 감춘 목, 짧은 다리, 둥근 손과 몸. 감염체는 비대칭 눈·이빨로 표정을 만든다.
- 앞뒤가 판처럼 눌리지 않게 정측면에서도 둥근 뒤통수·등·배가 읽혀야 한다. 2026-10-20 감염체 5종 머리 깊이 +18%, 크롤러를 제외한 몸통 깊이 약 +18~21% 보강(I-68). 얼굴·의복 부품도 같은 표면에 맞춘다. 현재 수치·재생성/4방향 비교 경로는 [모델 규격 6.1](character-model-spec.md#61-앞뒤-볼륨-보강-2026-10-20-a-2i-68)을 따른다.
- 조형 변경 후 이동·피격·시체 캡슐과 근접 경계, 입에서 나오는 효과를 함께 점검한다. 인간형/끌개/덮치는 적 반경 보정 및 토사물/연결의 입 앵커 적용은 [모델 규격 6.2](character-model-spec.md#62-모델과-판정연출-연동-2026-10-20) 참조. 검사는 `InfectedAlignmentCheck`.
- 색만 바꾸지 말고 자세·큰 부위·공격 준비 동작으로 역할을 읽히게 한다. 외형만 보고 공격을 예측할 수 있는지가 검토 기준이다.
- 일반 근접은 손/날개의 준비 → 타격 → 복귀 동작이 필요하다. 닿았다는 이유만으로 피해를 주지 않는다. 돌격 중 충돌 피해는 예고와 돌격 자세가 있는 별도 행동이다.
- 피격 점멸 후 원래 색을 복원하고 다른 개체의 공유 재질을 바꾸지 않는다. 원래 팔이 있는 모델 위에 보조 팔을 중복 생성하지 않는다.
- 감염체 5종은 현재 약 3,787~4,223삼각형이다. 플레이어 모델을 재사용하는 동물 적은 이 예산으로 자동 경량화되지 않으므로 군중 성능·LOD는 별도 확인한다.

## 2. 조우 테마 그룹

현재 풀은 [StageTheme.cs](../game/scripts/Enemies/StageTheme.cs)에 정의된다. ‘3개 테마’는 서로 다른 완성 캠페인 3개가 있다는 뜻이 아니다.

| 그룹 / 테마 키 | 일반 적 | 특수 적 | 현재 외형 방향 |
|---|---|---|---|
| 감염체 / `zombie` | `humanoid`, `crawler` | `tether`, `leaper`, `spitter`, `balloon`, `bull` | 큰 얼굴의 인간형과 낮은 포복형, 역할마다 혀·후드·부푼 볼 등 강조 |
| 야생 동물 / `animals` | `wild_animal` | `bull`, `balloon` | 일반 적은 현재 라쿤 모델을 재사용하고 장비를 숨김 |
| 무장 동물 / `armed` | `armed_animal`, `wild_animal` | `armed_veteran`, `bull` | 사격 적은 현재 랫서판다 모델 재사용, 총기와 사격 전조로 구분 |

동물 종 배정은 현재 [Stage.cs](../game/scripts/World/Stage.cs)에 있다. 테마에 따라 황소·풍선형이 중복 등장하는 것은 현재 구성이고 향후 테마 전용 외형이 모두 준비됐다는 의미가 아니다.

## 3. 개체별 특징

현재 등급은 [monsters.csv](../game/content/data/monsters.csv)의 `tier`다. 아래는 현재 구현 요약이며 피해·거리·시간 수치는 중복 기재하지 않는다.

| ID / 현재 등급 | 외형에서 읽힐 특징 | 공격 역할 / 구분 기준 |
|---|---|---|
| `humanoid` / common | 큰 둥근 얼굴, 어긋난 머리털·이빨, 짧은 팔다리 | 서서 접근하는 일반 근접 감염체 |
| `crawler` / common | 낮은 몸통, 앞쪽으로 나온 얼굴·팔 | 네 발로 기어오는 느낌의 낮은 근접 적. 낮은 외형과 탄환 피격 높이는 별도 관리 |
| `tether` / named | 늘어진 혀, 큰 얼굴 | 연결로 플레이어를 끌어당기고 구속. 연결과 공격 전조가 보여야 함 |
| `leaper` / named | 둥근 후드, 낮게 웅크린 몸 | 도약 후 달라붙어 구속. 일반 보행과 도약 준비 자세 구분 |
| `spitter` / named | 부푼 볼·배, 오므린 입 | 토사물 원거리 공격. 입과 발사 방향이 읽혀야 함 |
| `balloon` / named | 통통한 작은 몸 위의 커다란 풍선 머리(`balloon.glb`, 2026-10-21 Codex, [지시문](model-briefs/named-bull-balloon.md)). 터지면 `Head`가 사라지고 몸만 남음 | 파열 행동. 파열 관련 수치는 `balloon_pop.json` 참조 |
| `bull` / named | 앞으로 숙인 땅딸막한 황소 인형, 크고 굵은 뿔 · 튀어나온 크림색 주둥이(`bull.glb`, 2026-10-21 Codex, [지시문](model-briefs/named-bull-balloon.md)). 보스와 달리 금장 없음 | 예고 후 돌격, 돌격 중 충돌 피해. 평상시 접촉과 구분 |
| `wild_animal` / common | 현재 장비 없는 라쿤 | 야생 동물 근접. 라쿤 얼굴·귀·꼬리 특징 유지 |
| `armed_animal` / common | 현재 총을 든 랫서판다 | 사격 전조와 엄폐 차폐가 있는 일반 원거리 적. 탄은 40m/s 가는 구적탄(C-22) |
| `armed_veteran` / named | 현재 랫서판다 무장 모델 재사용 | 정예 원거리 적. 별도 정예 외형의 충분한 식별성은 후속 검토; named 분류도 M-8의 검토 대상 |
| `boss` / boss | 전용 모델 `boss.glb`(두 발로 선 황소 두목: 금관·금 코뚜레·어깨 보호대·챔피언 벨트·큰 주먹, [지시문](model-briefs/boss.md)), 게임이 1.7배로 키움(`bosses/boss.json`의 `scale`) | 난전(서바이버) 보스(M-22·M-24). 100/66/33% 3페이즈: 돌진(`boss_charge.json`)·빨간 원 내려찍기 → 소환 추가 → 부채꼴 탄막 추가·빨라짐. 페이즈·스킬은 [몬스터 테이블 규격](mode-monster-tables.md) 3장. 모델은 2026-10-21 Codex 첫 제작(A-17) |
| `boss_bull_giant` / boss | 네임드 황소 모델(`bull.glb`)을 2.3배로 키운 임시 외형(2026-10-21) | 난전 중간 보스 "거대 황소": 돌진 → 뛰어 내려찍기 → 황소 소환 ([규격](mode-monster-tables.md) 3장) |
| `boss_balloon_king` / boss | 풍선 모델(`balloon.glb`)을 2.6배로 키운 임시 외형 | 난전 중간 보스 "풍선 대왕": 넓은 부채꼴 탄막 · 풍선 소환 → 통통 튀어 내려찍기 |
| `boss_spitter_mother` / boss | 토사물 감염체 모델을 2.2배로 키운 임시 외형 | 난전 중간 보스 "토사물 어미": 굵은 탄 부채꼴 · 제자리 내려찍기 → 일반 몹 소환 |
| `plush` / common | 선택한 플레이어 종을 복제하고 감염 색 적용 | 기존 복제 좀비 경로. 현재 위 3개 기본 테마 풀에는 포함되지 않음 |

보스·네임드 추가 후보와 Codex 모델링 진행 방식, 등급 `boss` 추가 방향은 [개편 방향](mode-weapon-direction.md) 5.1·8장(T-21·A-17, 구현 전).

`named`는 현재 데이터 등급으로, 고유 이름이나 보스 전용 모델이 완성됐다는 뜻은 아니다. 시체 정책은 [시체 유지 규격](corpse-retention.md)을 따른다. 일반 시체는 연출용, 네임드 시체는 별도 유지 정책을 쓰며 루팅은 후속 계획이다.

## 4. 플레이어 종 재사용과 구속 규칙

- 플레이어 모델을 적으로 써도 플레이어 저장 외형이나 공유 재질을 덮어쓰지 않는다. 감염 색·장비 숨김은 해당 적에 적용한다.
- `MakeZombie`의 정의 ID와 모델의 원래 노드 이름이 다를 수 있다. 얼굴·귀·꼬리·팔 보정을 복합 ID 때문에 빠뜨리지 않는다(I-30·I-31).
- 구속의 정식 방향은 동료 구조다. 현재 싱글 테스트에서는 F8 탈출 치트가 기본 활성화되어 있다. 이를 정식 자력 탈출 능력으로 기록하지 않는다(C-14).
- 행동과 수치는 [몬스터 규격](throwable-monster-spec.md), `monsters.csv`, `monster_traits/*.json`을 따른다. 일반/네임드 등급을 행동 이름만으로 추정하지 않는다.

## 5. 새 몬스터 작성 양식

| 항목 | 작성 내용 |
|---|---|
| 이름 / 고유 ID / 상태 | 계획·제작 중·게임 적용·검증 완료 |
| 그룹 / 종 / 등급 | 감염체·야생·무장 테마, 재사용 종 또는 전용 모델, common/named |
| 외형 특징 | 기본 크기에서 보이는 얼굴·큰 부위·실루엣, 기존 적과의 차이 |
| 행동 | 접근 방식, 공격 전조·타격·복귀, 중단·회피·해제 조건 |
| 재사용 범위 | 플레이어 모델·장비·원래 팔 사용 여부, 감염 색 적용 여부 |
| 구현 경로 | 외형 `.tres`/GLB, `monsters.csv`, 특성 JSON, 행동 코드, 테마 풀 등록 |
| 시체 / 검증 / 제약 | 유지 등급·루팅 계획 여부, 판정·실제 렌더·군중 비용·미검증 항목 |

추가 후 확인: 실제 게임 크기에서 플레이어/일반 적/특수 적 식별, 공격 전조와 피해 시점, 벽 차폐, 기절·사망 중단, 구속 해제, 팔 중복, 피격 색 복원, 시체 정책. 관련 검사는 `EnemyExpansion`, `EnemyAttackCheck`, `HitFlashCheck`, `TailMeleeCheck`이며 새 ID도 검사하도록 확인한다. 이번 문서 정리에서는 실행 검사를 추가로 수행하지 않았다.

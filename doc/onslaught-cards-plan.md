## 1. 사용자 방향

**2026-10-21 1차**
- 난전의 진열대 선택 환경이 별로다. **난전에서는 바닥에 떨어지는 아이템이 없어야 한다.** 아쉽지만 **카드 타입**으로 간다.
- 1·2번 무기를 정하고, 세 번째도 무작위로 고르는데 **따라다니는 것(소환수) 중에서** 고른다. 소환수는 **맨 처음에는 따라만 다닌다**.
- 카드 효과는 **누적되며 시너지**가 나야 한다. 평범한 총싸움 느낌은 아니어야 한다. 화염·독·냉기탄보다 **기능적인 것**, 사거리·치명타·장전·탄창 같은 평범한 것 외에 **우리 게임만의 특별한 것**이 필요하다.
- 카드가 **나에게 붙을지 소환수에 붙을지** 어떻게 정하나? 일반 뱀서류처럼 **레벨업 기준**도 후보.
- 선택 창은 **하데스처럼**. 급하면 **X로 닫고 다시 열 수 있어야** 한다. 닫으면 화면 아래 구석의 **+ 아이콘**, 밀린 수는 **숫자**. 얻은 효과는 화면 오른쪽에 **버프 아이콘처럼 쌓인다**.

**2026-10-21 2차 (결정)**
- **소환수는 3가지 타입**: **드론**(비행), **부사수**(미니 캐릭터, 이족보행), **펫**(사족보행, 등에 무기 장착).
- **쓰러지면 솜이 터졌다가 다시 일어나는 것은 부사수만.** **드론과 펫은 적에게 맞지 않는다.**
- 강아지 · 거북이는 등에 무기를 단 펫으로 어울린다. **같은 동물이 부사수로도 가능**(이족 · 사족이라 생김새는 다름).
- 카드는 **2종류**: **일반 카드**와 **특별 카드**.
  - 보스 · 네임드 · 일반 몹 모두 **경험치**를 준다. 레벨업하면 일반 카드.
  - **보스를 잡으면 특별 카드.** 보스도 경험치를 주므로 특별 카드를 먼저 받고, 이어서 경험치로 레벨업하면 일반 카드를 받는 순서.
  - 고르지 못하고 쌓인 카드는 **받은 순서 그대로** 유지된다(특별 · 일반이 섞여도).
  - **한 번 펼쳐 본 3장은 접었다 다시 펼쳐도 바뀌지 않는다.** 처음 펼칠 때 무엇이 나올지 미리 정해져 있어도 상관없다.
- 보스의 특별 카드는 **정말 특별**해야 한다. 지금 카드 효과는 평범하다. 마법스러운 것도 좋지만 **내 총기의 특징이 드러나야** 하고, **고른 총기 타입별 카드 풀**이 필요해 보인다. → 리서치(9장).

## 2. 한 판의 흐름

1. **무장**: 무기 카드 3장 → 1번 칸. 다시 무기 카드 3장(앞에서 고른 것 제외) → 2번 칸. 소환수 카드 3장 → 소환수. 지금의 무장 단계(`ModeArming`)를 쓰고, 셋 다 고르면 시계가 간다. 무장 카드는 닫을 수 없다.
2. **싸움**: 처치하면 바로 경험치(바닥 구슬 없음). 레벨업마다 일반 카드 1회.
3. **보스**: 특별 카드 1회 → 이어서 경험치 → 레벨업이면 일반 카드.
4. **판 구조 (결정 3차, 2026-10-21): 보스 기준 4구간, 약 20분.**

| 구간 | 길이 | 끝에 나오는 보스 | 보상 |
|---|---|---|---|
| 1 | 약 3분 | 중간 보스 1 | 특별 카드 + 경험치 |
| 2 | 약 4분 | 중간 보스 2 | 특별 카드 + 경험치 |
| 3 | 약 5분 | 중간 보스 3 | 특별 카드 + 경험치 |
| 4 | 약 6분 | 최종 보스 | 처치 = 클리어 |

   - 구간 시계는 **앞 보스를 잡은 뒤부터** 다시 간다(보스 기준). 구간 합 18분 + 보스전 시간 = 약 20분.
   - 구간 길이 3 · 4 · 5 · 6분은 사용자 확인(2026-10-21).
   - 보스가 나오는 동안 일반 몹은 줄어들고, 보스를 잡으면 짧은 정비(지금의 named 처치 정비 시간처럼) 뒤 다음 구간(추천).
   - 영상 · 검사용으로 구간 길이를 줄이는 설정을 둔다(`mode_rules.json`, 추천).

판당 목표(추천): 일반 카드 25~35장(앞 구간은 자주, 뒤로 갈수록 드물게), 특별 카드 3장(중간 보스 3마리). 20분 판이라 카드 종류가 충분해야 한다: 공통 30장 + 총 분류마다 개조 3장 · 수치 3장 + 소환수 타입마다 6장 정도에서 시작.

## 3. 카드 얻기와 쌓아 두기 (결정 + 추천)

- **경험치**: 일반 몹 · 네임드 · 보스 모두. 네임드는 많이, 보스는 아주 많이. **팀 공유 경험치(추천)**: 누가 잡든 팀 레벨이 오르고 레벨업하면 **모두 각자** 일반 카드를 받는다.
- **특별 카드**: 보스 처치 때만(결정). 네임드는 경험치만(결정).
- **쌓아 두기(결정)**: 받은 카드는 줄(큐)에 받은 순서대로 쌓인다. 특별 · 일반이 섞여도 순서를 바꾸지 않는다. 창은 늘 줄의 맨 앞 카드를 보여 준다.
- **3장은 받을 때 정해진다(추천, 사용자 허용)**: 카드를 받는 순간 3장을 뽑아 저장한다. 접었다 펴도, 다른 카드를 먼저 받아도 그대로. 멀티에서는 방장이 뽑고, 파티원이 다시 접속해도 같다. 미리 정하면 "닫았다 열어 다시 뽑기"가 원천적으로 막힌다.
  - 다만 뒤 카드의 3장은 앞 카드를 고른 결과를 모른다(앞에서 얻은 카드의 단계가 반영되지 않음). 단계 표시(Ⅰ→Ⅱ)는 **펼칠 때** 다시 계산해 보여 준다.

## 4. 소환수 (결정: 3타입)

### 4.1 타입

| | **드론** (비행) | **부사수** (미니 캐릭터 · 이족) | **펫** (사족 · 등에 무기) |
|---|---|---|---|
| 적에게 맞는가 | **안 맞음** (결정) | **맞음. 쓰러지면 솜이 터지고 잠시 뒤 다시 꿰매져 일어남** (결정) | **안 맞음** (결정) |
| 움직임 (추천) | 내 머리 위. 나무 · 기둥 · 몹 무시 | 내 옆을 걸어 따라옴. 가끔 엄폐 · 자리 잡기 | 땅으로 빠르게 따라옴, 장애물은 돌아감. 적에게 달려들기 |
| 무기 (추천) | 작은 레이저 · 조명 (약함, 사거리 김) | **사람 총을 그대로 듦** (화력 최고) | 등에 단 전용 무기(미니 기관총 · 화염 · 박격포 중) |
| 장점 (추천) | 언제나 같이 있음, 장애물 무시, 멀리 봄(조명 · 정찰) | 가장 강함, 적을 끌어 나를 지킴, 내 총 카드와 시너지 | 빠르고 죽지 않음, 몸으로 적을 밀어냄 |
| 단점 (추천) | 화력 약함, 넉백 없음 | 쓰러지면 한동안 없음, 움직임이 느림 | 땅으로 다녀서 길이 막히면 늦음, 화력 중간 |
| 카드 성격 (추천) | 지원: 표식 · 조명 · 느리게 · 막아 주기 | 총 카드: 내 총 분류 풀과 같은 카드 일부를 받음 | 몸 · 무기: 돌진 · 넉백 · 등 무기 교체 |

- **동물**(결정): 강아지 · 거북이 등 같은 동물을 부사수(이족)로도, 펫(사족, 등에 무기)으로도 만든다. 동물마다 작은 성격 차이(추천): 강아지 = 빠름 · 공격 빈도, 거북이 = 느림 · 단단함(부사수) / 넓은 등 무기(펫). 드론은 장난감 드론 · 무당벌레 드론 같은 외형 변형.
- **부사수의 무기(추천)**: 부사수는 **내 1번 또는 2번 무기와 같은 분류의 총**을 든다. 그래서 내 총 분류 카드 일부가 부사수에게도 붙는다(5.2). "부사수 = 나의 작은 분신"이라는 느낌. (11장 Q-22)
- **처음엔 따라만 다님**(결정): 얻은 직후엔 따라다니며 약한 기본 행동만(추천: 드론 = 비추기, 부사수 = 가까운 적 한 발씩, 펫 = 짖어서 적 한 마리 끌기). 공격력 · 능력은 소환수 카드로 붙는다.
- 소환수 카드 3장은 타입 · 동물 조합에서 뽑는다(예: "드론", "강아지 부사수", "거북 펫").
- 모델링: 지시문 → Codex → Blender 최적화(A-17). 부사수는 플레이어 캐릭터 규격의 작은 버전이라 [캐릭터 모델 규격](character-model-spec.md)을 다시 쓴다.

### 5.2 고른 총 분류별 카드 풀 (결정 방향 + 추천)

사용자 방향대로 **고른 총의 분류마다 풀**이 있다. 리서치 결과 가장 기억에 남는 무기 업그레이드는 수치가 아니라 **총이 작동하는 방식을 바꾸는 것**이었다(9장). 그래서 분류마다 "개조" 카드를 둔다. 지금 게임에 있는 시스템(점사 · 곡사 · 충전 · 거치 · 관통 · 넉백)을 키우는 쪽이라 만들기도 쉽다.

| 분류 | 개조 카드 (그 총이 하는 일이 바뀜) | 수치 카드 |
|---|---|---|
| **권총 · 기관단총** (9mm) | **쌍권총**: 같은 총을 하나 더(번갈아 쏨) / **팬 파이어**: 탄창을 다 비우면 마지막 발이 부채꼴로 흩어짐 / **빠른 손**: 장전 직후 3발은 장전 없이 무기 교체 | 연사 · 이동 중 퍼짐 |
| **돌격소총** (5.56 · 7.62) | **유탄 발사기 부착**: 장전할 때마다 유탄 한 발 / **점사 전환**: 3점사로 바뀌고 점사 마지막 발 치명타 / **총검 돌격**: 도약에 찌르기 | 탄창 · 반동 |
| **경기관총** | **거치 사격**: 멈춰 있으면 퍼짐 0 · 연사 증가 / **달아오른 총열**: 오래 쏠수록 화염탄 / **탄띠 휘두르기**: 탄창 끝에서 주변 넉백 | 탄띠 길이 · 회전 속도 |
| **산탄총** (12게이지) | **슬러그탄**: 한 발로 관통 · 큰 넉백 / **용의 숨결**: 화염 부채꼴 / **문짝 따기**: 가까이 맞힌 적이 날아가 나무 · 기둥에 박힘(기절) | 펠릿 수 · 넉백 |
| **저격 · 지정사수** | **꿰뚫기 사슬**: 관통할 때마다 대미지 증가 / **표적 표시**: 맞힌 적에게 팀 전체 대미지 증가 / **원샷 장전**: 처치하면 바로 장전 | 조준 속도 · 치명타 |
| **로켓런처** | **유도 장치**: 조준점으로 휘어 감 / **집속탄**: 터지면 작은 폭탄 여러 개 / **로켓 점프**: 내 발밑에 쏘면 크게 도약(피해 없음) | 폭발 반경 · 충전 시간 |
| **박격포** | **연속 포격**: 한 번에 3발이 줄지어 떨어짐 / **조명탄**: 떨어진 자리 주변이 오래 밝음 · 적이 보임 / **이동 포대**: 거치 없이 쏨 | 충전 시간 · 반경 |
| **레일건** | **과충전**: 오래 모을수록 관통 · 벽 관통 / **반사**: 나무 · 기둥에 맞으면 튕김 / **잔류 전기**: 지나간 선에 전기 장판 | 충전 시간 |

- **공통 카드**(모든 총): 상태 효과 3종(5.3), 넉백 · 시체 · 헬륨 · 빛 · 소리 카드(5.4), 기본 수치.
- **수치 카드**는 흔하고 작게. 개조 카드는 드물고, 한 무기에 개조는 2개까지(추천).

| 대미지 | 짧고 셈 | 길고 약함, **중첩**될수록 셈 | 없음 |
| 기능 | **옮겨붙음**, 시체도 탐 | **죽으면 독구름** | **느려짐 → 얼음** → 맞히면 산산조각 |
| 겉모습 | 솜이 그을림 | 초록 슬라임 페인트 | 푸른 서리 |

### 5.4 우리 게임 시스템을 키우는 카드 (추천)

| 시스템 | 카드 예 |
|---|---|
| 넉백(무게 · `hit_power`) | 볼링(밀려난 적끼리 부딪히면 피해), 핀볼(나무 · 기둥에 부딪히면 기절) |
| 시체가 남음(T-21) | 솜 폭발(죽으면 주변 밀어냄), 시체 바리케이드, 재봉질(시체 근처에서 회복) |
| 헬륨 · 풍선 | 헬륨탄(맞은 적이 떠올라 무력화, 떠 있을 때 처치하면 펑) |
| 빛 · 시야(C-23) | 조명탄환(맞은 적이 빛나 팀 모두에게 보임, 빛나는 적에게 치명타 +) |
| 소리(`noise_m`) | 미끼탄(맞은 자리로 근처 적이 모임) |
| 들판 장애물 | 도탄(나무 · 기둥에서 튕김) |
| 협동 | 십자포화(둘이 같은 적을 맞히면 표식) |

### 5.5 누적 · 시너지 (추천)

> 신선하고 우스꽝스러운 카드 후보 70여 장, "상태를 만드는 카드 / 쓰는 카드" 시너지 방식, 연쇄 예시는 [난전 카드 아이디어 풀](onslaught-card-ideas.md)에 있다.

같은 카드 중첩(Ⅰ~Ⅲ) → 같은 태그 3장 보너스 → 두 태그가 있으면 조합 카드(금색). 예: 화염 + 넉백 = 불붙은 볼링공, 냉기 + 넉백 = 빙판, 독 + 시체 = 오염된 솜, 산탄총 개조 + 핀볼 = 벽에 박힌 적이 폭발.

## 6. 특별 카드 (보스 보상)

### 6.1 특별해지는 방법 (리서치 → 추천)

참고 게임에서 "특별한 보상"은 세 가지 길이었다(9장).

1. **총을 바꿔 버림 (오버클록 방식)**: 그 총 하나에만 붙고, 총의 정체가 바뀐다. 이득이 클수록 대가도 있다.
2. **판의 규칙을 바꿈 (아르카나 방식)**: 모든 무기 · 소환수에 걸리는 새 규칙.
3. **강한 이득 + 확실한 대가 (보스 유물 방식)**: 고르는 순간 플레이 방식이 달라진다.

그래서 특별 카드 3장은 **"내 1번 총 변신 · 내 2번 총 변신 · 규칙 카드(또는 소환수 각성)"**로 뽑는다(추천). 일반 카드보다 크고 금속 테두리, 펼칠 때 연출(하데스의 전설 축복처럼).

### 6.2 총 변신 (총 분류별, 그 총 하나에만)

| 분류 | 특별 카드 | 이득 | 대가 |
|---|---|---|---|
| 권총 · 기관단총 | **탄창 없는 총** | 장전이 없어짐(계속 쏨) | 대미지 −30% |
| 돌격소총 | **분대 지원 사격** | 쏠 때마다 소환수 · 팀원 총도 같은 적을 같이 쏨 | 내 연사 −25% |
| 경기관총 | **회전 포탑** | 멈추면 360° 자동 사격 | 멈춰 있을 때만 쏨 |
| 산탄총 | **솜뭉치 대포** | 맞은 적들이 솜으로 엉겨 한 덩어리로 묶임 → 굴러가며 볼링 | 장전 2배 |
| 저격 · 지정사수 | **시간 정지 조준** | 조준하는 동안 세계가 느려짐(싱글) / 조준한 적이 멈춤(멀티) | 조준 중 이동 불가 |
| 로켓런처 | **떼거리 로켓** | 한 번에 작은 유도 로켓 8발 | 직격 대미지 없음 |
| 박격포 | **포격 요청** | 지도 어디든 조준(화면 밖 포함), 5발 연속 | 충전 2배 |
| 레일건 | **차원 관통** | 한 발이 화면 끝까지, 지나간 적 모두에게 치명타 | 충전 중 이동 −50% |

### 6.3 규칙 카드 (모든 무기 · 소환수)

| 카드 | 하는 일 |
|---|---|
| **쌍둥이** | 2번 무기를 소환수도 같이 들고 쏨(부사수는 하나 더, 드론 · 펫은 축소판) |
| **마지막 한 발** | 탄창의 마지막 발은 언제나 폭발 + 치명타 |
| **움직이는 장전** | 움직이는 동안 장전이 2배 빠름, 서 있으면 느림 |
| **솜의 축복** | 쓰러진 적의 솜이 나에게 날아와 붙어 잠깐 보호막 |
| **헬륨 파티** | 팀 전체 총알이 가끔 적을 띄움, 떠 있는 적 처치 시 펑 (팀 카드) |
| **인형 뽑기** | 몇 초마다 크레인이 내려와 가장 큰 적을 집어 무리에 던짐 |
| **유리 대포** | 모든 대미지 2배, 최대 체력 절반 (보스 유물식 대가) |

### 6.4 소환수 각성

| 소환수 | 각성 |
|---|---|
| 드론 | **편대**: 드론 3대로 나뉨(하나하나는 약함) |
| 부사수 | **분대장**: 부사수 2명, 쓰러진 부사수가 서로 일으킴 |
| 펫 | **올라타기**: 펫에 타서 이동이 빨라지고 등 무기를 내가 조종 |

## 7. 선택 창 · HUD

### 7.1 카드 창 (하데스식)
- 가운데에 카드 3장을 세로로. 한 장 = 큰 아이콘(대상 표시) · 이름 · 희귀도 색 · 설명 · 단계 · 태그. 특별 카드는 더 크고 금속 테두리.
- 마우스 또는 숫자 1·2·3. 오른쪽 위 X로 닫기. 무장 카드는 X 없음.

### 7.2 열려 있는 동안 (추천)
- 세계는 멈추지 않는다(멀티와 같은 규칙). 이동 · 도약은 되고, 사격 · 조준 · 투척은 안 됨. 마우스 커서가 보임.

### 7.3 쌓인 카드 (+ 아이콘)
- 닫으면 + 아이콘에 들어감. 쌓인 수를 숫자로. 줄 맨 앞이 특별 카드면 + 아이콘이 금색.
- 다시 열기: F 키(아이콘에 표시). 위치 추천: 오른쪽 아래(탄약 칸 위), 버프 줄 근처. (Q-16)
- 순서 · 내용은 3장 규칙대로 바뀌지 않음.

### 7.4 버프 줄 (오른쪽)
- 얻은 카드 아이콘을 세로로. 단계(Ⅱ), 태그 보너스는 태그 아이콘 + 개수. 대상별 묶음(나 / 1번 / 2번 / 소환수). 특별 카드는 맨 위에 큰 아이콘.

## 8. 멀티 · 데이터

- 방장이 경험치 · 레벨 · 각자의 카드 줄(각 카드의 3장)을 정한다(M-9). 파티원은 고른 번호만 보낸다. 줄은 플레이어 스냅샷에 실린다.

## 13. 카드 실험실 플레이 피드백 (사용자 2026-10-21, 결정)

### 13.1 3번 칸 = 특수무기 · 투척물 (쿨타임)
- 난전에서는 **투척물을 G 대신 3번 칸**으로 옮긴다. 3번 칸 무기는 모두 **쿨타임**으로 다시 쓴다(탄 · 개수 없음).
- **난전의 특수무기 · 투척물 데이터는 전용으로 따로** 쓴다(시나리오 · 거점의 `throwables.csv`·무기 표와 분리, 쿨타임 · 카드 연결이 들어감).
- 무장도 바뀐다: 시작하자마자 **1 · 2 · 3번 칸을 정하는 카드**가 차례로 뜬다.
- **고무오리 미끼**는 카드가 아니라 3번 칸 **투척물** 하나로. 미끼는 네임드 · 보스를 끌지 못한다(지금 미끼 규칙과 같음: 일반 몹만).
- **꽥**도 카드가 아니라 3번 칸 **특수무기**로: 주변을 팍 밀쳐내는 무기.

### 13.2 카드 트리 (기본 카드 → 강화 카드)
- 기본 카드를 한 번 고르면 그 카드는 다시 나오지 않고, **그 카드의 강화 카드**만 나온다. 예: 풍선탄을 고른 뒤 → "풍선탄 폭발 범위 Lv1", "풍선탄 폭발 대미지 Lv1"…
- **풍선탄**(이름 그대로): 맞으면 **부풀어 오르고**(커지는 연출 좋음) **N방 맞으면 터진다**. 떠오르기(둥실)는 뺀다. 강화: 폭발 범위 · 폭발 대미지.
  - **네임드 · 보스는 풍선탄이 통하지 않는다**(부풀지 않음). 단 일반 몹이 터진 폭발의 대미지는 입는다.
- **찍찍이탄**도 같은 트리 방식.
- **당구**는 공용 카드가 아니라 **저격 · 샷건 전용**. 퍼지는 느낌이 달라 **분류마다 이름을 다르게**(추천: 저격 "관통 당구", 샷건 "산탄 볼링").

### 13.3 구급상자 (난전)
- 줍지 않는다. **시작할 때 1개**, 쓰면 나를 회복.
- 레벨업 일반 카드의 구급상자 트리:
  - **회복량**: 처음엔 시간에 걸쳐 30%만 → 50% → 70% → 100%.
  - **빠른 회복**(총 회복량은 같고 걸리는 시간만): 10초 → 5초 → 3초 → 즉시.
  - **설치형으로 바꾸기**: 바닥에 설치. 처음엔 바짝 붙으면 주변 사람도 회복되는 범위 → **범위 Lv**로 넓어짐 → **부활 효과** 추가.

### 13.4 무기 칸별 카드
- 1 · 2 · 3번 칸 무기마다 **공용 카드 + 특별한 전용 카드**. **무기(분류)마다 전용 옵션 5~6가지**(5.2 표의 3장 → 5~6장으로 늘림, Q-27).

### 13.5 실험실에 바로 필요한 것
- **치트로 초기화**하면 시작하자마자 1 · 2 · 3번 칸을 정하는 카드 화면(하데스식)이 뜨는 것을 볼 수 있게.

### 13.6 모드와 상관없는 무기 피드백 (C-26 · C-28)
- 샷건이 저격처럼 멀리 보이는 것은 별로: **조준해도 샷건은 화면이 거의 그대로**. 저격은 **소총의 1.5배 이상** 멀리, 소총은 지금 그대로 → 2026-10-21 구현(`aim_view`, 저격은 화면이 넓어짐).
- 특수무기는 **들고 있을 때만** 느려진다 → 지금도 들고 있는 총의 `move_speed_pct`만 적용됨을 검사로 확인(`WeaponHandlingCheck`).
- 저격은 멀리서 쏘면 **첫 발은 시야 밖이면 몬스터가 알아채지 못하는** 것도 좋겠다(C-28, 아이디어).

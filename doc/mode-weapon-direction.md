# 무기 · 모드 · 몬스터 개편 방향

> **상태**: 기획 정리 (2026-10-21). **1~3장의 1단계(타입별 이동속도·조준, 3번 특수무기 칸, 박격포 거치, 레일건)는 2026-10-21 구현**([무기 규격](weapon-spec.md) 8장). **5.1·5.2장의 1차(boss 등급, 모드별 몬스터 테이블, 보스 페이즈·스킬 데이터, 난전 정비 시간)는 2026-10-21 구현**([몬스터 테이블 규격](mode-monster-tables.md)). **8장의 첫 시험(난전 보스 전용 모델을 Codex로 제작)은 2026-10-21 완료**([지시문](model-briefs/boss.md)). 나머지는 구현 전. 사용자가 2026-10-21에 준 방향과 Claude의 추천안을 모았다.
> 각 항목의 결정 상태는 [결정 기록](decisions.md)의 C-24~C-27, M-23~M-26, T-21, L-13, A-17, Q-9~Q-12를 따른다. `[유력]`은 사용자가 방향을 준 것, `[확정]`은 사용자가 고른 것, `[미결]`은 아직 고르지 않은 것이다. 2026-10-21 사용자가 모드 이름·배낭 크기·사거리 대미지를 추천안대로 확정했다.
> **표기**: "사용자 방향"은 사용자가 말한 내용, "추천"은 Claude 제안이다. 수치는 모두 시작값 제안이며 플레이로 조정한다.
> **현재 구현과의 관계**: 지금 무기 규칙은 [무기 규격](weapon-spec.md)과 C-3·C-4, 생존·서바이버 1차 버전은 [모드 3.1](menu-multiplayer-plan.md)과 M-22다. 이 문서의 내용이 구현되면 해당 결정을 갱신하고 「바뀐 결정」에 남긴다.

## 1. 총기 분류 (C-24)

**사용자 방향**: 디비전 1처럼 **돌격소총 · 기관단총 · 저격소총 · 경기관총 · 산탄총** 다섯 가지로 크게 나눈다. 기관단총은 이동속도에서 유리하면 좋겠다. 대미지·탄창·총알 수만으로 충분한지 검토.

**추천**: 대미지·탄창·총알 수만으로는 부족하다. 체감 차이는 **발사 간격, 퍼짐·반동, 유효사거리, 장전 시간, 이동속도**에서 나온다. 무기 데이터에는 이미 유효사거리, 최대사거리 대미지 배율(`falloff_min`), 퍼짐, 반동, 관통, 피격 넉백, 소음 칸이 있으므로 아래만 더한다.

| 추가 칸 (제안) | 뜻 |
|---|---|
| `move_speed_pct` | 이 무기를 들었을 때 이동속도 % |
| `aim_range_mult`, `aim_move_pct`, `aim_focus_mult` | 조준(3장) 중 유효사거리 배율 · 이동속도 % · 집중이 차는 속도 |
| `crit_mult` | 치명타 배율 (저격 타입에서 크게) |

| 타입 | 역할 | 이동속도 (제안) | 타입 고유 차이 (제안) |
|---|---|---|---|
| 기관단총 | 근접 기동 | 110% | 이동 중 퍼짐이 적음, 장전 빠름, 유효사거리 짧음 |
| 돌격소총 | 만능 | 100% | 중거리, 조준 보너스 중간 |
| 경기관총 | 무리 제압 | 85% | 쏠수록 퍼짐이 줄어듦, 큰 탄창, 장전 느림, 관통 1 |
| 산탄총 | 근거리 폭발력 | 95% | 넉백 큼, 거리가 멀어지면 대미지 급감 |
| 저격소총 | 한 방 | 85% | 조준 시 유효사거리 크게 증가, 관통, 치명타 배율 큼 |

- 지금의 분류(`smg`, `assault_rifle`, `lmg`, `shotgun`, `bolt_sniper`, `dmr`)는 이 다섯 갈래에 그대로 들어간다. `bolt_sniper`·`dmr`은 저격소총 갈래 안의 하위 분류로 둔다.
- **개별 총**은 같은 타입 안에서 "한 줄 개성"을 하나씩 준다. 예: MP5는 정확하고 조용함 / 우지 계열은 빠르지만 많이 퍼짐 / M4는 균형 / AK는 한 발이 세고 반동이 큼 / M16은 점사.
- 타입 기본값은 `weapon_types.csv`, 개별 총은 덮어쓸 칸만 `weapons.csv`에 둔다(T-3 유지).

## 2. 3번 특수무기 칸 (C-25)

**사용자 방향**: 로켓런처(알라봉)처럼 탄이 적은 무기는 주무기 칸에서는 쓸 수가 없다. **특수무기**(로켓런처·레일건·박격포 같은 필살기용 중화기)로 분리해 **3번 칸**에 둔다. 직진형은 주무기처럼 쏘고 곡사형은 수류탄처럼 범위로 조준한다. 박격포는 쏘는 동작 시간이 길어야 한다.

**추천**:
- 칸: 1 보조 / 2 주무기 / **3 특수** / G 투척 / Q 구급상자. 3번 키는 지금 비어 있다.
- 직사형(로켓·레일건)은 2번처럼 조준하고, 곡사형(박격포)은 G처럼 착탄 원·최대 거리로 조준한다(C-11과 같은 조작).
- 박격포: 거치 0.8초(이동 불가) → 발사 → 회수 0.5초. 착탄까지 1~1.5초, 휘파람 소리로 예고.
- 레일건(새 무기): 충전 0.6~1초 동안 조준선 표시, 맞은 적 전부 관통.
- 탄약: 시나리오는 맵에서 줍는 소수의 탄이고 탄약 더미로 충전되지 않는다(C-4의 "로켓·박격포 충전 불가" 유지). 서바이버는 6장의 쿨타임 규칙.
- 구현하면 C-3(슬롯)과 C-4(탄약 더미)를 갱신한다.

## 3. 조준과 저격 (C-26, C-27)

**사용자 방향**:
- 수류탄이나 곡사 무기를 조준하는 동안 **이동속도 -50%**.
- 저격 맛: 이스케이프 프롬 덕코프처럼 조준하면 멀리 보이고, 마우스가 투척 조준처럼 앞으로 나간다. 누르고 있는 동안 앉아쏴 자세, **이동속도 30%**, 유효사거리 증가. 우클릭과 Ctrl 중 고민 → **둘 다 지원**(둘 중 하나라도 누르는 동안).
- 사거리 대미지: 유효사거리 안 100%, 그 밖(사거리 안)은 30~50% 랜덤, 사거리 밖은 안 맞음? 저격 보너스 대미지를 따로 둘지?

**추천**:
- 우클릭과 Ctrl 모두 "누르고 있는 동안 조준". 투척 조준 중의 우클릭은 지금처럼 취소(C-11 유지).
- 조준 중: 낮은 자세, 퍼짐 0, 유효사거리 ×1.5~2(타입별), 카메라가 커서 쪽으로 앞당겨짐(최대 화면의 약 40%), 조준선 표시.
- 조준은 모든 총에서 되지만 보너스 크기를 타입별로 다르게(저격 큼, 돌격소총 중간, 기관단총·산탄총 작음) 해서 조작을 하나로 통일한다.
- **확정(C-27, 2026-10-21)**: 사거리 대미지는 랜덤 대신 **선형 감소**. 유효사거리 안 100% → 최대사거리에서 `falloff_min`까지 줄고, 최대사거리 밖은 안 맞는다. 지금 구현과 같은 규칙이다. 랜덤은 저격에서 운으로 대미지가 달라져 억울하게 느껴지기 때문에 쓰지 않는다.
- 저격 보너스는 따로 두지 않고 기존 **집중(치명타)** 을 쓴다. 조준 중에는 집중이 빨리 차고, 저격 타입만 치명타 배율이 크다(예: ×2.5).

## 5. 세 모드 공통

### 5.1 몬스터 등급 (T-21)

**사용자 방향**: 몬스터는 **보스 · 네임드 · 일반**으로 나눈다. 시체 시간과 물리 처리는 보스와 네임드를 같게, 일반만 따로. 보스는 RPG 보스처럼 **페이즈와 여러 특수 스킬**이 있어야 한다.

**추천**: `monsters.csv`의 `tier`에 `boss`를 더한다. 시체 정책(T-14·T-16)에서 `boss`는 `named`와 같이 처리한다. 지금 `boss` 행(M-22)은 `named`로 들어가 있으므로 이때 옮긴다.

### 5.2 모드별 몬스터 테이블과 리듬 (M-24)

**사용자 방향**:
- 생존과 서바이버는 랜덤성이 강하되 초반부터 너무 센 적이 나오면 안 된다. **몬스터 테이블은 모드별로** 따로 관리.
- 둘 다 큰 웨이브가 끝나면 몹이 잠깐 안 오는 **정비 시간**이 필요하다. 정비 시간은 강한 네임드를 처리한 뒤가 좋다.
- **보스는 2~3분 전투**가 필요한 튼튼함.
- 테마(좀비 / 적대종족 / 적대종족 무장)는 지금은 판마다 고른다(A-3, 나중에 바뀔 수 있음).

**추천**:
- 테이블 칸(제안): 몬스터 ID, 등급, 가중치, 등장 시작 웨이브/시간, 동시 최대 수, 체력·공격 배율, 테마. 예: `content/data/modes/<mode>/spawns.csv`.
- 한 판의 리듬: 웨이브 → 네임드 → **정비 30~45초(몹 없음)** → … → 보스.
- 보스 체력은 "목표 전투 시간 × 예상 분대 DPS"로 정하고 인원 보정(M-5)을 받는다.
- 보스 페이즈: 100 / 66 / 33%, 페이즈마다 스킬이 하나씩 늘어남. 스킬은 데이터(JSON: 예고 모양·준비 시간·피해·대기 시간). 스킬 후보: 원형 내려찍기, 직선 돌진, 소환, 부채꼴 탄막, 지속 장판, 약점 노출(기절 중 추가 피해), 격노.

### 5.3 맵 구조와 절차적 생성 (L-13)

**사용자 방향**: 맵을 키운다. 나중에 모든 맵은 절차적 생성(랜덤 맵)을 추구한다. 지금은 구조만 고려.
- 시나리오: 구조가 타이트함.
- 생존: 랜덤성의 영향을 많이 받음. 방 하나하나가 크고(지금 중간 통로의 약 4배), 일자 진행이 아니라 사방으로 뻗음.
- 서바이버: 벽이 거의 없는 넓은 야외 평지. 지형은 랜덤할 게 없고 오브젝트(나무·기둥 등) 위치만 잘 분포되게 랜덤.

**추천**:
- 시나리오: 좁은 구간 조각을 일자로 이어 붙이는 생성.
- 생존: 큰 방들을 잇는 방 그래프(갈래·순환 포함).
- 서바이버: 넓은 평지에 포아송 분포(최소 간격 보장)로 장애물 배치, 시작 지점 주변은 비움.
- 첫 단계: 지금 `Stage`가 `StageOneLayout`에 직접 묶여 있는 부분(시작 지점·문·세이프하우스·흐름장 찍기)을 공통 맵 인터페이스로 떼어 낸다.

## 6. 생존 — 파밍 · 인벤토리 (M-25)

**사용자 방향**:
- 인벤토리가 있어야 한다. 장착 칸(1·3·4·5 등)은 원하는 것을 **드래그해서 장착**.
- **이 모드에서만 탄 종류**가 있다. 무기마다 쓰는 탄이 다르고(예: 8mm·5mm), 총에 마우스를 올리면 무기 타입·탄 종류가 보인다.
- 탄창 포함 총알 수로 자동 계산되고, 소모되면 알아서 탄창을 채운다.
- 인벤토리 밖으로 드래그하면 바닥에 떨어짐. **팀원끼리 교환**이 목표.
- 돌아다니며 파밍한다. 네임드·보스가 죽으면 시체 루팅이 아니라 **주변으로 여러 아이템이 떨어진다.**
- 몬스터는 강해지기보다 후반에 수량이나 어려운 패턴의 몬스터가 늘어난다. 네임드·보스의 공격력은 초반·후반 큰 차이 없음, **보스 체력은 조금씩 증가**.
- 인벤토리 칸 수, 탄창 하나가 한 칸을 차지할지(인벤이 커야 할지, 부족한 게 맛인지) 검토.

**추천**:
- 장착 칸 1~5(보조 · 주무기 · 특수 · 투척 · 구급) + 배낭 격자.
- **확정(M-25·Q-10, 2026-10-21)**: 배낭은 **4×5 = 20칸**으로 시작. 큰 배낭을 주우면 24·30칸(제안값). 조금 부족해야 고르는 재미가 있다.
- 탄창을 한 칸씩 두지 않고 **탄 종류별 묶음**으로 쌓는다. 장전하면 묶음에서 자동으로 빠진다.
  - 9mm: 권총·기관단총 / 5.56: 돌격소총·경기관총 / 7.62: AK·지정사수·저격 / 12게이지: 산탄총 / 특수탄(로켓탄·포탄·레일건 배터리)
  - 한 칸 기준 예: 5.56 60발, 12게이지 12발, .50 5발
- 마우스 오버 정보: 무기 타입, 탄 종류, 대미지, 탄창 크기.
- 바닥에 떨어진 물건은 지금의 바닥 무기 줍기를 넓혀 쓴다. 팀원 교환은 우선 "바닥에 놓고 줍기", 직접 교환은 다음 단계.
- 네임드·보스의 아이템 흩뿌리기는 네임드 시체 위치 고정(T-16)과 맞물린다. 멀티에서는 방장이 떨어질 아이템과 위치를 정한다(M-9).

## 7. 서바이버 — 뱀서식 성장 (M-26)

**사용자 방향**:
- 탄창은 유지하되 **총알은 무제한**. 그래서 기존 1번 무기(권총)는 필요 없어 보인다.
- 들어가자마자 무기를 고른다. 1번 무기: 랜덤 주무기·특수무기 3개 중 하나 → 바로 2번 무기: 같은 랜덤 풀에서 셔플된 3개 중 하나. 3장 카드는 너무 흔하니 다른 방법을 찾고 싶다(나중에 바꿀 수 있음, 추천 요청).
- **특수무기는 총알 무제한, 대신 한 발 쏘면 쿨타임이 아주 김.** 쿨타임 동안 다른 무기로 버틴다.
- 네임드 시체나 보스를 루팅하면 다시 3개 중 하나를 고르는 업그레이드.
- 경로 루트가 아니라 **아주 넓은 지형**, 나무·기둥 같은 장애물은 있음.
- 팀이 멀어지면 안 보이니까 화면 밖 팀원은 **화면 가장자리에 반투명 화살표 + 이름**.
- 이 모드의 네임드·보스는 진짜 체력이 많고 세야 한다. 일반 몬스터도 체력이 좀 많아져야 한다. **보스·네임드는 전용 테이블**.

**추천**:
- 무기 칸 두 개(1·2), 보조 권총 칸은 없음.
- 고르는 방법 추천: **바닥에 놓인 무기 진열대.** 시작 지점에 무기 3자루가 실제로 놓이고, 하나를 주우면 나머지는 사라진다. 3D로 보여서 영상에 좋고 지금 줍기 시스템을 그대로 쓴다. 업그레이드는 네임드·보스를 잡으면 보급 상자가 터지며 3개가 튀어나오는 같은 방식.
  - 다른 후보: 맵에 보급 상자 3개가 떨어지고 걸어가서 여는 것(위치 선택이 곧 위험) / 같은 무기를 두 번 집으면 강화(쌍권총 방식).
  - 최종 방식은 `[미결]`(Q-11).
- 특수무기 쿨타임 20~40초, 칸에 쿨타임 원 표시.
- 화면 밖 표시는 팀원과 보스 모두에 쓴다.
- 1차 버전(M-22)은 일반 몹 체력을 데이터의 60%로 낮췄다. 이 방향(일반 몹도 단단하게)과 반대이므로 전용 테이블을 만들 때 다시 정한다.

## 8. 보스·네임드 종류 추가와 모델링 (A-17)

**사용자 방향**: 보스·네임드급 몬스터 종류를 늘린다. 스킬을 넣으려면 모델링을 추가하는 게 좋겠다. **몬스터 모델링은 GPT(Codex)를 실행해서 진행**하고 싶다.

**추천 후보** (외형 기준은 [몬스터 가이드](monster-design-guide.md), 추가 양식은 같은 문서 5장):

| 등급 | 후보 | 스킬 아이디어 |
|---|---|---|
| 보스 | 거대 황소 (지금 `boss`, 전용 모델로 교체) | 돌진, 내려찍기, 소환, 격노 |
| 보스 | 풍선 여왕 | 떠다니며 풍선 소환, 헬륨 장판, 터질 때 페이즈 전환 |
| 보스 | 고릴라 인형 | 내려찍기 파동, 드럼통 던지기 |
| 보스 | 랫서판다 사령관 (무장 테마) | 미니건 부채꼴 탄막, 포격 요청(박격포 원), 방패병 호출 |
| 네임드 | 방패 감염체 | 정면을 막음, 뒤나 옆을 쏴야 함 |
| 네임드 | 자폭 너구리 | 달려와 폭발 |
| 네임드 | 저격 랫서판다 | 레이저 조준선 후 한 방 |
| 네임드 | 거미형 크롤러 | 거미줄로 감속 |
| 네임드 | 치유 감염체 | 주변 적 회복 오라 |

**모델링 진행 방식 (제안)**:
1. Claude가 몬스터마다 규격 지시문을 쓴다: 단순 도형 체형(D-5), 노드 이름, 충돌 크기, 모델 크기, 삼각형 예산([캐릭터 모델 규격](character-model-spec.md)).
2. 이 PC의 Codex CLI(`codex exec`, 저장소 `AGENTS.md`를 읽음)가 `prototypes/character-lab`와 에셋 폴더 안에서만 모델을 만든다.
3. Claude가 게임에 붙여 실제 렌더와 전용 검사(`EnemyExpansion`, `EnemyAttackCheck`, `HitFlashCheck` 등)로 확인하고 문서를 갱신한다.
4. 같은 파일을 동시에 고치지 않도록 한 번에 한 마리씩.

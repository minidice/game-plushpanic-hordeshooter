# 드론·부사수 모델 제작 계획

2026-10-22. 사용자 승인: 드론 4종, 기존 캐릭터를 축소한 부사수 프리셋 4종, 드론 장비 공용 교체, 고/저품질. 앞서 제안한 쿼드콥터·무당벌레·꿀벌·UFO를 제작한다.

## 설계와 범위

- 드론: 미터/+Y 위/+Z 앞, Body 아래 EquipmentSocket(0,-0.22,0). 몸체 4종×고/저 GLB, 하부 장비 light/laser/blaster/support 4종. 장비 루트는 상단 접촉면이고 아래쪽으로 내려온다. 종별 보정 없이 붙이며 비행 자세와 품질 전환 중 동일 장비 인스턴스를 유지한다. 펫 등 장비와는 장착 방향/규격이 다르다.
- 고품질 최대30,000/저품질10,000삼각형, 공용 장비3,500 이하. Blender 원본 재생성 도구와 GLB를 관리하고 output은 제외한다. 저품질은 동일 조형을 감량한다.
- 부사수: goose/cadet(베레모), duck/scout(고글), raccoon/engineer(헬멧·배낭), redpanda/guard(보호 조끼). 프리셋 JSON, 기존 CharacterRig/AppearanceProfile 재사용, 원본 정의 수정 없이 시각 루트를 0.60배. 총/손/총구도 같은 루트 안에서 축소. 충돌 참고 치수는 원본×0.60으로 노출하되 실제 충돌·AI는 만들지 않는다.
- 기존 PetQuality 설정/저장 키는 호환 유지하고 표시명을 소환수 모델 품질로 확장. 드론은 별도 고/저 메시, 부사수는 원본 공유 메시의 자동 LOD 편향을 High4/Low0.5로 변경(별도 저품질 GLB 아님). 부사수는 모델 축소만으로 면 수가 줄지 않는다.
- 모델 라이브러리/프리셋/표현까지. 소환 카드·추종·피해·공격 기능·네트워크는 후속. 장비 역할 명칭은 외형 표현이며 실제 지원 능력을 구현하지 않는다.

## 구현 순서

- [x] build-drones.py와 validate-drones.py: 몸체8/장비4, 구조·예산·두 품질 피벗 검사. 기존 펫 생성기는 import 시 생성하지 않도록 main guard만 추가.
- [x] DroneModel.cs: 생성/장착/해제/품질 전환/비행 자세와 설정 구독. SidekickModel.cs·sidekick_presets.json: 네 프리셋·기존 무기와 손 재사용·품질 LOD.
- [x] CompanionModelCheck: 4×2×4 교체/해제, 잘못된 ID, 설정 전환, 자세/무기 보존, 프리셋 격리·원본 보존·축소 총구. 전용 실제 렌더: 고/저·장착표·프리셋·움직임·6개 단독 장면.
- [x] 펫/메뉴 회귀 검사·실제 이미지 검토·독립 최종 리뷰, decisions/issues/규격/체크리스트 갱신.

검사 중점: 로터/날개와 하부 장비 간섭, 교체 중 잃는 장비 상태, 글로벌 이벤트 정리, 원본 캐릭터/사용자 외형 변경, 저품질 부품 소실. 저사양 실제 전투 성능은 이번 모델 검사로 보장하지 않는다.

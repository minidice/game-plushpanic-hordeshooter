# 그림 지시문: 카드 이펙트 스프라이트 (`fx_*`) — 모여라! · 불붙음 · 꽥 광선 · 정전기 솜 · 미친 과학자 거위

> **상태**: 2026-10-22 작성. Codex CLI(`codex exec -s workspace-write`)에 맡기는 이펙트 그림 작업(decisions.md M-29 4단계 3묶음, [카드 계획](../onslaught-cards-plan.md) 16.6 · 16.6.1~16.6.3). 사용자 규칙: 이펙트 · 모델 · 아이콘 같은 리소스는 Codex가 만든다.
> **왜**: 팀 특별 카드 네 장이 화면에 상태를 보여 줘야 한다. 바닥의 원 · 경고 부채꼴, 머리 위 표시(별 · +/− · 큰/작은 거위), 불꽃 · 김 · 전기 불꽃 같은 파티클. 게임은 이 그림을 `Sprite3D` · 파티클 · 바닥 판에 붙여 쓴다(Claude).
> **검토자**: Claude가 스크립트를 실행해 PNG를 만들고 게임에 붙여 실제 렌더로 확인한다. Codex는 그림을 만드는 스크립트까지만 만든다.

## 1. 공통 규칙

- 분위기: 봉제 인형 · 장난감 톤, 납작하고 두툼한 외곽선(어두운 `1c2230`, 2~6 px) — 단, **바닥 판 · 빛 번짐 그림(원 · 부채꼴 · 불꽃 · 김 · 전기)은 외곽선 없이** 부드러운 가장자리.
- 배경 **투명**(RGBA PNG). 4배로 그린 뒤 줄여 안티에일리어싱. Python 3 + **Pillow만**. 결정적으로(시드 고정).
- 색 팔레트: 빨강 `e5484d` · 주황 `ff9b4a` · 노랑 `ffd23f` · 금 `ffcf5a` · 연두 `7dff9a` · 하늘 `6bb8ff` · 파랑 `3f6fd8` · 보라 `c08bff` · 분홍 `ff9ccc` · 흰 `f3f4f1` · 회색 `8c96a8`.
- 파티클용 그림(불꽃 · 김 · 전기 불꽃 · 별)은 **흰색에 가까운 밝은 색**으로 그려도 된다(게임이 색을 곱함) — 아래 표에 "흰 바탕"이라 적은 것.

## 3. 카드 아이콘 4장 (같은 스크립트가 아니라 `card_icons.py`에 더하기)

- `prototypes/ui-icons/tools/card_icons.py`(이 작업에서 만든 파일)에 아래 4장을 더해 **23장**, 끝 출력 `CARD_ICONS_BUILT 23`, 단언도 23장 기준. 기존 19장 결과는 바꾸지 않는다. 그림 규칙은 [카드 아이콘 지시문](card-icons.md) 1장 그대로(256², 외곽선).
  - `card_gather.png` 모여라!: 거위 머리 세 개가 동그랗게 모여 있고 가운데 금색 확성기
  - `card_honk_beam.png` 꽥 광선: 금색 나팔 경적에서 앞으로 펼쳐지는 부채꼴 빛(노랑 → 투명)
  - `card_static_fluff.png` 정전기 솜: 흰 솜뭉치 둘(빨강 + 표시 · 파랑 − 표시) 사이에 노랑 번개
  - `card_mad_scientist.png` 미친 과학자 거위: 보라 액체가 든 둥근 플라스크(거품) 옆에 큰 거위 머리 · 작은 거위 머리

## 4. 만들 것 (Codex 작업 범위)

1. **새 파일** `prototypes/ui-icons/tools/card_fx.py` 하나: 2장의 15장을 쓰고, 파일마다 `CARD_FX_READY <파일>`, 끝에 `CARD_FX_BUILT 15`. **assert**: 크기 표대로, RGBA, 네 모서리 완전 투명(`fx_cone.png`는 위쪽 두 모서리), 서로 다름, 불투명 픽셀이 0이 아님.
2. **고칠 파일** `prototypes/ui-icons/tools/card_icons.py`: 3장대로 4장 추가.
3. 둘 다 실행하지 않는다. **Claude가 실행**: `python prototypes/ui-icons/tools/card_fx.py` · `python prototypes/ui-icons/tools/card_icons.py`

## 5. 하지 말 것

- `game/` 안의 C# · 데이터 · 장면 · 다른 에셋, `doc/`, 위 두 파일 말고 다른 도구 파일을 고치지 않는다.
- 커밋 · 푸시하지 않는다. 새 패키지를 설치하지 않는다.

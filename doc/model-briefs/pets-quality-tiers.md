# 사족 펫 품질 2단계 작업 계획

2026-10-22. 사용자 요청: 동시에 최대 6마리, 거북이·강아지·토끼의 형태 품질 우선 재제작, 공용 등 무기 교체 유지. 고품질/저품질 제공. 기존 [펫 규격](../pet-model-spec.md)의 피벗·미터/+Z 계약을 유지한다.

고품질은 연속된 몸통/목/발, 종별 귀·주둥이·등껍질을 우선하고 본체 최대 30,000삼각형을 제작 예산으로 삼는다. 저품질은 같은 조형에서 최대 10,000삼각형으로 감량한다. 두 수준의 피벗·소켓 변환은 같고 무기를 바꿔도 종/품질 보정이 필요 없어야 한다. 최대 6은 제작·측정 전제이며 이번 모델 라이브러리에서 소환 규칙을 구현하지 않는다.

사용 기술: Blender 생성기/GLB, Godot C#, 기존 설정 저장/한국어·영어 메뉴. 직접 현재 작업 공간에서 실행한다. 기존 효과 작업은 보존한다.

- [x] `build-pets.py`와 새 `pet_shapes.py`: 고밀도 강아지 조형 보완, 거북이 곡면 등껍질/연결 목·다리, 토끼 얼굴/큰 뒷다리/홈이 있는 귀. 고/저 6개 GLB 및 Blender 원본 생성. `validate-pets.py`에서 예산·피벗·색·품질별 경계 검사.
- [x] `PetModel.cs`: High/Low 생성 및 품질 교체, 무기와 루트 변환·걷기 유지. `GameSettings`/`MainMenu`/언어표: 펫 모델 품질 저장·복원과 메뉴 선택. `PetModelCheck`·`MenuCheck`로 검증.
- [x] `PetQualityCapture`: 품질별 같은 화면 비교, 기존 모델과 동일 조명 비교, 6마리 고/저 렌더 부하 측정. 얼굴·등껍질·귀·받침 접촉·총구 간격을 실제 렌더로 검사.
- [x] 최종 리뷰 및 결정/이슈/규격/체크리스트 갱신. 수치는 실측과 구분하고 실제 저사양 호드·멀티 미검증을 기록.

검사 중점: 저품질 실루엣/색 경계 붕괴, 색 가져오기 누락, 소켓 떠 있음, 품질 교체 중 무기 유실, 잘못된 저장 값과 개인 설정 덮어쓰기. 외형을 확인하지 않고 면 수만 늘린 것을 품질 개선으로 보고하지 않는다.

## 실행 결과

- 고/저 본체: 거북이 29,824 / 9,538, 강아지 23,084 / 7,385, 토끼 25,404 / 8,125삼각형. GLB 8종과 피벗 일치 검사 통과.
- 빌드 경고/오류 0, PetModelCheck 185, MenuCheck 44, Integration 148 통과. 통합 종료 ObjectDB 경고 4개(I-17), 전용 검사/캡처 경고 없음. Blender 6.0 제거 예정 경고는 남음.
- 실제 4방향·두 무기·48프레임 걷기·전후 비교 확인. 독립 리뷰에서 중요한 결함 없음.
- 6마리 단독 렌더 수치는 [규격](../pet-model-spec.md)에 조건과 함께 기록. 저사양 실제 전투 성능 보장으로 해석하지 않는다. 결정/이슈/체크리스트·캐릭터 규격·소환수 계획의 관련 범위를 갱신했다.

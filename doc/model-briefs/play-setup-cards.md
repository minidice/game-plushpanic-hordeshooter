# 그림 지시문: 게임 설정 카드 그림 (`play_*`) — 시나리오 · 거점 · 난전 카드

> **상태**: 2026-10-28 작성. Codex CLI(`codex exec -s workspace-write`)에 맡기는 UI 그림 작업(decisions.md M-39, [게임 설정 설계안](../features/menu-ui/play-setup-plan.md) 4장). 사용자 규칙: 그림은 항상 Codex.
> **왜**: 시작 화면의 "게임 설정"에서 모드(시나리오 · 거점 · 난전)를 고르면 그 아래 카드 줄(시나리오 2개, 거점 · 난전은 적 계열 3개)이 나온다. 고른 카드는 큰 그림으로, 후보는 작은 카드로 보인다(Left 4 Dead 캠페인 선택처럼, 단 우리 UI 톤으로). 사용자 선택: **Codex가 처음부터 그린 납작한 일러스트**.
> **검토자**: Claude가 스크립트를 실행해 PNG를 만들고 메뉴에 붙여 실제 화면으로 확인한다. Codex는 그림을 만드는 스크립트까지만 만든다.

## 1. 공통 규칙

- 분위기: 봉제 인형 · 장난감 톤의 **납작한 일러스트**(두툼한 외곽선 4 ~ 6 px `1c2230`, 둥근 모양, 면 색 + 하이라이트 한 줄, 그림자는 납작한 어두운 면 정도). **글자 · 숫자 · 로고 없음.** 카드 아이콘([지시문](card-icons.md))과 같은 손맛이되 **장면**(배경 + 인물 실루엣)이다.
- 크기 **640 × 400**, 불투명(RGB). 메뉴가 둥근 모서리로 자르므로 가장자리까지 그린다. 아래쪽 1/4은 이름 글자가 올라갈 수 있게 조금 어둡게(아래로 갈수록 `0d1114` 쪽으로 35%까지).
- 바탕 톤은 메뉴(짙은 남색 `0d1114` · 패널 `06101e`)와 어울리게 **어둡고 채도 낮은 하늘 · 땅**, 그 위에 인물 · 소품만 밝은 색. 모드마다 시간대를 다르게: 시나리오 = 해 질 녘(주황 · 보라 하늘), 거점 = 실내 조명(따뜻한 노랑 램프), 난전 = 밤(남색 · 달빛).
- **우리 캐릭터**: 둥근 봉제 동물(거위 · 오리 · 라쿤 · 레서판다), 헬멧 · 조끼, 작은 총. 장면마다 2 ~ 4명, 뒤에서 본 모습이나 옆모습 실루엣으로 단순하게.
- **적 계열**(C-31): 감염무리 = 회녹색 피부의 사람 모양 감염체(일상복, 팔을 앞으로), 수렵단 = 동물(독수리 · 호랑이 · 사자) 머리에 몽둥이 · 칼 · 나무활, 무장단 = 동물에 총(소총 실루엣) · 방탄복. 적은 장면 뒤쪽 · 가장자리에 무리로, 얼굴은 단순하게(무섭기보다 장난감 같은 위협).
- 팔레트(이 안에서, 어둡게 섞기 가능): 잉크 `1c2230` · 남색 `0d1114` `1a2433` `2b3a52` · 하늘 강조 `b8e5ff` · 노랑 `ffcf5c` · 주황 `ff9b4a` · 빨강 `ff5b4f` · 보라 `7a5ea8` · 녹회색 `7f8f6a` · 감염 녹색 `9fb36a` · 갈색 `8a6a46` · 흰 `f3f4f1` · 회색 `8c96a8`.
- Python 3 + **Pillow만**(이미 설치됨). 결정적으로(무작위를 쓰면 시드 고정). 2배로 그린 뒤 줄여 안티에일리어싱.

## 2. 만들 그림 (`game/assets/ui/play-setup/<파일>`)

| 파일 | 카드 | 장면 |
|---|---|---|
| `play_scenario_campaign.png` | 시나리오 ① 계획 캠페인(도시 → 지하 → 풀밭 → 물과 다리) | 해 질 녘 도시 거리: 아스팔트 길에 흰 점선, 양쪽 건물 · 철망 담, 멀리 다리와 강의 실루엣. 앞에 우리 분대 3명이 길을 따라 걸어가는 뒷모습, 길 끝 · 건물 사이에 감염무리 몇 |
| `play_scenario_short.png` | 시나리오 ② 짧은 캠페인(창고 지구, 임시) | 반은 어두운 창고 안(선반 줄 · 상자 · 드럼통), 반은 열린 셔터 너머 숲길 · 모래주머니 벙커 해치. 우리 2명이 셔터 쪽으로 |
| `play_survival_zombie.png` | 거점 · 감염무리 | 창고 안 발전기(노란 램프 · 케이블)를 둥글게 둘러싼 우리 4명, 사방 문 · 창에서 감염무리가 몰려옴 |
| `play_survival_animals.png` | 거점 · 수렵단 | 같은 발전기 진지, 몰려오는 쪽이 몽둥이 · 활을 든 독수리 · 호랑이 · 사자 무리 |
| `play_survival_armed.png` | 거점 · 무장단 | 같은 진지, 방탄복에 소총을 든 동물 무리(총구 섬광 두세 개) |
| `play_survivor_zombie.png` | 난전 · 감염무리 | 달밤의 넓은 풀밭(낮은 나무 · 돌기둥), 가운데 우리 한 명을 둥글게 둘러싼 감염무리, 뒤에 큰 보스 실루엣 하나 |
| `play_survivor_animals.png` | 난전 · 수렵단 | 같은 풀밭, 수렵단 무리 + 큰 황소 보스 실루엣 |
| `play_survivor_armed.png` | 난전 · 무장단 | 같은 풀밭, 무장단 무리 + 큰 보스 실루엣(무거운 총) |

- 같은 모드의 세 장은 배경 구도를 같게 하고 적 계열만 바꿔, 줄로 놓였을 때 차이가 한눈에 보이게.

## 3. 만들 것 (Codex 작업 범위)

1. **새 파일** `prototypes/ui-icons/tools/play_setup_cards.py` 하나. 실행하면 위 8장을 쓰고, 파일마다 `PLAY_CARD_READY <파일>`, 끝에 `PLAY_CARDS_BUILT 8`.
2. **assert**: 크기 640 × 400, 모드 RGB, 8장이 서로 다름(픽셀 해시), 아래 1/4 평균 밝기가 위 3/4보다 낮음, 장마다 사용 색 수가 너무 적지 않음(축소 팔레트로 12색 이상).
3. 실행은 하지 않는다. **Claude가 실행**: `python prototypes/ui-icons/tools/play_setup_cards.py`

## 4. 하지 말 것

- `game/` 안의 C# · 데이터 · 장면 · 다른 에셋, `doc/`, 다른 도구 파일(`card_icons.py` · `vote_icons.py` 포함)을 고치지 않는다. 새 파일 하나만. 필요한 그리기 도우미는 다른 파일을 import하지 말고 복사한다.
- 커밋 · 푸시하지 않는다. 새 패키지를 설치하지 않는다.

## 5. 끝났다고 볼 기준

- `python -m py_compile prototypes/ui-icons/tools/play_setup_cards.py` 통과.
- 마지막 메시지에: 만든 파일, 장면별 구성, 확인하지 못한 것.

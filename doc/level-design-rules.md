# 레벨 디자인 규칙

## 진행 방향 — 확정 2026-10-20

**스테이지 주 경로의 70% 이상은 화면 기준 우측 상단으로 진행한다.** 월드 좌표의 북동쪽이 아니라, 실제 기본 플레이 카메라에서 보이는 방향이다. 전 구간을 같은 방향으로 만들라는 뜻은 아니다.

- 입구 → 주요 목표 → 출구의 필수 진행 경로를 기준으로 측정한다. 선택형 파밍 방, 전투 중 회피·후퇴, 동일 통로 재방문은 분모에서 제외한다.
- 경로를 방향이 바뀌는 지점마다 구간으로 나눈다. 화면 오른쪽을 0°로 할 때 위쪽으로 **15~75°** 향하는 구간을 우측 상단 진행으로 센다. 이 각도 범위는 현재 프로젝트의 운영 기준이며 조정 가능하다.
- 비율은 구간 개수가 아니라 **바닥 이동 거리의 합**으로 계산한다. `우측 상단 구간 길이 / 전체 필수 경로 길이 ≥ 0.70`.
- 나머지 구간에는 좌우 굴곡, 우회, 짧은 역방향 목표, 수직 공간을 허용한다. 필수 왕복을 늘려 수치만 충족하지 않는다.
- 입구에서 다음 진행 방향을 바닥 도색·출입구·조명·랜드마크로 읽을 수 있게 한다. 전투 중에는 캐릭터와 공격 예고를 장식물이나 전면 벽이 가리지 않아야 한다.

## 현재 Stage 1 적용

기존 세이프룸 → 거리 → 창고 → 야적장 → 세이프하우스의 주축은 월드 `+X`다. 카메라를 수직 55° / 수평 **-30°**로 두어 이 축이 화면 우측 상단으로 투영되게 했다. Tab 확대에서도 방향은 동일하다. WASD는 화면 방향을 기준으로 움직인다.

구역 간 주축은 규칙에 맞는다. 셔터 제어판 접근, 엄폐물 우회 등 세부 이동은 다른 방향을 허용한다. 향후 경로 배치를 바꿀 때는 실제 플레이 동선의 길이 비율을 다시 측정한다. 카메라 방향 검사만으로 세부 경로 전체의 70%를 자동 인증하지 않는다.

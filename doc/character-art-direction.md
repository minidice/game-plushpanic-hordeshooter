# 캐릭터 아트 기준 — 매끈한 데포르메 동물과 입체적인 장비

2026-10-25, A-25·D-5·C-31. **사용자 확정 방향:** 봉제인형을 목표로 삼지 않고 이번에 첨부한 덕코프 이미지4장의 느낌을 기준으로 한다. 아래 명칭과 구체적인 제작 방법은 이미지를 해석한 작업 기준이며 개별 모델의 최종 아트 승인과는 구분한다.

작업 명칭은 **“매끈한 데포르메 동물 + 입체적인 밀리터리 장비”**로 통일한다. 영어 작업 지시에는 `stylized animal characters, clean continuous forms, smooth matte surfaces, grounded equipment`를 쓴다. 특정 셰이더나 실제 제작 재질을 사진만으로 단정하지 않는다.

## 참고 이미지에서 가져올 특징

- `images (2).jpg`: 머리–몸이 자연스럽게 이어지는 큰 덩어리, 작고 단순한 검은 눈, 넓은 부리와 뾰족한 볏, 얇고 납작한 새 발. 날개 끝은 소수의 큰 깃으로 구분되고 무기와 맞닿는다.
- `6552.jpg`: 조금씩 다른 키·배·볏으로 개체 차이를 주면서 같은 종으로 읽히는 실루엣. 몸 표면은 단순하고 조끼·총기의 구조는 또렷하다. 발 주변의 그림자가 바닥 접촉을 보여 준다.
- `6553.jpg`, `6554.jpg`: 단순한 동물 얼굴·몸과 두께 있는 조끼/파우치/무기의 디테일 차이. 종별 부리·눈매·큰 색 영역이 우선 읽힌다. 따뜻한 조명에서도 몸과 장비의 재질 차이가 남는다.
- 이미지의 헬멧·선글라스는 이번 요청으로 장착 허용한 것이 아니다. 일반 몬스터의 투구·눈 장구류 제외 정책(C-31)은 유지한다. 색·장비 조합을 그대로 복제하지 않으며 자체 모델로 원리를 적용한다.

## 제작 기준

| 부위 | 목표 | 피할 해석 |
|---|---|---|
| 몸/머리 | 단순한 큰 윤곽과 연속된 표면, 종에 맞는 목·배 연결 | 솜을 채운 듯한 볼·배 패치, 구를 여러 개 붙인 몸 |
| 얼굴 | 작은 검은 눈, 얕은 돌출, 절제된 반사; 부리/주둥이와의 간격으로 표정 | 단추 테두리·유리구슬처럼 큰 눈, 별도 볼 덩어리, 기본 미소를 모든 종에 강제 |
| 눈썹 | 얇은 곡면과 끝이 좁아지는 윤곽, 모양/각도/두께/좌우 차이로 개체 구분 | 눈을 가리는 덩어리·두꺼운 막대, 모든 개체에 같은 화난 표정 |
| 날개/갈기/볏 | 끝으로 좁아지는 큰 형태 몇 개와 필요한 겹침; 부드러운 표면과 명확한 끝의 대비 | 모든 끝을 둥글게 부풀리기, 쿠션 칼라나 구슬 고리 같은 갈기 |
| 손/발/다리 | 작은 파지 형태, 평평한 발바닥, 얇은 발끝과 좁은 발목; 종별 특징 보존 | 벙어리장갑·동그란 슬리퍼를 공통 정답으로 삼기, 모든 부위를 같은 둥근 덩어리로 만들기 |
| 표면 | 넓고 매끈한 음영, 과하지 않은 광택; 몸/부리/발/옷/금속의 반사 차이 | 몸 전체의 천 결·봉제선·스티치·패딩, 털 한 올씩 묘사, 전체를 광택 플라스틱으로 통일 |
| 장비 | 몸을 감싸는 두께, 옆면·어깨 연결, 분명한 파우치 입체감과 실제 손잡이 접촉 | 가슴 앞에 떠 있는 장비, 몸과 같은 부드러운 덩어리 재질, 잔장식만 추가 |
| 조명 | 면의 연결과 발 접지가 읽히는 명암; 통제 조명과 게임 조명 둘 다 검수 | 과한 노란 조명·반짝임·AO로 부실한 형태를 가리기 |

옷의 재봉선이나 동물의 실제 색 무늬는 필요한 곳에 쓸 수 있다. 제거 대상은 캐릭터 몸 전체를 천으로 만든 인형처럼 표현하는 습관이다. 짧은 팔다리와 귀여운 과장은 유지하며 실제 동물 해부 비율로 바꾸는 요구로 확대하지 않는다.

## 기존 모델과 다음 수정의 구분

최초 반영은 방향·제작 지시·체크리스트 정정이었다. 이후 [앵무새 모델과 머리 표시 동작](parrot-clean-forms.md), 다음 추천 작업으로 [독수리](eagle-clean-forms.md)와 [사자](lion-clean-forms.md)를 수정·검수했다. 이어서 [순록·인간형 감염체](reindeer-zombie-clean-forms.md)의 모델을 수정·검수했다. 플레이어는 [랫서판다 얼굴·귀·손발](redpanda-clean-forms.md)부터 적용했다. 이어 [라쿤 얼굴·귀·손발](raccoon-clean-forms.md)을 개선했다. 거위·오리와 호랑이·코뿔소는 후속이다.

사용자 후속 요청으로 앵무새·독수리·사자·순록 네 종에 [10개 눈썹 조합](common-monster-brows.md)을 공통 런타임 외형 모듈로 추가했다. 눈썹이 없는 얼굴만을 새 아트 기준의 정답으로 해석하지 않는다.

## 문서 우선순위와 범위

캐릭터 제작 시 이 문서 → 종별 외형 가이드 → GLB 기술 계약 순으로 읽는다. 앵무새·독수리·사자 검수 문서와 과거 모델 브리프의 봉제 표현은 당시 제작 해석의 이력이며 새 지시로 재사용하지 않는다. D-5의 관절 없는 피벗 방식은 구현 제약이지 손발이 떨어진 인형처럼 보여야 한다는 미술 목표가 아니다.

환경은 A-25의 덕코프 중심/젤다 단차·밀도 기준을 유지한다. 프로젝트명·리소스 ID의 `plush`는 기술 식별자이며 변경하지 않는다. A-20에서 별도로 승인한 사족 펫의 귀여움/아기 인형 기준은 이번 동물 캐릭터 참고를 이유로 자동 개편하지 않는다. UI·VFX·보스 능력·복장 정책도 별도 재설계하지 않는다.

첨부 이미지 자체는 개인 첨부 폴더에 있고 버전 관리하지 않는다. 저장소에서는 위 특징 요약을 재사용 기준으로 삼으며, 상세 모델 비교 때는 원본 참고 이미지와 실제 렌더를 함께 본다.

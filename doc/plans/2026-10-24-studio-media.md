# Studio 이펙트·사운드 검수 구현 계획

> writing-plans / 독립 VFX·오디오·UI 병행. 기존 로컬 Studio 확장 요청에 따른 구현 선택이며, 별도 사용자 설계 승인을 받았다고 표현하지 않는다.

목표: 현재 게임의 실제 효과 생성기와 사운드 로더를 웹에서 검수한다. 저장·외부 배포 없이 현재 작업 폴더를 읽고 Debug 전용 bridge를 사용한다.

접근: 브라우저에서 효과를 재구현하면 셰이더/동작이 달라지고, 매번 게임 창을 조작하면 웹 검수 목적과 맞지 않는다. 기존 Godot bridge에서 실제 프레임을 촬영해 브라우저에서 재생한다. 사운드는 실제 Sfx가 선택한 합성 PCM 또는 로컬 교체 음원을 브라우저 기본 플레이어로 듣는다. 게임 거리 감쇠·버스 상태 효과·랜덤 피치·동시 발음은 원음 미리보기 범위 밖이다.

- [x] `/effects`, `/sounds` 메뉴, 검색/분류/속성/출처. 기존 메뉴 유지.
- [x] `StudioEffects.cs`: 실제 게임 코드 호출, 짧은 프레임 시퀀스, 재생/일시정지/속도/타임라인. 대표값은 검수 예시로 표시. 무기 데이터는 실제 Armory에서 읽음.
- [x] `StudioSounds.cs`: SoundRecipes 전체와 Sfx override 우선순위, 원음·길이·반복·볼륨/피치/버스 등 실제 설정. 임의 리소스 경로 요청 불가.
- [x] `StudioPreview.cs`/`server.mjs`: GET `/api/media`, POST `/api/effects/render`, `/api/sounds/preview`. 기존 loopback·동일출처·요청 직렬화/재시작 유지.
- [x] 검사: API 부재 실패부터 확인, 실제 렌더 프레임/변화·음원 PCM/등록 목록·알 수 없는 ID·겹친 메뉴 요청·소스 불변. 브라우저 재생/정지/빠른 전환·음원 해제. 기존 도감/캐릭터 회귀와 Debug/ExportRelease Studio 제외 확인.
- [x] T-25/이슈 검토/체크리스트/Studio·사운드 규격 갱신, 결과와 미검증 범위 기록.

주의: 이전 파괴 벽 작업의 미커밋 변경은 유지. 설정·세이브 변경 없음. 이펙트 모델과 사운드 자산의 게임 동작 자체를 변경하지 않는다. 소리는 사용자 재생 입력 전 자동 출력하지 않는다. 짧은 총격 이펙트가 첫 프레임 전에 사라지지 않도록 촬영 시간과 실제 프레임 검증이 필요하다.

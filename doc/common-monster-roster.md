# 일반 몬스터 조합 개편

2026-10-25 사용자 승인: 이 문서는 연속 대화에서 확정한 방향과 구현용 초깃값을 구분한다. 네임드·보스 개편은 이번 범위 밖이다.

## 승인된 방향

- 감염무리 / 수렵단 / 무장단. 스테이지는 한 계열을 기본으로 하고 시작·종료 구역/진지 경비처럼 데이터에 명시한 구역만 다른 집단을 허용한다. 난이도나 무작위 선택 때문에 다른 집단이 섞이지 않는다.
- 동물은 같은 종족끼리 무리를 이룬다. 독수리·앵무새·사자·호랑이·순록·코뿔소의 특징을 머리/부리/갈기/뿔/꼬리로 읽게 한다. 종족 특성 + 무장 방식 + 무기 종류 + 외형의 조합이다.
- 수렵단은 일상복/현대 장구류 없이 몽둥이·칼·나무활. 무장단은 플레이어와 공통 총기 모델(MP5/AK47/M4)과 가끔 나이프, 선택적인 방탄복(2026-10-25 후속 요청: 선글라스·안대 등 눈 장구류 제외). 특징을 가리는 투구 없음.
- 종족별 전투 차이를 둔다. 특수한 예외를 제외한 일반 추격 속도는 기본 플레이어4.4m/s보다 조금 빠르다. 플레이어 버프/구르기를 따라서 적 속도를 자동 증가시키지 않는다.
- 일반 감염체는 기존 인간형을 개선한 좀비 한 종족, 공통 비무장 근접 행동. 스킬은 네임드에 남긴다. 일상복·청바지/면바지/하의 없음/찢어진 바지/멜빵/양복, 옷 무늬·얼룩·해짐의10프리셋(안대 프리셋은 줄무늬 청바지 차림으로 변경). 외형이 전투 수치를 바꾸지 않는다. 타투 없음.
- 지역/무리의 대표 색 테마를 먼저 결정한다. 감염체 복장은 갈색·녹색 범위를 유지한다. 붉은 독수리는 붉은 배색 안에서, 녹색 독수리는 녹색 배색 안에서만 개체 차이를 둔다. 종족 식별 부위·좀비 피부는 의복/주요 색 영역과 분리한다. 완전 무작위 RGB 대신 검수한 배색 세트를 쓴다.
- Studio도 실제 공통 데이터/모델/생성기로 종족·계열·무기·색 테마·프리셋/무리 조합을 확인한다. 게임과 별도의 웹용 몬스터를 만들지 않는다.

## 구현 선택과 초깃값

- 속도4.55–4.75m/s, 종족별 체력/질량/공격 준비/회전 성향은 초기 조정값이다. 기본 모델/무리 품질을 실제 플레이로 검수한 뒤 조절한다.
- 모델은6종 동물 + 인간형 개선1종, 공통 부착 노드와 재질 채널을 사용한다. 실제 게임에서는 호스트가 외형 프리셋을 무작위로 정하고 등장 이후 고정한다. Studio의 10종 비교는 재현 가능한 순서로 보여준다. 옷은 적합한 프리셋 부품만 표시하며 공유 재질을 개체별로 오염시키지 않는다.
- 일반 적의 전투 조합은 기존 MonsterDefinition을 독립 합성한다. 전투/복제의 정체성과 시각 프리셋을 함께 고정하고 개체 생성 이후 시드/무장을 바꾸지 않는다. 기존 네임드/보스 데이터와 분리한다.
- 멀티에는 등장 때 조합 식별자를 전달해 종족/무장/판정/색/복장이 같게 보이게 한다. 프리셋 외형은 매 프레임 전송하지 않는다. 늦은 합류·데이터 불일치도 검사한다.
- 조우는 기본 테마를 유지하는 무리 프로필과 명시적 구역 예외를 사용한다. 지정된 무기 구성은 기본 인원에서 정확히 배정하고 모드/인원 보정 시 반복 배정한다.
- 기존 humanoid/crawler 등 legacy ID는 저장/기존 전용 검사 호환을 위해 유지할 수 있지만 새 일반 감염체 풀은 인간형 한 종으로 구성한다. 기존 네임드/보스의 외형과 기술은 유지한다.

# 폭발·화염·독 효과 품질 및 공통 데이터

현재 확장: 2026-10-27 [A-27 화염·연무](features/effects-audio/decisions.md#a-27-화염연무의-시각-계층과-무해한-잔흔), [A-28/A-29 폭발·가독성 통합 기록](features/effects-audio/log/012-check-effects-rollout.md). 아래의 2026-10-24 검사 수치는 당시 이력이며 최신 검사는 기능 기록을 따른다.

2026-10-24. 사용자가 공통 부품+계열별 조합 추천안과 Studio 공통 데이터 연결을 승인했다. 구현/검증 결과는 아래에 별도로 기록한다.

## 범위와 구조

- 짧고 선명한 스타일을 유지하며 수류탄/드럼통/로켓/박격포는 섬광·화염 덩어리·파편·먼지·연기를 공유하고 시간/형태를 구분한다. 화염병은 착탄 확산과 낮은 지속 불꽃, 독은 비행 방울→착탄 물보라→거품 웅덩이를 연결한다.
- `game/content/data/combat_effects.json`은 효과 ID·표시 이름·계열·색·시각 수치·사용처와 Studio 표본 크기/시간의 원본이다. 웹 전용 복사본을 만들지 않는다. 기존 피해·충돌·피해 반경·DPS·유효 시간은 전투 데이터가 소유한다. 미리보기 수치는 피해 데이터가 아니다.
- `CombatEffectCatalog`는 원본을 엄격하게 읽는다. `CombatBurstEffect`와 `CombatSurfaceEffect`, `CombatProjectileEffect`는 판정 없는 외형만 생성하며 Studio도 같은 생성기를 사용한다. 효과 시간은 명시적으로 진행해 Studio 고정 시간 캡처에서 게임과 같은 움직임을 얻는다.
- 런타임은 발생원 키로 효과를 선택한다. Studio는 등록 효과를 자동 열거하고 ID/계열/사용처/원본/시각 수치/표본 조건을 보여 준다. 기존 총구·피격·소나·벽 붕괴는 보존한다.
- 연료통 폭발은 `BarrelBurstVisual`, 다른 blast계열5종은 `ImpactBurstVisual`의 텍스처 카드로 표현한다. 화염 착탄/독은 공유 메시와 셰이더를 유지한다. 지속 화염과 연무 표본은 `AreaSurfaceVisual`의 GPU 입자 카드만 사용하고 바닥 면을 만들지 않는다. 원본 PNG는 `prototypes/effects/tools/generate_area_textures.py`로 재생성한다. 기존 레벨과 시점에 맞는 실제 엔진 렌더로 검수한다.

## 선택과 제약

전체 효과를 독립 제작하면 중복과 스타일 불일치가 늘고, 색/크기만 바꾸면 재질과 공격 종류가 구분되지 않는다. 승인된 공통 부품+계열별 조합을 적용한다. 시각 수치는 조정값이며 제품 확정 피해 수치가 아니다.

유효 위험 원의 바깥을 웅덩이로 칠하지 않는다. 불꽃은 낮고 군집 사이가 비어 캐릭터를 가리지 않게 한다. 기존 화염의 시야용 광원/음향은 유지한다. 폭발의 추가 광원은 동시에 제한하고, 지속 위험 표시를 부하 제한 때문에 제거하지 않는다. 지형 전체에 투영되는 데칼/새로운 지형 피해 판정은 범위 밖이며 현재 바닥 높이 계약을 유지한다.

## 데이터 계약 (schema_version 1)

| 항목 | 의미 / 적용 |
|---|---|
| `id`, `name`, `kind`, `family` | 고유 ID, 표시 이름, burst/surface/projectile, blast/fire/poison/smoke. smoke는 surface만 허용 |
| `sources`, `used_by` | 런타임 조회 키(중복 금지), `game/scripts/` 기준 사용처. Studio도 그대로 표시 |
| `color`, `accent`, `particles` | 6자리 RGB, 작은 파편/입자 수 0~48 |
| `lobes`, `spread`, `rise` | burst/surface만. 덩어리0~24, 퍼짐0.1~0.85, 상승0~3. spread는 중심 폭발/장식 연기·불티·독 군집의 분포. 지속 불꽃 뿌리와 폭발 범위층은 실제R 기준으로 따로 유지하며 rise는 불꽃 높이/거품 상승 |
| `smoke_color` | burst 및 fire/smoke surface의 필수6자리 RGB |
| `light_energy`, `duration_s` | burst만. 추가 광원0~6, 시각 수명0.1~3초 |
| `opacity`, `residue_s` | fire/smoke surface만 필수. 카드 농도0.01~1, 무해한 잔흔0~3초. smoke의 잔흔은0만 허용 |
| `preview_radius_m` | 모든 종류의 Studio 표본 크기0.05~10m. 피해 반경 설정이 아님 |
| `preview_lifetime_s` | surface/projectile의 Studio 표본 수명0.01~15초. 실제 전투 지속시간 설정이 아님 |

해당 kind에서 사용하지 않는 키·빠진 필드·중복 필드/ID/발생원·잘못된 색/범위는 로드 오류로 표시한다. 잘못된 발생원을 기본 폭발로 조용히 대체하지 않는다. 실제 웅덩이 크기와 종료는 기존 위험 지대 노드가 결정한다. 프로필 추가는 현재 세 가지 생성 방식 안에서 지원하며, 새로운 물리/효과 종류는 코드를 추가해야 한다. JSON 수정 후 Studio **로컬 데이터 다시 읽기**로 새 프로세스를 로드한다.

| ID | 연결 |
|---|---|
| `blast` | 일반 `weapon`과 기본 `blast` 발생원, 자체 폭발 오브젝트 |
| `grenade`, `lure` | 수류탄·유인 폭발 |
| `barrel`, `rocket`, `mortar` | 연료 팽창·진행 방향·위로 솟는 형태 |
| `fire_impact`, `fire_pool` | 화염병 착탄 및 지속 위험 |
| `smoke_cloud` (`smoke_preview`) | 노란 저층 연무. Studio 표본 전용, 피해/시야 차단 없음 |
| `poison_flight`, `poison_impact`, `poison_pool` | 실제 적 투사체, 착탄, 기존 VomitHazard |

폭발은 최대24개·추가 광원4개이며 오래된 일회성 장식만 줄인다. 지속 위험 노드는 이 제한으로 제거하지 않는다. 시각 RNG는 고정 독립 인스턴스로 전투 RNG를 소비하지 않는다. `visibility_alpha` 인스턴스 셰이더 값으로 불꽃/연기/거품/독 꼬리를 감쇠한다.

### 화염·연무 현재 계약

- 공유 정의는12개다. fire_pool은 불꽃24개/불티12개/얇은 연기12개, opacity0.78, 잔흔2초. smoke_cloud는 연무20개, opacity0.58, 잔흔0초. 수치는 피해 밸런스와 독립적인 제작값이다.
- 사용자 후속 요청으로 화염과 연무의 바닥 그림을 제거했다. 지속 화염/연무의 지면 면, 그을음, 착탄 화염의 바닥 충격파 링을 만들지 않는다. 불꽃·불티·연기 분포가 대략적인 범위를 전달하며 정확한 판정 경계를 선으로 표시하지 않는다. 중앙부터 순차적으로 나타나며 전역35% 시작 농도/일괄 감쇠는 사용하지 않는다.
- 지속 불꽃은 `area_flame_particles.gdshader`가 고정 입자 INDEX마다 같은 밑동 위치를 계산한다. 재생성 때 위치를 다시 뽑지 않으며 수평 이동/상승 이동은 없다. 중앙부터 외곽으로 점화 시차를 두고 각0.48초 동안 나타나 약1.1초에 전체 분포가 갖춰진다. 높이±12%, 기본 농도0.47~0.61, 프레임 위상을 흔들되 생성/소멸 곡선으로 높이·농도를 함께 곱한다. 종료 전 약0.45~0.65초부터 개별적으로 작아지고 기본 잔연기2초 설정에서는 종료 뒤 최대0.8초 안에 잔불이 사라진다. 시각 수명이2초 미만이면 출현 시간을 비례 축소한다.
- 연무는 `area_smoke_particles.gdshader`의 고정 슬롯을 쓴다. 중앙 근처에서 시작해1.25초 동안 퍼지고 반경별로 시차를 두어 각0.65초 동안 부풀어 오른다. 유지 중에는 작은 흐름/회전/농도 변화만 보인다. 슬롯마다1.15~1.8초에 걸쳐 서로 다른 시점에 사라진다. 독립 연무는 표본 수명 안에 소멸하고, 화염의 옅은 연기는 기존 잔연기2초 안에 소멸한다. 짧은 수명은 곡선 길이를 제한한다.
- 카드에는 무음영 재질과 깊이 기반 Proximity Fade를 적용한다. 불티는 기존 입자 수명 곡선, 화염/연무는 명시적 시간의 개별 출현·소멸 곡선을 사용한다. 입자는 fixed seed6517/SpeedScale0/60Hz로 생성하고 `RequestParticlesProcess`로만 진행한다. 셰이더도 TIME 대신 전달된 clock을 사용하므로 Studio 정지·타임라인과 게임 일시정지에서 벽시계 시간이 흐르지 않는다.
- 자연 종료의 화염은 시각 노드만 같은 Stage.Effects로 이동해 짧게 작아지는 잔불과2초 이내의 옅은 잔연기를 남긴다. 잔흔은 같은 소유자 아래 최대24개, 넘치면 오래된 장식부터 제거한다. 별도 광원/음향/피해는 추가하지 않는다. 실제 피해는 기존 시간에 끝나며 시각 확산이 피해 반경 확산을 뜻하지 않는다. 장면이 제거되면 함께 정리된다.
- 연무는2×2아틀라스(각512px), 불꽃은4×4아틀라스(각128px,16프레임의 닫힌 주기). 이전 시안의 흐름 노이즈512px2종/그을음512px3종/지면 셰이더는 원본으로 보존하지만 현재 화염/연무에서 로드하지 않는다. 에셋은 `asset_paths.json`의 `vfx.area_*`로 등록하고 `.import`와 밉맵 설정을 함께 관리한다.
- 일반 연무/화염은 벽과의 시각 교차선을 부드럽게 처리하지만 벽 우회 시뮬레이션이나 지형 투영은 하지 않는다. 현재 FireZone의 수평 반경 판정 자체는 바꾸지 않았다.

### 연료통 폭발 현재 계약 (A-28)

- `barrel`만 `BarrelBurstVisual`로 생성한다. 기본값은 화염 덩어리9/연기9/잔불5/불티20/섬광1장이다. 연무2×2/불꽃4×4 아틀라스의 기존 PNG와 등록 경로를 공유하며 새 이미지 파일은 추가하지 않는다.
- `duration_s`는1.45→2.4초. 섬광0.14초, 주 화염 최대약0.68초(출현 시차 포함), 잔불 최대약1.35초, 연기최대2.32초로 개별 소멸한다. 각 시간은 duration/2.4에 비례한다. `lobes`는 화염·연기 수, 절반 올림은 잔불 수이며 `particles`는 불티 수다. 기존 color/accent/smoke_color/spread/rise도 적용한다.
- 바닥 면/링을 생성하지 않는다. 연기 카드는 부풀며 올라가고, 잔불은 퍼진 자리에 머물며 작아진다. 깊이 기반 교차 감쇠와 알파로 가장자리를 처리한다. 폭발이 벽을 우회하거나 지형을 따라 흐르는 시뮬레이션은 아니다.
- CPU가 명시적 나이로 위치·크기·농도·아틀라스 프레임을 계산하고 GPU가 카메라 대면 카드를 그린다. TIME·독립 타이머·추가 피해/음향 없이 기존 부모의 수명/일시정지를 따른다. 동시24폭발/4광원 제한을 유지한다. 실제 피해/반경은 바꾸지 않는다. 다른 폭발은 이후 A-29에서 별도 확장했다.
- 최신 검사/비교 렌더와 성능 표본은 [009 기록](features/effects-audio/log/009-art-barrel-burst.md)을 따른다.

### 다른 폭발 계열과 가독성 현재 계약 (A-29)

- `blast/grenade/rocket/mortar/lure`는 새 `ImpactBurstVisual`을 사용한다. 기존 연무2×2 아틀라스, 명시적 시계, 고정 독립 RNG를 공유한다. 바닥 링은 만들지 않는다. 연료통의 잔불/곡선은 복사하지 않고 기존 구현 그대로 유지한다.
- 수명은 기존 순서대로0.95/0.85/1.0/1.2/0.85초다. 섬광은 전체 수명의12%, 화염/충격 덩어리는 계열별 약20~38%에 개별 시작 시차, 연기는 전체94% 이내에 소멸한다. 수류탄의 짧은 화염과 길쭉한 파편, 로켓 진행 방향의 분포 편향, 박격포 상승 먼지, 유인의 분홍색을 유지한다. 다른5종에 연료통의 지속 잔불을 추가하지 않는다.
- 로켓은 전달된3D direction을 정규화하고0벡터일 때 방사형으로 생성한다. 초기 화염은 폭발 원점에 두며, 떨어지는 파편의 하한만 `floorY-at.Y+0.06`으로 제한해 공중 폭발을 바닥으로 옮기지 않는다.
- 실제 보스 내려찍기 예고/플레이어/HUD의 고정 장면에서 영역 효과1/6/12개를 겹친다. 기준 화면 대비 RGB변화 면적은 점유율 보조치이며 GPU overdraw나 가독성 점수가 아니다. 낮은 렌더 비용 조건(scale0.67/MSAA 없음)은 같은 GPU의 검수이고 제품 품질 메뉴/실제 저사양 장비가 아니다. [가독성 근거](features/effects-audio/log/010-check-area-readability.md).
- 최신 통합 검사/렌더와 남은 제약은 [012 기록](features/effects-audio/log/012-check-effects-rollout.md)을 따른다. 기존 역사적 성능값을 최신값으로 대체 해석하지 않는다.

### 피해 반경의 시각 보정

- 최신 보정은 [013 기록](features/effects-audio/log/013-art-damage-reach.md)을 따른다. 모든 blast와 fire_impact에 `BurstReachVisual`을 붙인다. 실제 전달된R의0.72~0.79 위치에 외곽16카드,0.2~0.48 위치에 내부8카드를 배치한다. 기본 카드 전체 너비는 외곽0.66~0.74R/내부0.75~0.95R, 투명 가장자리를 포함해 실제 반경 근처까지 위협으로 읽히도록 렌더로 조정한 값이다. lobes0이면 범위 카드를 만들지 않는다.
- 최대0.07초(duration의12%와 작은 값)에 중앙에서 확산, 최대0.48초(duration의70%와 작은 값) 이내 개별 소멸. 최고 재질알파0.48. 지면 그림/연속 원 선을 추가하지 않고 중앙도 채워 고리 형태를 피한다. 부모 시계/수명/동시폭발 제한을 그대로 따른다.
- 로켓 중심 덩어리의 방향 강조는0.65R→0.25R로 줄인다. 실제 피해는 전방 부채꼴이 아닌3D 방사형이며 전 방향 범위층은 방향값에 영향받지 않는다. 일반 대상 R과 드럼통 연쇄/소품의 기존1.4R 상호작용은 구분한다.
- 지속 불꽃 뿌리는 기존기본0.77R→0.94R로 확장한다. spread는 장식 연기/불티를 계속 조정한다. 독은 기존 약0.98R 지면 표시를 유지하며 시각 전용 연무에는 피해 판정을 추가하지 않는다. 초기 불꽃 점화 시간은 유지하므로 착탄 입자가 끝난 뒤 외곽 불꽃이 다 켜지기 전의 가시성 차이는 남는다.
- 검사에서는 실제 Blast의0.95R 안 앞/뒤 표적과1.05R 밖 표적, 사방 입자와 실제 렌더를 확인한다. 검사용 흰 점은 일반 판정반경R의 표식으로 게임 효과에는 없다. 부드러운 알파/카메라 투영 때문에 픽셀 단위 정확한 판정선이나 벽/단차 우회 표시를 뜻하지 않는다.

### 성능과 남은 제약

최종 `CombatEffectsPerformance`는 RTX5070Ti, Vulkan Forward+, **1600×900**, VSync/프레임 제한 해제. 같은 Stage 2 숲 카메라와 고정된 적20개, 각각6초 중 초기1.5초 제외. 기본→지속 위험6개+초당 폭발10개: 평균 **1.86→2.81ms**, p95 **2.38→3.30ms**, draw calls 약 **861→1,242**. `game/output/vfx-performance.json/log`. 이 값은 현재 장면의 렌더 부하 표본이며 AI/네트워크·저사양·6인/장시간·GPU 단독 처리시간 측정이 아니다. `process_ms` 모니터는 프레임 간격과 측정 구간 의미가 달라 성능 판정에 사용하지 않는다. 초기1600×1000 측정은 투명도 수정 전 자료이므로 최종 수치와 직접 비교하지 않는다.

전용 가속 헤드리스 종료 ObjectDB37개는 AudioStreamWAV7/Playback30, 파괴 상세 재실행25개는 WAV5/Playback20으로 식별했다. 앞선 전용42·파괴23·통합2 경고는 별도 실행이다. 최종 창·부하 렌더는 종료 경고 없음. **I-17 미해결**이며 테스트 통과를 메모리 안전 입증으로 표현하지 않는다. 실제2PC·저사양·장시간 검수, 지형에 밀착 투영하는 데칼은 미실행/범위 밖. 기존 FireZone 바닥 높이 계약을 유지하며 피해 판정은 개편하지 않았다.

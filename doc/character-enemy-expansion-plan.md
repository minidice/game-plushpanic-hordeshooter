# 캐릭터·장비·적 확장 — 2026-10-19

## 현재 확인
- 실제 대상은 `game/` Godot 4.7.2 C# + Jolt 프로젝트다. `prototypes/goose-playtest`는 이전 검증본이다.
- 캐릭터 리소스 카탈로그, 모델 부착점, 데이터 기반 무기/몬스터, 캠페인 1개, 풍선형·돌진형 특수 적이 있다.
- 회피가 캐릭터 전체를 한 바퀴 회전시키며, 얼굴/장비가 붙은 일체형 체형에서 부자연스럽다.
- 모델 교체 규격은 존재하지만, 실제 동물 GLB는 거위뿐이고 색상/장비 커스터마이징은 없다.

## 이번 적용 범위
1. 거위·오리·라쿤·랫서판다 플레이 모델. 종별 얼굴/꼬리를 유지하고 몸·부리/포인트·모자·조끼·배낭의 색과 착용을 메뉴에서 선택, 종별 설정 저장.
2. 모자 없음/전투모/베레모, 조끼/배낭 표시 선택. 첫 버전은 장비 외형만 변경하며 방어력 차이는 없다.
3. 회피 입력·쿨다운·벽 충돌은 유지하되 360도 회전을 제거. 몸을 낮추고 앞쪽 팔다리를 뻗는 짧은 도약으로 교체. 조류는 날개를 뻗는 같은 동작을 사용한다. 발 4개를 새로 달지 않는다.
4. 기존 총기 데이터/발사 시스템을 유지하며 교체 가능한 별도 GLB 총기 모델을 제작하고 연결한다. 총구 기준점 +Z와 손 위치 규격 유지.
5. 일반 인간형 감염체, 낮게 기어오는 감염체, 끌어당기는 특수 적, 도약해 붙잡는 특수 적, 토사물 원거리 적. 공격 전조·시야 차폐·붙잡기 해제·적 사망 시 정리·플레이어 사망 시 정리 포함.
6. 좀비/야생 동물/무장 동물의 세 가지 조우 테마를 데이터로 분리한다. 기존 1개 스테이지에서 테마별 적 구성을 검증하며, 서로 다른 완성 캠페인 3개를 만드는 범위는 아니다.

## 구속 규칙과 임시 탈출
정식 규칙은 동료 구조가 필요하고 일반 입력/시간 경과로 자력 탈출할 수 없다. 현재 동료 AI/멀티플레이가 없어 사용자 요청에 따라 메뉴에서 켜고 끄는 F8 테스트 치트를 기본 활성화한다. F8은 즉시 해제하고 붙잡은 적을 2초 기절시킨다. 향후 기본값을 false로 변경한다. 적 처치/기절과 벽에 끊긴 구속 연결도 해제 사유다.

## 구현 경계
- 모델 생성/최적화: 독립 생성 도구, 공통 동작 기준점, 색상 채널용 머티리얼 이름. 기존 비교실 코드는 보존.
- 외형: 인스턴스별 머티리얼 복제, 플레이어 설정이 다른 종/적/공유 리소스를 바꾸지 않게 한다.
- 상태: 생존/회피/기절/구속/사망의 우선순위를 명확히 한다. 구속 중 회피·사격·상호작용을 제한하고 해제 후 복구한다.
- 총기: 외형만 교체하고 무기 능력치는 기존 CSV를 따른다.
- 스테이지: 외형 테마와 공격 행동을 분리하되, 무장 동물의 원거리 공격은 전조와 엄폐 차폐를 갖춘다.

## 검증
- 기존 전체 엔진 검사와 빌드 유지.
- 4종 GLB 필수 부품/색상 채널/모델 크기 검사.
- 외형 설정 저장·복원, 공유 재질 오염 방지, 장비 숨김/교체.
- 도약 중 360도 회전 없음, 착지 후 변환 복구, 기존 충돌/쿨다운 검사.
- 특수 적 공격 전조/벽 차폐/구속과 해제/사망 및 씬 정리 검사.
- 테마별 생성 목록과 새 총기 모델 로드 검사.
- Godot 실제 렌더로 메뉴, 4종, 도약, 적 모델을 확인.

## 제한
아트의 첫 게임 적용본이며 최종 수작업 조형/텍스처 베이킹/LOD/4인 네트워크 동기화는 별도 단계다. 물리 사망은 캡슐 강체와 시각적 변형을 유지한다.

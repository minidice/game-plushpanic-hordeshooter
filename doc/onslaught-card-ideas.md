# 난전 카드 아이디어 풀 (M-27)

> **상태: 브레인스토밍 (2026-10-21).** 아무것도 확정되지 않았다. 카드 규칙(일반 · 특별, 대상, 쌓기, 창)은 [난전 카드 · 소환수 계획](onslaught-cards-plan.md)에 있고, 이 문서는 **카드 효과 후보**만 모은다.
> 사용자 요청: 신선하고 **우스꽝스러운** 효과, **시너지**가 나는 것, **다양**한 것. 수치는 모두 가안이다.

## 1. 만드는 기준

**우스꽝스러움 다섯 가지**
1. **화면에서 바로 보인다**: 적이 부풀고, 뒤집히고, 날아가고, 달라붙는다. 숫자만 바뀌는 카드는 기본 수치 카드로만 둔다.
2. **물리가 예상 못 한 연쇄를 만든다**: 넉백 · 시체 · 굴러가는 인형. 우리 게임은 넉백이 무게로 나뉘고 시체가 남는다(T-21).
3. **소리 개그**: 거위의 꽥(지금 피격 비명 `honk`), 고무오리 삑삑, 헬륨 목소리.
4. **귀여운 파괴(큐트 고어)**: 피 대신 솜 · 단추 · 페인트.
5. **대가도 웃기게**: 머리가 커진다, 총이 뒤로도 나간다.

**시너지 장치 — "상태를 만드는 카드 / 상태를 쓰는 카드"**
카드는 적이나 바닥에 **상태**를 남기거나(만듦), 어떤 상태인 적에게 추가 효과를 낸다(씀). 한 카드가 만든 상태를 다른 카드가 쓰면 시너지가 저절로 생긴다. 새 카드를 만들 때 **만드는 상태와 쓰는 상태를 하나 이상** 적게 해서, 외톨이 카드를 줄인다.

| 상태 | 뜻 | 겉모습 |
|---|---|---|
| **불붙음** | 짧은 도트, 닿으면 번짐 | 그을린 솜 · 불꽃 |
| **슬라임** | 긴 도트, 중첩 | 초록 페인트 |
| **꽁꽁** | 느려짐 → 얼음(멈춤) | 푸른 서리 |
| **둥실** | 헬륨으로 떠오름, 아무것도 못 함 | 몸이 부풀어 뜸 |
| **꼬마** | 작아짐: 약하고 빠름, 밟힘 | 반 크기 |
| **왕** | 커짐: 느리고 맞히기 쉬움, 다른 적을 막음 | 두 배 크기 |
| **데굴** | 뒤집혀 구르는 인형, 부딪힌 적을 넘어뜨림 | 팔다리가 늘어진 인형 |
| **찍찍이** | 맞은 적끼리 달라붙어 덩어리 | 벨크로 줄무늬 |
| **반짝** | 빛나서 팀 모두에게 보임 | 몸이 빛남 |
| **어질** | 혼란: 아무 데나 걷고 아무나 침 | 머리 위 별 · 양말 씌움 |
| **기절** | 잠깐 아무것도 못 함 | 머리 위 새 · 땅에 박힘 |
| **날아감** | 넉백으로 나는 중 | 솜 꼬리 |
| **솜 더미** | 시체(바닥에 남음) | 솜 · 단추 |
| **미끼** | 소리를 내는 물건, 적이 모임 | 고무오리 · 깡통 |
| **페인트 바닥** | 바닥에 칠한 색 | 색 웅덩이 |

**다양성 장치 — 발동 시점을 고르게**
같은 "맞으면 ~" 카드만 쌓이지 않도록, 카드마다 **발동 시점**을 하나 정하고 아래 칸이 고르게 차게 만든다.

| 발동 | 예 |
|---|---|
| 맞힐 때 | 풍선탄, 축소탄 |
| 처치할 때 | 솜 폭발, 풍선 승천 |
| 장전할 때 | 꽥 장전, 탄창 던지기 |
| 도약할 때 · 착지할 때 | 착지 쿵, 솜 트램펄린 |
| 맞을 때 · 쓰러질 때 | 비상 풍선, 솜 갑옷 |
| 시간마다 | 인형 뽑기 손, 디스코 드론 |
| 멈춰 있을 때 · 달릴 때 | 롤러스케이트, 둥지 |
| 팀원 · 소환수 가까이 | 하이파이브, 합창 |

## 2. 카드 후보

표의 "만듦 → 씀"은 1장의 상태 이름이다. 태그는 시너지 · 태그 보너스용.

### 2.1 적을 웃기게 바꾸기

| 카드 | 하는 일 | 만듦 → 씀 |
|---|---|---|
| **풍선탄** | 맞을수록 적이 부풀다 일정 이상이면 **둥실** 떠오름. 떠 있는 적을 쏘면 펑, 주변 넉백 | 둥실 → 날아감 |
| **축소광선** | 맞은 적이 **꼬마**가 됨. 꼬마는 도약 착지로 밟아 바로 처치 | 꼬마 |
| **왕 저주** | 가끔 적 하나가 **왕**이 됨. 느리고 길을 막아 다른 적이 뒤에서 줄을 섬. 왕 처치 시 솜 폭포 | 왕 → 솜 더미 |
| **헝겊 인형화** | 처치 대신 가끔 적이 **데굴** 인형이 되어 굴러가며 볼링 | 데굴 |
| **찍찍이탄** | 맞은 적끼리 달라붙어 **찍찍이** 덩어리. 덩어리가 클수록 느리고, 다섯 마리가 붙으면 한 덩어리로 펑 | 찍찍이 |
| **양말 씌우기** | 맞은 적 머리에 양말. **어질**: 시야를 잃고 옆 적을 때림 | 어질 |
| **태엽 장난감** | 맞은 적이 태엽 인형이 되어 마지막으로 걷던 방향으로만 직진(벽에 부딪혀 넘어짐) | 데굴 |
| **뿅망치탄** | 위에서 맞은 듯 적이 땅에 박혀 머리만 나옴(기절). 다시 맞히면 "두더지 잡기" 치명타 | 기절 |
| **간지럼탄** | 적이 웃느라 멈춤. 웃음이 옆 적에게 옮음 | 어질 |
| **고깔모자** | 맞은 적에게 생일 고깔. 고깔 쓴 적을 처치하면 폭죽 · 색종이 · 작은 폭발 | 처치 시 폭발 |

### 2.2 시체(솜 더미)로 장난치기

| 카드 | 하는 일 | 만듦 → 씀 |
|---|---|---|
| **솜 폭발** | 처치하면 솜이 터져 주변을 밀어냄 | 날아감 |
| **솜 눈사람** | 넉백 된 시체가 굴러가며 다른 시체를 붙여 커지는 솜 눈덩이 | 솜 더미 → 데굴 |
| **솜 트램펄린** | 솜 더미 위에서 도약하면 두 배 높이, 착지 충격파 | 솜 더미 |
| **다시 꿰매기** | 시체 일부가 잠깐 **내 편 꼬마 인형**으로 일어나 싸우다 다시 쓰러짐 | 솜 더미 → 소환수 |
| **솜 비** | 처치할 때 솜이 하늘로 솟았다가 내려와 맞은 적을 느리게 | 꽁꽁(약하게) |
| **단추 지뢰** | 시체에서 단추가 튀어나와 바닥에 남음. 밟은 적이 미끄러져 데굴 | 데굴 |
| **바느질 회복** | 솜 더미 근처를 지나가면 체력 조금(나 · 소환수) | 솜 더미 |

### 2.3 소리 · 꽥 (거위의 정체성)

| 카드 | 하는 일 | 만듦 → 씀 |
|---|---|---|
| **꽥 장전** | 장전할 때 크게 꽥, 주변 적 넉백(거위가 아니면 그 종의 울음) | 날아감 |
| **메아리** | 꽥 · 폭발 소리가 나무 · 기둥에 부딪혀 한 번 더 충격파 | 날아감 |
| **고무오리 미끼** | 총알 일부가 땅에 고무오리를 남김. 삑삑 소리로 적이 모임. 오리를 쏘면 폭발 | 미끼 |
| **깡통 차기** | 도약할 때 발밑에서 깡통이 굴러 나가 소리를 내며 적을 유인 | 미끼 |
| **헬륨 목소리** | 둥실이나 헬륨 맞은 적은 공격력이 줄고 목소리가 높아짐(피격음 피치 ↑) | 둥실 → 약화 |
| **합창** | 소환수와 동시에 꽥하면(장전 · 도약 겹침) 큰 충격파 | 소환수 |

### 2.4 넉백 · 물리 장난

| 카드 | 하는 일 | 만듦 → 씀 |
|---|---|---|
| **당구** | 날아가던 적이 다른 적에 부딪히면 그 적이 같은 힘으로 날아감(연쇄) | 날아감 → 날아감 |
| **범퍼** | 나무 · 기둥이 핀볼 범퍼가 됨: 부딪힌 적이 더 빠르게 튕김 | 날아감 |
| **자석탄** | 맞은 적이 다음에 맞은 적에게 끌려가 쾅 | 날아감 |
| **고무줄** | 넉백 된 적이 원래 자리로 되튕겨 오며 길 위의 적과 충돌 | 날아감 |
| **볼링공 탄** | 총알이 땅에 떨어져 굴러가는 볼링공이 됨(느리지만 묵직) | 데굴 |
| **반동 비행** | 사격 반동이 아주 커져 내가 날아감. 뒤로 쏘면 이동기, 날아가며 부딪힌 적은 넘어짐 | 날아감 |
| **무거운 엉덩이** | 도약 착지 때 쿵, 주변 적이 뒤집혀 데굴 | 데굴 |

### 2.5 헬륨 · 풍선

| 카드 | 하는 일 | 만듦 → 씀 |
|---|---|---|
| **풍선 승천** | 처치한 적에 풍선이 달려 하늘로. 올라가는 동안 아래로 솜 폭탄을 떨어뜨림 | 둥실 |
| **비상 풍선** | 체력이 낮아지면 풍선이 붙어 2초 떠올라 무적(한 판에 몇 번) | — |
| **풍선 가게** | 시간마다 내 주변에 풍선이 생김. 쏘면 터지며 헬륨 구름 | 둥실 |
| **풍선 묶기** | 둥실 상태 적끼리 줄로 묶여 같이 떠다님 → 하나를 터뜨리면 줄줄이 | 둥실 → 찍찍이 |

### 2.6 빛 · 어둠

| 카드 | 하는 일 | 만듦 → 씀 |
|---|---|---|
| **조명탄환** | 맞은 적이 **반짝**, 반짝 적에게 치명타 + | 반짝 |
| **반딧불 탄피** | 탄피가 바닥에서 잠깐 빛남. 빛 위의 적은 반짝 | 반짝 |
| **그림자 인형극** | 조명을 받은 적의 그림자가 일어나 그 적을 때림 | 반짝 → 피해 |
| **디스코볼** (드론) | 드론이 디스코볼이 되어 빛을 돌림. 빛 맞은 적이 춤추며 멈춤 | 어질 |

### 2.7 장전 · 탄창 장난

| 카드 | 하는 일 | 만듦 → 씀 |
|---|---|---|
| **탄창 던지기** | 장전할 때 빈 탄창을 던짐. 맞은 적 기절 | 기절 |
| **총 던지기** | 장전 대신 총을 던져 폭발시키고 새 총이 손에 생김(장전 시간 0, 남은 탄 수만큼 폭발) | 날아감 |
| **룰렛 탄창** | 탄창마다 무작위 탄: 불 · 슬라임 · 꽁꽁 · 풍선 · 찍찍이 중 하나 | 무작위 |
| **탄피 비** | 탄피가 많이 튀어 바닥에 깔림. 밟은 적이 미끄러져 데굴 | 데굴 |
| **마지막 한 발** | 탄창의 마지막 발은 거대한 탄(크기 3배) | 날아감 |
| **페인트 탄창** | 장전할 때 발밑에 페인트 웅덩이. 내 색 위의 팀원은 장전 빠름, 적은 미끄러움 | 페인트 바닥 |

### 2.8 이동 · 도약 · 나

| 카드 | 하는 일 | 만듦 → 씀 |
|---|---|---|
| **롤러스케이트** | 빠르지만 멈추기 힘듦. 부딪힌 적은 데굴 | 데굴 |
| **둥지** | 3초 멈춰 있으면 둥지를 틀어 받는 피해 감소, 둥지에서 알(작은 폭탄)이 굴러 나감 | — |
| **거대 머리** | 내 머리가 커짐: 치명타 확률 크게 +, 맞기 쉬움(대가) | — |
| **솜 갑옷** | 맞을 때마다 솜이 쌓여 몸이 동그래짐(보호막). 꽉 차면 솜 폭발 | 날아감 |
| **도약 불길** | 도약한 길에 불길 | 불붙음 |
| **엉덩이 썰매** | 도약 착지 후 미끄러지며 적을 넘어뜨림 | 데굴 |

### 2.9 소환수 장난 (드론 · 부사수 · 펫)

| 카드 | 대상 | 하는 일 |
|---|---|---|
| **물어오기** | 펫 | 적을 물어 와 내 앞에 내려놓음(선물). 놓인 적은 잠깐 기절 |
| **흉내쟁이** | 부사수 | 내가 장전하면 같이 장전, 내가 도약하면 같이 도약, 꽥도 따라함 |
| **고깔 배달** | 드론 | 드론이 적에게 고깔모자를 씌우고 다님(2.1 고깔모자) |
| **자리 바꾸기** | 모두 | 키 한 번으로 나와 소환수 위치 교환 |
| **꼬리 잡기** | 펫 | 펫 뒤로 적이 줄줄이 따라옴(미끼 역할). 펫이 돌면 줄이 휘둘림 |
| **부사수 낙하산** | 부사수 | 쓰러지면 솜이 터지는 대신 하늘로 날아갔다가 내 옆에 낙하산으로 내려옴(착지 충격파) |
| **등 무기 바꾸기** | 펫 | 등 무기를 물총(맞은 적이 꽁꽁에 잘 걸림) · 비눗방울(둥실) · 팝콘 기계(무작위 넉백)로 |
| **드론 우산** | 드론 | 내 머리 위에서 우산을 펴 투사체 한 발씩 막음 |

### 2.10 팀 (멀티)

| 카드 | 하는 일 |
|---|---|
| **하이파이브** | 팀원과 스치면 둘 다 장전 완료 + 짧은 속도 |
| **인간 대포** | 팀원에게 도약하면 팀원이 나를 조준점으로 던짐 |
| **줄넘기** | 두 사람 사이에 줄이 생겨 지나가는 적을 넘어뜨림 |
| **같이 꽥** | 팀원과 동시에 꽥(장전)하면 큰 충격파 |

### 2.11 웃긴 대가가 있는 카드 (강함 + 불편함)

| 카드 | 이득 | 대가 |
|---|---|---|
| **거꾸로 총** | 앞뒤로 동시에 발사 | 반동이 두 배로 흔들림 |
| **술 취한 탄** | 대미지 2배 | 탄이 구불구불 날아감 |
| **풍선 몸** | 이동 빠름, 낙하 없음 | 넉백을 아주 많이 받음 |
| **춤바람** | 쏘는 동안 빙글빙글 돌며 360° 사격 | 조준 불가 |
| **대왕 거위** | 몸이 커지고 체력 2배 | 맞기 쉽고 좁은 틈을 못 지나감 |

## 3. 시너지 연쇄 예시

카드 두세 장이 만나면 이렇게 된다. 조합 카드(금색)는 이 중 반응이 좋은 것을 이름 붙여 만든다.

| 조합 | 화면에서 일어나는 일 |
|---|---|
| 찍찍이탄 + 풍선탄 | 달라붙은 덩어리가 통째로 떠오름 → 쏘면 덩어리째 터지며 솜 비 |
| 축소광선 + 무거운 엉덩이 | 꼬마들 사이로 도약 → 착지 한 번에 꼬마 떼가 밟히고 뒤집힘 |
| 당구 + 범퍼 + 반동 비행 | 내가 날아가 부딪힌 적이 날아가고, 그 적이 나무에서 튕겨 또 다른 적을 날림 |
| 고무오리 미끼 + 도약 불길 | 오리 주변에 모인 적 위로 도약해 불길 → 불붙은 무리가 서로 번짐 |
| 솜 폭발 + 솜 눈사람 + 솜 트램펄린 | 시체가 굴러 커진 눈덩이 위에서 도약 → 높이 뛰어 착지 충격파 |
| 양말 씌우기 + 왕 저주 | 양말 쓴 왕이 어질해서 주변 적을 쓸어버림 |
| 꽥 장전 + 메아리 + 합창 | 장전할 때마다 나 · 소환수 · 메아리로 충격파 3번 |
| 룰렛 탄창 + 태그 보너스 | 탄창이 바뀔 때마다 다른 상태가 쌓여 상태 태그가 골고루 참 |
| 풍선 승천 + 고깔모자 | 고깔 쓴 적이 풍선에 매달려 올라가며 폭죽을 뿌림 |
| 탄피 비 + 롤러스케이트 | 바닥에 깔린 탄피 위를 미끄러지며 적을 줄줄이 넘어뜨림 |
| 펫 꼬리 잡기 + 찍찍이 | 펫 뒤로 줄 선 적들이 서로 붙어 한 줄 덩어리 → 펫이 돌면 철퇴처럼 휘둘림 |
| 조명탄환 + 그림자 인형극 + 디스코볼 | 반짝인 적의 그림자가 춤추며 그 적을 때림 |

## 4. 조심할 것

- **읽기 쉬움**: 4인 멀티에서 효과가 겹치면 적을 못 본다. 상태마다 색 · 실루엣을 하나씩 정하고(1장 표), 큰 효과(덩어리 · 눈덩이)는 반투명 처리.
- **성능**: 물리 연쇄(당구 · 데굴 · 눈덩이)는 동시에 움직이는 수에 상한. 시체 수는 지금 규칙(T-21)을 따른다.
- **멀티**: 연쇄 판정은 방장만 한다(M-9). 파티원은 결과(위치 · 상태)만 받는다.
- **조작을 빼앗지 않기**: 내 이동을 바꾸는 카드(반동 비행 · 롤러스케이트 · 춤바람)는 대가 카드로만, 한 판에 하나만 나오게.
- **20분 판**: 효과가 쌓여 화면이 너무 어지러우면 오른쪽 버프 줄에서 끄는 기능은 넣지 않는다(카드 선택이 곧 책임). 대신 상태 표시 크기를 줄이는 설정.

## 5. 먼저 시험할 묶음 (추천)

지금 있는 시스템(넉백 · 시체 · 헬륨 · 꽥 · 빛)으로 빨리 만들 수 있고, 서로 연쇄가 나는 12장:
풍선탄 · 찍찍이탄 · 축소광선 · 양말 씌우기 · 솜 폭발 · 솜 트램펄린 · 꽥 장전 · 고무오리 미끼 · 당구 · 범퍼 · 무거운 엉덩이 · 탄창 던지기.
이 묶음으로 "웃긴가 · 읽히는가 · 시너지가 보이는가"를 먼저 본 뒤 나머지를 늘린다.

## 6. 카드 실험실 1차 (2026-10-21, T-22)

`Start-Game.ps1 -CardLab`(장면 `tests/CardLab.tscn`): 난전 들판에서 무적 · 무제한 탄으로 카드를 켜고 끄며 놀아 본다. 키는 F1~F6 카드, 0 전부 켜기/끄기, F7 일반 몹 무리, F8 네임드(황소 · 정예병 · 풍선 차례로), F9 계속 나오기, F10 느리게, F11/F12 1·2번 총 바꾸기(`weapon_pool`), Backspace 몹 지우기. 시작 총은 M4 · 레밍턴 870. **Home = 치트 초기화**(프라이팬만 남기고 1 · 2 · 3번 칸을 정하는 카드 창이 차례로 뜸), **L = 시험용 레벨업 카드**(꺼져 있는 실험실 카드 3장), **F = 미룬 카드 열기/닫기**.

| 키 | 카드 | 지금 수치 (`LabCards.cs`) |
|---|---|---|
| F1 | 풍선탄 | 명중마다 부풂 0.12 + 대미지/250, 다 차면 4초 둥실(높이 0.55 m). 떠 있는 적을 맞히면 펑: 반경 3 m, 넉백 110, 대미지 20 |
| F2 | 찍찍이탄 | 맞으면 6초 찍찍이. 찍찍이끼리 몸 + 0.6 m 안이면 한 덩어리: 가운데로 끌림, 걸음 35%, **넉백을 나눠 같이 움직임**. 5마리면 터짐: 반경 3.2 m, 넉백 140, 대미지 35 |
| F3 | 솜 폭발 | 처치마다 반경 2.6 m, 넉백 95, 대미지 6 (한 프레임 8번까지) |

| F5 | 꽥 장전 | 장전을 시작할 때 꽥: 반경 3.5 m, 넉백 130, 대미지 5 |
| F6 | 고무오리 미끼 | 명중 10번마다 오리(미끼)가 떨어져 3.5초 동안 반경 12 m의 일반 몹을 모은 뒤 펑(반경 3.2 m, 대미지 40, 넉백 130) |

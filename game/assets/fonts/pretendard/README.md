# Pretendard v1.3.9

Unmodified static OTF files from the author's release:
https://github.com/orioncactus/pretendard/releases/tag/v1.3.9

Archive: `Pretendard-1.3.9.zip`, entries `public/static/Pretendard-{Regular,Bold,ExtraBold}.otf`.
License: `LICENSE.txt` copied verbatim from that archive (SIL Open Font License 1.1).
The export preset includes this notice/license file in the game package. `Export-Game.ps1` also copies it
beside the executable under `licenses/pretendard/` so players can read it without unpacking the PCK.

# 순록·인간형 감염체 조형 후속

사용자 요청: 순록과 좀비를 현재 동물 개선 흐름으로 진행하고 순록의 뿔 특징을 살린다. 기존 사용자 승인 `doc/character-art-direction.md`, A-25/C-31과 인간형 감염체·10개 일상복 계약을 따른다.

## 설계

순록은 매끈한 몸/머리와 길게 이어지는 주둥이, 작은 눈, 귀와 분리된 가지 뿔, 얇고 평평한 갈라진 발굽을 만든다. 끝이 좁아지고 가지 사이 공간이 읽히는 뿔을 주된 실루엣으로 삼는다. 조끼는 몸을 감싸는 구조와 사각 파우치로 맞춘다. 공통 눈썹 10조합을 새 얼굴 위치에 연결한다.

좀비는 기존 인간형 감염체 원본을 출발점으로 머리/턱·눈·손발과 옷의 연결을 다듬는다. 부푼 피부 패치·몸의 봉제선·큰 유리 눈을 피하고 절제된 비대칭/피부색과 낡은 일상복으로 감염체를 읽히게 한다. 무기/스킬/눈 장구류를 추가하지 않고 기존10복장·무늬 모듈/팔레트 계약을 유지한다.

## 작업과 검증

1. Blender 생성기에서 두 종만 수정·내보내기. 이전 GLB 보관과 같은 카메라의 실루엣/단색/최종색 전후 렌더, 독립 재가져오기/피벗/삼각형/모듈/접지 검사. 다른5종 해시 보존. 모델 담당은 생성기·검사/비교 도구·2GLB를 소유한다.
2. 부모 작업은 순록 눈썹 부착/스키마/Studio 검사 연결, 실제 게임 회귀 및 새 두 종 검수 장면을 담당한다. 종·무장·일상복의 실제 초기화에서 얼굴/손/복장 가림과 머리 최대 움직임을 확인한다. 모델 담당과 부착 기준점을 공유한다.
3. Studio에서 순록6무기/4색 및 좀비10복장, 실제 게임 이동/공격과 맵 조명 렌더 확인. 전용 검사·일반/네트워크 검증·빌드, 독립 검토를 마친다. decisions/issues/checklist/세부 문서에 실행 증거·한계를 기록한다.

전투·충돌/속도·생성 정체성은 변경하지 않는다. 머리 진폭은 실제 접합부 스트레스 검수로 필요할 때만 시각 설정으로 줄인다. 이번에는 커밋/푸시하지 않는다. 장시간/저사양 성능·실제2PC·모든 경사면 발 IK는 완료 범위에 포함하지 않는다.

# 기본 방탄형 후보 04

2026-10-23. 사용자가 승인한 추천안: 복장 종류를 늘리기 전에 기본 방탄형 한 벌의 큰 면·두께·재질을 정리하고, 같은 모델을 중립 조명과 게임 분위기에 가까운 조명에서 비교한다. 기존 게임과 후보 01~03은 보존했다.

## 조형과 재질

- 조끼 앞뒤는 몸의 모든 굴곡을 따라가는 대신 넓고 비교적 평평한 면으로 정리했다. 몸을 뚫지 않는 공통 여유값을 측정해 표면 전체에 적용했다.
- 일정한 높이의 통 모양 목둘레를 낮은 앞목과 기울어진 어깨로 바꿨다. 원형 팔 구멍은 날개 위치에 맞춰 기울이고 아래쪽을 조금 더 평평하게 재단했다. 옆구리와 등판의 연결은 유지했다.
- 둥근 테두리를 얇은 평면 바인딩으로 교체했다. 돌출 파우치와 작은 웨빙 격자는 이번 기본 방탄형에서 제외하고 넓은 가로 띠 3줄로 구성했다. 이전 파우치형은 후보 03에 보존돼 있다.
- 조끼는 어두운 청회색 무광 천, 띠는 절제된 회녹색, 테두리는 짙은 색으로 구분했다. 헬멧은 녹색 도장 표면으로 바꾸고 천보다 반사를 높였다. 헬멧·배낭·몸의 형상은 보존했다.
- 새 재질은 표준 glTF PBR이다. 조끼 roughness 0.91, 띠 0.90, 바인딩 0.94, 헬멧 0.46/metallic 0.05. 재질 수치는 제작 선택이며 실제 물성 측정값이 아니다. 이번 후보에는 새 텍스처나 노멀맵을 만들지 않았다.

몸·얼굴·발·날개의 외형은 바꾸지 않았다. 작은 렌더에서의 개선은 복장·헬멧 재질과 조명에 의한 것이며 체형 개선으로 표현하지 않는다.

## 측정과 검증

| 대상 | 후보 03 | 후보 04 |
|---|---:|---:|
| 조끼 삼각형 | 15,644 | 7,068 |
| 캐릭터 전체 삼각형 | 37,122 | 28,546 |
| 조끼 메시 / 재질 | 1 / 3 | 1 / 3 |

조끼 삼각형은 **54.8% 감소**했다. 캐릭터 전체는 메시 14개, 재질 슬롯을 기준으로 구별한 재질 20개다. 폴리곤 감소와 실제 게임 성능 향상은 같은 검증이 아니며 LOD·드로콜·멀티 성능 측정은 별도다.

최종 GLB 두 개 재가져오기와 형상·재질·보존 검사 **50개 통과**. [검사 결과](output/refined-armor/validation.json).

- 보호 파일 6개의 SHA-256 유지: 기존 게임 거위 GLB, 후보 01 Blender·GLB, 후보 02 Blender, 후보 03 Blender·GLB.
- 몸 등 기존 메시 11개와 헬멧·배낭의 정점·면 보존, 복제 시 세계 변환 오차 0.000001 미만. 헬멧 재질 변경은 새 후보의 독립 슬롯에만 적용.
- 내보낸 메시·삼각형 수와 축·경계 확인, 면적 0인 면 없음, 조끼 분리와 부착점·Muzzle 유지.
- 기본 크기 몸통과 조끼의 삼각형 표면 교차 없음. 원래 날개의 기본 / 앞 20° / 뒤 15° / 바깥 20° / 앞 20°+바깥 15°를 양쪽에 검사해 총 10개 자세에서 조끼와 표면 교차 없음.
- 헬멧·조끼 roughness가 GLB 재가져오기 후에도 일치. 조끼 삼각형 8,000 미만 및 후보 03보다 감소 확인.
- 최종 2×2 조명 비교, 전체 방향 모음, 작은 화면 비교를 직접 열어 목둘레·팔 구멍·큰 면·반사 차이와 표제 배치를 확인했다.

제작 중 원래 몸에 정점별로 밀착시키는 방식이 미세한 굴곡을 새 옷에 옮기는 것을 확인해, 전체에 공통 여유를 주는 규칙적인 곡면으로 바꿨다. 팔 구멍 끝에는 정확한 경계 샘플을 추가했다. 가느다란 옆선의 면적 0인 면은 각도 폭을 가진 실제 띠로 재작성해 해결했다. 최종 검사는 이 수정 후 재실행했다.

## 재현과 남은 범위

저장소 루트에서 실행한다. 입력은 후보 03 Blender 원본이며 이전 생성기는 수정하지 않았다.

```powershell
& 'C:/Util/Blender Foundation/Blender 5.2/blender.exe' --background --python-exit-code 1 --python prototypes/grounded-art/tools/build_refined_armor.py
& 'C:/Util/Blender Foundation/Blender 5.2/blender.exe' --background --python-exit-code 1 --python prototypes/grounded-art/tools/validate_refined_armor.py
python prototypes/grounded-art/tools/compare_refined_armor.py
```

생성 명령에 `-- --preview`를 추가하면 새 후보의 두 조명 사선만 렌더한다. 전체 비교판 재생성에는 전체 실행이 필요하다. 비교 도구는 기존 Pillow 의존성을 사용한다.

게임은 무기를 들 때 원래 날개를 별도 팔로 교체하므로 위 자세 검사는 실제 무기·장전·달리기의 무간섭 보장이 아니다. Godot 가져오기, 무기용 팔, 체형 슬라이더, 다른 종, 피격·사망, 멀티·성능은 검증하지 않았다. 새 재질을 게임 외형 색 채널에 연결하는 작업도 별도다.

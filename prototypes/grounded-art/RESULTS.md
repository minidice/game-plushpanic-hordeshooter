# 거위 군장 후보 01 — 제작 기록

날짜: 2026-10-22. 상태: **독립 모델 검토용 후보, 게임 미적용**.

## 제작 내용

- 거위 몸·얼굴·부리·눈·눈썹·날개·발·꼬리의 기존 메시 11개를 유지했다. 비교 시 기본 헬멧·조끼·배낭만 착용하고 양쪽 모두 선택형 베레모·머리털·고글·헤드셋·패딩 조끼·내장 총은 제외했다.
- 헬멧: 좁아진 외곽, 매끈한 돔, 얇은 고무 테두리, 작은 전면 마운트·측면 레일. 과장된 흠집과 큰 장식은 새 후보에 넣지 않았다.
- 조끼: 아래쪽을 두르는 기존형을 앞뒤 가슴판·어깨끈·옆 고정끈으로 변경했다. 탄창 파우치 두 개, 작은 조절 버클, 웨빙을 추가했다.
- 배낭: 등판 패드·어깨 연결·손잡이·지퍼·압축끈·옆주머니를 분리된 형태로 제작했다. 옆주머니 포함 폭 약 0.620 → 0.554 m, 몸 뒤쪽 최대 좌표 약 0.701 → 0.654 m(Blender Y)로 줄였다. 값은 이 후보의 제작 수치이며 게임 규칙 확정값이 아니다.
- 천·웨빙·헬멧·고무·금속을 표준 glTF PBR 재질로 구분했다. 절차적 셰이더 전용 효과 없이 내보낸다.

## 렌더 비교 조건

사선·정면·측면·후면·후면 사선·상단 시점 작은 크기, 총 여섯 시점에 대해 기존형과 후보를 같은 원점에 **각각** 렌더한다. 두 모델을 조명에서 서로 다른 거리에 놓는 비교가 아니다. 카메라·조명·색 관리·렌더 샘플·원래 몸 재질은 동일하다.

Blender 5.2.2 LTS / Cycles 32 samples / denoise / AgX Medium High Contrast. 일반 렌더는 900×1050, 작은 크기 렌더는 900×600. 비교판은 기존형 왼쪽, 후보 오른쪽이다. 이미지 합성 도구는 실제 렌더를 배치·축소하고 표제를 넣으며 모델을 다시 그리거나 보정하지 않는다.

원본 GLB의 재질·정점색을 이용한 Blender 비교다. **Godot의 현재 커스터마이징 설정·런타임 몸 셰이더·조명과 같은 결과라고 주장하지 않는다.** 작은 크기 이미지는 상단 시점에서의 읽힘 확인이며 실제 게임 화면이나 지정 해상도에서의 정확한 픽셀 크기 재현이 아니다.

## 측정값

| 대상 | 삼각형 | 메시 오브젝트 | 사용 재질 |
|---|---:|---:|---:|
| 기존 거위 + 기본 군장 | 20,975 | 14 | 27 |
| 후보 거위 + 새 군장 | 26,914 | 14 | 19 |
| 새 군장만 | 11,716 | 3 | 7 |
| 새 헬멧 | 4,340 | 1 | 4 |
| 새 조끼·파우치 | 5,436 | 1 | 4 |
| 새 배낭 | 1,940 | 1 | 4 |

부품별 재질은 서로 공유하므로 합산하지 않는다. 메시 오브젝트 3개가 드로콜 3회를 의미하지 않는다. 기존보다 총 삼각형은 증가했으며 아직 런타임 최적화·LOD·6인 성능을 검증하지 않았다.

## 검증과 제작 중 수정

- 원본 게임 GLB SHA-256과 보존 복사본 일치, 생성 후 원본 해시 유지.
- 군장을 제외한 메시 11개는 원래 정점·면·세계 변환 해시와 일치.
- 최종 캐릭터 GLB와 군장 전용 GLB를 새 Blender 장면에 재가져와 **41개 검사 통과**: 원본 보존, 파일 로드, 스튜디오/뼈대 미포함, 연결 노드, 면적 0인 면 없음, 삼각형 수, 크기·축 오차 0.0001 m 미만, 몸·헬멧·배낭 부모 관계, Muzzle 유지, 군장만 내보내기.
- 최종 비교 모음과 사선 비교 PNG를 직접 열어 헬멧 형태, 조끼 착용 위치, 배낭 폭·돌출, 양쪽 카메라 구도와 표제를 확인했다. 생성·검사·비교 도구의 Python 구문 검사도 통과했다.
- 첫 실행은 비어 있는 Blender 장면의 World가 없어 렌더 초기화에서 실패했다. 자체 World 생성으로 수정했다. 이후 실행은 `--python-exit-code 1`을 사용해 Python 오류를 프로세스 실패로 반환한다.
- 첫 헬멧의 앞뒤 높이 차이가 정수리까지 적용돼 꼭대기가 뾰족하게 보였다. 가장자리 보정이 정수리에서 사라지도록 수정하고 다시 렌더했다.
- GLB 재가져오기 검사에서 얇은 버클·등판의 베벨이 두께 절반에 도달하며 퇴화면이 발생한 것을 확인했다. 베벨을 최소 두께의 40% 이하로 제한하고 재검사했다.
- 문서 작성 시 `doc/decisions.md`, `doc/issues.md`, 캐릭터 규격을 확인했다. 이 작업은 분리된 미적용 아트 후보이며 게임 기능·동작·제품 결정의 변경이 없어 기존 게임 문서의 이슈를 완료 처리하거나 새 제품 결정 ID를 발급하지 않았다.

## 재현

저장소 루트에서 PowerShell로 실행한다. 기존 생성기를 호출하지 않으며 출력은 이 폴더 내부다. 다른 AI가 게임 코드를 수정 중이어도 게임 빌드·가져오기는 필요 없다.

```powershell
& 'C:/Util/Blender Foundation/Blender 5.2/blender.exe' --background --python-exit-code 1 --python prototypes/grounded-art/tools/build_goose_kit.py
& 'C:/Util/Blender Foundation/Blender 5.2/blender.exe' --background --python-exit-code 1 --python prototypes/grounded-art/tools/validate_assets.py
python prototypes/grounded-art/tools/make_comparisons.py
```

비교판 작성 의존성: Python + Pillow 12.1.1(`tools/requirements-render.txt`), Windows 맑은 고딕. 이번 작업에서는 이미 설치된 도구를 사용했고 패키지를 설치하지 않았다. 생성기는 실행 시 기존 게임 GLB를 다시 복사하므로 이후 원본이 바뀌면 `manifest.json`의 입력 해시도 바뀐다.

## 통합 전 남은 확인

- 현재는 고정된 기본 자세. 총을 잡는 팔·장전·피격·사망·몸 크기 커스터마이징과의 간섭은 미검증.
- 기존 `goose_helmet`, `goose_vest`, `goose_pack` 부착점과 상위 노드를 유지했다. 그러나 베레모 등 비선택 옵션은 빈 피벗만 남기므로 전체 게임 자산의 즉시 대체품은 아니다.
- 후보의 trim·webbing·hardware는 공유 재질이다. 게임의 장비 색 변경 채널에 어떻게 연결할지 통합 시 결정해야 한다.
- Godot 가져오기·실제 렌더·멀티·성능 검사는 실행하지 않았다. 원본 게임 파일과 기존 생성기에는 쓰기 작업을 하지 않았다.
- 사용자 외형 승인 전의 첫 후보이며 이 모델로 모든 종의 최종 스타일이 확정되는 것은 아니다.

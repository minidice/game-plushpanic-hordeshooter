# 캐릭터 비교실

실제 Godot 게임은 [`../../game/Start-Game.cmd`](../../game/Start-Game.cmd)로 실행합니다. 이동·조준·사격·피격·물리 사망을 연결한 프로젝트이며, 이 비교실의 4종 비율 편집 기능은 그대로 유지합니다.

라쿤 / 랫서판다 / 오리 / 거위의 **일체형 체형·쿼터뷰 가독성·장비 가림·충돌 후 변형**을 판단하는 3D 비교 모델입니다. v0.3은 첫 아트 보정본으로, 몸 표면에 그린 얼굴 무늬·조형한 귀와 부리·곡면 조끼·파우치·고글·무기를 잡는 팔·재질별 반사와 스튜디오 조명을 추가했습니다. 사용자 참고 이미지의 목 경계 없는 콩 체형과 높은 시점/작은 화면 크기를 유지합니다. 최종 아트나 게임에 바로 넣는 완성 캐릭터가 아닙니다.

## 실행

`Start-Preview.ps1`을 PowerShell로 실행하거나 이 폴더에서 `npm start` 후 http://127.0.0.1:4173 을 엽니다. 인터넷 없이 실행되며, 첫 의존성 설치만 인터넷이 필요합니다. 폰트가 없어도 시스템 글꼴로 표시됩니다.

1. 캐릭터 카드를 선택합니다.
2. 윗부분 볼륨·몸체·꼬리·부리·상체 길이·헬멧·움직임을 조절합니다. 머리와 몸통은 하나의 연결된 표면이며, 종마다 별도 값으로 저장됩니다.
3. **장비 전후**로 선택한 종의 맨몸/장비 착용을 나란히 비교합니다.
4. **플레이 크기 · 기본**은 고도 55도, 확대 1배(세로 시야 18 단위)입니다. 캐릭터는 카드 화면 높이의 약 10%로 표시됩니다. 이는 이미지에서 추정한 시작점이며 실제 원본 카메라 수치를 복원한 것은 아닙니다.
5. **확대 · 쿼터뷰**는 35도/4.8배, **낮은 시점 · 체형**은 12도/6배이며 스튜디오 조명이 켜집니다. 기본 플레이 버튼은 지형 배경으로 돌아갑니다. 슬라이더로 5~70도, 1~6배 조절이 가능합니다.
6. 동작 메뉴에서 걷기 / 조준을 유지한 옆걸음 / 반동 / 넘어짐 / 눌림·공중 회전 / 물리·날리기 / 대기를 선택합니다.
7. **3D 모델 저장**은 현재 비율의 4종과 제작된 동작 5개를 GLB로 저장합니다. 장비 체크 상태가 내보내기에 적용됩니다. Rapier 물리 모드의 비행 기록은 GLB 애니메이션에 포함하지 않습니다.

**비율 저장 / 불러오기**는 JSON 설정을 보관합니다. 브라우저 자동 저장은 같은 주소/브라우저에서만 유지됩니다. 다른 브라우저나 PC로 옮길 때 JSON을 저장하세요.

## Blender 5.2

- `output/character-comparison.blend`: 일체형 모델 4종, 세 가지 카메라, 조명, 동작 5개. 저장된 기본 카메라는 `Gameplay_55deg_DEFAULT`입니다.
- `output/character-comparison.png`: 낮은 시점의 확대 렌더.
- `output/character-comparison-gameplay.png`: 기본 쿼터뷰/크기 렌더.
- `output/characters-base.glb`: 맨몸 4종 + 동일 무기 + 동작 5개.
- `output/characters-equipped.glb`: 헬멧·배낭·파우치 착용 4종 + 동작 5개.
- Blender의 **파일 → 가져오기 → glTF 2.0**에서 GLB를 직접 열 수 있습니다.
- `Build-Blender.ps1 -GlbPath "내보낸 파일.glb"`는 GLB를 카메라/조명/바닥이 있는 `.blend`로 변환하고 PNG도 렌더합니다. 결과는 `output/`에 생깁니다.
- 기존 설치 `C:\Util\Blender Foundation\Blender 5.2\blender.exe`를 사용합니다. MCP나 Blender 애드온 설치가 필요하지 않습니다.

Blender에서 `raccoon_root`, `redpanda_root`, `duck_root`, `goose_root`를 선택한 뒤 **오브젝트 속성 → 사용자 정의 속성**에서 전체 너비·높이와 일부 부품의 상대 크기를 조절할 수 있습니다. 원래 내보낸 모양에 대한 배율입니다. 일체형 몸체의 윗부분 볼륨이나 상체 프로파일 변경은 브라우저 편집기를 사용하세요. `head` 오브젝트는 별도 머리 메쉬가 아니라 얼굴 부착 기준점입니다.

Space로 기본 8방향 걷기를 재생합니다. 다른 동작은 NLA 트랙에서 원하는 트랙만 활성화해 확인할 수 있습니다. 프레임 속도 24fps, 걷기 192프레임입니다.

## 물리와 변형

`root → body → deform → torso → 몸체/얼굴/장비/손발` 구조입니다. 머리·몸통은 종마다 하나의 닫힌 메쉬이며 목 경계가 없습니다. 얼굴과 장비는 별도 파츠지만 모두 같은 변형 기준점을 따라 움직입니다.

**물리 · 날리기**는 Rapier 0.21.0의 중력·충격량·회전·마찰·반발·CCD를 사용합니다. 비율에 맞는 캡슐 충돌체 하나와 바닥만 시뮬레이션합니다. 고정 60Hz로 8초를 계산한 뒤 재생하며, 비율을 바꾸면 다시 계산합니다. 주변 돌/상자는 크기 비교용 장식으로 충돌체가 없습니다.

착지 충격에 따라 시각 파츠를 눌렀다가 복원합니다. 충돌체 자체는 변형하지 않아 불안정한 접촉을 줄입니다. 이것은 **강체 충돌 + 시각적 squash/stretch**이며, 살·천이 부분적으로 접히는 소프트바디나 찌그러진 형상을 사용하는 충돌 시뮬레이션은 아닙니다. 얼굴과 장비도 단순하게 함께 눌립니다.

GLB 루트의 `extras.physics`에는 캡슐 반지름·반높이·중심·질량 정보가 들어갑니다. Godot/Jolt 등에 통합할 때 엔진의 강체/충돌체를 별도로 생성해야 하며, 이 GLB를 불러오는 것만으로 게임 물리가 설정되지는 않습니다. 게임 엔진에서의 충돌/네트워크 검증은 아직 수행하지 않았습니다.

## 범위와 한계

- 연결된 몸체와 부착 파츠의 오브젝트 변환 애니메이션입니다. 스키닝/본/게임 이동 로직은 포함하지 않습니다.
- 걷기는 제자리 루프, 옆걸음은 제한된 좌우 이동입니다. 넘어짐은 물리 시뮬레이션이 아닌 과장된 포즈입니다.
- 머리와 헬멧 비율을 극단적으로 바꾸면 간섭이 생길 수 있습니다. 장비 전후 비교로 이를 확인하는 것이 목적입니다.
- 귀는 헬멧 착용 시 양옆으로 접힙니다. 실제 투구 구멍이나 장비 탈착 물리는 구현하지 않았습니다.
- 총구 섬광은 브라우저에서만 보입니다. GLB에는 반동 동작만 저장합니다.
- 종별 털 색은 캐릭터 정체성용입니다. 실제 4인 플레이 식별용 색상/이름표는 별도 설계가 필요합니다.
- 확대 검토를 위해 곡면과 부속품의 메시 밀도를 높였습니다. 다수 적을 표시하는 실제 게임용 LOD·메시 병합·텍스처 베이킹은 수행하지 않았습니다.

## 재생성·검증

`npm test` → 연속 몸체/법선·파라미터·모드 전환·스케일 애니메이션·물리 비행/착지/안정화·극단 비율 충돌 검사.

`npm run build` → 기본 GLB 두 개와 기본 비율 JSON 재생성.

`./Build-Blender.ps1` → 기존 Blender 5.2로 기본 장면 생성, PNG 렌더, `output/blender-verification.json` 검사 보고서 작성.

모델은 `src/model.mjs`와 `src/sculpt.mjs`에서 생성하므로 브라우저와 GLB의 기하 구조가 동일합니다. Three.js 0.180.0은 MIT, Rapier 0.21.0은 Apache-2.0 라이선스이며 원문은 해당 `node_modules` 패키지에 있습니다.

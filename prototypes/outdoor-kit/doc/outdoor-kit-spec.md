# 야외 모델 팩 — 2차 보완 — 2026-10-22

사용자 요청: 시나리오 Stage 2를 건물 밖으로 고려하고 야외 모드에 쓸 오브젝트/배경을 별도 폴더에서 선행 제작한다. 현재 게임 저장소와 다른 AI 작업을 변경하지 않는다. 사용자가 선택한 가림 표현은 **가리는 나뭇잎·지붕 일부를 옅은 형태로 남김**이다.

## 범위와 완료 기준

- GLB 32종, 재생성 가능한 Blender 도구와 조형 원본, 이미지·검색·분류가 있는 로컬 HTML 목록.
- 현재 게임 카메라 55도/-30도에 대응하는 쿼터뷰. 미터 단위, GLB +Y 위, 바닥 중심 피벗. 조명/시간대 색을 모델에 굽지 않는다.
- `Keep`은 줄기·하부·바닥과 낮은 풀/부속. `Occlude_*`는 수관 구역·지붕·상부 벽. 가림은 인스턴스/부위별로 제어한다. 불투명 GLB 원본은 유지한다.
- 별도 Godot 검수 프로젝트에서 원본 불러오기, 부위별 옅은 디더 형태, 낮/석양/밤, 젖음/적설 재질 샘플을 렌더한다. 날씨 게임 시스템이나 자동 가림 감지는 구현하지 않는다.
- 충돌/이동 차단은 모델의 외형과 분리하여 manifest에 추천 프록시를 기록한다. 수관이 이동을 막지 않는다. **추천값이며 게임에 적용된 물리가 아니다.**
- Stage 2 구성과 생존/난전 맵 변경, 차량 탑승·운전, AI/멀티/실제 날씨는 후속. 차량을 위한 통로 폭은 레벨 단계에서 실제 차체·회전반경으로 결정한다.

## 선택한 제작 방식

독립 GLB + 부위 명명 + manifest + 검수 프로젝트를 사용한다. 장점은 기존 맵·C#에 의존하지 않고 복사할 수 있다는 것. 통짜 메시 방식은 일부 가림 제어가 어렵고, 지금 게임의 맵 코드를 함께 수정하는 방식은 병행 작업을 방해하므로 선택하지 않았다.

소품의 크기/팔레트/폴리곤은 아트 검수 제안이다. Stage 2 야외 방향과 가림 선호는 사용자 요청이며, 최종 레벨·모드 구성/최종 아트 품질 승인으로 확대 해석하지 않는다.

## 검수

GLB의 구조·유효 정점·외부 의존성·역할·피벗·삼각형 예산을 자동 확인하고, Godot에서 32개를 모두 로드한다. HTML 이미지/링크와 실제 모델 렌더를 확인한다. 게임 통합/2PC/호드 성능은 이 독립 팩의 통과 조건이 아니다.

# 야외 모델 팩 검증·제약 — 2026-10-22

원 게임의 이슈 목록을 덮어쓰지 않는 독립 기록이다. I-80(나무 수관 가림)·I-79(다른 시나리오 맵 연결)·성능/멀티 제약은 검토 후 유지하며 이번 제작으로 해결됐다고 주장하지 않는다.

## 제작 중 확인한 문제

| ID | 증상/확인된 원인 | 해결/재발 방지 | 상태 |
|---|---|---|---|
| OUT-I1 | 반복 제작한 작은 나무/열린 컨테이너의 가림 상태가 적용되지 않음. Blender 숫자 접미사 뒤 `_Mesh`가 이름 정리 과정에서 사라지고 검수기가 메시 이름으로 부모 부위 키를 덮어씀. 작은 나무 원본/가림 PNG가 동일한 것을 리뷰에서 확인 | 메시를 정규 부위명+`_Mesh`로 생성하고 `MeshInstance3D`는 의미 역할 노드에서 제외. GLB 이름 검사와 인스턴스별 가림/복원 검사, 이미지 차이 검사로 재발 방지 | 해결(독립 팩). 재생성·28 GLB/48표면/11비교 검사 및 재검토 통과 |

제품 버그로 새 이력을 만들지 않은 제작/검수 준비 문제:

- 첫 구조 검사는 모델 생성 전 manifest 없음으로 실패했다(예상한 실패).
- 첫 Godot 가져오기가 원본 `.blend`까지 가져오려다 로컬 Blender 경로 설정 오류. `source/.gdignore`로 엔진 입력을 GLB로 제한했다. 기존 게임/편집기 개인 설정은 건드리지 않았다.
- 검수 스크립트 Variant 추론 오류를 명시적 bool로 수정. `_initialize`에서 트리 진입 전 global transform을 읽던 검수 준비 오류는 deferred 실행으로 수정. 이후 실제 정점으로 크기/바닥 피벗 검사.
- 창고 앞 하부 벽이 출입구를 가로지르던 조형을 문 양옆으로 나눴다. Blender 기본 브러시 재질 참조 경고는 원본에 사용하지 않는 기본 재질을 제거하도록 수정했다.
- Blender 5.2의 `Material.use_nodes`는 6.0 제거 예정 경고를 출력한다. 생성 실패와 구분한다. 6.0은 검증하지 않았다.
- 복사 거부 검사의 PowerShell UTF-8 오류문을 Python이 CP949로 읽으면서 검사 로그에 UnicodeDecodeError가 발생했다. subprocess 디코딩을 UTF-8로 명시한 뒤 동일 복사/거부 검사를 경고 없이 다시 통과했다. 실제 게임 파일은 대상이 아니었다.

## 남은 제약

- 현재 게임에 미적용. 독립 GLB·도감·검수 샘플이며 자동 가림 감지/충돌/길찾기/총알 판정/네트워크 코드가 없다.
- `fade`는 즉시 토글한다. 전환시간/히스테리시스, 겹친 수목 다수의 점무늬 체감, 카메라 확대와 실제 캐릭터/공격 가독성은 후속 검수.
- 원형 그림자 유지. 적 시야 C-23은 유지할 통합 계약이며 이 팩으로 검사/변경되지 않았다.
- 날씨는 재질/조명 샘플. 지붕 아래 적설 차폐/누적/눈비 입자/물리 파도/바람/일몰 계산 미구현. 별도 UV 아틀라스·LOD/HLOD·MultiMesh 없음.
- 모델 1개당 16,000삼각형 이하는 제작 검사 예산일 뿐 호드/6인/저사양 성능 보장이 아니다. 컨테이너는 약 11,000삼각형이며 부위/재질별 드로콜도 통합 시 측정한다.
- 원 게임 Integration/MapCheck/VisionTierCheck는 실행하지 않았다. 게임 코드에 변경이 없는 독립 폴더 검수를 게임 통합 검증으로 대체하지 않는다.

## 2차 조형 작업 — 2026-10-22

사용자의 잎 겹침/바위 디테일 피드백은 제품 버그로 새 ID를 발급하지 않고 조형 개선으로 반영했다. OUT-I1의 역할 이름/인스턴스 격리 검사를 나무 5종과 열린 컨테이너로 확장했다.

- 생성 도구의 헬퍼 변수 `b`가 기존 소품 오브젝트 변수와 충돌해 하천 생성이 중단됨. 전용 `nature_api` 이름으로 분리한 뒤 재생성했다.
- 하천 굽이의 연결점이 Blender 전역 이름 중복으로 접미사를 얻음. 실제 Godot 연결점 검사에서 실패를 확인하고, 내보내기 시 `Connection_*`도 이름 정규화 대상에 포함했다. 연결점 위치와 4개 끝의 실제 정점 단면을 비교한다.
- 첫 렌더의 규칙적인 물 반짝임을 불규칙 노이즈로 바꾸고, 이끼 면의 개별 법선 오프셋이 만든 가는 틈을 공통 수직 오프셋으로 줄였다. 둑/잔디 중복 면도 제거했다.
- 물가의 단면 연결은 제공하나 하천 끝 막음/호수 연결, 주변 지형 통합, 물리 수심/유속/충돌은 별도 작업이다. 물은 실제 투명/굴절이 아닌 불투명 색상 모델이다.
- 나무는 디테일 증가로 약 8.7천~1.2만 삼각형이다. 1개당 1.6만 예산 확인은 실행 성능 보장이 아니며, 실제 숲 밀도에 따른 LOD/MultiMesh 검토는 후속이다.
